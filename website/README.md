### 三、首页与详情如何做到专业

首页从上到下按以下顺序组织：

1. **品牌首屏：** 保留深蓝、校园视觉与现有主张；控制说明文字，清楚区分预约与浏览两个动作。
2. **双产品入口：** 学生管理与高校人事各自说明服务对象、业务范围、详情入口。
3. **典型业务场景：** 精选三至四条可说明清楚的流程。页面标题写客户办什么事，截图数量放到展厅中作为辅助信息。
4. **产品体验：** 选少量有代表性的界面，可放大、切换角色；完整图片进入独立展厅，减少首页重复铺图。
5. **实施与信任：** 清楚交代服务过程、部署选择、数据衔接和公司信息。有证据的资质再展示。
6. **新闻与更新：** 只呈现已发布内容；没有文章时不摆放假新闻，暂时收起推荐区。
7. **预约与页脚：** 单一清楚的预约动作，以及电话、公司主体、备案、隐私与系统登录入口。

统一详情模板为：“产品定位 → 学校的问题 → 一条典型流程 → 关键能力 → 各角色怎么用 → 代表界面 → 实施边界与常见问题 → 预约”。能力清单、完整业务地图保留在深入阅读层，不把所有截图、规则和内部技术说明堆在首屏。

文字调整示例：“四大系统，各 10 个 PC 页面”改为“从教学安排到学生服务，查看关键业务如何办理”；“当前素材包已提供……真实证据”这类内部说明改为客户能理解的功能或素材说明。未核验能力不能写成已经交付，原型图、演示数据、真实产品界面须分别标注。

视觉上延续深蓝品牌区和浅色阅读区，统一标志、导航、正文宽度、标题层级、按钮和页脚；控制装饰文字与动画，中文为主。保留校园导览作为可选体验，正文和联系方式不等待导览或大图加载才能出现。375、390、430 像素手机宽度与桌面均要验证。截图审核不能代替完整无障碍验证，键盘焦点、弹窗返回、图像替代文字和实际颜色对比度仍需测试。
