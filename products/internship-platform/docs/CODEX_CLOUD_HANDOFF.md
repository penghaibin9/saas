## 云端开始时

1. 核验当前分支和提交，确认包含本说明及 `mobile/src/styles/internship-flow.css`；不要从主分支或旧工作区继续。
2. 使用锁文件安装依赖，沿用Vue及uni-app。产品各端是 `admin-web/`、`student-web/`、`enterprise-web/`、`mobile/`，共用 `backend/`。
3. 从仓库根运行 `npm --prefix products/internship-platform/mobile test`。构建入口为移动工程内 `npm run build:h5`、`npm run build:mp-weixin`，必须按当前环境明确设置 `VITE_API_BASE_URL`；不得使用本机回环地址当成正式微信可访问地址。
4. 后续优先补正常角色的新单据真实业务闭环及对应权限、刷新回读；使用独立测试数据库，禁止直接写终态或放宽权限。已有归档记录保留原终态。
5. 未获授权不合并主分支、不发布生产、不删除真实数据。不把旧提交的验证结果当成新提交已验。

本地详细证据和安装包仍由原电脑保管；本文中的通过结果为已记录的本机检查，不声称云端已启动、已连接数据库或已部署。
