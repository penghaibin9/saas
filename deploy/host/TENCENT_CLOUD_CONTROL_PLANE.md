# 腾讯云 CVM 控制面安全验收清单

> 本清单是**人工/控制台验收**，不会调用腾讯云 API，也不会自动修改安全组、CVM、CAM、CWP、快照或生产数据。
>
> 目的：补齐 Linux 主机之外的云控制面。主机脚本全绿不能证明腾讯云安全组、实例角色或主机安全服务配置正确。

## 1. 安全组

修改前先导出/备份当前安全组规则，保留可回退证据。

生产公网入站只允许：

- SSH 实际端口：仅管理员固定公网 CIDR；
- 80/tcp：仅 HTTP→HTTPS / ACME；
- 443/tcp：正式 HTTPS。

必须确认不存在互联网来源的：

- 3306 MySQL；
- 6379 Redis；
- 3310 ClamAV；
- 2375/2376 Docker API；
- 8000 FastAPI upstream；
- Vite / Node / 临时调试端口。

验收证据：安全组导出或截图 + 实例关联关系 + 操作时间。

## 2. CVM 公网暴露面

逐台确认：

- 实例当前公网 IP / EIP 是否确实需要；
- 未使用的 EIP 已解绑/回收；
- 不存在额外公网网卡或临时测试实例；
- 生产实例没有绑定“全端口开放”类安全组；
- 同一实例不要叠加过多安全组导致规则冲突或误放行。

## 3. CWP / 主机安全

生产 CVM 必须在腾讯云主机安全/CWP或等价能力中显示在线，并至少确认：

- 暴力破解/密码破解防护；
- 异常登录告警；
- 恶意文件/木马检测；
- 高危漏洞检测；
- 安全基线检测；
- 告警联系人/通知链路可用。

不得把“安装了 agent”当成验收通过；必须确认控制台最近心跳、风险状态和告警链路。

## 4. CAM / 实例角色 / 元数据凭证

腾讯云 CVM 元数据服务在实例绑定 CAM 角色时可以提供该角色的临时凭证。因此：

- 不需要实例角色的 CVM 不绑定角色；
- 必须绑定时，只授予业务真实需要的最小权限；
- 禁止给业务主机绑定 AdministratorAccess 等宽权限角色；
- 禁止在仓库、镜像、systemd unit、shell history、日志中保存长期 SecretId/SecretKey；
- 应用存在 SSRF/任意 URL 访问能力时，将“访问实例元数据后取得临时凭证”纳入威胁模型和测试；
- 发现疑似主机入侵时，同时评估并轮换/撤销相关 CAM 权限和临时凭证来源，而不是只改 Linux 密码。

验收证据：实例当前角色名称、对应策略清单、最小权限复核结果。不要在验收文档粘贴任何真实临时密钥。

## 5. 云账号与运维身份

生产控制面至少要求：

- 日常运维使用独立子账号，不共享主账号；
- 高权限账号开启多因素认证；
- 不把云 API 长期密钥放在生产服务器；
- 离职/人员变更及时回收 CAM、SSH、公钥和控制台权限；
- 变更安全组、快照、CVM、密钥等高风险操作有可追溯人员和时间记录。

## 6. 快照、备份与恢复

- 主机加固前有可回退快照；
- 数据库/文件备份使用仓库已有备份体系，不用 CVM 快照替代数据库级备份；
- 快照权限、备份桶/COS 权限保持最小化；
- 至少一次隔离恢复演练成功后才允许把“有备份”标记为通过。

## 7. 正式 TLS 与域名

确认：

- 域名解析只指向当前正式入口；
- 80 仅用于跳转/ACME；
- 443 使用完整正式证书链；
- 自动续期存在且完成 dry-run/等价验证；
- 旧证书、旧域名、旧公网入口不再留下旁路。

## 8. 最终控制面放行条件

只有以下证据同时存在，腾讯云控制面才标记 PASS：

1. 安全组导出/截图已归档；
2. SSH 仅管理员来源 CIDR；
3. 仅 80/443 对公网开放；
4. CWP/主机安全在线且告警链路可用；
5. CVM 实例角色完成最小权限复核；
6. 无静态云密钥落盘/入库；
7. 快照回退点和离机备份均存在；
8. 隔离恢复演练成功；
9. 正式 TLS 与续期验收完成；
10. `check-host-security.py`、`check-docker-port-exposure.py`、`check-dockerd-launch-flags.py` 三份现场报告均 `passed=true`。

本清单通过前，PR/CI 全绿也不能宣称“生产服务器安全上线完成”。
