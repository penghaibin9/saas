# Handoff:学生 PC 门户(Student PC Portal)

## Overview
这是「职校学生全生命周期 SaaS 平台」的学生侧 Web 工作台设计——承接小程序做不了的重活(大文件上传、长文档、大表格、打印/导出),与老师 PC 管理端物理隔离。设计覆盖登录、门户外壳(导航/主题/套餐门禁)、首页工作台、我的档案、毕业设计工作台、消息通知、家长只读端,以及教务学业/岗位实习/就业服务/学工事务/迎新报到/办事大厅 6 个业务模块共 33 个三级页面。

**本设计已严格依据仓库内以下文档产出,这些文档是后端契约与信息架构的权威来源,实现时必须以它们为准、本 README 仅补充前端可视化与交互细节:**

- `student-portal/docs/01-学生PC门户-生产级施工包(总纲与5期规划).md` —— 架构、API 命名空间(读 `/mobile/*`、PC 重活写 `/portal/*`)、模块契约、数据/权限/审计原则、5 期路线图
- `student-portal/docs/02-学生PC门户-详细菜单规划.md` —— **唯一菜单事实源**:每个三级页面的页面形态、学生动作、对接老师端模块、后端现状(🟢已有/🟡部分/🔴新增)
- `student-portal/docs/00-学生PC门户-外部对标证据包.md` —— 能力范围对标依据
- `docs/04-UI与全端交互/design/学生PC门户-页面级设计方案.md` —— 产品定位、模块插件化(module contract)、租户套餐开关、统一文件/消息/时间线中心
- `docs/04-UI与全端交互/ui/fable5-pc-final/archive/uploads/平台设计/uploads/00-全端UI视觉与交互设计规范 V2.1 最终冻结版.md` —— 本设计遵循的视觉与交互冻结规范(色彩、字体、组件、退回/驳回交互、异常状态)

## About the Design Files
本包内的 `*.dc.html` 文件是**设计参考原型**(Claude 的 Design Component 格式,内联样式 + 一个运行时脚本),**不是可直接复制的生产代码**。它们的作用是把交互、布局、状态和文案钉死下来,方便你在真实代码库里照着 1:1 还原。

**关键:仓库里已经有真实前端工程 `student-portal/`(Vue 3 + Vite + Pinia + Vue Router + Element 风格自定义组件),而且已经有可运行骨架**(`src/layouts/PortalLayout.vue`、`src/stores/{session,portalConfig,ui}.js`、`src/services/{request,portalApi}.js`、`src/platform/{moduleRegistry,menuRegistry,routeRegistry,permissionGuard,featureFlags}.js`、`src/components/{StatusTag,DataPanel,FileDropzone,ProgressTimeline,SensitiveText,TodoPanel,StateBlock,ModuleCard}.vue`)。

**不要新起技术栈或新建工程。** 请在 `student-portal/` 现有骨架里,把本设计对应的页面实现为 Vue 组件,复用现有 `platform/*` 注册机制、`services/request.js` 的统一请求层、和已存在的公共组件(必要时增强这些组件,而不是重造)。`src/views/template/ModuleTemplateView.vue` 目前是通用占位页——本设计里教务学业/岗位实习/就业服务/学工事务/迎新报到 5 个模块应该拆成各自的真实页面组件(建议每模块一个 `src/modules/<key>/` 目录,内含 `views/*.vue` + `api.js`,参照施工包第 3 章 module contract)。

## Fidelity
**Hi-fi。** 颜色、字号、间距、圆角、状态色、交互动效均为终稿,可直接照抄数值;文案是最终中文文案(可结合真实数据源替换,但语气/长度请保持一致)。唯一的例外是登录页左侧"校园实景图"用的是可拖拽占位图(`<image-slot>`),需要替换成学校真实照片。

## 整体架构(所有页面共享)

### 文件 = 路由分组
设计用**多文件**模拟多路由(每个 `.dc.html` = 一组同前缀的路由,内部用 tab 切换三级页面):

| 文件 | 对应真实路由前缀(建议) | 说明 |
|---|---|---|
| `学生PC门户.dc.html` | `/portal/home`、`/portal/profile`、`/portal/graduation`、`/portal/messages` | 门户外壳 + 首页工作台 + 我的档案 + 毕业设计 + 消息通知,四个模块内嵌在同一个 shell 里,用 `#home`/`#profile`/`#graduation`/`#messages` hash 切换 |
| `教务学业.dc.html` | `/portal/academic/*` | 8 个三级页(见下) |
| `岗位实习.dc.html` | `/portal/internship/*` | 6 个三级页 |
| `就业服务.dc.html` | `/portal/employment/*` | 4 个三级页 |
| `学工事务.dc.html` | `/portal/affairs/*` | 7 个三级页 |
| `迎新报到.dc.html` | `/portal/orientation/*` | 4 个三级页(含离校) |
| `办事大厅.dc.html` | `/portal/service-hall` | 聚合入口,不含独立后端 |
| `登录.dc.html` | `/login` | 独立不带壳的登录页 |
| `家长端.dc.html` | 独立子应用 `/guardian` 或子域名 | 家长只读端,和学生门户完全隔离的一套壳 |

真实实现中,这应该变成 Vue Router 的真实路由树(每个"文件"变成一个父路由 + children,每个 tab 变成一个子路由 `path`),而不是文件级 hash——hash 只是设计原型里模拟"深链接"的手段。

### 门户外壳(除登录页/家长端外全部共用)
- **左侧栏 248px**:品牌区(校徽 36-38px 圆角方块渐变 + 校名 + "学生服务门户") + 10 项一级导航(图标 19px 线性描边 + 文字,当前项高亮 `background:var(--pri-50);color:var(--pri);font-weight:600`,未开通模块置灰锁定见下)+ 底部"退出"。
- **顶栏 62px**:页面标题(20px/600) + 平台副标题 · 搜索框(230px,占位不接后端搜索) · "数据范围·本人" 药丸(蓝底蓝字,固定文案,来自 V2.1 规范"数据范围仅本人须常驻提示") · 消息铃(未读数红点) · 头像 + 姓名 + 身份文字。
- **内容区**:`max-width:1280px` 居中,`padding:24-32px`,卡片式,圆角 14-16px,白底,`border:1px solid #EEF0F3`,`box-shadow:0 1px 2px rgba(16,24,40,.04)`。
- **水印**:内容区铺一层极低透明度(≈0.03)、旋转 -24°、平铺的 SVG 文字水印,内容为"{{学生姓名}} · 数据范围:本人",对应合规要求"仅本人数据 + 水印"。可通过 tweak 开关关闭。

### 套餐 / 模块授权门禁(P1 阻断项,已在设计里实现)
每个文件都有 `servicePackage` 参数(四选一:全生命周期版 / 学业+实习包 / 毕设+就业包 / 只读门户版),对应后端 `featureFlags` + `moduleRegistry`:
- 未包含在当前套餐的模块:左侧导航项**置灰 `#C6CCD6` + 小锁图标**,点击弹 toast "该模块未开通,请联系学校管理员",不跳转。
- **直接访问**未开通模块的文件/路由(例如收藏夹直达):整页替换为"该模块未开通"卡片(灰底锁形图标 + 说明文案 + 返回首页按钮),不显示任何 tab 或数据——这是 `NotEnabledView` 的等价实现,请求相同的产品行为。
- 真实实现:这个判断应该在**路由守卫**(`platform/permissionGuard.js` + `routeRegistry.js`)里做一次,而不是每个页面各写一遍。

### 深链接与状态保持
- 每个文件内部的 tab/view 切换会同步写 `location.hash`(如 `#courseSelect`),并在 `componentDidMount` 读取 hash 恢复——对应"刷新子路由不 404"的要求。真实实现直接用 Vue Router 的具名路由 + `history` 模式即可,不需要 hash hack。
- 首页待办/快捷入口点击后跳转到目标模块文件的默认 tab(真实实现改成 `router.push({name:'academic-course-select'})` 这类具名跳转,可选地把"跳转后直接定位到具体三级页"也做上,这是当前设计已验证可行的交互期望)。

## 交互与状态清单
- **四态**:所有数据区块理论上需要 loading/empty/error/只读四态(当前设计只画了正常态 + 部分空态如"暂无违纪记录""近期无异常",真实实现需要补上骨架屏和错误重试态,复用现有 `StateBlock.vue`)。
- **二次确认**:设计里"提交""删除类"操作直接 toast 成功,真实实现里发布/驳回/退回/归档/导出敏感数据等高风险操作需要接 `AppConfirmDialog` 二次确认(V2.1 规范 §13.4)。
- **课程冲突校验**(教务学业·选课中心):选课时按时间段字符串比对已选课程,冲突则整行提示 + 阻止勾选,真实实现需要后端接口返回真实冲突判定,不能纯前端比对。
- **退回/整改**统一样式:红色系不可关闭提示条(退回人+时间+原因+截止)+ 主按钮"重新提交",毕业设计页是范式,其余模块的退回态请复用同一视觉,不要每个模块各画一套(V2.1 规范强制要求)。
- **脱敏 + 授权查看留痕**:敏感字段默认掩码,点击"眼睛/授权查看"图标切换明文,同时应写审计日志(设计里只是本地 toast 模拟)。

## Design Tokens 汇总
- **字体**:`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", Arial, sans-serif`;数字统一 `font-variant-numeric: tabular-nums`。
- **字号**:页面大标题 20-22px/600,卡片标题 15-16px/600,正文 13.5-14px,辅助文字 12-12.5px,指标数字 22-32px/700。
- **间距**:4px 栅格,页面外边距 24-32px,卡片内边距 18-24px,区块间距 14-18px。
- **圆角**:标签/按钮 6-9px,卡片 14-16px,大卡片/弹层 16-20px。
- **阴影**:卡片 `0 1px 2px rgba(16,24,40,.04)`;强调卡片/弹层 `0 20px 60px -20px rgba(16,24,40,.18)`。
- **中性色**:主文字 `#1D2129`,次文字 `#4E5969`,弱文字 `#86909C`/`#98A0AE`,边框 `#EEF0F3`/`#E5E8EE`,背景 `#F5F7FA`(随主题变为 `var(--bg)`)。

## Assets
- 所有图标均为内联 SVG,20px 线性描边(`stroke-width:1.6-1.9`,`stroke-linecap/linejoin:round`),来自项目自绘的简单几何图形(书本/学位帽/公文包/建筑/盾牌/铃铛等),无版权依赖,可直接照抄 path 数值或用同风格图标库(如 Lucide/Tabler Icons)替换。
- 登录页校园照片是占位(`image-slot.js` 组件),需替换为学校真实实景图。
- 二维码是装饰性占位图案,不可扫描,对接微信开放平台后替换为真实二维码。
- 未使用任何第三方图片/字体资源。
