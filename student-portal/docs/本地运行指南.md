# 学生 PC 门户 · 本地运行指南（一个人也能跑起来）

> 目的：把这条分支拉到你自己的电脑，本地把「后端接口 + 学生门户前端」跑起来，用于对接/开发前端。
> 已实测：下面的「极简路径」用 SQLite（一个文件当数据库，**不用装 MySQL**），登录 `student/123456` →
> 门户接口全部返回真实数据，验证通过。SQLite 仅供个人开发/联调，**不是 MySQL 正式验收**。

---

## ⭐ 极简路径（推荐，只需 Python + Node，不用装 MySQL）

### 0. 装两样东西（一次性）
- **Python 3.12**：https://www.python.org/downloads/
- **Node.js 20**：https://nodejs.org/

### 1. 把代码拉到本地
在你电脑的项目文件夹里：
```bash
git fetch origin claude/student-portal-folder-fht7ae
git checkout claude/student-portal-folder-fht7ae
```

### 2. 起后端（3 条命令）
```bash
cd backend
pip install -r requirements.txt
python scripts/seed_dev_student.py          # 一键建库(SQLite) + 造演示学生账号
```
`seed_dev_student.py` 会生成 `backend/data/dev.db` 并造好账号 **student / 123456（学校编码 demo-school）**。
然后启动：
```bash
# macOS / Linux
DB_ENABLED=true DATABASE_URL="sqlite+pysqlite:///./data/dev.db" MOCK_LOGIN_ENABLED=true uvicorn app.main:app --reload --port 8000

# Windows PowerShell
$env:DB_ENABLED="true"; $env:DATABASE_URL="sqlite+pysqlite:///./data/dev.db"; $env:MOCK_LOGIN_ENABLED="true"; uvicorn app.main:app --reload --port 8000
```
验证：浏览器打开 **http://localhost:8000/docs** —— 看到全部接口（含 `/portal/*`）。

### 3. 起前端（新开一个终端）
```bash
cd student-portal
npm install
npm run dev
```
打开 **http://localhost:5173/portal/** → 用 **student / 123456** 登录（学校编码填 `demo-school`）。
> 前端默认已连 `http://localhost:8000`（见 `src/services/request.js`）；如需改地址，`cp .env.example .env` 后设 `VITE_API_BASE_URL`。

### 4. 前端每个页面调哪个接口
对照 **`student-portal/docs/02-学生PC门户-详细菜单规划.md`**：每个菜单都标了页面形态、对接模块、是 `/mobile/*`（查看类）还是 `/portal/*`（PC 重活类）。

## 正式路径（要 MySQL 级验收时再用）
把极简路径第 2 步换成 MySQL：
1. 装 MySQL 8，建库 `CREATE DATABASE student_lifecycle_dev DEFAULT CHARSET utf8mb4;`
2. `cd backend && cp .env.example .env`，改 `.env`：
   ```
   DB_ENABLED=true
   DATABASE_URL=mysql+pymysql://用户名:密码@127.0.0.1:3306/student_lifecycle_dev?charset=utf8mb4
   MOCK_LOGIN_ENABLED=true
   ```
3. `pip install cryptography`（MySQL8 认证需要）→ `alembic upgrade head`（建表）→ 再造账号/数据。
4. `uvicorn app.main:app --reload --port 8000`。

## 常见卡点
| 现象 | 解决 |
|---|---|
| `No module named 'app'` | 一定要在 `backend/` 目录下运行 uvicorn |
| 写接口返回「演示模式不支持」 | 你没设 `DB_ENABLED=true`；按上面命令带上环境变量 |
| 前端调接口跨域报错 | 后端 `.env` 的 `CORS_ORIGINS` 需含 `http://localhost:5173`（默认已含） |
| 登录失败 | 账号 `student`、密码 `123456`、学校编码 `demo-school`；确认跑过 `seed_dev_student.py` |
| 想要更多演示数据（成绩/实习等） | 让 AI 扩充 `seed_dev_student.py`，或参考 `backend/scripts/seed_demo_data.py` |

> 卡住了直接把报错贴给 AI，一步步排。
