# 微信小程序部署上线手册（新手版）

> 适用项目：毕业设计及岗位实习管理平台  
> 推荐方案：一台 Linux 云服务器 + 一个已备案域名 + HTTPS + Docker  
> 原则：先让网页和 API 正常，再配置小程序，最后提交微信审核。

## 一、先认识这套系统

系统分为三部分：

1. `internship-backend/`：后端和数据库接口，必须运行在服务器上。
2. `web/`：电脑管理端，由服务器提供访问。
3. `miniprogram/`：微信小程序代码，通过 HTTPS 调用服务器接口。

小程序不是独立服务器。只上传小程序代码、没有部署后端和数据库，登录、打卡、周报等功能都不能使用。

## 二、上线前需要准备

- [ ] 已认证的微信小程序账号和 AppID
- [ ] 一台中国大陆 Linux 云服务器（建议 Ubuntu 22.04/24.04，最低 2 核 4 GB）
- [ ] 一个域名；服务器在中国大陆时通常还要完成 ICP 备案
- [ ] 域名的 HTTPS 证书（需要 `fullchain.pem` 和 `privkey.pem`）
- [ ] 能登录服务器的工具（云厂商网页终端也可以）
- [ ] 微信开发者工具稳定版

建议先使用一个域名同时提供网页和接口，例如：

```text
管理端：https://school.example.com/
小程序接口：https://school.example.com/api
```

下面把 `school.example.com` 当作示例。实际操作时全部换成你自己的域名。

## 三、注册并配置小程序账号

1. 打开[微信公众平台](https://mp.weixin.qq.com/)，注册“小程序”账号。
2. 完成主体认证，记录“开发管理 → 开发设置”里的 AppID。
3. 根据学校实际业务选择服务类目。涉及教育类目时，以微信后台显示的资质要求为准。
4. 暂时不要提交审核，先完成服务器部署和真机测试。

注意：AppSecret 只能保存在后端服务器的 `.env` 文件中，绝不能写进小程序代码或发到群里。

## 四、部署服务器（推荐 Docker）

### 4.1 登录服务器并安装 Docker

在服务器终端依次执行：

```bash
curl -fsSL https://get.docker.com | sh
docker --version
docker compose version
```

如果云厂商安全组拦截端口，请放行 `22`、`80`、`443`。不要把 MySQL 的 `3306` 端口开放到公网。

### 4.2 上传代码

可用 Git 拉取，也可以把整个项目压缩后上传并解压。进入后端目录：

```bash
cd /你的项目路径/毕业设计/internship-backend
cp .env.example .env
```

### 4.3 修改生产配置

打开 `.env`，至少修改这些项目：

```dotenv
NODE_ENV=production
DB_HOST=db
DB_USER=root
DB_PASSWORD=换成一个强数据库密码
DB_NAME=internship_management
JWT_SECRET=换成至少32位的随机字符串
APP_PUBLIC_URL=https://school.example.com
CORS_ORIGIN=https://school.example.com
WX_MP_APPID=你的小程序AppID
WX_MP_SECRET=你的小程序AppSecret
```

生成 JWT 随机字符串：

```bash
openssl rand -hex 48
```

`WX_TEMPLATE_NOTIFY` 是订阅消息模板 ID，不使用订阅消息时可以暂时留空。

### 4.4 第一次启动并初始化数据库

```bash
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml exec app npm run migrate:all
docker compose -f deploy/docker-compose.yml exec app npm run seed
```

检查容器：

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs --tail=100 app
```

浏览器访问 `http://服务器公网IP/`。能看到登录页，说明 HTTP 部署成功。

### 4.5 配置域名解析

在域名服务商控制台新增一条 A 记录：

```text
主机记录：school（按你的域名决定）
记录值：服务器公网 IP
```

等待解析生效后，访问 `http://school.example.com/` 验证。

### 4.6 开启 HTTPS

1. 向云厂商或证书机构申请证书。
2. 把证书文件放到服务器的：

```text
internship-backend/deploy/certs/fullchain.pem
internship-backend/deploy/certs/privkey.pem
```

3. 复制 HTTPS 配置并替换域名：

```bash
cp deploy/nginx.https.conf.example deploy/nginx.https.conf
nano deploy/nginx.https.conf
```

把文件中的所有 `example.com` 改成真实域名，然后启动 HTTPS：

```bash
docker compose \
  -f deploy/docker-compose.yml \
  -f deploy/docker-compose.https.yml \
  up -d
```

验证下面两个地址：

```text
https://school.example.com/
https://school.example.com/api/health
```

必须满足：浏览器没有证书警告，HTTP 会自动跳到 HTTPS，API 健康检查能返回成功结果。

## 五、配置小程序代码

### 5.1 填写正式 AppID

用文本编辑器打开 `miniprogram/project.config.json`，将：

```json
"appid": "touristappid"
```

换成你的真实 AppID。不要填写 AppSecret。

### 5.2 填写服务器地址

打开 `miniprogram/config.js`，修改：

```js
schoolName: '你的学校名称',
apiBase: {
  develop: 'http://localhost:3000/api',
  trial: 'https://school.example.com/api',
  release: 'https://school.example.com/api'
}
```

- `develop`：开发者工具使用；后端在本机时可保留 localhost。
- `trial`：体验版和真机测试使用，必须是 HTTPS。
- `release`：正式版使用，必须是 HTTPS。

代码会阻止体验版/正式版连接 HTTP 或示例域名，避免误发布。

### 5.3 导入微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择 `毕业设计/miniprogram/`，不要选择整个毕业设计目录。
3. 填写真实 AppID，点击“导入”。
4. 本地联调时可在“详情 → 本地设置”临时勾选“不校验合法域名”。正式上传前不能依赖这个开关。

## 六、配置微信服务器域名

登录微信公众平台，在“开发管理 → 开发设置 → 服务器域名”中配置：

| 配置项 | 填写内容 |
| --- | --- |
| request 合法域名 | `https://school.example.com` |
| uploadFile 合法域名 | `https://school.example.com` |
| downloadFile 合法域名 | `https://school.example.com` |

注意：只填写域名，不要填写 `/api`，不要使用 IP 地址，不要使用 HTTP，也不要填写 localhost。

## 七、隐私保护和接口权限

本项目会使用定位打卡、拍照、选择文件、上传/下载材料。提交审核前：

1. 在微信公众平台完善“小程序用户隐私保护指引”。
2. 如实声明处理的信息，包括位置信息、照片或视频、用户选择的文件，以及账号资料。
3. 说明用途，例如“用于学生实习签到及佐证材料提交”。
4. 检查“开发管理 → 接口设置”中定位相关接口是否可用。
5. `app.json` 已声明 `getLocation` 和位置授权用途，不要删除。

隐私声明必须和实际功能一致，写少了容易审核被拒，写多了也不合适。

## 八、真机测试清单

在开发者工具点击“预览”，用手机微信扫码。至少完整测试：

- [ ] 学生账号登录、退出、首次改密码
- [ ] 首页数据和通知加载
- [ ] 获取定位、拍照打卡、上下班时段
- [ ] 新建周报、选择文件、上传附件
- [ ] 请假、岗位申请、成果和报告提交
- [ ] 教师账号查看学生、进入待批阅并审批
- [ ] 附件下载和打开
- [ ] 断网、登录过期时有清楚提示
- [ ] iPhone 和 Android 各测试一台

开发者工具能用不代表手机一定能用。真机失败时，优先检查 HTTPS 证书和三类服务器合法域名。

## 九、上传、体验、审核和发布

1. 微信开发者工具右上角点击“上传”。
2. 版本号可从 `1.0.0` 开始，备注写本次功能。
3. 微信公众平台进入“管理 → 版本管理”，先选择为体验版。
4. 邀请老师或同学作为体验成员，完成一轮真实网络测试。
5. 填写隐私保护指引、服务类目、用户协议等审核材料。
6. 提交审核；如审核员需要账号，提供专用审核账号和清楚的操作路径。
7. 审核通过后点击“发布”。审核通过不会自动发布。

建议审核备注：

```text
本小程序用于学校毕业设计及岗位实习管理。
测试账号：review_student / 单独提供的密码
教师审核入口：首页 → 待批阅
定位用途：学生在实习单位进行签到，用户点击打卡后才获取位置。
```

不要在公开文档或代码仓库中保存真实审核密码。

## 十、日常维护

查看运行状态：

```bash
cd /你的项目路径/毕业设计/internship-backend
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f app
```

更新代码前先备份，再重建并执行迁移：

```bash
node scripts/backup-db.js
git pull
docker compose -f deploy/docker-compose.yml -f deploy/docker-compose.https.yml up -d --build
docker compose -f deploy/docker-compose.yml exec app npm run migrate:all
```

每次更新后重新做“真机测试清单”。HTTPS 证书到期前要续期，否则小程序会突然无法请求服务器。

## 十一、常见问题

| 现象 | 最常见原因 | 处理办法 |
| --- | --- | --- |
| 开发者工具能用，手机不能用 | 使用 localhost、HTTP 或未配置合法域名 | 改成公网 HTTPS，并配置三类合法域名 |
| 提示示例域名未替换 | `config.js` 仍是 example.com | 改成真实接口域名 |
| 登录一直失败 | 后端未启动、数据库密码错误 | 查看 app 容器日志，核对 `.env` |
| 上传成功但下载失败 | 漏配 downloadFile 域名 | 在微信后台补充 downloadFile 合法域名 |
| 定位接口不可用 | 未声明隐私用途或接口权限受限 | 完善隐私指引并检查接口设置 |
| HTTPS 有红色警告 | 证书过期、域名不匹配或证书链不完整 | 重新部署匹配域名的完整证书链 |
| 502 Bad Gateway | app 容器未启动 | 查看容器状态和后端日志 |
| 审核被拒 | 类目、资质、隐私说明或测试路径不清 | 按审核反馈修改，并提供专用测试账号 |

## 十二、正式上线前最后核对

- [ ] AppID、学校名称和正式 HTTPS API 地址已替换
- [ ] AppSecret 只存在服务器 `.env`，没有进入小程序代码
- [ ] `NODE_ENV=production`，JWT 和数据库均为强密码
- [ ] request、uploadFile、downloadFile 合法域名均已配置
- [ ] 隐私保护指引与定位、拍照、文件功能一致
- [ ] 初始管理员密码已修改，未导入演示数据
- [ ] 学生、教师两个角色均已真机测试
- [ ] 数据库和上传材料已设置异机备份
- [ ] HTTPS 证书已设置到期提醒
