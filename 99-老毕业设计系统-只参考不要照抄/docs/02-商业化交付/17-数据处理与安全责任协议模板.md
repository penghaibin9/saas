# 数据处理与安全责任协议模板

> 建议作为学校与系统实施/运维方合同附件。甲方为学校，乙方为系统实施或运维服务商。

## 1. 角色与边界

- 甲方决定教学管理目的、数据范围、账号权限、保管期限和对外提供规则。
- 乙方仅按甲方书面指令完成部署、维护、备份和故障处理，不得自行使用数据训练模型、营销或另作他用。
- 未经甲方书面同意，乙方不得转委托；经同意转委托的，保护义务不得降低。

## 2. 数据范围

以经甲方确认的《个人信息处理清单》为准。生产数据库、附件、备份、日志和导出文件均属于受保护数据。演示环境必须使用明确标注的合成数据，不复制真实学生信息。

## 3. 安全责任矩阵

| 事项 | 甲方 | 乙方 |
| --- | --- | --- |
| 业务合法性、告知同意、档案期限 | 主责 | 配合 |
| 账号审批和权限复核 | 主责 | 提供技术能力 |
| HTTPS、补丁、漏洞修复、日志 | 监督 | 主责 |
| 数据库与附件备份 | 确认策略、抽查 | 执行并报告 |
| 第三方接口和数据出境 | 审批 | 未获批不得启用 |
| 安全事件 | 决策与上报 | 立即处置并提供证据 |

## 4. 强制控制

1. 生产与演示环境隔离；生产环境不得存在 `demo_`、`smoke_`、`crud_` 测试账号。
2. 数据库不得直接暴露公网；运维采用实名账号、最小权限和操作留痕。
3. 传输使用 HTTPS；密码、密钥不得进入代码仓库或聊天群。
4. 下载和导出必须鉴权；敏感导出记录操作人、时间、条件和数量。
5. 备份加密、异机保存并按月恢复演练；恢复结果形成记录。
6. 测试、培训和截图优先使用标准合成演示数据。

## 5. 事件响应

乙方发现数据泄露、丢失、越权或攻击后应立即隔离风险并通知甲方，不得隐瞒。初报包含时间、范围、影响、已采取措施和联系人；后续提供根因、恢复、证据保全和改进报告。

## 6. 终止与销毁

合同终止后，乙方按甲方指定格式移交数据库、附件、配置和文档。甲方验收后，乙方在约定期限内删除持有副本并提交销毁确认；依法或合同要求保留的除外。
