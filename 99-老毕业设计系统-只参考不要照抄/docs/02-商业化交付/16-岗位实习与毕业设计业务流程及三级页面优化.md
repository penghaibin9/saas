# 岗位实习与毕业设计业务流程及三级页面优化

## 1. 当前问题诊断

1. 毕业设计原先把选题、任务书、指导、成果、互查、答辩和成绩放在同一个“全流程”分组，二级阶段不清楚。
2. 部分页面只告诉用户“有什么数据”，没有说明当前环节、前置条件、完成后的下一步和退回处理。
3. “待审核、待审批、待批阅、审核中”混用。它们底层可以保留不同状态码，但用户侧需要统一语义。
4. 实习申请包含教师、院校和企业三个环节，列表如果只显示“待审核”，无法判断卡在哪一方。
5. 风险、缺报、保险和催办分散，缺少“发现—分派—处置—复核—关闭”的统一闭环。
6. 毕设指导记录承担日常指导，但中期检查没有形成明确的阶段结果和整改入口。
7. PC 与移动端功能重复过多。移动端不应承担复杂配置、批量导入、统计和归档。
8. 低频功能与高频待办同等展示，教师和学生进入首页后仍需寻找今天要做的事情。

## 2. 优化后的三级菜单树

### 2.1 岗位实习

| 岗位实习 | 进行期 | 在岗监管、打卡记录、周报月报、请假管理、换岗终止、教师巡访 |

## 3. 角色完整流程

### 3.1 院校管理员

实习：创建批次和计划 → 审核企业/岗位 → 配置流程和材料要求 → 终审申请/换岗 → 查看全校过程与风险 → 发布考评 → 核验归档。

毕设：创建批次和节点 → 审核课题 → 开放选题 → 监控任务书和指导进度 → 布置互查 → 安排答辩 → 复核发布成绩 → 归档。

### 3.2 二级学院管理员

维护本院师生和专业 → 执行本院计划 → 审核本院业务 → 监控教师负荷和学生进度 → 处理本院风险 → 核验材料。所有查询必须限制在本学院。

### 3.3 指导教师

审核申请/协议 → 指导学生在岗过程 → 批阅周报、请假和报告 → 巡访并处理风险 → 完成鉴定和评分；申报课题 → 下达任务书 → 记录指导和中期检查 → 审查成果 → 互查/答辩评分 → 确认成绩。

### 3.4 学生

查看岗位 → 提交申请 → 签署协议 → 完成打卡、周报、请假和报告 → 查看考评；提交选题志愿 → 确认任务书 → 接受指导并整改 → 提交成果和查重 → 参加答辩 → 查看成绩。

### 3.5 企业导师

维护企业和岗位 → 确认录用 → 查看在岗学生 → 配合异常核实 → 填写企业评价与鉴定。企业导师不参与学校内部成绩发布和归档审批。

## 4. 页面调整清单

### 合并

- 企业审核与岗位管理保留独立数据页，但统一放入“准备期—企业岗位”业务入口。
- 打卡记录和过程监管在管理视角合并为“在岗监管”，详情中查看单个学生打卡时间线。
- 风险、缺报、保险和投诉在工作台汇总为风险摘要，具体处理仍进入对应三级页。
- 答辩安排和答辩评分归入“答辩成绩”，按角色显示不同操作。

### 拆分

- 选题管理拆成课题申报、选题轮次、学生志愿和匹配结果四个页签。
- 指导记录增加中期检查与整改跟踪，不把阶段结论埋在普通指导文本中。
- 成果页拆分提交版本、查重结果、教师审查和互查整改四个页签。
- 档案页拆分材料清单、缺失项、审核记录和归档结果。

### 删除或隐藏

- 删除无后续动作的假按钮和只展示空壳的入口。
- 移动端隐藏批次配置、流程配置、批量导入、复杂统计、归档锁定等低频管理能力。
- 省平台模块、入口、流程和销售话术全部隐藏。

### 新增

- 页面流程上下文：当前环节、前置条件、下一步、异常处理。
- 学生/课题详情时间线、材料清单、风险记录和操作日志。
- 中期检查结论：通过、限期整改、不通过。
- 风险责任人、整改期限、复核人和关闭原因。

## 6. 统一状态机

### 6.1 通用提交审核状态机

`草稿 → 待责任人审核 → 已通过 → 已完成/已归档`

异常分支：`待责任人审核 → 已退回 → 草稿/待修改 → 重新提交`。使用“退回”表示允许修改重交；只有业务永久终止才使用“拒绝”或“已终止”。

### 6.2 实习主状态机

`未进入实习 → 准备中 → 待上岗 → 在岗中 → 考核中 → 已完成 → 已归档`

旁路状态：请假中、换岗审核中、风险处理中、终止审核中。旁路不得覆盖主状态，处理完成后回到合法主状态。

### 6.3 毕设主状态机

`未启动 → 选题中 → 任务书确认 → 指导中 → 中期检查 → 成果检查 → 答辩中 → 成绩待发布 → 已完成 → 已归档`

成果退回、中期整改、二次答辩作为可追踪的子流程，不能直接修改主流程历史。

## 7. PC与移动端分工

| PC端 | 移动端 |
|---|---|
| 批次、流程、角色和权限配置 | 今日待办和通知 |
| 企业岗位、师生、课题批量管理 | 打卡、周报、请假、报告提交 |
| 组合筛选、批量审批、批量催办 | 教师快速通过/退回与评语 |
| 数据统计、质量监控、风险总览 | 查看本人学生、风险和进度 |
| 导入导出、材料核验、档案归档 | 学生查看流程、意见和结果 |
| 答辩编排、成绩复核发布 | 答辩签到和现场评分 |

## 8. 10分钟销售演示动线

1. 0:00—1:00：管理员工作台，展示今日待办、完成率和风险摘要。
2. 1:00—2:30：实习准备期，从计划、企业岗位到申请录用和协议。
3. 2:30—4:00：手机学生端完成打卡、周报提交，PC立即看到进度。
4. 4:00—5:00：教师移动端批阅，演示退回、重新提交、通过闭环。
5. 5:00—6:00：风险中心展示发现、分派、整改、复核和关闭。
6. 6:00—7:30：切换毕业设计，展示选题、任务书、指导和中期检查。
7. 7:30—8:30：成果提交、查重、互查整改和答辩评分。
8. 8:30—9:30：实习和毕设成绩发布、材料清单与档案归档。
9. 9:30—10:00：权限、审计、备份和私有化部署收尾。

## 9. 实施优先级

### P0：成交和验收必需

- 三级菜单、角色工作台、统一状态词、申请录用闭环、风险闭环、成果退回重交、材料归档。
- 所有页面显示前置条件、下一步和异常处理。

### P1：降低管理成本

- 组合筛选、批量审批/催办、学生/课题详情时间线、中期检查整改、档案缺失清单。

### P2：规模化交付

- 流程节点配置、学校字段配置、角色数据范围、统计指标配置和多学校模板复制。
