# 软件著作权登记申请指引

软著是教育行业投标的基础门槛（多数采购文件要求投标人具备相关软著）。本系统建议登记 2 件：
1. 《毕业设计及岗位实习管理平台（PC端）软件 V1.0》
2. 《毕业设计及岗位实习管理平台微信小程序软件 V1.0》

## 申请渠道
中国版权保护中心（ccopyright.com.cn）在线申请，普通登记免官费，审查周期约 30-40 个工作日；加急可走代理（数百至千元级）。

## 需准备的材料
| 材料 | 本项目对应来源 |
|---|---|
| 申请表 | 在线填写，开发方式选"独立开发"，权利人为个人或后续成立的公司主体 |
| 源程序鉴别材料 | 前、后各连续 30 页源代码（每页≥50行）。建议前30页取 `internship-backend/app.js` + `routes/`，后30页取 `管理平台.html` 脚本段或小程序 `pages/` |
| 文档鉴别材料 | 用户手册前后各30页，可基于《06-验收自检对照表》扩写各模块操作说明并配界面截图 |
| 身份证明 | 个人：身份证；公司：营业执照 |

## 注意事项
- 源代码页眉需含软件名称+版本号，页码连续。
- 申请前确定权利人主体：若计划以公司名义投标，先注册公司再以公司名义登记（或登记后做著作权转让）。
- 版本号与后续投标文件保持一致（V1.0）。
