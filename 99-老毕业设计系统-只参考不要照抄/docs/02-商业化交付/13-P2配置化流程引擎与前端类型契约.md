# P2：配置化流程引擎 + zod 契约层 + 前端类型生成

> SaaS V1 蓝图 P2 落地。解决"30 校审批流程不一致只能改代码"，并打通前后端强类型契约。
> 测试 64 全过；流程引擎端到端冒烟（学生提交→教师审批→状态流转、越权403、非法动作400、缺参400）通过。

---

## 一、配置化流程引擎（状态机）
把审批/阶段流转从代码 if-else 改为**配置驱动**，每校一份定义可后台改而不改代码。

**数据层**（每租户库，[`models/workflowModel.js`](../../internship-backend/models/workflowModel.js)）：
`t_workflow_def`(定义) / `t_workflow_state`(状态节点) / `t_workflow_transition`(流转:from→to+动作+允许角色) / `t_workflow_instance`(运行实例) / `t_workflow_history`(流转历史)。
开通学校/迁移时**自动种入 3 条默认流程**：实习申请审批、实习报告审批、请假审批。

**引擎纯函数**（可单测）：`resolveTransition`(状态+动作→流转) / `canPerform`(角色权限) / `availableActions`(某状态该角色可执行的动作)。

**Service**（[`services/workflowService.js`](../../internship-backend/services/workflowService.js)）：`current`(状态+可执行动作+历史) / `dispatch`(驱动流转，校验合法性+角色权限+落历史) / `replaceDefinition`(配置化核心：替换状态+流转) / `seedDefaults`。

**接口**（`/api/v1/workflows`，[`routes/workflowRoutes.js`](../../internship-backend/routes/workflowRoutes.js)）：
| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/workflows/defs` | 流程定义列表 | 管理员 |
| GET | `/workflows/def/:bizType` | 取定义 | 管理员 |
| PUT | `/workflows/def/:bizType` | **配置流程**（状态+流转） | 管理员 |
| PUT | `/workflows/def/:bizType/enabled` | 启停 | 管理员 |
| POST | `/workflows/seed` | 种入缺省流程 | 管理员 |
| GET | `/workflows/:bizType/:bizId` | 单据当前状态+可执行动作+历史 | 登录 |
| POST | `/workflows/:bizType/:bizId/dispatch` | 驱动流转 | 登录（动作权限由配置判定） |

**示例**（实习申请 intern_apply，单据 101）：学生 `submit` → 待教师审核 → 教师 `approve` → 待院校审批 → 院校 `approve` → 已通过。学生越权 `approve` 返回 403；`teacher_ok` 状态下 `submit` 返回 400。每校可在后台改状态/流转/允许角色，无需改代码。

## 二、zod 契约层（铺开）
- [`validators/schemas.js`](../../internship-backend/validators/schemas.js) 新增 `wfDispatch`、`wfDefinition`（流程配置校验）；已接 `workflows` 的 dispatch / setDefinition。
- 契约层现覆盖：认证、报酬、平台开通、流程引擎；后续模块按同一模式渐进接入。

## 三、前端类型生成（前后端契约对齐）
- [`scripts/gen-frontend-types.js`](../../internship-backend/scripts/gen-frontend-types.js)：以 `openapi/spec.js`（与 zod 契约一致）为**单一事实源**，把 OpenAPI 组件 schema 转成 TypeScript 接口。
- 输出 [`web/spa/src/types/api.ts`](../../web/spa/src/types/api.ts)（12 个类型：`ApiResp<T>` + LoginReq/RegisterReq/StipendCreateReq/User/Tenant/Plan/Stipend/WorkflowState/RiskRadarDim…）。
- `npm run gen:types` 重新生成。前端 `web/spa` 可 `import type { Tenant } from './types/api'` 强类型对接，契约改了重生成即可。
- OpenAPI 文档同步补全流程引擎接口（`/api/docs` 可见）。
