# 学年数据封存与移交 SOP

对应采购要求："每学年结束后对所有数据材料导出封存，以网盘方式交付学校，移交完成后销毁本年度数据。"

## 流程（学年结束后 15 个工作日内完成）
1. **冻结**：通知学校后设置平台只读（停止写入操作），公告挂出。
2. **导出**：
   - 数据库全量：`deploy/backup.sh` 生成 SQL 包
   - 业务归档：PC 端"档案归档→导出归档包"、"导出实习手册"、"毕设归档导出"、"学信网格式导出"
   - 附件文件：`uploads/` 目录整体打包（照片、周报附件、成果文件）
3. **校验**：按《06-验收自检对照表》抽 5 名学生核对档案完整性；生成清单（文件名+大小+SHA256）。
4. **交付**：加密压缩（密码独立渠道发送），上传学校指定网盘，附《数据交付清单》签收。
5. **销毁**（学校书面确认后 30 日内）：删除生产库当年度数据与备份，出具《数据销毁确认函》双方盖章。
