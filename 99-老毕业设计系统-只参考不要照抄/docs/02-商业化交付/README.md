# 商业化交付包

| 文件 | 用途 | 紧急度 |
|---|---|---|
| 01-软著申请指引 | 投标资质基础，周期最长（30-40工作日），最先启动 | ★★★ |
| 02-等保整改对照表 | 投标承诺 + 中标后整改路线 | ★★ |
| 03-售后服务承诺书(SLA) | 直接响应采购文件质量要求，投标文件附件 | ★★★ |
| 04-隐私政策与用户协议(草案) | 上线合规 + 小程序审核需要，需律师定稿 | ★★ |
| 05-数据封存与移交SOP | 响应采购文件数据移交条款 | ★★ |
| 06-验收自检对照表 | 投标前自检 + 验收现场演示脚本 | ★★★ |

技术部署见 `internship-backend/deploy/README.md`（仓库根目录起）（Docker 一键部署 / PM2 / 备份 / 上线检查单）。

## 下一步行动顺序
1. 立即启动软著申请（周期最长）
2. 按 deploy 包把系统部署到一台云服务器，绑定 https 域名，跑通小程序正式域名
3. 用 06 表逐条自测，🔶 项联调（微信 AppID、省平台凭证）
4. 找 1-2 个系部做免费试点，攒真实运行数据和使用证明
5. 注册公司主体 → 等保定级备案 → 参与投标
