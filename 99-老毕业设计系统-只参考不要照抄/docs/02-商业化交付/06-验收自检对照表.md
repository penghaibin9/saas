# 验收自检对照表（按采购功能清单逐条核对）

> 采购文件约定"验收时逐条核对，存在未满足事项则验收不通过"。本表用于投标前自检与验收现场演示路径。
> 状态：✅ 已实现且可独立验收 ｜ 🔶 本地流程已实现、仍需外部凭证/正式环境联调 ｜ ⛔ 缺失

## 一、总体要求
| 采购条款 | 系统对应 | 状态 |
|---|---|---|
| 统一数据库、毕设+实习两系统融合 | 同一后端/库，PC 端左侧双业务线导航 | ✅ |
| 微信小程序扫码登录，一次登录全程使用 | 当前为内存票据 + 账号密码确认的流程模拟，不等同微信身份认证 | 🔶 需正式 AppID、code2session/openid 与共享票据存储联调 |
| 全程无纸化、过程材料平台存档 | 各环节均有上传/留痕 | ✅ |
| 自动生成实习学生档案、Excel 导出 | 档案归档页 + 导出归档包 | ✅ |
| 省平台获取待抽名单、自动校验差异、一键上传成果链接 | 当前支持 Excel 导入校验与本地上传状态模拟，不产生省平台真实回执 | 🔶 需省平台接口文档、测试凭证与真实回执联调 |

## 验收演示动线建议（30 分钟）
登录（账号密码；扫码仅在正式 AppID 联调后列入验收） → 实习计划申报审批 → 学生小程序打卡(范围校验) → 教师批阅周报(快捷评语/批量) → 风险预警+缺报监测 → 毕设选题→任务书→查重→答辩评分→成绩 → 省厅 Excel 校验演示（真实上传须凭正式回执验收） → 档案归档导出 → 数据大屏收尾。
