# 系统使用说明书

> 毕业设计及岗位实习管理平台 · 使用说明书（面向师生与管理员）

## 1. 访问与登录

| 端 | 地址 |
| --- | --- |
| PC 管理端 | `http://服务器IP:3000/admin` |
| 移动端 H5（学生/教师） | `http://服务器IP:3000/m/index.html` |
| 移动端 H5（企业） | `http://服务器IP:3000/m/enterprise.html` |
| 数据大屏 | `http://服务器IP:3000/screen` |

**登录**：输入账号（工号/学号）与密码 → 登录。**首次登录会强制修改初始密码**（需数字+字母、≥6 位）。

> 演示账号（密码均 `demo1234`，仅演示环境）：`demo_admin` / `demo_teacher` / `demo_stu1` / `demo_ent`。
> 系统按账号角色自动加载对应菜单，无需手动切换身份。

## 2. 学生使用指南

登录移动端 H5 或 PC 端，首页为功能宫格 / 工作台。

| 要做的事 | 在哪 | 步骤 |
| --- | --- | --- |
| 找实习 | 实习岗位 | 浏览岗位 → 投递申请 → 等待审核 |
| 签协议 | 三方协议 | 待签协议 → 在线签署 |
| 每天打卡 | 打卡签到 | 到岗后定位打卡（需在企业范围内，支持上/下班） |
| 写周报月报 | 周报月报 | 新建 → 填写 → 提交，教师批阅后可见评语 |
| 请假 | 我的请假 | 填写起止与事由 → 提交 → 等教师审批 |
| 交报告 | 实习报告 | 上传报告 → 提交评阅 |
| 毕设 | 毕设选题/任务书/成果 | 选题 → 确认任务书 → 提交成果（查重）→ 答辩 → 查成绩 |
| 有问题 | 投诉上报 | 提交投诉/安全上报，学校处理 |

## 3. 指导教师使用指南

| 要做的事 | 在哪 | 步骤 |
| --- | --- | --- |
| 审申请 | 待审核申请 | 同意/驳回学生岗位申请 |
| 会签协议 | 协议会签 | 教师签署三方协议 |
| 看进度 | 学生进度 | 查看所带学生打卡/日志/报告完成情况 |

| 毕设指导 | 任务书/指导记录/成果审查/答辩评分 | 下达任务书、记录指导、审成果、答辩评分、录成绩 |

## 4. 院校 / 分院管理员使用指南

| 要做的事 | 在哪 | 步骤 |
| --- | --- | --- |
| 建基础数据 | 基础数据 | 维护学院/专业/班级 |
| 建账号 | 用户管理 | 新增/导入师生账号（默认密码 123456，首登改密） |
| 下达计划 | 实习计划 | 制定计划，设定打卡/周报/月报次数要求 |
| 审企业岗位 | 企业审核 / 岗位审核 | 审核企业入驻与岗位发布 |
| 终审录用 | 申请录用 | 院校审核 → 登记录用（建立实习分配） |
| 监控预警 | 风险预警/缺报监测/保险预警 | 查看异常并处置 |
| 核成绩 | 实习考评 | 配置权重 → 核算 → 发布实习成绩 |
| 数据上报 | 省厅数据对接 / 数据分析 | 导出学信网格式、对接省平台、看大屏 |
| 归档 | 档案归档 | 实习/毕设档案归档 |
| 查审计 | 审计日志 | 查看所有写操作责任链 |

## 5. 企业（导师）使用指南

| 要做的事 | 在哪 | 步骤 |
| --- | --- | --- |
| 入驻 | 登录页「申请入驻」 | 提交企业信息与账号，等学校审核 |
| 发岗位 | 我的岗位 | 发布/编辑岗位（待学校审核上架） |

## 6. 常见问题

| 问题 | 说明 |
| --- | --- |
| 打卡提示"不在范围内" | 需在企业设定的经纬度+半径范围内；坐标由管理员在企业管理中维护 |
| 登录提示"请求过于频繁" | 触发登录限流，等约 1 分钟再试（防爆破保护） |
| 忘记密码 | 由管理员在用户管理中"重置密码" |
| 看不到某菜单 | 菜单按角色显示，无权限的功能不展示 |
| 首次登录要改密 | 安全要求，设置新密码后即可正常使用 |
