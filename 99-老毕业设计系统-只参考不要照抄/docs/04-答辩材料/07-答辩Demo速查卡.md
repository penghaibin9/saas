# 答辩 Demo 速查卡（一页纸）

> 打印或手机打开备用。开场 30 秒定调 → 点 5 下走通闭环 → 收尾强调 3 句。
> **演示前必做**：`.env` 配好 `DEEPSEEK_API_KEY`（让 AI 真跑）→ `npm start` → 浏览器开 `http://localhost:3000/admin`，提前登录到工作台。

---

## 🎬 开场（30 秒，背下来）
> "我做的是一套**职业院校实习管理平台**，覆盖**顶岗实习 + 毕业设计**两条完整业务线。
> 它有三个区别于市面产品的点：**一是用 AI 做主动风险预警**，二是**一套代码支持私有化和 SaaS 多校两种部署**，三是**对标教育部规定做了完整合规闭环**。下面我演示核心闭环。"

---

## 👆 点这 5 下（主闭环，3 分钟）

| 步骤 | 操作 | 一句话讲解 |
|---|---|---|
| 1 | 工作台 → 指着待办/数据卡片 | "管理员进来一眼看到待审、风险、过程未达标的聚合待办" |
| 2 | 左侧「过程监管·打卡」 | "学生 GPS 打卡，**带反作弊**——模拟定位、位移突变都会被标记待核实" |
| 3 | 「周报月报」→ 打开一篇 → 点 **AI 质检** | "AI 给周报打分 + 指出敷衍/空泛，教师批阅提效（**这里是真模型，不是规则**）" |
| 4 | 「风险预警」 | "AI 从日志文本识别**脱岗/想离职/被克扣工资**等弱信号，主动预警——这是市面产品基本没有的" |
| 5 | 顶部切到「**数据大屏**」(/screen) | "迎检一键投屏：在册/打卡率/在岗率/风险，**点 KPI 卡片还能下钻**到明细" |

> 备选加分点（有时间再点）：「家长知情书」→ 演示**家长扫码在线电子签**；「实习报酬」→ **自动校验不低于试用期80%**。

## 🎯 收尾强调这 3 句
1. **"不是一个 CRUD 毕设，是能私有化也能 SaaS、对标教育部合规、用 AI 做主动预警的可交付系统。"**
2. **"技术上有真东西：用 AsyncLocalStorage + 代理实现 DB-per-tenant，40 个模块零改动支持多校独立库。"**
3. **"工程上是商用级：50+ 后端模块、RBAC、审计、限流、优雅退出、幂等迁移、单元测试，可直接部署。"**

## 🛟 评委可能问 + 标准答法
- **"AI 是真的还是套壳？"** → "接 DeepSeek，配了 key 就真调；没配会**明确标 isDemo** 降级演示，绝不伪造结论。发送前还做了 PII 脱敏，学生隐私不外泄。"
- **"和工学云这类产品比？"** → "日常打卡、合规我对齐了，还多了 **AI 风险预警**和**毕设+实习双闭环**；原生 App、信创是后续基建路线，已有适配层预留。"
- **"防作弊怎么做？"** → "定位侧检测模拟定位 + 精度异常 + 位移突变（不可能的时速），高风险打卡标记待教师核实。"
- **"数据安全？"** → "JWT 强密钥校验、参数化 SQL、字段白名单防提权、操作审计、CSP、登录限流（可 Redis 集群共享）。"
- **"能支撑多大规模？"** → "多租户 DB 隔离、对象存储抽象、定时任务分布式锁、/metrics 可接 Prometheus 监控。"

## ⚠️ 防翻车
- Demo 前**先登录好**停在工作台，别现场敲密码（首登强制改密会打断节奏）。
- AI 调用有几秒延迟，点了**等一下**，别狂点。
- 网络/AI 万一抽风：它会**自动降级演示**，照样有结果，淡定说"这是未联网时的演示模式"。
- 大屏点 KPI 会**新开标签**到管理端，提前说明"点卡片可下钻"。
