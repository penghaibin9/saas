# 技术亮点与创新点（答辩讲解）

> 用于答辩时凸显系统的技术含量与工程成熟度。建议每点配一句"问题—做法—效果"。

## 一、核心创新点（差异化，重点讲）

### 1. AI 主动风险预警（从"规则触发"到"语义识别"）
- **问题**：实习安全监管传统靠人工巡检与规则关键词，脱岗/心理/权益等弱信号易漏。
- **做法**：接入大模型（DeepSeek），对学生周报/月报文本做语义级风险研判，输出风险等级 + 命中信号 + 处置建议；并提供日志智能质检、报告辅助评阅、岗位智能匹配、政策问答助手。
- **效果**：把"事后发现"变"过程预警"；教师批阅效率提升。
- **工程亮点**：可插拔——配置密钥即真用，未配置则**确定性演示降级且明确标注 isDemo**，绝不伪造权威结论；**发送前对手机号/身份证/邮箱脱敏**（数据最小化，PIPL 合规）；按月**用量配额护栏**防成本失控。

### 2. 单代码库双部署形态（私有化 single / SaaS multi）
- **问题**：职院既有私有化诉求，又有区域统建（多校）诉求，通常要维护两套代码。
- **做法**：用 `AsyncLocalStorage` 承载"当前请求所属租户" + 数据库句柄 **Proxy**，实现 **DB-per-tenant**：40+ 个 Model **零改动**自动落到正确的租户库，事务亦然。
- **效果**：`TENANCY_MODE=single` 行为与单库完全一致；`multi` 模式按学校路由到独立库，数据物理隔离，JWT 携带租户标识防跨校令牌复用。

### 3. 教育部对标的合规闭环
- 家长知情同意（**在线电子签**，留存签署人/IP/时间，监护人合规）、实习鉴定表、巡访、就业去向、查重、学信网导出、**实习报酬台账（自动校验不低于试用期工资80%）**、**标准数据报送包（面向省级/国家平台）**。
- 体现对《职业学校学生实习管理规定》的逐条落地，是面向真实采购的硬支撑。

## 二、工程成熟度（体现"能交付"）

- **分层架构**：route → controller → model，统一鉴权（RBAC + 强制首次改密）、统一响应、参数化 SQL、字段白名单防批量赋值提权。
- **安全**：JWT 生产密钥强校验、扩展名白名单 + 随机文件名、操作审计链、CSP/安全响应头、登录限流（**可选 Redis 多实例共享配额**）、AI 发送前脱敏。
- **可观测/可运维**：结构化 JSON 日志 + requestId 全链路、优雅退出（SIGTERM 排空连接池）、健康检查、**幂等迁移（t_migration 版本表）**、备份+**恢复演练 SOP**。
- **质量**：核心逻辑单元测试覆盖（鉴权守卫、注册防提权、报酬合规、报送映射、AI 降级等），CI 可回归。
- **触达/体验**：站内 + 微信 + 短信 + **邮件**多渠道；移动端 **PWA + 弱网离线打卡**（断网入 IndexedDB 队列，联网自动重放）——直击车间/工地弱网痛点。

## 三、演示建议

1. **答辩前在 .env 配好 `DEEPSEEK_API_KEY`**，让 AI 质检/风险预警**现场真跑**一遍（最直观）。
2. 演示动线：学生写一篇"敷衍"周报 → AI 质检给低分+建议 → 写含"想辞职/克扣工资"的日志 → 风险预警高亮 → 教师端看到预警。
3. 配合 `业务流程演练.html` / 演练手册，展示"院校管理员—教师—学生—企业—家长"全角色闭环。

## 四、一句话总结

> 不是一个 CRUD 毕设，而是一套**可私有化也可 SaaS、对标教育部合规、用 AI 做主动风险预警**的实习管理平台，具备真实交付与商用的工程完备度。
