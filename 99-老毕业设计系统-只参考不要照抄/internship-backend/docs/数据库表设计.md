# 数据库表设计（本轮新增 / 修改）

> 数据库：`internship_management`，字符集 `utf8mb4`，引擎 InnoDB。
> 所有表均含逻辑删除 `is_deleted`(部分)、`create_time`、`update_time`。
> 迁移脚本均**幂等**，统一入口：`npm run migrate:all`。

## 表与功能 / 迁移对照总览

| 表名 | 对应功能模块 | 创建迁移 |
|------|-------------|----------|
| `t_user`（修改） | 用户：新增「强制首次改密」 | `migrate` |
| `t_enterprise`（修改） | 实习单位坐标 + 打卡范围 | `migrate:intern` |
| `t_intern_plan` | 实习计划（审批流） | `migrate:intern` |
| `t_assignment` | 实习分配（教师+企业） | `migrate:intern` |
| `t_checkin` | GPS 打卡签到 | `migrate:intern` |
| `t_intern_log` | 实习周报 / 月报 | `migrate:logs` |
| `t_leave` | 请假申请 | `migrate:logs` |
| `t_announcement` | 公示信息 / 通知公告 | `migrate:gd` |
| `t_gd_task` | 毕业设计任务时间节点 | `migrate:gd` |
| `t_gd_topic` | 毕设选题与指导老师 | `migrate:gd-thesis` |
| `t_gd_grade` | 毕设成绩（评阅/答辩/综合） | `migrate:gd-thesis` |
| `t_gd_achievement` | 毕设成果上传 / 审阅 | `migrate:gd-thesis` |
| `t_quality_check` | 质量监控 / 互查配对 | `migrate:gd-quality` |
| `t_gd_guidance` | 毕业设计指导记录（教学组织） | `migrate:gd-guidance` |
| `t_teacher_record` | 教师月报 / 寻访记录 | `migrate:teacher-record` |
| `t_satisfaction` | 企业满意度评价 | `migrate:satisfaction` |
| `t_province_student` | 省厅名单 / 校验 / 上传 | `migrate:province` |
| `t_insurance` | 实习保险单 | `migrate:insurance` |

> 另有 `migrate:base`：当库中缺少基础表（college/major/class/enterprise/position/application/report/notification）时，
> 以 `CREATE TABLE IF NOT EXISTS` **非破坏性**补齐，不删除任何已有数据。
