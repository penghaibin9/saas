# 商业化功能 · 第一波（让学校"敢验收"）

对标习讯云/悦实习等商业软件，本次补齐 4 个决定"学校敢买"的能力。全部**不依赖外部合同/账号**即可运行；微信/短信通道为"填了 .env 即生效"的脚手架。

## 一键部署
```bash
cd internship-backend
npm install
npm run migrate:all      # 已含 audit / enterprise-portal / complaint-safety 三个新迁移
npm start                # 启动后自动加载审计中间件 + 保险定时任务
```
管理端：浏览器打开 `管理平台.html`（默认连 localhost:3000）。演示账号 `admin / 123456`。

---

## 1. 操作审计日志（迎检/等保一票否决项）
- **全局中间件**记录所有写操作的责任链：谁 / IP / 时间 / 动作 / 对象 / 结果 / 请求摘要（密码等敏感字段自动脱敏）。只增不改不删。
- 院校管理员看全校，分院管理员仅看本院（数据隔离）。
- 前端：管理平台「审计日志」页（概览卡片 + 多条件筛选 + 详情）。
- 接口：`GET /api/audit-logs`、`GET /api/audit-logs/overview`
- 表：`t_audit_log`

## 2. 迎检数据大屏（领导驾驶舱）
- 服务端**一次聚合**实习/风险/分析数据：在册实习人数、打卡率、在岗率、过程未达标、涉险学生、合作企业，+ 打卡趋势/状态分布/学院规模/企业Top + 风险与未达标名单。
- 独立全屏深色大屏 `数据大屏.html`，30 秒自动刷新，适合迎检投屏/答辩演示；管理平台工作台「🖥 迎检数据大屏」一键进入（token 经 hash 传递）。
- 接口：`GET /api/analytics/cockpit`

## 3. 企业端自助（闭合企业协同）
- 新增**企业导师**角色（role=5）。闭环：企业公开注册 → 管理员审核（激活账号）→ 企业登录 → 发布岗位（待学校审核上架）→ 确认录用（通知学生）。
- 前端：登录页「申请入驻」；管理平台「企业审核」页；企业端「我的岗位 / 收到的申请」控制台。
- 接口：`POST /api/public/enterprise-register`、`GET /api/enterprises/pending`、`PUT /api/enterprises/:id/audit`、`/api/enterprise-portal/*`
- 变更：`t_user.enterprise_id`、`t_enterprise.audit_status/audit_remark/contact_email`

## 4. 投诉 + 消息触达 + 保险闭环（安全合规）
- **投诉/异常/安全上报**：任意角色可上报，管理员/教师按范围处理，状态流转通知上报人；紧急联系人字段入库。表 `t_complaint` + `t_user.emergency_*`。
- **消息触达配通**：站内信 + 微信订阅消息 + 短信三通道。微信脚手架已接 `notify()`；新增**短信适配器** `utils/sms.js`（阿里/腾讯可插拔，未配 .env 静默跳过）。重要通知 `notify(..., {sms:true})` 走短信。
- **保险预警定时任务**：每日扫描"即将到期保单"与"在册实习未投保学生"，自动通知学生/管理员；管理平台「保险预警」页可查清单并「立即扫描」。接口 `GET /api/insurances/warnings`、`POST /api/insurances/scan`。

## 需要外部条件才能"真打通"的（第二波，已留好接口）
| 能力 | 现状 | 通了需要 |
|---|---|---|
| 微信订阅消息 | 脚手架已接 notify | 小程序 AppID/Secret/模板ID 填入 .env |
| 短信触达 | 适配器已接 notify | 阿里/腾讯短信账号 + 在 sms.js 接 SDK |
| 省平台对接 | 本地名单匹配/导入导出 | 省厅真实 API 文档与凭证 |
| 统一身份认证 | 账号密码登录 | 学校 CAS/OAuth 端点 |
