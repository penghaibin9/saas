## 六、PC 登录常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示「登录已过期」但刚输密码 | 旧版前端把密码错误也当 401 退出 | 已修复：密码错误显示「用户名或密码错误」 |
| 提示「尝试过于频繁」 | 登录限流 15 分钟 10 次 | 开发环境已放宽；或重启后端清空内存计数 |
| demo_admin 无法登录 | 未执行 seed | `npm run seed:demo` |
| 登录后闪退回登录页 | localStorage 里 token 过期 | 登录页点「清除本地登录缓存」 |
