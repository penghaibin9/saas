# 学校验收清单（真卖交付 · Phase 1）

> 省实习平台 live 对接不在本期范围，备案流程以 mock/Excel 验收。

## 一、环境与部署

- [ ] 服务器 HTTPS 证书有效，域名可访问
- [ ] Node.js 后端 `npm start` 或 systemd/pm2 守护运行
- [ ] MySQL 数据库已执行 `npm run migrate:all` 及 `npm run migrate:sales1`
- [ ] `.env` 已配置 JWT_SECRET（≥32 位）、数据库、CORS_ORIGIN
- [ ] Nginx 反向代理按 `deploy/nginx.conf.example` 配置
- [ ] 定时备份：`node scripts/backup-db.js` 可成功生成 SQL 文件

## 二、统一身份认证（CAS）

- [ ] 系统配置中启用 CAS，填写 `cas_server_url` / `app_public_url`；跨域回跳仅在确有需要时配置 `CAS_RETURN_TO_ALLOWLIST`，否则留空
- [ ] PC 登录页显示「统一身份认证登录」
- [ ] 从学校 CAS 登录后可自动进入管理端（用户 username 或 eeid 与 CAS 账号一致）

## 三、实习全流程

- [ ] 实习计划申报 → 审批 → 分配
- [ ] 学生 GPS 打卡（围栏内/外提示）
- [ ] 周报/月报提交与教师批阅
- [ ] **换岗/终止**：学生或教师发起 → 教师审 → 管理员终审执行
- [ ] 实习协议三方签署
- [ ] 企业入驻与岗位审核上架

## 四、安全与合规

- [ ] 投诉/异常/安全上报与处理闭环
- [ ] 保险到期预警与扫描
- [ ] 操作审计日志可查询导出
- [ ] 学生紧急联系人可在移动端维护

## 五、消息触达

- [ ] 站内通知正常
- [ ] （可选）微信小程序订阅消息：配置 WX_MP_* 后管理端显示「已配通」
- [ ] （可选）短信：配置 SMS_* 后重要节点可发短信

## 六、迎检演示

- [ ] PC 工作台 → 商业化能力各模块可演示
- [ ] 迎检数据大屏 KPI 正常
- [ ] 实习备案：生成 → 导出 Excel → mock 提交（不要求省平台 live）

## 七、文档交付

- [ ] `frontend/help.html` 运维手册
- [ ] 本验收清单签字确认
- [ ] 管理员/教师/学生操作培训记录
