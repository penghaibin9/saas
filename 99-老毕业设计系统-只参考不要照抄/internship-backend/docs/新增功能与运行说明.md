# 毕业设计 + 岗位实习管理平台 —— 后端新增功能与运行说明

> 本文档记录本轮安全加固 + 功能扩建的内容、数据库迁移和接口清单。
> 所有迁移均**幂等**（可重复执行），不会破坏已有数据。

## ⚠️ 重要发现：你的数据库缺少基础表

执行迁移时发现，数据库 `internship_management` 里**只有 `t_user`，缺少 `t_enterprise / t_application / t_college` 等基础表**
（基础表结构 `init-db.sql` 从未在此库完整建过）。

我**没有**运行会清库的 `init-db.sql`，而是新增了**非破坏性**迁移：
- `migrate:base`：用 `CREATE TABLE IF NOT EXISTS` 补齐缺失的基础表；
- `migrate:reconcile`：你库里 `t_college/t_major/t_class` 来自另一套结构（缺 `status`、`t_class` 用 `year` 无 `college_id/grade`），
  此迁移按本项目模型**补齐缺失列并回填**（`grade`←`year`、`class.college_id`←专业的学院），并把旧 `year` 改为可空。

两者均已包含在 `npm run migrate:all` 中，**完整保留你的已有数据**。本次已成功执行，全部表/列就绪，
并已通过 `npm run smoke` 端到端联调（36/36 全部通过）。

> 旧服务（3000 端口，改动前启动的）若仍能跑，可能连的是另一套数据库或 Java 后端建的表。
> 用新版前请停掉旧进程后 `npm start`。

## 一、如何运行（重要）

```bash
# 1. 安装依赖（如未安装）
npm install

# 2. 确认 .env 配置（参考 .env.example）
#    生产环境必须设置 >=32 位的 JWT_SECRET，否则拒绝启动
#    可用：node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

# 3. 执行全部数据库迁移（新增字段与新表，幂等）
npm run migrate:all

# 4. 启动（启动后浏览器打开 http://localhost:3000 即为已对接后端的前端控制台）
npm start         # 默认 http://localhost:3000  （demo_admin / demo1234 登录）

# 5.（可选）灌入演示数据：贯穿两子系统，便于答辩演示
#    账号：demo_admin / demo_teacher / demo_stu1 / demo_stu2（密码 demo1234）
npm run seed:demo

# 6.（可选）一键 HTTP 冒烟测试：覆盖实习+毕设核心链路
#    会自动播种 smoke_admin/smoke_teacher/smoke_student 测试账号（密码 smoke1234），不影响真实数据
npm run smoke
#    若服务跑在别的端口： SMOKE_BASE=http://localhost:3999/api npm run smoke
```

> ⚠️ 之前可能有一个旧版本服务仍占用 3000 端口（改动前启动的）。
> 升级后请先停掉旧进程再 `npm start`，否则访问到的是旧代码。

### 单独执行某个迁移
| 命令 | 作用 |
|------|------|
| `npm run migrate:base`     | 非破坏性补齐基础表（缺失时才建，不删数据） |
| `npm run migrate:reconcile`| 协调既有 college/major/class 表的列差异（补列+回填） |
| `npm run migrate`          | t_user 增加 must_change_password 字段 |
| `npm run migrate:intern`   | 企业表加经纬度/打卡半径 + 实习计划/分配/打卡表 |
| `npm run migrate:logs`     | 周报月报表 + 请假表 |
| `npm run migrate:gd`       | 公示信息表 + 毕设任务节点表 |
| `npm run migrate:gd-thesis`| 选题指导 / 成绩 / 设计成果表 |
| `npm run migrate:gd-quality`| 质量监控/互查表 |
| `npm run migrate:province` | 省厅毕业生名单表 |
| `npm run migrate:all`      | 以上全部 |

## 一点五、前端控制台（已对接后端）

`internship-backend/frontend/index.html` 是一个**已连真实 API** 的单文件控制台（深蓝侧边栏，沿用演示UI风格），
由后端自动托管：启动后访问 `http://localhost:3000/` 即可登录使用，无需单独部署。

- 登录走 `/api/users/login`，令牌存 localStorage，所有请求带 `Authorization: Bearer`
- **按角色动态菜单**：院校/分院管理员看全部模块；教师/学生进入对应「我的工作台」
- 已对接页面：工作台概览、公示信息、任务节点、学生档案、指导老师、成绩管理、质量监控、省厅数据、
  实习计划审批（带通过/开启/结束按钮）、实习分配、打卡签到、请假、统计分析（含企业满意度可视化）、实习单位、我的工作台
- 列表/导出/图表均取后端真实数据；Excel 导出按钮直接下载
- **可交互操作**：新建实习单位(含坐标/打卡半径)、发布公示、新建实习计划、录入企业满意度、
  实习计划通过/开启/结束、通知全部已读
- 通知中心：查看站内消息并一键已读
- **学生/教师管理**：新建 / 编辑 / 启用禁用 / 重置密码 / 删除
- **选题与指导**：新建 / 编辑 / 删除（选学生、选指导老师）
- **打卡补录**：管理员/教师为学生补录打卡（`POST /api/checkins/manual`）
- **ECharts 可视化**：统计分析页用饼图/柱图/折线（CDN 加载，离线自动降级为内置 SVG 柱图）
- **微信扫码登录**：登录页「微信扫码」Tab，生成二维码 + 轮询 + 手机端确认（模拟，端点见下）

### 微信扫码登录（模拟）`/api/wechat`（公开，登录前流程）
- `POST /qr` 生成二维码票据 → `GET /qr/:ticket` 轮询状态 → `POST /qr/:ticket/confirm`（账号密码确认，等价微信授权回调）
- 生产接入真实微信时只需把 confirm 换成微信 OAuth 回调，前端时序不变

## 二、安全加固（本轮已完成）

1. **注册提权漏洞修复**：公开注册一律强制为学生(role=4)，禁止前端自带 role 提权。
2. **机密不入库**：根目录新增 `.gitignore`，移除已误提交的 node_modules 与含明文密码的 `SQL/application.yml`。
3. **JWT 密钥兜底**：生产环境缺失/不足 32 位直接拒绝启动。
4. **分院管理员越权修复**：用户管理、申请审核、实习相关全部按本学院隔离，且分院不能创建/提升为管理员。
5. **强制首次改密**：管理员建号、重置密码、Excel 导入的账号首次登录必须改密（数字+字母组合），改密前仅放行改密/个人信息接口。
6. **登录/注册限流**：单 IP 15 分钟最多 10 次。
7. **报告/附件鉴权下载**：`GET /api/reports/:id/download`，随机文件名 + 防路径穿越。
8. **CORS 白名单、基础安全头、请求体限流、生产环境隐藏错误细节、移除未鉴权探库口**。
9. **输入校验**：手机号/邮箱格式、分页参数夹紧（防 NaN/超大值）。
10. **导入事务化**：Excel 批量导入包事务、限行数、限文件类型。

## 三、新增接口清单（统一前缀 `/api`，除登录/注册外均需 `Authorization: Bearer <token>`）

### 岗位实习

**实习计划 `/intern-plans`**（状态：1申报 2通过 3开启 4结束 5驳回）
- `GET /` 列表，`GET /:id` 详情
- `POST /`（院校/分院）创建=申报
- `PUT /:id` 修改（申报/驳回态）
- `PUT /:id/approve`（院校）审批 `{agree, reason}`
- `PUT /:id/open`、`PUT /:id/close`（院校/分院）开启/结束
- `DELETE /:id`

**实习分配 `/assignments`**
- `GET /`、`GET /:id`
- `POST /`（院校/分院）单个分配 `{plan_id?, student_id, teacher_id, enterprise_id}`
- `POST /import` Excel 批量（列：学生学号/老师工号/企业名称）
- `GET /import/template` 模板
- `PUT /:id` 改派，`DELETE /:id` 移除

**打卡签到 `/checkins`**
- `POST /`（学生）打卡 `{latitude, longitude, address?, remark?}` —— 自动按实习企业坐标 + 半径做地理围栏校验
- `GET /mine`（学生）打卡概况
- `GET /`（各角色按权限）打卡记录

**周报/月报 `/intern-logs`**（type: weekly/monthly；状态：0草稿 1提交 2通过 3驳回）
- `GET /`、`GET /:id`
- `POST /`、`PUT /:id`（学生，支持附件 file），`PUT /:id/submit`，`DELETE /:id`
- `PUT /:id/review`（教师）`{agree, teacher_comment, reject_reason}`

**请假 `/leaves`**（状态：0草稿 1提交 2通过 3驳回）
- `GET /`、`GET /:id`、`POST /`、`PUT /:id`、`PUT /:id/submit`、`DELETE /:id`（学生）
- `PUT /:id/review`（教师）`{agree, reject_reason}`

**实习统计 `/intern-stats`**（院校/分院/教师）
- `GET /summary` 概览卡片（实习人数/企业数/今日打卡/待批阅/待审批）
- `GET /unchecked?days=N` 未打卡学生
- `GET /incomplete` 未达标学生（签到/周报/月报未满足计划要求）
- `GET /process` 实习过程统计（签到/周报/月报 vs 计划要求）

**实习保险单 `/insurances`**
- `GET /`、`GET /:id`（学生看自己；院校/分院看管理范围）
- `POST /`、`PUT /:id`、`DELETE /:id`（院校/分院）

**实习企业 `/enterprises`**（已扩展）
- 新增字段：`longitude` `latitude` `checkin_radius`(米，0=不约束)

**导出 `/export`**
- `GET /intern-archive` 实习学生档案 Excel（院校/分院/教师）
- `GET /assignments` 实习分配、`GET /checkins` 打卡记录
- `GET /gd-topics` 选题及指导老师一览表、`GET /gd-grades` 成绩汇总表

### 毕业设计

**公示信息 `/announcements`**：`GET /`、`GET /:id`；`POST/PUT/DELETE`（院校/分院，支持附件）

**任务时间节点 `/gd-tasks`**：`GET /`、`GET /:id`；`POST/PUT/DELETE`、`PUT /:id/complete`（院校/分院）

**选题与指导 `/gd-topics`**：`GET /`、`GET /:id`；`POST/PUT/DELETE`、`POST /import`（教师配备 Excel：学生学号/老师工号/选题名称）

**成绩 `/gd-grades`**：`GET /`（院校/分院/教师）、`GET /mine`（学生）；`POST /`（按学生 upsert）、`POST /import`（Excel：学号/评阅/答辩/综合成绩）、`DELETE /:id`

**设计成果 `/gd-achievements`**（状态：0待审阅 1通过 2驳回 3未完成）
- `GET /`、`GET /:id`
- `POST /`、`PUT /:id`（学生上传/重交，支持附件+链接）、`DELETE /:id`
- `PUT /:id/review`（教师）`{status:1|2|3, reject_reason}`

**质量监控/互查 `/quality-checks`**（状态：0待审阅 1通过 2驳回 3未完成）
- `GET /`、`GET /:id`
- `POST /`（单条配对）、`POST /generate`（一键生成检查清单：`{batch_name, check_type:census|sample, scope:self|cross, checker_ids[], student_ids[], sample_rate?}`）
- `DELETE /:id`
- `PUT /:id/review`（教师）`{status:1|2|3, opinion}`

**可视化分析 `/analytics`**（院校/分院）
- `GET /intern` 实习分析（申请状态分布、企业Top10、近14天打卡趋势、学院规模、行业分布）
- `GET /gd` 毕设分析（选题指派率、成果状态分布、成绩分档、任务完成情况）
- `GET /gd-summary` 毕设仪表盘卡片（选题/成果/成绩/任务计数）
- `GET /excellence` 优秀学生 / 优秀指导老师（按毕设综合成绩）

**企业满意度 `/satisfaction`**
- `GET /` 列表、`POST /`（院校/分院/教师评价，score 1-5）、`DELETE /:id`
- `GET /analytics` 满意度分析（总体均分 + 各企业平均，用于可视化）

**毕设指导记录 `/gd-guidances`**（教师维护，学生/管理员可查看）
- `GET /`、`GET /:id`；`POST /`、`PUT /:id`、`DELETE /:id`（教师）

**我的工作台 `/workbench`**（教师/学生）
- `GET /` 角色化聚合：教师看各类待办数量+指导规模；学生看实习进度+待办+成绩

**教师专属 `/teacher`**
- `GET /students` 我的实习生（含签到/周报/月报完成情况）
- `PUT /students/:id/reset-password` 帮指导学生重置密码（重置后强制学生改密）

**教师月报/寻访 `/teacher-records`**（type: monthly月报 / visit寻访；status: 0草稿 1提交）
- `GET /`、`GET /:id`（教师看自己/分院看本院/院校看全部）
- `POST /`、`PUT /:id`（教师，支持附件）、`PUT /:id/submit`、`DELETE /:id`

### 省厅 / 其它

**省厅数据 `/province`**（仅院校管理员）
- `GET /` 名单，`GET /template` 模板
- `POST /fetch` 一键获取（Excel 导入模拟）
- `GET /verify` 与本校学生校验差异（省有校无 / 校有省无 / 已匹配）
- `PUT /:id/upload` 上传成果链接至省平台（模拟）
