## 2. 已退役与禁止继续使用

- 客户端禁止调用 `/files/upload`、`/files/meta/{fileId}`。
- 普通上传、元数据、列表、版本和授权 URL 只使用 `/files` 权威合同。
- `/files/download/{fileId}` 只允许存在于共享 File SDK 作为本地开发或强敏感代理回退；业务页面不得自行拼接。
- 业务模块禁止直接导入腾讯云 COS SDK、拼接对象 Key、发放永久密钥或自行实现下载授权。
- 禁止提交阶段触发器、一次性补丁脚本、运行时上传/导出产物和本地密钥。

## 3. 阻塞与外部验收账本

这些事项不能在无正式云资源和学校真实数据的 GitHub Actions 中伪造为“已验证”，但不会阻塞其它施工：

1. **真实 COS 端到端**：需配置一个私有测试桶、最小权限 CAM/STS、CORS、生命周期和服务端加密，执行 50MB/500MB 文件分片、暂停恢复、应用重启后下载、预签名过期和跨租户拒绝。
2. **浏览器 SDK 制品**：当前管理 PC 固定加载腾讯官方 `cos-js-sdk-v5@1.10.1` 浏览器制品；正式上线前优先下载到同源静态目录并配置 CSP/SRI，避免学校网络无法访问公共 CDN。
3. **大文件跨会话续传**：当前 SDK 支持同页面任务暂停/恢复；浏览器关闭后的 UploadId 持久化恢复尚未用真实 COS 证明，不标记为完成。
4. **真实容量成本**：GitHub Actions 只验证容量统计、增长预测和硬限额逻辑；实际 COS 存储类型、请求次数、流量和地域价格必须以腾讯云账单验证。
5. **教务剩余迁移范围**：学籍名册主链已迁移，注册归档、未注册名单、成绩、课表、模板文书和证明材料仍需按调用扫描逐项接入，不能因名册成功就宣称阶段 7 全量完成。

## 4. 正式环境配置检查

- COS 桶必须私有；禁止匿名读写。
- 永久 SecretId/SecretKey 只存在服务器密钥管理或环境变量，不进入前端、仓库、日志和任务 JSON。
- STS 仅允许单个 `quarantine/{tenantId}/.../{uuid}.{ext}` 精确 Key，时长默认 900 秒。
- CORS 仅开放实际学校域名和必要方法；暴露 `ETag`、`Content-Length`，不使用生产环境 `*` 来源。
- quarantine、rejected、preview、export 设置短生命周期；archive 按学校策略长期保存或沉降低频存储。
- clamd 仅容器内部网络或 Unix Socket，不暴露公网；扫描服务异常 fail-closed。
- file-scan-worker 与 file-governance-worker 由进程守护启动，健康检查、重启和积压告警可见。
