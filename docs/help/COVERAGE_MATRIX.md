## 状态定义

- **已发布**：已进入 clean / verified runtime，具备专项合同或代码证据，可出现在搜索、本页帮助或帮助中心。
- **部分覆盖**：已有正式帮助，但真实学校、真实设备或特殊业务组合仍需运营验收；不把外部验收缺口写成“系统功能已完成”。
- **隔离**：历史内容未重新验真，不进入正式运行时。

## 仍需真实运营证据，而不是继续编帮助文案

1. 不同学校真实角色与数据范围组合的人工验收；
2. 微信真机、弱网、隐私授权、系统 WebView 差异；
3. 可视化 HTML 与真实页面截图的隐私/版本持续复核；
4. 人工客服/工单升级闭环；
5. 通过搜索无结果和 NOT_HELPFUL 数据持续发现知识缺口。

这些属于上线实施和持续运营，不应通过复活旧帮助或虚构功能来“补齐覆盖率”。
