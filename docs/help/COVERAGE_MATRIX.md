状态定义：`已核验内容存在` 表示运行时已有对应帮助且有代码或页面证据；`部分覆盖` 表示已有内容但缺少真实角色验收或完整排障；`待建设/待核验` 表示当前证据不足。

> Markdown 草稿不等于产品已发布；静态代码核验也不等于真实学校角色验收完成。

## 第三阶段收口（2026-08-07）

本阶段已按真实系统页面核验并接入 7 张系统管理高频任务卡：教职工账号与角色、角色权限与数据范围、组织结构初始化、学生 Excel 导入、导入错误与回执、访问权限排查、账号异常排查。新增内容进入运行时帮助模型，不另建第二套 Markdown 正文。

当前仍不得宣称完成的项目：真实学校管理员端到端验收、忘记密码/统一认证差异、学期与年级主数据、小程序帮助入口、跨模块统一导出，以及逐业务错误码与异常状态机。
