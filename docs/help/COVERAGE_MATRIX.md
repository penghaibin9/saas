# P0 帮助覆盖矩阵

状态定义：`已核验` 表示运行时存在且有代码或资产证据；`部分覆盖` 表示已有内容但缺少真实角色验收或完整排障；`待建设/待核验` 表示当前证据不足。

> Markdown 草稿不等于产品已发布。

| 优先级 | 高频任务 | 主要角色/端 | 当前判断 | 关键缺口 |
|---|---|---|---|---|
| P0 | 学校首次开通配置顺序 | 学校管理员 / PC | 部分覆盖 | 仅有治理草稿，尚未核验运行时入口和试点验收 |
| P0 | 首次登录、修改密码、忘记密码 | 全部用户 / 多端 | 部分覆盖 | 多端入口、短信/统一认证差异和异常码未统一 |
| P0 | 创建部门、专业、年级、班级和学期 | 学校管理员 / PC | 待建设 | 需按真实配置顺序拆解并验证权限 |
| P0 | 创建教师账号并分配角色 | 学校管理员 / PC | 待建设 | 账号、角色、数据范围需分层说明 |
| P0 | 看不到菜单、按钮或学生数据 | 管理员、教师 / PC | 部分覆盖 | 治理草稿尚未进入运行时真值 |
| P0 | 新增一名学生 | 学籍管理员 / PC | 部分覆盖 | 需核验入口、字段和重复规则 |
| P0 | 微信扫码采集学生资料 | 管理员、学生 / 多端 | 部分覆盖 | 需真实设备、有效期、重复提交和隐私验证 |
| P0 | Excel 批量导入学生 | 学籍管理员 / PC | 部分覆盖 | 模板版本、预校验、错误行和回滚需实测 |
| P0 | 导入失败、重复学生和错误行处理 | 学籍管理员 / PC | 部分覆盖 | 缺按错误类型的诊断树和真实样例 |
| P0 | 培养方案到课程、教学班配置顺序 | 教务 / PC | 已核验内容存在 | 仍需真实角色确认按钮和状态 |
| P0 | 排课、选课、成绩录入和发布 | 教务、教师 / PC | 已核验内容存在 | 正式发布不可变、退回和异常路径需强化 |
| P0 | 学工申请、审核、退回和归档 | 学工、辅导员 / 多端 | 已核验内容存在 | 移动端入口和跨业务差异需验证 |
| P0 | 岗位实习完整流程 | 管理员、导师、学生 / 多端 | 已核验内容存在 | 企业角色、移动端和正式归档证据需补齐 |
| P0 | 实习打卡、周报、请假和异常处置 | 导师、学生 / 多端 | 已核验内容存在 | 弱网、补卡、退回和消息到达需实测 |
| P0 | 毕业设计完整流程 | 管理员、导师、学生 / 多端 | 已核验内容存在 | 学生端与教师移动端入口需验证 |

| P0 | 查询、筛选、导出和导出结果 | 管理员、教师 / PC | 待建设 | 需统一异步导出、数据范围、脱敏和失败恢复 |

## 近期施工顺序

1. 权限/数据范围、账号登录、组织初始化、导入错误、统一导出；
2. 四大业务的退回、失败、正式发布和恢复路径；
3. 教师与学生小程序；
4. 搜索无结果统计、文章反馈和按版本发布。
