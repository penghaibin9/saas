# 如何批量导入学生

## 这篇帮助能解决什么

使用系统当前版本的 Excel 模板批量建立学生主档，并安全处理校验失败、重复学生、组织不存在和部分成功等情况。

## 适用角色与端

- 适用角色：学校管理员、学籍管理员。
- 适用端：学校管理 PC。

## 操作前准备

1. 院系、专业、年级和班级已经建立并核对编码或名称；
2. 当前账号具有学生导入权限和目标组织的数据范围；
3. 已明确学号、证件号、手机号等字段的唯一性要求；
4. 已备份原始花名册，并保留不可修改的原始版本；
5. 已确定本批数据负责人和错误处理人；
6. 首次导入先用少量测试数据验证，不直接一次导入全校。

## 常见入口

> 正式发布前必须核验当前部署版本的菜单、模板名称和导入按钮。

常见入口（以当前部署版本为准）：进入学生主档或学生管理页面，找到批量导入入口。

## 操作步骤

### 步骤 1：下载系统最新模板

必须从当前导入页面重新下载模板。不要继续使用微信群、邮件附件或个人电脑里保存的旧模板。

**正确结果：** 获得当前版本模板，字段标题、示例、必填说明和选项与导入页面一致。

### 步骤 2：保留模板结构并填写数据

填写时遵守：

- 不修改工作表名称和表头；
- 不合并单元格；
- 不在数据区域增加说明行、空标题或汇总；
- 学号、证件号、手机号等按文本处理，避免科学计数法和前导零丢失；
- 日期使用模板要求的格式；
- 枚举值使用系统允许的正式名称或编码；
- 组织名称或编码必须与系统已有数据一致；
- 删除公式、批注和外部链接后再上传；
- 一行只代表一名学生。

**正确结果：** 模板结构未改变，每一行数据都能对应到唯一学生和唯一组织。

### 步骤 3：在本地进行首次清理

上传前至少检查：

1. 学号是否重复；
2. 证件号是否重复或格式错误；
3. 姓名是否为空或含多余空格；
4. 院系、专业、年级、班级是否存在；
5. 手机号和日期格式是否正确；
6. 是否混入标题、合计、备注或空行；
7. 是否包含不应上传的额外敏感信息。

**正确结果：** 明显错误在上传前已经清理，减少反复试错和错误数据。

### 步骤 4：上传并执行预校验

选择文件后先查看系统返回的总行数、可导入数、错误数、重复数和警告信息。

如果系统提供“预校验”和“确认导入”两个阶段，不要跳过预校验。

**正确结果：** 系统没有直接写入正式数据，先明确显示本批数据的校验结果。

### 步骤 5：处理错误行

下载或记录错误行，按错误原因修改。只处理失败行，不要在不清楚结果时把全部数据再次上传。

常见错误：

| 现象 | 常见原因 | 处理方式 |
|---|---|---|
| 班级不存在 | 组织未建立、名称不一致或层级错误 | 核对系统组织，先补组织或修正模板 |
| 学号重复 | 系统已有学生或模板内部重复 | 查询已有主档，确认是更新还是删除重复行 |
| 证件号格式错误 | 位数、字符、空格或 Excel 格式问题 | 按学校规则核对并改为文本格式 |
| 必填字段为空 | 表头错位、公式返回空或确实缺失 | 填写真实值，不用随意占位 |
| 枚举值无效 | 性别、状态等写法不在系统选项内 | 改用模板说明中的允许值 |
| 无权导入该班级 | 当前账号数据范围不足 | 由学校管理员调整授权或换有权账号处理 |

### 步骤 6：确认导入范围

确认本次将新增、更新、跳过或拒绝多少条数据。若页面没有明确说明更新规则，不要假设重复数据会自动覆盖。

**正确结果：** 操作人知道本次导入将影响哪些学生，能够接受并追踪结果。

### 步骤 7：执行导入并保存结果

确认后执行导入，保存批次编号、操作时间、成功数、失败数、错误文件和操作人信息。

**正确结果：** 页面明确显示导入完成状态，成功、失败和跳过数量相加与处理总数一致。

### 步骤 8：导入后抽查和对账

至少按不同院系、专业、班级抽查学生，并核对：

- 学号、姓名和证件信息；
- 组织归属；
- 学籍状态；
- 学生账号；
- 教师数据范围；
- 成功数、失败数和原始行数。

**正确结果：** 导入结果可在学生列表查询，抽查无错班、重复、漏导或越权可见。

## 不要这样处理

- 不要反复上传同一完整文件来碰运气；
- 不要删除已有学生后重新导入来规避重复校验；
- 不要把错误行混回原文件后再次全量导入；
- 不要随意修改模板表头或工作表名称；
- 不要用虚假证件号、手机号占位正式唯一字段；
- 不要通过公开群聊传递含敏感信息的花名册。

## 完成后的正确结果

- 成功学生只存在一份主档；
- 组织归属和学籍状态正确；
- 有权限的老师能够看到，其他老师不能越权查看；
- 导入批次和错误结果可追溯；
- 失败行能够单独修复后重新导入。

## 常见问题与排查

### 上传后没有任何数据

检查文件格式、工作表名称、表头、数据起始行、隐藏行列、公式结果和文件是否损坏。重新下载最新模板做最小样例验证。

### 显示成功，但列表中看不到学生

检查当前学校、组织、年级、班级、学籍状态、筛选条件和数据范围。清除筛选后用学号查询。

### 部分成功后能否把原文件再导入一次

不建议。先确认系统对成功行和重复行的处理规则，优先下载失败行，仅修复失败记录后重新导入。

### 可以用导入来批量修改已有学生吗

只有当前页面和模板明确支持“更新”时才可以。未明确支持时，应按新增导入处理，不要假设会覆盖正式数据。

### 导入耗时很长怎么办

不要重复点击。先查看是否已经生成导入任务、状态或结果记录；确认没有运行中的任务后，再由管理员或售后排查文件规模、队列和服务状态。

## 权限与数据范围

- 导入属于高风险批量写操作，应只授予明确的学籍维护人员；
- 导入前后应记录操作人、文件、批次、时间、成功数和失败数；
- 数据范围不足时不得通过临时授予全校超级权限长期解决；
- 导入文件应按学校数据安全要求保存和销毁；
- 下载错误行时同样要防止个人信息外泄。
