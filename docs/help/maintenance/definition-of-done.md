# 帮助条目完成定义

帮助条目不能仅因为“文字已经写了”就标记为已发布。

## P0 必须项

- [ ] ID 唯一且稳定；
- [ ] 标题使用用户任务语言；
- [ ] 适用角色和端明确；
- [ ] 入口与当前版本一致；
- [ ] 前置条件明确；
- [ ] 步骤经过目标角色真实点击；
- [ ] 完成后的正确结果明确；
- [ ] 权限和数据范围说明准确；
- [ ] 至少覆盖一个常见失败或退回路径；
- [ ] 涉及正式发布、归档或成绩真值时说明不可逆影响；
- [ ] 相关路由、文章和资产链接有效；
- [ ] 不包含真实账号、密钥或个人信息；
- [ ] 内容负责人和复核日期已记录；
- [ ] 自动校验通过；
- [ ] 复核证据可以追溯到 PR、测试记录或验收记录。

## 资产附加项

### 可视化 HTML

- [ ] 与当前业务状态机一致；
- [ ] 不把规划能力画成已上线能力；
- [ ] 不包含真实姓名、手机号、身份证号等信息；
- [ ] iframe 沙箱策略满足需要；
- [ ] 移动端和窄屏可阅读。

### 操作截图

- [ ] 来自固定测试租户和测试账号；
- [ ] 一张图只说明一个步骤；
- [ ] 隐私已脱敏；
- [ ] 文件名可追溯到文章和步骤；
- [ ] 页面版本变化时重新复核。

## 状态转换

- `draft → reviewed`：完成内容和真实路径复核；
- `reviewed → published`：进入运行时真值并通过自动校验；
- `published → stale`：功能、路由、字段、权限或图片已变化；
- `stale → published`：重新验证并记录证据；
- `* → archived`：已被替代且所有入口已迁移。
