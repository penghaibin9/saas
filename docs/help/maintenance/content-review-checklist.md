# 帮助内容发布复核清单

文章从 draft 进入 reviewed 前必须检查：

## 页面一致性

- 菜单入口与当前版本一致；
- 按钮名称与页面一致；
- 页面截图来自当前版本。

## 业务正确性

- 适用角色正确；
- 前置条件完整；
- 状态流转无误；
- 退回和异常路径已说明。

## 数据安全

- 无真实学生信息；
- 无真实教师账号信息；
- 无企业联系人隐私；
- 导出示例已脱敏。

## 维护信息

- 有文章 ID；
- 有负责人；
- 有复核日期；
- 有适用版本。

## 图片检查

- 一图一个步骤；
- 标注清晰；
- alt 文本存在；
- 原图和发布图分离管理。
