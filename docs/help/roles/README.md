# 按角色找帮助

帮助中心不直接按菜单展示，而按用户职责提供入口。

## 角色入口

- 学校管理员：开通配置、组织权限、账号管理、数据维护。
- 教务人员：培养方案、教学任务、成绩与教学流程。
- 学工人员：学生事务、审批、风险和档案。
- 辅导员/班主任：学生跟进、提醒、异常处理。
- 任课教师：教学任务、学生数据和待办处理。
- 实习指导教师：实习过程指导、周报、异常和评价。
- 毕业设计指导教师：选题、过程审核、材料和答辩。
- 学生：申请、提交材料、查看进度和接收通知。

每个角色入口后续必须绑定：

- 高频任务卡；
- 对应端（PC/小程序）；
- 权限前置条件；
- 常见问题。
