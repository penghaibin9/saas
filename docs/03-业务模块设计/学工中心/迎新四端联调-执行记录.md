# 迎新与住宿四端联调记录

更新：2026-09-06。本记录接续《迎新与住宿统一流程-教师PC规划》，其中上一轮“后端待统一、小程序未修改”的描述为历史状态，以本记录的新证据为准。

## 业务主线

1. 教师 PC 准备迎新批次、报到环节、新生名单和房源。名单必须关联学生主档，未关联者先补关联，不能用迎新记录编号代替学生编号分床。
2. 学生 PC / 小程序激活账号，补充资料、到校信息、提交材料和绿色通道申请。教师在原业务审核入口处理同一申请。
3. 教师在统一分配计划中准备名单、生成方案、处理冲突、人工调整并发布。发布产生床位预留；学生两端查看同一住宿安排。设置报到后公布的床位，在公布条件满足前不显示地址和床位编号。
4. 学生出示报到凭证；教师 PC 或教师小程序预检、核验并确认现场报到。材料、缴费、住宿的后续办理与现场报到分开，不把现场报到直接视为入学完成。
5. 宿管在房态图选床办理实际入住。已有预留须核对预留学生；不能把预留显示成已入住。调宿、退宿走原正式业务，成功后同步迎新住宿展示。
6. 学生报到后仍能补交材料。教师在“资格与入学确认”或教师小程序“迎新办理”查看缺项，条件齐备后确认入学。
7. 学校管理员处理未到校、取消、延期或恢复报到。未到校/取消释放合法预留；延期保留预留；已实际入住须先走正式退宿。
8. 批次内全部学生已确认入学或已完成未到校/取消处置，才可关闭批次；关闭后生成逐生归档快照，重复执行不重复归档。
