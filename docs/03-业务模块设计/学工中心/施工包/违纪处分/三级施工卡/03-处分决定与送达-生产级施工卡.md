## 3. 真实业务结果与边界

- **谁做什么**：EFFECTIVE 后辅导员生成/打印处分决定书，线下送达学生并登记送达回执(时间+回证 file_id)；学生移动端可签收(留痕，不改效力)；超时未回执催办。
- **进入**：案件 EFFECTIVE。**退出**：送达回执登记完成(EFFECTIVE 留痕不改状态)。
- **上游**：审批(02)生效；**下游**：考察期计算(04)、台账(06)、归档。
- **本卡完成**：`/deliver` 端点 + delivered_at/回执列(Alembic) + 决定书打印(未接打印管线则该子项 partial 记欠账) + 学生签收留痕 + 7 日无回执催办。
- **不做**：决定书事实模板库(V2)。
- **仅学校可决定**：送达方式枚举与启用、送达超时天数(默认 7)、决定书文号规则、本人是否可见事实明细。
