## 3. 真实业务结果与边界

- **让谁完成什么**：学生（移动端）或辅导员/资助老师代受理，提交家庭经济信息+致困类型+材料，进入四级评审。
- **进入条件**：批次 OPEN、时间窗内、该生本批次无在途申请。**退出条件**：进入 CLASS_REVIEW（评审卡接手）。
- **上游**：认定批次(OPEN)、学生主档 StudentProfile。**下游**：认定审核卡；家庭经济供 reveal。
- **本卡必须完成**（代码阶段）：申请列表(脱敏)独立页 + 受理表单(致困类型/是否低保/材料附件) + 详情(脱敏+reveal 入口) + 字段契约统一。
- **明确不做**：家庭经济 OCR、民政核验（backlog）。
- **仅学校可决定**：致困类型枚举本校口径、材料必传项、是否允许辅导员代受理。
