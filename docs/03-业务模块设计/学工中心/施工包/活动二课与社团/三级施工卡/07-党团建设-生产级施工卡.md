## 3. 真实业务结果与边界

- 让**学校党委/组织委员**登记学生入党发展阶段台账(材料+时间节点)，做时长规则校验与阶段推进，正式党员后回写政治面貌。
- 进入条件：有 `studentAffairs.league.*`(党委/组织委员)。退出：FULL_MEMBER。
- 上游：学生主档、`t_file_object`(材料)。下游：政治面貌经更正接口回写主档；进 360(仅"存在发展阶段"摘要，不进材料明细)。
- 本卡完成：`t_affairs_league_dev`(一生一条)+`t_affairs_league_dev_stage`(阶段流转) + 阶段登记/推进/材料/政治面貌回写。
- 不做：组织生活全流程(会议/党费/三会一课)；智慧团建深度对接(若学校有则只读镜像，待定)。
- 学校决定：**各阶段材料清单与时限(如积极分子≥1年)、审批层级、是否对接智慧团建/智慧党建、回退权限归属**。

## 6. 主流程、异常流程与状态机

阶段：`APPLICANT→ACTIVIST→DEVELOPMENT→PROBATIONARY→FULL_MEMBER`(只进不退)。
- 主流程：登记(材料+时间)→时长规则校验(如 ACTIVIST≥1年,学校配)→上级确认→推进→FULL_MEMBER 后回写政治面貌(走学生中心更正接口)。
- 异常：跳级推进→409;时长不足→422;回退→需党委权限+reason≥5+审计;越权→403;政治面貌直写主档→**禁止**(必须走更正接口)。

检查：材料明文防试探(无权限整段不返回)、越权、跨租户、政治面貌禁直写、材料附件校验。

**权限码归口（§A）**：本卡 `studentAffairs.league.view / register / advance / reveal / export` 属 13A §12 **未列**的活动二课细分域，登记为「§12 授权矩阵待扩展（活动二课细分）」，施工前须由权限总控/§12 正式扩展补入再种 RBAC。政治面貌走学生中心更正接口回写，不直写主档。菜单键 `menu:studentAffairs:activities` 为 navPlan 命名，非动作码。

**审计表分流（§B，重敏感）**：业务动作 LEAGUE_*（登记 register）/ LEAGUE_ADVANCE（阶段推进）/ LEAGUE_POLITICAL_UPDATE（政治面貌回写，另叠加学生中心更正接口自身审计）→ `t_affairs_audit_trail`；**党团发展材料明文查看 `reveal`（LEAGUE_MATERIAL_VIEW）→ `t_security_audit_log`**（SENSITIVE_VIEW，原因≥5字+最小授权）；越权拒绝 → `t_security_audit_log`；**材料/名册导出 = 双写**（`t_affairs_audit_trail` 记发起 + `t_security_audit_log` 记敏感导出+水印，敏感材料默认剔除）。

**SEC-5（真实缺陷·未实现·三段式，重敏感域）**：现状本域后端端点仅 `Depends(require_staff)`（`backend/app/core/security.py` L97-103），**无 `studentAffairs.league.*` / `reveal` 细粒度强校验**——党团材料属高敏感，仅 `require_staff` 无法拦截明文试探；§2 grep 实证本卡端点整体 `missing`。本卡 §7/§9 已给应校验权限码（**设计**），属**编码阶段待实现项，本轮未落地**，不得记为已实现端点；施工时 `reveal`/材料查看须最小授权 + 原因 + 无权限整段不返回 + 六要素强校验，**严禁停留在 `require_staff`**。
