## 3. 真实业务结果与边界

- **让谁完成什么**：资助老师受理学费减免（孤儿/建档立卡/特困）与临时困难补助（突发疾病/家庭变故）；简链审批（辅导员核实→资助/学工处审定，学院评审可配跳过）；发放。
- **进入条件**：批次 OPEN + 事由充分（佐证）。**退出**：GRANTED/REJECTED/RETURNED/CANCELLED。
- **上游输入**：困难库等级（可选前置，减免类可强制）；学籍。**下游**：发放台账（卡 07）、360。
- **本卡必须完成（恢复代码时）**：解除两类 V1 硬拦；节点链支持"COLLEGE_REVIEW 可配跳过"（简链）；佐证附件；发放记 result。
- **明确不做**：绿色通道完整流程（只引用迎新 `t_orientation_green_channel`，backlog）；减免自动核算学费（依赖财务，backlog）。
- **仅学校可决定**：减免比例档次（全免/半免）；临补额度；是否走学院评审（简链开关）；是否困难库前置。

## 4. 页面/工作区与交互规格

复用工作台（project_type 过滤 TUITION_REDUCTION/TEMPORARY_AID）。受理弹窗：事由（textarea 必填）+ 佐证附件 + 金额（减免可为减免额/临补为补助额）。简链模式下详情不显示学院评审节点。三态同卡 01。
