## 3. 真实业务结果与边界

- **让谁完成什么**：资助老师/学工处/校院领导看五指标看板——① 资助覆盖率（受助人数/在校人数）② 资助金额汇总（按类型/学院/年度）③ 困难生受助率（受助困难生/困难库人数）④ 勤工在岗人数 ⑤ 贷款在贷人数/金额；指标可下钻脱敏名单，支撑上报与决策。
- **进入条件**：有 result 台账数据。**退出**：只读看板。
- **上游输入**：result 台账（卡 07）、application（各态计数）、困难库（卡 02 引用）、勤工在岗（卡 03）、贷款在库（卡 04）。**下游**：Excel 汇总导出、上级上报。
- **本卡必须完成（恢复代码时）**：`/funding/stats` 聚合端点（按 scope 过滤）；五指标看板页；指标下钻脱敏名单；汇总与 result 台账 0 差异（对账）。
- **明确不做**：跨年度趋势预测（backlog）；与财务系统对账（backlog）。
- **仅学校可决定**：上报指标口径与维度；覆盖率分母（在校/在籍/资助范围）；领导可见指标范围。
