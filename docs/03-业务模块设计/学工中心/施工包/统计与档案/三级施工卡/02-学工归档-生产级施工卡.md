## 3. 真实业务结果与边界

- **谁完成什么**：学工处建批次+确认归档+全校下载；学院完整性审查（通过/退回）+本院下载；辅导员本班缺件补传（见 03 卡）。
- **进入条件**：登录+STUDENT_AFFAIRS+对应 archive key。
- **退出条件**：批次到 ARCHIVED（只读保管）。
- **上游输入**：各域终态数据（收编，只读）；**下游输出**：ARCHIVED 只读档案 + 水印包（t_export_task）+ 360 归档摘要。
- **本卡必须完成**（施工阶段）：`GET /archive/batches`(D-04)、collect 真实缺件计算(D-05)、advance 支持 RETURN+reason≥5(D-08)、SA_CONFIRM 真实水印包(D-06)、4 端点补 permission key + scope(六要素)、ARCHIVED 冻结校验（跨域，评估）。
- **明确不做**：档案包下载/补传（在 03 卡）；含心理专项默认关。
- **仅学校能决定**：①归档触发时点（学年末/学期末/迎评；手动 vs 定时）②contentTypes 默认内容清单 ③审批是否必经学院、是否需校级终审 ④归档保留年限。
