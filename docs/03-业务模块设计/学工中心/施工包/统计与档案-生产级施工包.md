## 5. 业务目标、角色与完整闭环

- **解决的真实问题**：学工中心 B/C 包各业务（请假/困难/奖助/处分/谈话/宿舍/风险）产生分散数据。学年末/迎评/审计时，学校需要①**可核查的学生学工档案**（归档）②**可上报的汇总数字**（统计）。本模块是学工中心**收口件**——把散落业务变成"拿得出的账"与"报得出的数"。
- **购买/管理部门**：学校学工处（归档确认+全校统计）、二级学院学工办（本院完整性审查+本院统计）、辅导员（本班缺件补传+本班切片）。
- **使用角色**：学工处管理员 / 学院学工负责人 / 辅导员（班主任按校配置同辅导员）；心理老师仅在含心理专项时按 `PSY_STUDENT` 授权参与（默认不参与）。校/院领导只读统计驾驶舱（下钻二次鉴权）。
- **发起/处理/审核/查看/归档责任**：学工处发起批次并终态确认（ARCHIVED）→ 系统 collect 生成档案包+缺件 → 辅导员补传 → 学院完整性审查（通过/退回）→ 学工处确认归档并生成水印包 → 处/院按范围下载。统计为只读，各角色按数据范围看不同切片。
- **主流程**：见 §7 状态机。
- **异常/撤回/退回/重复/超时/关闭/重开**：collect 幂等（同生不重复建包，`affairs_archive_service.py` L70-74 dup 检查）；advance 非法状态→409（L92-93）；审查退回→回 COLLECTING 补缺；ARCHIVED 只读冻结（**设计目标**，现代码未拦截业务表写，见 §16 缺口）。
- **与其他模块的输入输出关系**：见 §5.1。

### 7.2 档案包状态机（`ArchivePackage.status`，model L37-38）

`PENDING_GEN → PENDING_SUPPLEMENT → SUBMITTED → ARCHIVED`（异常分支 `RETURNED`），**随批次流转**（回链 batch_id）。当前代码：collect 建包=PENDING_GEN，advance 到 ARCHIVED 时批量置 ARCHIVED（L110-111）。中间态 PENDING_SUPPLEMENT/SUBMITTED/RETURNED **枚举已定义但流转逻辑未实现**（补强项）。

### 7.3 统计（无状态机 —— 只读聚合）

统计为只读查询，无状态流转。数据实时聚合各域 stats。**无需状态机**，理由：不产生/不修改业务数据。仍须覆盖：空数据（显示 0 不显示 undefined/Invalid Date）、error/no-permission 三态、重复请求幂等（GET 天然幂等）。

### 10.2 继承的硬规则（务必落到每张卡）

- **两层授权**（§8A）：平台→学校模块授权（STUDENT_AFFAIRS）；学校→角色授权。未授权模块菜单不显示；已授权无权限→有菜单无按钮/403。
- **六要素判定**（§8A.1 / §17 L775）：激活角色+模块授权+权限key+数据范围+业务关系+资源状态，**后端最终裁定，前端隐藏≠授权**。当前归档 4 端点仅 `require_staff`——**六要素严重不足，施工必补**。
- **数据范围**（§8）：处=ALL、院=COLLEGE、辅=CLASS/ADVISOR、心理=PSY_STUDENT。每个读/写接口 scope 过滤来自 `t_teacher_student_scope`（封装 `getStudentAffairsScope`）。
- **敏感统一控制**（§10.1 L522-531）：脱敏默认；完整值需授权+原因≥5+二次确认+水印+审计+导出留痕（`t_export_task` 用途≥5）。
- **心理红线**（§10.2 L536）：心理明细任何导出**强制剔除，默认锁死学校不可改**；不输出诊断结论；无权限区块整段不返回（防试探）。归档包/统计导出默认无心理明细。
- **拒绝码**：401/403/404/409/422/429（见 §9）。
- **审计表分流**（冻结规范 B，两表各司其职，非冲突/非二选一）：
  - **业务流转** → `t_affairs_audit_trail`（域 `AffairsAuditTrail`，biz_type="ARCHIVE"）：BATCH_CREATE / COLLECT / ADVANCE(APPROVE/RETURN) / ARCHIVED 及创建、提交、审核、退回、状态变化。
  - **敏感/明文/导出/下载/越权** → `t_security_audit_log.record()`：SENSITIVE_VIEW（查看脱敏明文/心理·困难·处分明细/完整姓名联系方式）、DOWNLOAD（归档包下载）、EXPORT（统计/台账导出）、越权拒绝——记 who/when/what/why/租户/数据范围快照/责任快照/水印/原因≥5。
  - **双写**：确认归档→下载/导出归档包 = 业务动作写 `t_affairs_audit_trail`（记发起）+ 敏感动作写 `t_security_audit_log`（记敏感导出+水印+原因+sha256，另入 `t_export_task`）。

> 注：SEC-1（campus-service mental-records 涉密直返）/SEC-2（风险心理白名单含 STUDENT_AFFAIRS_ADMIN）/SEC-3（家庭经济 income_encrypted 明文）/SEC-4（宿舍异常回写 student_id=0）归属心理关注/风险/困难认定/宿舍等域，本模块仅作**跨域只读聚合下游**（读取来源清单见 §5.1，只读不重算），不承接其修复，但统计/归档消费上述数据时须遵守其脱敏与心理剔除红线（D-09）。
