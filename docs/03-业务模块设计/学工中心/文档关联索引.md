## 2. 跨模块依赖与只读边界

| 依赖项 | 来源 | 本中心规则 |
|---|---|---|
| **学生主档** | `student_service`、`StudentDetailView` | **本中心可写学工域表**；主档字段变更须走学生主档流程 |
| **教师身份** | 系统用户/组织 | **不得**重复建教师账号体系；辅导员范围来自班级绑定 |
| **权限** | 系统管理 00-权限总控 | 后端 `authz` 必校验 |
| **教务成绩/预警** | 教务 `t_acad_*` | **只读**引用；不得在学工重复录成绩 |
| **文件/工作流/审计** | 平台底座 | 统一服务，不得 mock |
| **数字迎新** | [数字迎新中心](../数字迎新中心/README.md) | 菜单属学工二级；代码可 `orientation` 模块 |

**允许写入**：`frontend/src/views/admin/student-affairs/`、`frontend/src/modules/orientation/`、`backend/app/api/v1/student*.py`、`campus_service`、`orientation.py`、学工 models/services/tests

**禁止重复建设**：教务学籍/成绩、实习企业库、毕设流程、系统 RBAC 核心表
