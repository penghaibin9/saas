# 13A 学工中心 D 包-上线补强与商业增强施工卡

> D 包面向正式上线和商业化演示，包含心理健康安全红线、统计归档、移动端补齐，以及数字迎新公共底座补强专项。本文档是施工卡，不是实现记录。

## 1. D 包范围

| 模块 | 优先级 | 目标 |
|---|---|---|
| 心理健康 | P0 | 授权查看、危机干预、转介随访闭环；不做诊断 |
| 学工归档 | P0 | 形成学生学工档案包、归档审计、导出申请 |
| 学工统计 | P0 | 指标库、报表、导出、学院/校级统计 |
| 小程序学工入口 | P1 | 学生/教师高频入口，不替代 PC 管理 |
| 数字迎新公共底座补强 | P1 | 只补迎新既有页面日期/Excel/导出底座欠账 |
| 学生活动、第二课堂 | P1 | 报名、签到、认定、积分、申诉 |
| 社团与学生组织、党团建设 | P2 | 组织、成员、换届、推优、材料 |
| 辅导员考评、学院驾驶舱、在校服务 | P2 | 考评、领导驾驶舱、服务入口承接 |

## 2. 心理健康安全施工卡

| 项 | 内容 |
|---|---|
| 页面 | 预约 `/psych/appointments`；筛查摘要 `/psych/screening-summary`；危机干预 `/psych/crisis`；转介随访 `/psych/referrals-followups` |
| 红线 | 不生成、不展示“诊断结论”；只能记录预约、评估摘要、干预动作、转介、随访、结案 |
| 用户 | 心理老师、授权辅导员摘要、学院/学工处督办摘要、校领导汇总 |
| 状态机 | reported/appointed/assessed/intervention/referral/followup/closed |
| 权限 | 心理老师按授权学生；辅导员默认只看风险等级和待办，不看咨询原文；校领导看汇总 |
| 审计 | 每次查看、解锁、导出、转介、关闭均写审计；敏感查看必须有 reason |
| 导出 | 默认排除咨询原文、量表明细、危机细节；导出仅摘要和状态 |
| 联动 | 可向风险预警输出“心理授权摘要/风险等级/待办”，不得把原文写入普通风险详情 |
| 验收 | 未授权 403；授权过期不可看；导出无敏感原文；危机处置全链路可追溯 |

D 包上线前必须复核：心理敏感权限、归档版本、统计口径、导出审计、小程序端权限、数字迎新公共底座、公共组件复用。任何计划中、部分完成、外链/过渡状态不得写成已完成。

## 11. D 包第一层：生产级设计（心理 / 归档 / 统计 / 小程序 / 迎新底座）

### 11.1 心理健康生产级红线（10 条强制）

| 序号 | 规则 | 开发动作 | 验收 |
|---|---|---|---|
| 1 | 不做诊断 | 页面/接口/导出禁止出现「诊断结论」「病症判定」字段 | 全文检索无诊断词 |
| 2 | 不展示诊断结论 | 只展示预约、评估摘要、干预动作、转介、随访、结案 | 辅导员默认只见摘要 |
| 3 | 心理明细强权限 | `t_affairs_psych_authorization` 控制可见学生与字段级权限 | 未授权 403 |
| 4 | 授权过期自动失效 | 授权表 `expire_at`；过期后接口返回 403，前端隐藏 | 过期后刷新不可见 |
| 5 | 查看必须写审计 | 每次查看、解锁、导出写 `t_affairs_audit_trail` + reason | 审计链完整 |
| 6 | 导出默认不含咨询原文、量表明细、危机细节 | 导出列白名单；`AppExportConfirm` 二次确认 | 导出文件抽检 |
| 7 | 危机干预必须闭环 | reported→assessed→intervention→referral/followup→closed | 状态不可跳跃 |
| 8 | 转介、随访、结案必须留痕 | 每次动作独立记录 + 附件可选 | 时间线可追溯 |
| 9 | 普通辅导员只看授权摘要 | 风险/画像只显示等级、待办，不含原文 | 辅导员角色实测 |
| 10 | 校领导只看汇总 | 驾驶舱只有数量/趋势，无个人明细默认 | 下钻二次鉴权 |
