## 使用说明（给 Claude Code）

1. 先读差距矩阵对应行的 **KEEP / STRENGTHEN / MISSING**。  
2. 打开该三级施工卡：按 **保留项** 不动，只做 **补强/新建项**。  
3. 禁止改学工施工包、禁止改业务代码范围外的共享文档（本轮已只做文档）。  
4. 代码阶段优先：PC `/archive` `/stats` `/plans` `/guidance-plans` 接线；实习销假/超期未归新建；指导教师 user_id。
