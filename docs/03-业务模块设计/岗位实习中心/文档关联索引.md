## 2. 跨模块依赖与只读边界

| 依赖项 | 来源 | 规则 |
|---|---|---|
| **学生主档** | 学工/学生服务 | 实习学生绑定读主档；不得平行学生主表 |
| **教师/指导老师** | 用户+业务关系 | 实习指导关系表授权 |
| **企业主数据** | 本中心企业库 | 不得与就业中心重复建企业平行库 |
| **权限** | 系统管理 00-权限总控 | 企业导师外部身份受限 |
| **文件/审计** | 平台底座 | 协议导出、敏感评价需审计 |
| **学工/教务** | 请假、学籍状态 | 只读或接口回调，不重复建设 |

**允许写入**：`backend/app/api/v1/internship*.py`、`backend/app/models/internship.py`、`backend/app/services/internship_*`、`frontend/src/views/admin/internship/`、`miniapp/.../internship/`

**禁止**：学工请假主流程、教务成绩、毕设、学生主档核心 schema 单方面修改
