## 2. Fable5 建议采纳矩阵

### 2.1 采纳：进入生产提升范围

| 能力 | 采纳方式 | 约束 |
|---|---|---|
| 合规红线规则 | 建设可配置、可解释、可审计的规则服务 | 不把政策判断写死在页面；规则命中区分阻断与预警 |
| 岗前安全教育 | 批次规则、课程/材料、学习记录、测验与完成门禁 | 不重复建设通用课程平台；只做实习所需轻闭环 |
| 打卡围栏与可信证据 | 保存精度、距离、围栏判定、照片和异常原因 | 服务端时间为准；原始证据不可覆盖 |
| 打卡风险识别 | 设备复用、低精度、异常时空跳跃等服务端规则 | 只标“疑似/需核验”，不得自动定性作弊 |
| 实习申请实体 | 岗位申请、自主实习、审核、录用、撤回和卡点方 | 与意向、匹配、协议明确边界，禁止用协议状态冒充申请 |
| 报酬与协议条款 | 结构化登记并进入协议、审核和风险提醒 | 金额使用定点数；学校规则可配置 |
| 跨省备案与监管报送 | 备案状态、编号、报送批次、失败重试与审计 | 先确定真实报送规范，不伪造“已上报”闭环 |
| 周报相似度辅助 | 作为教师提示和复核依据 | 不自动认定抄袭；算法、阈值和命中内容可解释 |
| 免实习/豁免 | 独立申请、审批、材料、状态与归档 | 不与普通实习完成状态混用 |
| 企业导师真实评价 | 一次性短期令牌或正式外部身份通道 | 教师代录必须标来源，不能计入真实企业评价率 |
| 成绩等次 | 在现有百分制和权重核算上派生等次 | 唯一权威规则源；发布后变更必须走复核 |
| 实习手册与档案包 | 复用现有归档与文件中心扩展材料清单 | 文件必须真实存在、可鉴权下载、可追溯 |
| 统一状态与文案 | 进入公共常量、状态组件和内容规范 | 不为视觉展示擅自扩大后端状态机 |

### 2.2 调整后采纳

| 原建议 | 调整结论 |
|---|---|
| 小程序检测模拟定位 | 微信小程序无法可靠获得系统模拟定位标志；只保存可获得证据并由服务端做疑似判断 |
| 随机点名 | 可作为可选批次能力；必须有通知、响应窗口、失败原因、申诉和隐私说明 |
| 企业导师免注册 H5 | 可用于低频评价，但令牌必须一次性、短有效期、绑定业务对象并全程审计；高频业务应使用正式外部身份 |
| 学生状态扩为 17 态 | 先画出现状状态迁移图；能用旁路申请/风险状态表达的，不扩主状态 |
| 自动从身份证回填出生日期 | 仅在合法授权、最小化处理和数据质量校验前提下执行；不得在日志或导出暴露完整证件号 |
| 企业省份自动猜测 | 只作为待确认建议值，不能直接成为监管报送权威数据 |
| 工作台指标 | 从各业务服务读取冻结口径，不在页面或工作台重新写 SQL 形成第二套统计 |

## 3. 生产提升施工顺序

### P0：事实和安全收口

1. 校验 PC、小程序与后端全部接口契约，清除悬空调用。
2. 正式构建禁用 mock 和演示凭据，补微信正式认证链路。
3. 增加岗位实习模块授权门禁、角色权限和跨租户负向测试。
4. 更新本文档入口及所有仍会指导开发的旧目录引用。
5. 固化当前测试基线，解决测试超时并接入 CI。

### P1：核心业务可靠性

1. 实习申请与自主实习申请真实闭环。
2. 指导教师用户关系、容量和分配审计。
3. 批次规则唯一来源、版本冻结和历史快照。
4. 销假与超期未归独立状态机及风险联动。
5. 打卡服务端幂等、围栏证据、异常规则和申诉链。
6. 协议版本、报酬条款、附件鉴权和电子签来源核验。

### P2：合规与商业化增强

1. 合规红线规则和安全教育。
2. 跨省备案与监管报送。
3. 企业导师真实评价通道。
4. 周报相似度辅助、成绩等次、免实习。
5. 随机点名、实习手册和档案包增强。

### P3：上线门禁

1. 核心接口、状态机、越权、幂等、并发和附件安全测试全绿。
2. PC 与微信小程序真机 E2E 通过。
3. 完成容量压测、慢查询治理、监控告警、备份恢复和回滚演练。
4. 学校政策决定项形成配置和验收记录。

## 4. 每项需求的开工模板

任何新能力开工前必须按以下顺序填写：

1. 当前代码证据：Model、Service、Router、PC、小程序、Test。
2. 现状分类：`KEEP / STRENGTHEN / MISSING / DROP`。
3. 业务边界：本域负责什么、依赖哪个公共底座、禁止复制什么。
4. 状态机与权限：角色、数据范围、合法迁移、幂等和审计。
5. 数据变更：从当前 Alembic head 生成迁移，不手填历史编号。
6. 跨端契约：接口字段、错误码、空错权、弱网和重试行为。
7. 验收证据：测试命令、结果、页面走查、迁移与回滚。

## 5. 文档优先级

1. 本收口总控：生产提升唯一入口。
2. 当前代码与测试：实现事实和验收事实。
3. `岗位实习中心-施工与验收归档.md`：既有能力历史证据。
4. 原生产级总册与99项矩阵：历史设计参考，冲突时不得覆盖代码事实。
5. 外部对标证据：用于说明需求来源，不直接决定实现。
