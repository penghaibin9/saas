## 第 1 章：产品定位与业务边界

### 1.1 模块解决的真实问题

岗位实习中心支撑职业学校**校外岗位实习全生命周期**：批次与规则、企业与岗位、学生建档与匹配、协议与保险、打卡请假、周报与计划任务、指导巡访、风险处置、评价与成绩、归档与统计，满足教育部《职业学校学生实习管理规定》（教职成〔2021〕4号）合规与学校验收。

### 1.2 主要用户

实习管理员、学院实习负责人、实习指导老师、辅导员、企业导师/联系人（外部）、学生、就业老师（边界）、校领导（只读统计）。

### 1.3 中心边界

| 对象 | 主责 | 不重复建设 |
|---|---|---|
| 学工中心 | — | 学生画像/处分/心理 external-link |
| 教务中心 | — | 学籍、课表、校内实训（非校外实习） |
| 毕业设计中心 | — | 并行闭环，经 student_id 关联 |
| 就业中心 | 实习转就业数据可回流 | **就业跟进菜单不挂实习**（navPlan 2026-07-10 收口）；搜索仍可达 `/admin/employment` |
| 学生主档 | 实习记录、协议、打卡、成绩快照 | 不复制学籍 |
| 系统管理 | — | 权限/流程/文件中心 |

## 第 2 章：成熟商业系统共同核心

> 证据来源：仓库 [设计补强与升级总册 下篇 §1](./06-岗位实习中心设计补强与升级总册.md)（含公开资料提炼 + 老系统 99/internship-backend + 教职成〔2021〕4号）。本轮未独立联网复验。

### 2.1 参考资料 A：工学云·蘑菇丁（公开资料，仓库内提炼）

顶岗流程：计划→双选/自主报备→协议→GPS 签到→周报→批阅→评价→质量报告导出。亮点：学生 App 动线短、质量报告导出。

### 2.2 参考资料 B：习讯云（公开说明书提炼）

三阶段：准备期（计划/协议/保险）→过程期（签到/周报/请假/预警/巡访）→总结期（鉴定/成绩/归档）。亮点：免签到申请、签到积分、备案口径顺。

### 2.3 参考资料 C：校友邦 + 仓库老系统（99/internship-backend）

实践一体化 + 企业导师参与；老系统字段：防作弊打卡、五级申请、协议双状态、五项权重成绩、风险四态、归档五态。

**证据缺口**：无三份完整厂商私有手册原文在仓库；A/B 来自施工文档的公开资料二次提炼。

### 2.4 共同核心（15 项，详见补强总册 §1.6）

批次/计划、双通道安排（校排+自主）、企业资质、三方协议、保险、GPS 打卡+免打卡、周报批阅、请假销假、预警、巡访、评价成绩、归档、统计导出、监管合规材料。

### 2.5 本项目能力 vs 缺口

| 已有 | 缺口 |
|---|---|
| 批次/企业/岗位/学生/匹配/协议实例/打卡/异常/补卡/请假/周报/过程报告/指导/巡访/风险处置/评价/成绩/归档/统计/计划/保险/任务进度 | 五级申请链、自主实习完整链、企业门户、风险**自动**扫描、监管 8h/备案导出、permissionCode、归档 zip 包、navPlan 虚标 I |

### 2.6 禁止假功能

- 无 CA 时电子签仅 INTERNAL 校内签 + 扫描件，不得标「CA 已对接」。  
- 无算法不挂 AI 岗位推荐。  
- 就业跟进不得假装在实习菜单内 implemented（external-link）。

## 第 6 章：端到端完整业务流程

### 6.1 主链（学校统一安排）

```
批次 RUNNING → 企业/岗位入库 → 学生建档 → 意向/匹配 → 落岗 assign
→ 协议生成/下发/三方确认 → 保险核验 → 计划书发布/任务确认
→ 打卡/补卡/请假 → 周报/过程报告 → 指导/巡访
→ 风险处置 → 企业评价/自评/教师评 → 成绩核算发布 → 归档 → 统计
```

### 6.2 关键流程表

| 流程 | 单据 | 审批 | 通知 | 归档 |
|---|---|---|---|---|
| 匹配落岗 | internship_record | 管理员 confirm | 待办 | 分配日志 |
| 协议 | agreement | 三方 confirm + esign INTERNAL | 催签 | 协议 PDF |
| 补卡 | makeup | 导师 approve/reject | — | 留痕 |
| 请假 | leave | 导师 review | — | 附件 |
| 周报 | weekly_report | review pass/return | 催交 remind | 周报台账 |
| 风险 | risk_record | handle/follow/close | 催办 | 处置记录 |
| 成绩 | final_score | publish | — | 成绩档 |
| 归档 | archive | force 可选 | 缺失提醒 | 7 项清单 |

## 第 7 章：状态机总表

### 7.1 实习学生 `InternshipRecord.status`（5 态 + 资格/归档）

典型：PENDING → ACTIVE → … → COMPLETED → ARCHIVED（详见 `internship_student_service`）；调岗/退岗走 `change_request`。

### 7.2 三方协议 `InternshipAgreement.status`

DRAFT → 待学生确认 → 待企业确认 → 待学校确认 → 已生效 → 已归档/作废；电子签 INTERNAL 分支（`esign/start`, `esign/sign`）。

### 7.3 打卡异常 `AttendanceException`

PENDING → HANDLED（合理/异常/转风险）；处理意见≥5字。

### 7.4 周报 `WeeklyReport`

DRAFT/SUBMITTED → PENDING_REVIEW → APPROVED / RETURNED。

### 7.5 风险 `RiskRecord`

PENDING → PROCESSING → CLOSED（含升级 escalate）。

### 7.6 成绩 `InternshipFinalScore`

核算 → 复核 → PUBLISHED（权重来自 `score_config`：打卡/周报/企业/学校等五项）。

> 完整 22 态设计见 [设计补强与升级总册 上篇 §5](./06-岗位实习中心设计补强与升级总册.md)。
