## 中心定位

学籍、注册、培养方案、教学任务、课表、成绩、学业预警、毕业资格预审等教务运行管理；与既有「学业过程」模块（`/admin/academic`）并存，新教务主路径为 `/admin/academic-affairs`。

---

## 真实代码目录

| 端 | 路径 |
|---|---|
| PC 菜单 | `frontend/src/config/navPlan.js` → `academicAffairs` |
| PC 页面 | `frontend/src/views/admin/academic-affairs/` |
| 既有学业过程（复用） | `frontend/src/modules/academic/`、`/admin/academic` |
| 后端 API | `backend/app/api/v1/academic.py`（既有）、`academic-affairs` 新路由（按契约扩展） |
| 模型 | `backend/app/models/academic.py`（`t_acad_grade`、`t_acad_warning` 等） |
| 测试 | `backend/tests/test_academic*.py` |
| 小程序 | `miniapp/src/pages/student/academic-affairs/`、`teacher/academic-affairs/` |

---
