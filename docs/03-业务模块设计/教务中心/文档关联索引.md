## 2. 跨模块依赖与只读边界

| 依赖项 | 来源中心/模块 | 本中心规则 |
|---|---|---|
| **学生主档** | 学工/学生服务 `backend/app/services/student_service.py`、`t_student_profile` | **只读**；学籍异动写 `t_aa_status_change`，不得平行建学生主表 |
| **教师与组织** | 系统管理/组织树、人事接口 | 只读引用；授课关系来自教学任务 |
| **权限/角色/数据范围** | [系统管理中心/00-权限总控](../系统管理中心/00-系统管理中心-权限角色模块授权与权责边界设计.md) | 不得在本中心硬编码角色名 |
| **文件/附件** | `file_service`、文件中心 | 业务表只存 `file_id` |
| **消息/待办/工作流** | `todos`、`approval`、Workflow 引擎 | 审批节点权限 ≠ 永久业务权 |
| **审计** | `audit_log` 服务 | 敏感导出/批量操作必须写审计 |
| **学业过程既有模块** | `/admin/academic`、`frontend/src/modules/academic/` | **可复用只读**；新教务走 `/admin/academic-affairs`，见融合设计 |
| **学工交界** | 学工请假、处分、风险 | 读学工 API/表；不得重复建请假/处分业务 |

**允许写入目录**：`frontend/src/views/admin/academic-affairs/`、`backend/app/api/v1/`（academic-affairs 路由）、`backend/app/models/`（`t_aa_*` 新表）、`backend/app/services/`（教务专属 service）、`backend/tests/test_academic*.py`

**禁止修改目录**（除非跨中心联合任务）：`backend/app/services/student_service.py` 核心主档、`frontend/src/modules/student/` 学工主模块、`backend/app/models/student.py` 主档结构（需联合评审）
