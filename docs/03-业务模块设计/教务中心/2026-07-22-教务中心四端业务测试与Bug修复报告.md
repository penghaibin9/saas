## 7. 已修复 Bug

### AA-E2E-001 节次时间重叠未拦截

- **模块**：校历节次  
- **端/角色**：老师 PC / ACADEMIC_ADMIN  
- **前置**：已存在启用节次 22:00-22:45  
- **步骤**：再创建 22:10-22:50  
- **预期**：409 DATA_CONFLICT  
- **实际（修复前）**：200 成功写入（DB 已出现重叠行）  
- **根因**：`create_time_slot` / `update_time_slot` 只校验序号唯一，不校验时间重叠  
- **修复**：增加 `_times_overlap` + `_assert_no_timeslot_overlap`  
- **文件**：`backend/app/modules/academic_affairs/services/academic_affairs_service.py`  
- **回归**：`tests/test_aa_calendar_period.py::test_r3...` **PASSED**；HTTP 8001 返回 `节次时间与第930节（22:00-22:45）重叠`  
- **注意**：本机 8000 存在幽灵 LISTENING，未加载新代码；验收请用重启后的干净进程或 8001

### AA-E2E-002 学生评教端能力缺口（已补齐）

- **模块**：教学评价  
- **端**：学生小程序（学生 PC 可后续复用同一 mobile API）  
- **实际（修复前）**：无学生评教页与 API  
- **修复**：
  - `mobile_academic_affairs_service.evaluation_tasks_my` / `evaluation_submit_my`（本班校验）
  - `GET/POST /api/v1/mobile/academic/evaluation/tasks|submit`
  - 小程序页 `pages/student/academic-affairs/evaluation` + `studentApi`/`realApi`/`pages.json` 入口
- **回归**：Round2 `R2.eval_*` 全 PASS；跨班提交返回 `403 NO_PERMISSION`

### AA-E2E-003 成绩任务未继承教学班导致名单为空

- **模块**：成绩管理  
- **端/角色**：老师 PC  
- **前置**：按 `teachingTaskId` 创建成绩任务但不传 `classId`  
- **实际（修复前）**：`roster` 返回空，无法录入  
- **根因**：`create_grade_task` 只取 body.classId，未从教学任务继承 class_id/course_name/credit  
- **修复**：`academic_affairs_grade_service.create_grade_task` 继承教学任务字段  
- **回归**：Round2 `R2.grade_task.classId=50` + 录入发布 + 成绩单可见
