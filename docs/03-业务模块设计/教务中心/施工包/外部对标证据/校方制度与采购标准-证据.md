# 教务业务真实校方制度与采购标准证据（研究执行者：AI，核验方式：WebSearch+WebFetch，查阅日期：2026-07-14）

> 说明：本证据包用于教务中心 7 个二级模块（成绩管理全流程、调停课、排课管理、考务管理、补考重修缓考免修、学院专业班级组织管理、教务归档）的**制度/政策约束**研究，不是产品对标证据包，不能替代 §5.1 所要求的"三家成熟系统产品能力+高校采用"证据。本包只解决"业务规则的官方/校方依据从哪来"的问题。
>
> 本项目目标用户为"职业院校"，覆盖面既可能是中等职业学校（中职）也可能是高等职业院校（高职专科）。以下证据按学段分别标注，两类学段的学籍管理规定并不完全通用，施工时需按学校实际学段选择适用条款，或做成可配置项。
