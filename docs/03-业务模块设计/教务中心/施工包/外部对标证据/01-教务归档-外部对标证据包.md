## 3. 至少三套成熟系统逐家核验

### 强智（湖南强智科技发展有限公司）

1. 产品/系统及厂商：强智综合教务管理系统 / 教学一体化服务平台，湖南强智科技发展有限公司；据行业检索该产品服务 900 余所高校，含 400+ 职业院校（该数字来自厂商自述，未单独核验，不计入正式证据表）。
2. 模块能力证据ID：`ARCHIVE-VEN-QZ-CAP`（C 级，弱——仅"成绩自动汇入学籍档案"一句）。
3. 高校采用证据ID：`ARCHIVE-VEN-QZ-ADOPT`（A 级——厦门软件职业技术学院 2024-10-31 真实启用通知，高职院校，学籍卡片/成绩/课表模块确认在产）。
4. 已核验事实：强智系统在高职院校真实承载学籍卡片查看、学生成绩录入与查看、学期课表查询；厂商官网自述成绩数据回写学籍档案。原计划核验的《教学一体化服务平台操作手册》PDF（天津医科大学官网托管）多次尝试 WebFetch 均因二进制/PDF 而抓取失败，未能取得手册内归档/打印章节原文，本条不计入证据表（不得凭 WebSearch 摘要转述为已核验事实）。
5. 不可推断边界：不能证明强智系统存在独立的"学期归档批次/完整性检查/封存水印包"功能；不能证明厦门软件职业技术学院已执行归档动作；厂商服务学校数量为自述数据，不作为独立证据。
6. 可转化的设计输入：学籍卡片、课表、成绩三类数据在成熟教务系统中均以"可查询、可打印"的形态存在，本项目"归档=六类物料完整性检查+只读打包+水印下载"的产品定位与厂商侧"以查询/打印为核心，不强调档案馆对接"的实际形态一致，支持手册"明确不做档案馆标准格式对接"的裁定。

### 正方（正方软件股份有限公司）

1. 产品/系统及厂商：教学管理信息服务平台，正方软件股份有限公司（国内高等教育信息化头部厂商之一）。
2. 模块能力证据ID：`ARCHIVE-VEN-ZF-CAP`（C 级，已核验但未命中归档相关表述，如实记录"页面未出现归档字样"）。
3. 高校采用证据ID：`ARCHIVE-VEN-ZF-ADOPT`（A 级但偏弱——山东财经大学 2018-07-09 通知证明正方系统曾为该校在产系统，但该校为本科院校且通知主题是"由正方切换到强智"，非归档场景）。
4. 已核验事实：正方为国内高校主流教务系统供应商之一，产品页明确的模块含学籍管理、成绩管理、考务管理；至少一所本科院校历史上在产使用。未取得高职院校层面的正方采用证据，亦未取得正方"归档"专项功能的官方原文。
5. 不可推断边界：不能证明正方教学管理信息服务平台具有专门的"教学档案归档/打包"模块；不能证明高职院校采用；不得把"该校在使用正方"泛化为"正方支持归档"。
6. 可转化的设计输入：与强智相同——正方产品定位同样以日常教务运行（学籍/成绩/考务/排课）为核心，未见其官网强调"档案馆对接"能力，进一步佐证本项目"教务系统只做归档前完整性检查+内部只读封存，不对接档案馆标准格式"的边界设定符合行业实际形态。

### 青果（上海鲲鹏计算机科技有限公司）

1. 产品/系统及厂商：青果教务综合管理平台，上海鲲鹏计算机科技有限公司；行业检索显示该产品在高职院校采用较多。
2. 模块能力证据ID：`ARCHIVE-VEN-KG-CAP`（C 级，CSDN 第三方技术博客转述，非一手材料）。
3. 高校采用证据ID：`ARCHIVE-VEN-KG-ADOPT`（A 级——开封职业学院 2023-03-24 登录流程指引，高职院校真实在产使用，含"学籍管理"入口）。另有重庆工业职业技术学院《关于全面启用青果教务管理平台的通知》标题命中（原 URL 二次访问 404，未能重新核验正文，不计入正式证据表，仅作为候选线索记录）。
4. 已核验事实：青果系统"学生学籍"模块用于建立/维护学籍档案、处理异动、专业分流（第三方博客转述）；开封职业学院真实在产使用该系统（学校一手材料）。
5. 不可推断边界：CSDN 博客不能作为产品官方能力证据，只能作参考线索；不能证明青果系统有归档专项模块；不能证明开封职业学院已执行归档业务。
6. 可转化的设计输入：与前两家一致的结构性发现——三家主流教务系统的高职院校真实采用证据均可查（学籍/成绩/课表/学籍档案初始化等日常模块），但**没有一家能取得"归档打包/封存/水印下载"专项功能的官方一手原文**。这是本次外部核验的诚实结论，不做拔高。

## 7. 禁止推断清单

- 不得推断强智/正方/青果任一家提供"学期归档批次""完整性检查""水印封存包"的具体产品功能、字段、按钮、状态机（未取得任一家一手原文）。

- 不得推断青果 CSDN 博客描述的"学籍档案初始化"字段结构等同于本项目 `t_student_profile`/`AaRegistration` 表结构。

- 不得推断《高等学校档案管理办法》第十五条的"学生类/教学类"划分与本项目"九数据域"存在逐条对应关系——本项目划分为项目自行设计，仅在总体方向上与该办法及南航归档指南一致。
