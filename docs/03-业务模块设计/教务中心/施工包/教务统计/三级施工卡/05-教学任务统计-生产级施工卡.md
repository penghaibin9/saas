## 3. 真实业务结果与边界

- 业务结果：教务处/学院教务查看教学任务确认完成率，下钻到未确认任务清单及对应教师，用于催办。
- 上下游：只读 `t_aa_teaching_task`/`_batch`；不回写；催办动作归属「教学任务」二级模块既有能力，本卡只读跳转。
- 必须完成：完成率卡+按学院分组+未确认任务下钻。
- 明确不做：不重复实现「教学任务」模块已规划的统计 P2 项——代码施工阶段需与该模块协调，避免同名不同数。
