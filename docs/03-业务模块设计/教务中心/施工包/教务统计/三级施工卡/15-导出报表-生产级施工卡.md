## 3. 真实业务结果与边界

- 业务结果：教务处/学院教务/专业负责人在任一统计 Tab 发起导出，或在本卡集中查看/管理历史导出任务，下载脱敏+水印的 Excel 文件。
- 上下游：读取其余 14 项统计卡的聚合结果作为导出内容源；不回写业务表；写入导出任务表+审计日志。
- 本卡必须完成：发起导出（指定 domain=11 项指标之一或教务总览全量）+导出历史列表+下载+失败重试。
- 明确不做：不做自定义报表设计器（拖拽字段、自定义模板，P2/backlog）；不做定时自动导出/订阅推送（V1 范围外）。
- 用户决定项：导出文件保留天数（沿用项目现有导出管线默认策略还是教务域单独设置）——非本卡独有问题，属项目导出管线通用配置，不需单独就本模块询问甲方。

## 5. 字段、按钮与校验

### 5.1 字段
| 字段 | 类型 | 必填/默认 | 说明 | 敏感级 |
|---|---|---|---|---|
| domain | string | 必填 | 11 项指标+教务总览之一（枚举） | 低 |
| filters | object | 可空 | 学期/学院/专业等，继承发起时所在 Tab 的当前筛选 | 低 |
| purpose | string | 必填≥5字 | 导出用途（对齐毕业资格审核既有惯例） | 低 |
| format | string | 固定 `xlsx` | 不支持 CSV 主方案 | 低 |

### 5.2 按钮
| 按钮 | 出现条件 | permission key | API | 状态变化 | 审计 |
|---|---|---|---|---|---|
| 发起导出 | 常驻 | `academicAffairs.stats.export` | `POST /academic-affairs/stats/export` | DRAFT→EXPORTING | `EXPORT_START` |
| 下载 | 状态=DONE | 同上（仅发起人或同 scope 管理角色） | `GET /academic-affairs/stats/export/{taskId}` | 无 | `EXPORT_DOWNLOAD` |
| 重试 | 状态=FAILED | 同上 | 同"发起导出" | FAILED→EXPORTING | `EXPORT_START` |

## 6. 主流程、异常流程与状态机

| 当前状态 | 动作 | 角色 | 前置条件 | 下一状态 | 非法操作/错误码 | 并发/幂等 | 通知/待办 | 审计 |
|---|---|---|---|---|---|---|---|---|
| （无）→DRAFT | 发起导出 | 有导出权限角色 | 已选 domain+填写 purpose | EXPORTING | 无权限→403；purpose<5字→400 | 同参数重复点击复用未完成任务 | 无 | `EXPORT_START` |
| EXPORTING | 系统生成 | 系统 | — | DONE/FAILED | — | 生成异常自动重试 1 次 | 无（V1 不做完成通知，用户主动查看历史列表） | `EXPORT_DONE`/`EXPORT_FAILED` |
| DONE | 下载 | 发起人/同 scope 管理角色 | 文件未过期 | DONE（终态） | 越权下载→403 | — | 无 | `EXPORT_DOWNLOAD` |
| FAILED | 重试 | 发起人 | — | EXPORTING | — | — | 无 | `EXPORT_START` |
