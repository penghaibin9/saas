## 3. 真实业务结果与边界

- 业务结果：教务处/学院教务/辅导员（本班协同只读）查看非 CLOSED 预警数按等级（如学分/挂科/绩点/毕业风险）与来源分组，下钻到处置记录。
- 上下游：只读 `t_acad_warning`；不回写（处置动作归属「学业预警」二级模块既有能力）。
- 必须完成：按等级+来源双维分组计数+下钻学生列表+处置记录查看入口。
- 明确不做：不重复实现「学业预警」模块规划中的统计项，需代码施工阶段协调唯一入口；不提供预警处置/关闭等写操作。
- 用户决定项：辅导员是否应能查看本班学生的教务侧预警统计（涉及跨中心权限授权点，见二级包 §10 第 3 行"需新增跨域只读授权点或复用 `studentAffairs.stats.view`"，属技术实现选择，非业务政策，不需甲方确认；但辅导员范围收窄依据仍需 `TeacherStudentScope` CLASS 类型记录，与学工域共用同一张表）。

## 10. 敏感数据、安全与审计

预警等级/来源为中敏（涉及学业困难标签），下钻学生列表默认展示但导出需写审计+水印；跨中心（辅导员）访问需明确记录访问来源模块。
