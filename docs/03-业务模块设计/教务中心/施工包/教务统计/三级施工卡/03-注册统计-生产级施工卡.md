## 3. 真实业务结果与边界

- 业务结果：教务处/学院教务查看某注册批次（学年注册/新生注册等）的完成率，下钻到未注册学生名单，便于催办。
- 上下游：读 `t_aa_registration`+`t_aa_registration_batch`+学生主档；不回写（催办动作属于「注册管理」二级模块的既有功能，本卡只读不新增催办按钮，避免越界）。
- 本卡必须完成：按批次的完成率卡+未注册学生名单下钻（脱敏列，参照学籍名册既有脱敏规则）+距法定注册截止日剩余天数提示。
- 明确不做：不做催办动作按钮（该动作归属「注册管理」模块，本卡仅提供数据入口跳转）。
- 用户决定项：无新增（沿用二级包 §10 通用范围政策项）。

## 5. 字段、按钮与校验

| 字段 | 类型 | 说明 |
|---|---|---|
| batchId | string | 必填（默认当前进行中批次） |
| completionRate | number | 系统计算，分母为 0 时返回 `null` |
| dueSoonDays | number | 距批次/法定截止日剩余天数（读校历配置，非硬编码） |

| 按钮 | permission key | API | 审计 |
|---|---|---|---|
| 切批次/查看 | `academicAffairs.stats.view` | `GET /academic-affairs/stats/registration` | 无 |
| 下钻未注册名单 | 同上 | `GET /academic-affairs/stats/registration/unregistered` | `STATS_DRILL_STUDENT` |
| 跳转催办（复用注册管理模块） | 同上 | 复用既有催办接口（不在本卡新增） | 复用既有审计 |
| 导出 | `academicAffairs.stats.export` | `POST /academic-affairs/stats/export` | `EXPORT_START` |

## 6. 主流程、异常流程与状态机

无状态机。异常：批次不存在或已结束时，页面提示"该批次已归档，数据仅供查询"而非报错。

## 9. 权限总控逐动作实例化
