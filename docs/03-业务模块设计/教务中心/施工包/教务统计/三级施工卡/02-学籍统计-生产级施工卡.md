## 3. 真实业务结果与边界

- 业务结果：教务处/学院教务按学期、按异动类型（转学/转专业/留级/休学/注销/复学/退学等）查看学籍异动人数分布与趋势，下钻到具体异动单。
- 进入/退出条件：同 01 卡。
- 上下游：读 `t_aa_status_change`（唯一来源）；不回写。
- 本卡必须完成：按 `change_type` 分组计数+按学院二级分组+趋势（近 N 学期对比，若历史数据不足则只显示当前学期）+下钻到异动单详情。
- 明确不做：不重复实现「学籍异动」二级模块下已规划的 `/roll/changes/stats` 页面本身（若该页面已建成，本卡改为跳转/复用而非重复开发；若未建成，两者需在代码施工阶段由用户/技术负责人裁定唯一入口，避免"同名不同数"违反 CLAUDE.md 融合设计原文"两个入口出现同名不同数的指标（口径必须同源）"红线）。
- 仅学校决定的业务政策：无（分类范围由既有表结构决定，非业务政策选择项）。
