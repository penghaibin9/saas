## 3. 真实业务结果与边界

- 教务处/学院教务/领导查看考务运行的汇总指标：批次完成率（各阶段占比）、缺考率、违纪率、监考工作量分布（按教师统计场次数）、考场利用率。
- 进入条件：至少存在一个批次；退出条件：无（只读看板）。
- 本卡必须完成：看板页（多指标卡片+明细表下钻）、按学期/学院筛选、导出。
- 明确不做：跨学期趋势预测/AI分析（V1 仅当期/历史学期对比原始数字，不做预测算法）。

## 5. 字段、按钮与校验

无新表；聚合口径：

| 指标 | 计算口径 |
|---|---|
| 批次完成率 | `COURSE_CONFIRMED/ARRANGED/PUBLISHED/FINISHED/ARCHIVED` 批次数 / 总批次数 |
| 课程确认率 | `CONFIRMED` 课程数 / 总课程数(按批次) |
| 缺考率 | `ABSENT` 类型 incident 数 / 应考人数(座位表总数) |
| 违纪率 | `DISCIPLINE_VIOLATION` 类型 incident 数 / 应考人数 |
| 监考工作量 | 按 `teacher_key` group by 统计 `t_aa_exam_invigilator` 场次数（本学期） |
| 考场利用率 | 已排考场数 / (若教学资源字典就绪)总可用考场数（V1 教室字典未就绪，本指标降级为"考场使用场次汇总"，不计算利用率百分比，backlog） |
