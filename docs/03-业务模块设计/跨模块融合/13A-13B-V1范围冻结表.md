## 4. "V1 明确不做"红线清单（对甲方与开发同时生效）

1. **不做自动排课**（含任何"简单"算法；V1 课表以导入/手工维护+冲突检测为准）。
2. **不做完整选课**（学生课表按行政班归属服务端推导；选课引擎 P2）。
3. **不做成绩录入/审核/发布/更正**（教务中心侧零成绩写端点，t_acad_grade 既有写入口不动）。
4. **不做考务全流程与缓考**（仅 P0 冻结 workflow_code 与请假联动契约）。
5. **不做补考/重修流程**（仅锁定"基于 t_acad_makeup/retake 加列升级"的 P2 方案）。
6. **不做国家/省平台上报**（走集成开放中心，待现场确认）。
7. **不做复杂第二课堂积分/德育积分/社团/党团/综合测评/辅导员考评**。
8. **不做深度心理测评**（V1 仅关注标记+强权限引用，不出现量表/诊断字样）。
9. **不做智能排宿**（V1 人工分配+目标床位校验）。
10. **不做家长端**（家校联系仅记录+审计；不发短信——短信 P2 且需求 §9 待确认）。
11. **不开学生 PC 门户**（学生入口只在小程序/H5，PC require_staff）。
12. **不新建平台管理端/消息表/待办表/预警表/学生表/教师表/归档文件表**（复用清单见草案）。
13. **不改既有六域表结构语义与既有 API 响应结构**（只允许草案列明的 nullable 加列）。
14. **不在验收期加功能、不为过测试放宽校验**（两份《开发阶段与验收用例》红线条款直接引用）。
