# 13A/13B 设计输入（V1.0+V1.1 原始需求压缩版 · 供各设计文档统一引用）

> 本文件是甲方需求的忠实压缩记录，是 13A/13B 全部设计文档的唯一需求来源。
> 平台总定位不变：职校学生全生命周期 SaaS 平台（Student Lifecycle OS）。
> 03-业务模块设计/学工中心/教务中心是平台的两个业务模块，不是独立系统。

## 0. 总原则

两个模块不能做成普通 CRUD（列表+详情+表单+审批按钮），必须按以下要素设计：
业务流程 / 状态机 / 权限范围 / 审批流 / 消息通知 / 学生360沉淀 / 统计指标 / 导入导出 / 移动端高频入口 / 审计记录。

每个业务必须回答：谁发起、谁审核、谁处理、谁查看、什么状态能/不能操作、退回后回到哪里、通过后影响什么、失败后提示什么、是否进入学生360、是否影响数据中心、是否通知学生/老师/家长、是否涉及敏感字段、是否需要导出归档。

主线：学生主档 → 身份/学籍/班级/专业 → 学工日常 → 教务教学过程 → 学业/学工风险 → 实习/毕设/就业 → 毕业资格 → 学生360归档 → 数据中心统计。

## 1. 业务域边界（必须遵守）

**学工中心负责**：请假/销假/续假、困难认定、奖学金、助学金、勤工助学、助学贷款、违纪处分、处分解除、心理关注、风险预警、谈心谈话、宿舍管理、学生活动、德育积分、家校联系、学工归档、辅导员工作台、班级画像。

**教务中心负责**：学年学期、校历、学籍、学籍异动、专业、培养方案、课程库、教学任务、课表、调停课、选课、考试、缓考、补考、重修、成绩、成绩更正、学业预警、毕业资格审核、教务归档。

**已有模块继续负责**：数字迎新（报到/材料/入学手续）、在校服务（学生服务申请）、学业过程（过程性学业数据）、岗位实习（申请/周报/指导/评价）、毕业设计（选题/任务书/开题/中期/答辩）、就业服务（去向/企业/跟进）、学生中心（主档/360/身份核验）、Workflow（审批流）、Security（脱敏/水印/审计）、Dashboard（统计/预警/驾驶舱）。

## 2. 13A 学工中心一级功能

学工首页、辅导员工作台、学生信息与画像、班级管理、请假销假、困难学生认定、奖学金、助学金、勤工助学、助学贷款、学费减免、临时困难补助、绿色通道、违纪处分、处分解除、荣誉称号、综合测评、思政队伍、辅导员考评、心理健康、风险预警、谈心谈话、家校联系、宿舍房源、智能排宿、宿舍异动、宿舍检查、公寓纪律、文明寝室、学生活动、社团管理、学生组织、志愿服务、第二课堂、党团建设、学工材料归档、学工统计分析、移动端学工服务。

### 2.1 学工首页（13A-01）
按角色出不同视图：
- 学工处管理员：全校学生数/风险数/今日待办/请假待审/奖助待审/处分待办/心理关注/困难学生/宿舍异常/辅导员完成率/归档率/学院风险与待办排行。
- 学院学工管理员：本学院同类指标。
- 辅导员：所带班级/今日待办/风险学生/待审请假/学业预警/待谈话/困难生/就业未填报/实习异常/消息。
接口 `GET /api/v1/student-affairs/dashboard`（tenant_id/current_user/current_role/data_scope/semester/date_range → summaryCards/todoList/riskStudents/workflowPending/classOverview/warningTrends/recentActivities）。角色 preset、租户过滤、范围过滤、风险学生可点进学生360。

### 2.2 辅导员工作台（13A-02）
最高频入口。模块：我的班级/我的学生/今日待办/请假审批/风险学生/学业预警/谈心谈话/困难学生/处分跟进/就业未填报/实习异常/毕设异常/学生快速搜索/学生360入口。
接口：counselor/workbench、counselor/students、counselor/todos、counselor/risk-students。
统一范围函数：getCounselorScope(user)、filterStudentsByCounselorScope(query,user)、assertCounselorCanAccessStudent(user,studentId)。
权限点：studentAffairs.counselor.dashboard.view / student.view / todo.handle / risk.handle。

### 2.3 学生信息与画像（13A-03）
不替代学生主档，在学工视角形成画像：基础信息/学籍状态/班级/辅导员/请假/奖助/困难认定/处分/心理关注/谈话/宿舍/活动/志愿/德育积分/学业预警/实习异常/就业状态/风险等级/成长时间线。
读取现有主档（student_master 等），学工业务沉淀 student_affairs_events / student_360_timeline / student_risk_records。
接口：students/{id}/profile、students/{id}/timeline。
安全：心理默认隐藏、困难脱敏、处分按权限、家庭脱敏、查看完整隐私必须审计。

### 2.4 班级管理（13A-04）
班级档案/学生/班干部/辅导员绑定/班主任绑定/班级画像/风险/活动/材料/统计。
流程：学院建班→绑定学院专业年级→分配辅导员→导入学生→设班干部→生成画像→动态维护→进入首页与数据中心。
画像指标：人数/男女/困难/风险/请假/处分/宿舍异常/学业预警/就业未填报/实习异常/毕设异常。
表：affairs_class_profile/cadre/event/material。接口 classes、classes/{id}、classes/{id}/students、classes/{id}/cadres。

### 2.5 请假/销假/续假（13A-05）
角色：学生/辅导员/学院学工/学工处/宿管/家长(可选通知)。
状态机：DRAFT/SUBMITTED/COUNSELOR_REVIEW/COLLEGE_REVIEW/STUDENT_AFFAIRS_REVIEW/APPROVED/REJECTED/RETURNED/CANCELLED/EXTENSION_REVIEW/WAIT_CANCEL_LEAVE/CLOSED/OVERDUE/ARCHIVED。
主流程：小程序发起→类型/起止/原因/材料→校验（本人/在籍/冲突/天数规则/材料）→生成请假单→按天数类型定审批流→辅导员→(长)学院→(重大)学工处→通过→通知学生(可选家长)→到期前提醒销假。
销假：返校→点销假→上传证明→记录实际返校→辅导员确认→CLOSED→进学生360。
逾期：到期未销→OVERDUE→风险预警→推辅导员→联系→可转家校→关闭。
表：t_cs_leave（扩展主单）+ t_file_object(LEAVE 附件) + t_affairs_leave_cancel_record / t_affairs_leave_extension；审批走 Workflow 不建 approval 表。
接口：POST leave、GET leave/my、GET leave/pending、POST {id}/approve|reject|cancel-leave|extension。
规则：student_id 从 token 取；tenant 从上下文取；重复提交拦截；审批走 Workflow；长假规则可配置。

### 2.6 困难认定（13A-06）
批次/申请/家庭经济/材料/班级评议/辅导员初审/学院复审/学校终审/等级/动态调整/年度复核/困难学生库。
状态机：NOT_STARTED/DRAFT/SUBMITTED/CLASS_REVIEW/COUNSELOR_REVIEW/COLLEGE_REVIEW/SCHOOL_REVIEW/PUBLICITY/APPROVED/REJECTED/ADJUST_REVIEW/ARCHIVED。
表：affairs_aid_identification_batch/apply、affairs_aid_family_economy、affairs_aid_review_record、affairs_aid_level_history。
接口：aid/batches、aid/apply、aid/{id}/review、aid/difficult-students。
安全：家庭经济强敏感、默认脱敏、导出水印、看完整必须审计。

### 2.7 奖助勤贷（13A-07）
统一资助抽象：affairs_funding_project/batch/application/review/publicity/result；项目类型 SCHOLARSHIP/GRANT/WORK_STUDY/LOAN/TUITION_REDUCTION/TEMPORARY_AID/GREEN_CHANNEL。
- 奖学金：建批次→条件→系统推荐名单（成绩/处分/学籍校验）→申请或推荐→辅导员初审→学院评审→学校复核→公示→确认→归档→学生360。校验：学籍异常/处分未解除/成绩不达标/同批次重复/材料缺失不能申请。
- 助学金：批次→读困难库→申请→辅导员核实→学院→学校→公示→名单→资助档案。
- 勤工助学：部门发岗→学生申请→校验（状态/困难等级/时间冲突）→部门筛选→辅导员确认→资助中心审批→上岗→月度考核→补贴记录→归档经历。
- 助学贷款：登记→回执上传→辅导员核对→资助老师审核→学校确认→记录年份金额银行状态→毕业前提醒确认。

### 2.8 违纪处分与解除（13A-08）
状态机：REGISTERED/COLLEGE_REVIEW/STUDENT_AFFAIRS_REVIEW/SCHOOL_REVIEW/EFFECTIVE/REJECTED/RETURNED/CANCELLED/REMOVE_REVIEW/REMOVED/ARCHIVED。
流程：登记→材料→学院初审→学工处复核→(严重)学校审批→生效→送达通知→学生360→联动奖助/评优/毕业资格/风险画像。
解除：申请→表现材料→辅导员初审→学院→学工处终审→REMOVED→360保留历史→毕业审核读最新状态。
表：affairs_discipline_case/decision/material/remove_apply/review。

### 2.9 心理健康与风险预警（13A-09）
风险来源：心理关注/学业预警/请假异常/宿舍异常/处分/长期未登录/实习异常/就业异常/家庭困难/人工标记/家校反馈。
风险状态机：NEW/ASSIGNED/PROCESSING/FOLLOWING/TRANSFERRED/ESCALATED/CLOSED/REOPENED。
流程：发现→生成记录→定来源等级→按责任规则分派（学业→辅导员/教务；心理→心理老师/辅导员；宿舍→宿管/辅导员；实习→指导教师/辅导员）→处置记录→可转谈话/家校→可升级→关闭→360。
表：affairs_risk_record/source/handle_record/transfer/close_record。
安全：心理记录仅心理老师/授权辅导员；普通教师只见"需关注"；导出默认不含心理明细。

### 2.10 谈心谈话（13A-10）
计划/记录/主题/结果/跟进/风险关联/家校关联/工作量统计。类型：日常/学业/心理/违纪/就业/实习/困难帮扶/宿舍异常。
流程：建计划→选学生主题→约时间→填记录→判断跟进→转风险/家校→360。

### 2.11 宿舍与公寓（13A-11）
房源（楼/层/房/床）、智能排宿、入住/调宿/退宿、异动、检查、夜不归宿、公寓纪律、文明寝室、卫生、安全检查。
排宿：维护房源→规则（学院/专业/班级/性别/年级/特殊）→生成方案→人工调整→学院确认→发布→学生小程序看宿舍→360。
调宿：发起→原因→辅导员审→宿管审→目标床位校验→通过→原床释放新床占用→记录。
检查：建任务→按楼/房检查→记录卫生安全违禁夜不归→异常同步辅导员→严重进风险→统计+360。

### 2.12 活动/社团/志愿/第二课堂（13A-12）
活动：发布→范围人数时间地点→报名→校验→签到→确认名单→生成学时/积分→360→第二课堂记录。
志愿：发布项目→报名→负责人审核→签到→确认时长→记录。

### 2.13 家校联系（13A-13）
监护人/紧急联系人/联系记录/家访/重点学生联系/通知记录/风险联动。
流程：进360→看脱敏号码→需完整号码填原因→审计→联系→填结果→关联风险→360。

### 2.14 学工归档（13A-14）
内容：请假/奖助/困难/处分/解除/谈话/心理风险/宿舍/活动/家校/风险处置/辅导员日志/班级材料。
流程：建批次→按学生生成档案包→辅导员补缺→学院审完整性→学工处确认→水印归档包→审计。

## 3. 13B 教务中心一级功能

教务首页、学年学期与校历、作息时间、学籍管理、入学注册、学年注册、学籍异动、学院/专业/班级、培养方案、课程库、教学计划、教学任务、排课管理、调停课、选课、免修、重修、补考、缓考、考务、等级考试、成绩管理、成绩审核、成绩发布、成绩更正、学业预警、毕业资格审核、教材、教学资源、教室资源、教学评价、教学质量、教务材料归档、教务统计分析、移动端教务服务。

### 3.1 教务首页（13B-01）角色视图
- 教务处：本学期教学任务/排课完成率/课表发布/选课进度/考试安排/成绩录入进度/成绩审核待办/学籍异动待审/学业预警数/毕业资格异常数。
- 学院教务员：本学院教学任务/未排课程/排课冲突/成绩未录/学籍异动/毕业资格异常。
- 任课教师：今日课程/授课班级/成绩录入任务/监考任务/调停课申请/学生名单。
- 学生：我的课表/课程/考试/成绩/学业预警/毕业资格进度。

### 3.2 学年学期与校历（13B-02）
学年/学期/校历/教学周/考试周/实习周/节假日/调休/作息/节次。
流程：建学年学期→起止→教学周→考试周→节假日调休→节次→发布→同步排课/考试/课表/工作台/学生端。
状态机：DRAFT/PUBLISHED/FROZEN/ARCHIVED。

### 3.3 学籍管理（13B-03）
学籍状态：PENDING_REGISTER/ACTIVE/REGISTERED/UNREGISTERED/SUSPENDED/RESUMED/TRANSFER_MAJOR/TRANSFER_SCHOOL/WITHDRAWN/RETAINED/GRADUATED/COMPLETED/INCOMPLETE/ARCHIVED。
入学注册：迎新完成→待注册→学院核身份专业班级→系统查报到缴费材料→注册名单→教务处审→在籍→360→同步学工教务实习毕设就业。
转专业：申请→校验时间/学籍/成绩→辅导员初审→原学院转出→目标学院接收→教务处终审→更新专业班级培养方案→360→统计。
休学：申请→材料→辅导员确认→学院→教务处→SUSPENDED→期间禁选课考试实习毕设→到期提醒复学。
复学：申请→辅导员确认→学院定班→教务处→在籍→重绑班级方案课程。

### 3.4 专业与培养方案（13B-04）
结构：公共基础/专业基础/专业核心/实践/选修/顶岗实习/毕业设计/毕业要求/总学分。
状态机：DRAFT/COLLEGE_REVIEW/ACADEMIC_REVIEW/RETURNED/PUBLISHED/ENABLED/FROZEN/DISABLED。
流程：教务处建编制任务→学院建专业年级→负责人编制→课程模块→学分学时开课学期性质→毕业要求→学院审→教务审→发布→绑定专业年级学生→教学任务/选课/成绩/毕业资格读取。
规则：课程不重复/总学分达标/开课学期合法/课程来自课程库/启用后修改必须新版本/历史学生用旧版本。

### 3.5 课程库（13B-05）
编号/名称/类别/性质/学分/学时(理论/实践)/适用专业/先修/负责人/状态/版本。
流程：负责人新增→基础信息→学分学时→类别性质→先修→学院审→教务审→启用→方案可引用。

### 3.6 教学任务（13B-06）
流程：教务处建学期任务批次→按培养方案生成应开课程→学院核对课程班级人数→分配教师→专业负责人确认→教师确认→学院提交→教务处审→可排课。
异常规则：无教师不能提交/容量小于班级人数提示/教师工作量超限提示/方案外课程需说明。

### 3.7 排课（13B-07）
前置：校历已发布/作息已配置/任务已审核/教室已维护/教师任务已确认/班级学生已生成。
V1 策略：不上复杂算法——规则校验+人工排课+冲突检测。
冲突类型：教师/班级/教室/课程时间冲突、容量不足、类型不匹配、校区时间不合理、教师不可用、周学时不满足。
表：academic_schedule_batch/time_slot/rule/item/conflict/publish。
流程：建批次→载入资源→规则→(自动)排→冲突报告→学院处理→教务复核→手动调整→预发布→教师确认→学生预览→正式发布。

### 3.8 调停课（13B-08）
流程：教师发起调/停/补→原课程→原因→目标时间教室→冲突检查→学院审→教务审→更新课表→通知师生。
状态机：SUBMITTED/COLLEGE_REVIEW/ACADEMIC_REVIEW/APPROVED/REJECTED/CANCELLED/APPLIED。

### 3.9 选课（13B-09）
流程：建批次→时间→适用年级专业班级→课程容量→规则（先修/冲突/学分上限/专业/年级/人数）→发布→学生选→校验→成功→统计→低人数可取消→锁定。
学生校验：时间内/范围内/未修过/满足先修/不冲突/不超学分/不超容量/重修规则。

### 3.10 考务（13B-10）
流程：建考试批次→类型→按任务和选课生成考试课程→学院确认→时间→考场座位→监考→准考名单→发布→学生看考试→教师看监考→考后记录缺考违纪缓考。
缓考：学生申请→材料→辅导员初审→任课教师确认→学院审→教务终审→标记→进缓考安排。

### 3.11 成绩（13B-11）
状态机：NOT_STARTED/INPUTTING/SUBMITTED/COLLEGE_REVIEW/ACADEMIC_REVIEW/PUBLISHED/RETURNED/(CHANGE_REVIEW)/ARCHIVED。
流程：课程结束生成录入任务→教师录入（平时/期末/总评构成）→校验范围构成→提交→学院审完整性→教务发布→学生小程序查→360→生成学业预警→毕业审核读取。
更正：教师发起→原/新成绩+原因+材料→学院审→教务审→更新→保留原值与记录→通知学生。

### 3.12 补考/重修/免修（13B-12）
补考：发布后识别不及格→名单→批次→安排→学生查看→录入补考成绩→按规则更新最终成绩。
重修：报名→展示可重修→申请→教务审→入重修选课→课程/考试→录入成绩。
免修：申请→材料→任课教师审→学院审→教务审→免修记录→学业进度标记。

### 3.13 学业预警（13B-13）
来源：挂科/低绩点/学分不足/缺考/重修过多/未注册/课程未通过/毕业资格异常/长期未参与教学。
流程：定时扫描→命中规则生成→推辅导员+学院教务员→学生端提醒→谈话→家校→关闭→360。

### 3.14 毕业资格审核（13B-14）
条件：学籍正常/方案学分达标/必修通过/选修达标/实习完成/毕设通过/无未解除严重处分/费用材料满足/就业去向填报/档案归档。
状态机：WAIT_PRECHECK/SYSTEM_PASSED/SYSTEM_ABNORMAL/COLLEGE_REVIEW/ACADEMIC_REVIEW/GRADUATED/COMPLETED/DELAYED/REJECTED/ARCHIVED。
流程：建批次→生成应审学生→系统预审(学分/课程/实习/毕设/处分/材料/就业)→学院看异常→辅导员补充→实习毕设学工就业各模块供数→学院初审→教务终审→毕业/结业/延毕名单→学生端展示→360归档。

### 3.15 教材/教室/评价/归档（13B-15）
教材：目录/课程教材/征订/班级教材/学生教材/发放/费用/退换。
教室：校区/楼/教室/实训室/机房/容量/设备/可用时间/借用/维修。
评价：学生评教/同行/督导/自评/课程评价/问卷/结果/统计。
归档：方案/课表/成绩/考试材料/毕业审核/任务材料/审批记录/水印/审计。

## 4. 关键联动闭环
1. 成绩发布→挂科/学分不足→学业预警→辅导员工作台→谈话→家校→360。
2. 处分生效→360→毕业资格审核读取→未解除严重处分→异常→联合处理。
3. 请假通过→考勤/考试知晓→考试期间请假可发起缓考→教务审批。
4. 困难认定通过→困难库→助学金/绿色通道/临时补助引用→辅导员关注→统计。
5. 宿舍夜不归宿→宿管登记→辅导员风险→联系→家校→关闭/升级。
