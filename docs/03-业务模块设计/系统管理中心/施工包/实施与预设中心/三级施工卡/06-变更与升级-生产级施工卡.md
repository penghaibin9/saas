# 变更与升级生产级施工卡

## 0. 身份与现状

`systemAdmin.implementation.changes` / `sys-implementation-changes` / `/admin/system/implementation/changes`；状态 `implemented_partial`。已支持从已安装版本创建继承快照的变更项目、记录来源安装版本，并通过新安装版本 supersede 旧版本；影响分析已接入真实配置段比较、风险等级和受影响主表计数，预约发布仍待增强。

## 1. 业务结果与页面

学校从当前安装版本创建变更草稿，选择升级模板或局部配置，系统列出影响的角色成员、组织引用、运行中流程、菜单工作台、通知模板和课程/培养方案；阻断项处理后预约/立即发布。回滚不是恢复数据库备份，而是基于旧快照生成反向变更并重新检查。

## 2. 字段、动作、状态

| 动作 | 前置/下一状态 | API/权限 | 二次确认/审计 |
|---|---|---|---|
| 创建变更 | 当前安装存在；→DRAFT | POST `/installations/{id}/changes`；`.change.manage` | reason，`CHANGE_CREATED` |
| 编辑变更 | DRAFT/ANALYSIS_FAILED | PATCH `/changes/{id}`；带 version | before/after |
| 影响分析 | 配置项目→已分析 | POST `/projects/{id}/changes/analyze`；`.change.manage` | 记录来源快照、变化段、风险等级和受影响主表计数 |
| 发布 | ANALYZED 且无 BLOCKER→APPLYING→APPLIED | POST `/changes/{id}/apply`；`.change.apply` | confirmText+reason+idempotencyKey |
| 回滚 | APPLIED 创建新的 ROLLBACK_DRAFT | POST `/installations/{id}/rollback`；`.change.rollback` | 高危确认、目标版本、原因 |
| 取消 | DRAFT/ANALYZED→CANCELLED | POST `/changes/{id}/cancel` | reason |

运行中审批流程、已产生业务事实、已发布成绩等不能被模板升级直接改写；只能新增兼容配置或提示人工迁移。并发发布由租户级锁/唯一 active installation 和版本字段阻止；重复 idempotencyKey 返回原发布结果。

## 3. 权限、安全和辅助能力

学校管理员可发布；责任域管理员可编辑本域草稿、查看本域影响；审计员只读。影响统计只返回数量和脱敏标识，查看具体人员仍受业务权限。需要站内通知/待办、变更台账、安装快照归档；附件与打印不需要；配置差异导出后置并加水印。

数据复用 installation 表（`parent_id/change_type/status/snapshot_hash`）和 section；审计记录 before/after 哈希、操作者、角色、租户、影响计数、结果和 traceId。

## 4. 测试、施工与验收

测试：无阻断发布；运行中流程阻断；旧 version 冲突；跨租户；无发布权限；重复发布幂等；回滚生成新版本而非删除；应用中取消被拒；失败步骤可重试。施工：change state/service→影响解析器→API→时间线/差异/确认页→测试/build。回滚停用新版本并激活上一可用快照需事务完成，失败保持原 active。

验收：一次角色模板升级能清楚看到受影响账号数和越权风险；不点发布不会改变现网；发布/失败/回滚全过程可审计。
