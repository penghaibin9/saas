# 已安装配置生产级施工卡

## 0. 身份与现状

`systemAdmin.implementation.installed` / `sys-implementation-installed` / `/admin/system/implementation/installed`；状态 `implemented_partial`。安装版本、来源方案、状态、时间和快照指纹已有统一只读页；字段级漂移分析和逐项跳转仍是后续增强项。

## 1. 业务结果与页面

按 12 类树展示已安装配置，不把快照冒充实时数据：每项同时显示来源方案/版本、安装时值、当前真实状态、是否漂移、责任模块和修改入口。支持搜索编码/名称/来源、查看前后差异、跳转现有真实维护页；没有权限时字段级遮蔽且不提供假编辑。

## 2. 字段与动作

| 字段/动作 | 规则 | API/权限 | 审计 |
|---|---|---|---|
| installationNo/sourceProfile/sourceVersion/installedAt | 不可编辑 | GET `/installations`；`.installed.view` | 只读 |
| section/itemKey/sourceValue/currentValue/driftStatus | currentValue 由真实表解析器读取；失败标 UNKNOWN | GET `/installations/{id}` | 敏感值不返回 |
| 查看差异 | before/after 为非敏感配置或脱敏摘要 | GET `/installations/{id}/diff`；`.installed.view` | 高风险配置查看记 `CONFIG_DIFF_VIEWED` |
| 跳转修改 | 根据 ownerRoute 跳现有系统页；已安装页不直接写散落主数据 | 前端路由 + 目标页权限 | 目标页自行审计 |
| 发起变更 | 复制基线快照生成草稿 | POST changes；`.change.manage` | `CHANGE_DRAFT_CREATED` |

## 3. 数据、权限、安全

使用 `t_system_preset_installation` 快照；解析器复用组织、角色、流程、配置、课程/培养方案真实表。快照哈希用于完整性，不包含密码、token、身份证/联系方式明文。学校管理员和各责任域管理员按权限查看相应 section；审计员可看脱敏差异；平台运营无默认跨校读取权。导出配置清单后置，启用时必须水印和审计。

安装记录状态 `APPLIED/SUPERSEDED/ROLLED_BACK`，不允许删除；当前版本由同租户唯一 active 约束/事务保证。漂移不自动覆盖，必须通过变更中心。

## 4. 测试、施工与验收

测试：12 类读取；真实表值变化显示 DRIFTED；解析失败 UNKNOWN；跨租户安装号不泄露；敏感值不进响应；无目标页权限不出现跳转；发起变更复制正确哈希。施工：snapshot resolver→list/detail/diff API→树形详情页→目标路由映射→权限/漂移测试。回滚只关闭页面，不删除快照。

验收：客户可回答“现在装了什么、来自哪个国标/方案版本、后来谁改过、去哪里改”；修改组织名称后只显示受控漂移，不破坏组织 ID。
