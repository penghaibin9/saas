# 03-学生敏感信息脱敏规则

- **文档性质**：敏感字段清单、脱敏格式、完整值查看授权、密文存储规则
- **适用端**：PC 管理端 + miniapp + 后端 + 导出 / 审计链路
- **依据（只引用、不重写）**：`docs/security/00-等保三级安全基线总册.md` §3.1 全局脱敏规则、§3.2 按模块清单；`docs/database/00-数据库设计冻结总册.md` §17 隐私脱敏与数据导出、`t_student_contact/t_student_family/t_student_guardian_auth`；`docs/rbac/07-敏感操作权限清单.md`
- **当前阶段声明**：脱敏为**设计要求**。真正的加密存储、字段级权限、完整值审计**必须在后端与数据库层实现**；前端脱敏展示只是最后一道遮挡，**不能替代服务端返回控制**——若后端把完整值发给前端再由前端遮挡，等于泄露。
- **生成日期**：2026-07-04

## 一、红线 1：必须默认脱敏的字段清单

以下字段**默认脱敏**，未经字段级授权任何端 / 任何角色只能拿到脱敏值（引用 DB 冻结册 §17.1）：

| 字段 | 敏感级 | 承载表（示例） |
|---|---|---|
| 身份证号 | `SECRET`（完整）/ `SENSITIVE`（脱敏） | `t_student_profile` |
| 手机号 | `SENSITIVE` | `t_student_contact`（`contact_value_encrypted`） |
| 家庭住址 | `SENSITIVE` | `t_student_contact` |
| 家长 / 紧急联系人电话 | `SENSITIVE` | `t_student_contact`、`t_student_family` |
| 家庭经济困难信息 | `SENSITIVE`/`SECRET` | `t_student_family` |
| 心理信息 | `SECRET` | 相关帮扶 / 咨询记录 |
| 处分信息 | `SECRET` | 相关学工记录 |
| 实习打卡定位明细 | `SENSITIVE` | `t_checkin`（仅打卡时采集，最小化） |
| 企业联系人电话 | `SENSITIVE` | `t_enterprise` |
| 成绩明细 | `SENSITIVE` | 学业过程相关表 |
| 银行卡 / 薪资 | `SENSITIVE` | 就业 / 资助相关 |

> 补充：监护人姓名 + 联系方式组合、家庭成员信息按 `SENSITIVE` 处理。**姓名**在跨范围列表 / 外发场景可脱敏（姓 + `*`）。

## 二、全局脱敏格式（展示层，引用基线 §3.1）

| 类型 | 脱敏规则 | 示例 |
|---|---|---|
| 身份证号 | 前 6 + `****` + 后 4 | `110101********1234` |
| 手机号 | 前 3 + `****` + 后 4 | `138****5678` |
| 姓名 | 姓 + `*` | `张*` / `张**` |
| 家庭住址 | 区 / 县 + `****` | `海淀区****` |
| 银行卡 | 前 4 + `*****` + 后 4 | `6222*****8888` |
| 薪资 | 区间或 `****` | `8k–10k` / `****` |

## 三、敏感分级定义（`SENSITIVE_LEVEL`）

| 分级 | 含义 | 展示 |
|---|---|---|
| `PUBLIC` | 公开信息 | 无限制 |
| `INTERNAL` | 校内可见 | 权限范围内登录用户可见 |
| `SENSITIVE` | 敏感信息 | **默认脱敏**，看完整值需字段权限 + 审计 |
| `SECRET` | 机密信息 | **禁止前端明文展示**（如密码、完整身份证、心理 / 处分） |

## 四、红线 2：谁能看完整手机号 / 身份证 / 家庭信息

**默认所有人只看脱敏值。** 查看完整值必须同时满足：① 具备字段级完整权限 `field:view_full`（或 `student.identity.view`/`student.contact.view`/`student.guardian.view`）；② 目标学生落在本角色数据范围内；③ 每次查看**写审计** `SENSITIVE_VIEW`。

| 敏感数据 | 可看完整值（建议最小授权） | 只看脱敏 | 完全不可见（硬隔离） |
|---|---|---|---|
| 完整手机号 | 学校管理员、学籍专职（`REGISTRAR` 画像）；辅导员 / 学院角色**限本范围**且需审计（是否放开待后端确认，默认收紧） | 一般教师、跨范围查看 | 平台运营；企业导师 |
| 完整身份证号 | 学校管理员、学籍专职（`REGISTRAR`）；`SECRET` 级，**前端不明文展示**，确需查看走字段权限 + 审计，且优先只给"后 4 位 / 摘要" | 其他有档案查看权限的角色 | 平台运营；企业导师；普通任课 |
| 家庭 / 经济困难 / 心理 / 处分 | 学校管理员、学工 / 资助专职、**本班级**辅导员（按需、审计）；心理 / 处分建议再收紧到专职 | — | **平台运营、企业导师、指导教师（毕设 / 实习）一律硬隔离** |

要点：

- **平台运营 `PLATFORM_OPERATOR` 永远看不到学生敏感明细**（只看聚合 / 租户 / 审计，见 `07`）。
- **企业导师 `ENTERPRISE_MENTOR`** 对家庭 / 心理 / 处分 / 毕设成果**硬隔离**（DB 冻结册红线 `ENTERPRISE_AUTH_STUDENTS`）。
- 完整身份证号属 `SECRET`，即便授权也**优先只给后 4 位或核验用摘要**，避免整串明文落到前端 / 日志。
- "有数据范围" ≠ "能看完整值"：辅导员能看本班学生**脱敏**手机号是常态；看**完整**手机号才需字段权限 + 审计。

## 五、密文存储（后端 / 数据库红线）

引用 DB 冻结册 §17.2：

- 敏感字段一律 `xxx_encrypted`（密文，AES/KMS）+ `xxx_hash`（不可逆，供查重 / 匹配），**库里绝不存明文**。
- 展示按字段权限 `field:view_masked`（脱敏）/ `field:view_full`（完整）分别解密与裁剪。
- **provider 返回 `displayValue` + `rawValue` 分离**：页面默认只用 `displayValue`；`rawValue`（完整值）仅在授权 + 审计通过时由后端下发，未授权时后端**根本不返回** `rawValue`。
- 审计与日志里敏感字段**只存摘要 + hash，不存明文**（见 `05`）；`detail` 中 `SECRET`/`L4` 脱敏，禁止 `password/token`。

## 六、按模块脱敏 / 导出 / 日志速查（引用基线 §3.2）

| 模块 | 敏感项 | 展示 | 导出 | 日志 |
|---|---|---|---|---|
| 学生主档 | 身份证 / 手机 / 住址 / 监护人 | 默认脱敏，完整需权限+审计 | 加密导出+水印，批量需审批 | 查看/导出必审计，日志脱敏 |
| 数字迎新 | 身份证 / 联系方式 / 家庭 | 同主档 | 迎新季批量限流+水印 | 采集/修改审计 |
| 毕业设计 | 毕设材料 / 评阅意见 | 指导评阅链；**企业导师禁看** | 加密档案+水印 | 批阅/退回审计 |
| 岗位实习 | 单位 / 定位 / 周报照片 | 定位最小化；企业授权范围 | 禁企业导师批量导出 | 代打卡红线审计 |
| 毕业就业 | 去向 / 薪资 / 单位 | 薪资脱敏 | 就业数据导出强审计 | 批量导出限流 |

## 七、开发验收清单

- [ ] 敏感字段库内加密（`xxx_encrypted` + `xxx_hash`），无明文列
- [ ] provider 返回 `displayValue/rawValue` 分离；未授权不下发 `rawValue`
- [ ] 完整值查看：字段权限 + 数据范围 + `SENSITIVE_VIEW` 审计三重门
- [ ] 平台运营 / 企业导师对相应敏感字段硬隔离
- [ ] 前端全站默认渲染脱敏值；`SECRET` 字段前端无明文渲染路径
- [ ] 审计 `detail` 脱敏，无明文身份证 / 手机 / token
