# 第二阶段（第三批）公共组件使用指南 —— 页面骨架 / 表单 / 业务选择器 / 数据展示 / 体验

> **文档性质**：面向业务模块开发者的公共组件调用手册（新手可执行）
> **创建日期**：2026-07-09
> **在线预览**：登录后访问 `/dev/components`，展开「第三阶段公共组件」区块看真实渲染与交互
> **统一入口**：`import { Xxx } from '@/components/common'`（UI 基元 `import { AppButton, AppBadge } from '@/components/ui'`）
> **配套**：第一批见 `02-第一阶段交付级公共组件使用指南.md`；本批为「页面骨架 + 表单 + 业务选择器 + 数据展示 + 体验」五组。

术语（英文=中文）：component（组件）、props（组件参数）、emit（组件事件）、slot（插槽）、
v-model（双向绑定）、token（设计变量）、partial（部分完成）、blocked（阻塞）、implemented（已完成）。

---

## 0. 一句话原则

学工 / 教务 / 毕设 / 实习各模块开发新页面时，**页面壳、表单、师生/组织/批次选择器、分页、结果页、水印、打印**这些，一律从公共入口取，不要每个页面自己写一套。

安全红线（本批同样适用）：

1. **业务选择器（AppStudentPicker 等）只做 UI**。可见的学生/教师/班级必须由后端按**数据范围**返回，前端不得自行放大范围。
2. **AppPrintButton** 只触发打印，不生成正式套打模板；正式成绩单/证书套打由后端出 PDF。
3. **AppRichTextEditor / AppQRCode / AppChartCard** 为 partial（部分完成），未接库/后端前不得当成熟能力对外宣称。
4. **AppWatermark** 是展示层防护，不替代后端导出审计与权限。

## 2. 第二组：通用表单（form）

**校验用法**：`<AppForm ref="f" :model="model" :rules="rules">` → `await this.$refs.f.validate()` 返回 `{ valid, errors, firstInvalid }`。
`rules` 结构：`{ 字段: [{ required?, message?, min?, max?, pattern?, validator? }] }`，`validator(value, model)` 返回 `true` / 错误串 / Promise。

| 组件 | 说明 | 关键 props | v-model | 状态 |
|------|------|------|------|------|
| `AppForm` | 表单容器 + 上下文 + 校验 | `model/rules/layout/labelWidth/labelAlign/size/disabled/readonly`；emit `submit` | — | implemented |
| `AppFormItem` | 字段行（label+必填+帮助+错误） | `label/prop/required/help/hint/error`；作用域 slot `{id,disabled,readonly,status}` | — | implemented |
| `AppFormSection` | 表单分组（fieldset，可整段禁用） | `title/description/compact/disabled` | — | implemented |
| `AppTextInput` | 文本输入 | `type/placeholder/clearable/size/status/maxlength`；slot `prefix/suffix` | 值 | implemented |
| `AppNumberInput` | 数字输入（步进/夹取/精度） | `min/max/step/precision/controls/size/status` | Number | implemented |
| `AppTextarea` | 多行文本 | `rows/maxlength/showCount/status` | 字符串 | implemented |
| `AppSelect` | 单选下拉（原生，无障碍好） | `options/labelKey/valueKey/placeholder/size/status` | 值 | implemented |
| `AppMultiSelect` | 多选下拉（标签+勾选+搜索） | `options/searchable/max/status` | 数组 | implemented |
| `AppRadioGroup` | 单选组（dot/button） | `options/variant/size/block` | 值 | implemented |
| `AppCheckboxGroup` | 多选组 | `options/max/size/block` | 数组 | implemented |
| `AppSubmitBar` | 提交条（提交/取消/重置） | `submitText/showCancel/showReset/loading/disabled/danger/sticky/align`；emit `submit/cancel/reset` | — | implemented |
| `AppRichTextEditor` | 轻量富文本 | `placeholder/disabled/readonly` | HTML | **partial** |

> `AppFormValidator`（原规划）已合并进 `AppForm`（rules + validate()），不再单独出组件。
> `AppRichTextEditor` 基于 contenteditable，**HTML 未消毒**，落库/展示前必须后端 XSS 清洗；图片/粘贴清洗未做 → partial。

```vue
<AppForm ref="form" :model="m" :rules="{ title:[{required:true,min:4,message:'题目≥4字'}] }" label-width="90px">
  <AppFormItem label="题目" prop="title">
    <template #default="{ status }"><AppTextInput v-model="m.title" :status="status" clearable /></template>
  </AppFormItem>
</AppForm>
```

## 3. 第三组：高校业务选择器（picker）—— 全部 partial

**统一能力**：`options`（本地选项）/ `remoteSearch(keyword)=>Promise<options>`（远程搜索预留）/ `multiple`（多选）/ `clearable` / `disabled` + `disabledReason` / `dataScopeHint`（数据范围提示）/ empty / loading / error。

| 组件 | 用途 | 备注 |
|------|------|------|
| `AppRemoteSelect` | **基座**：单/多选 + 本地/远程 + 数据范围提示 | 其余 Picker 都基于它 |
| `AppStudentPicker` | 选学生（学号/姓名） | dataScopeHint「仅你范围内学生」 |
| `AppTeacherPicker` / `AppMentorPicker` | 选教师 / 选导师 | 按管理范围 |
| `AppClassPicker` / `AppMajorPicker` / `AppCollegePicker` | 班级 / 专业 / 学院 | |
| `AppCoursePicker` | 课程 | |
| `AppRolePicker` | 角色（不超过自身权限） | |
| `AppTenantPicker` | 学校/租户（仅运营方） | |
| `AppCompanyPicker` / `AppPositionPicker` | 企业 / 岗位 | 实习 |
| `AppBatchPicker` | 批次（毕设/实习） | |
| `AppOrgCascader` | 学院→专业→班级级联 | 本地 data 树；远程懒加载未接 |
| `AppAcademicYearPicker` / `AppTermPicker` | 学年 / 学期 | 基于 AppSelect |

> **为什么全是 partial**：这批只统一了 UI 与调用规范，**未接真实后端**。业务方注入 `remoteSearch` 接真实接口后，仍受后端**数据范围**约束；接入并验收前一律标 partial，不得宣称「已接真实师生/组织数据」。

```vue
<!-- 单选，远程搜索交给业务方注入 -->
<AppStudentPicker v-model="stuId" :remote-search="api.searchStudents" data-scope-hint="仅本班学生" />
<!-- 多选，本地选项 -->
<AppTeacherPicker v-model="ids" multiple :options="teacherOptions" />
<!-- 组织级联 -->
<AppOrgCascader v-model="org" :data="orgTree" :levels="['学院','专业','班级']" />
```

## 4. 第四组：数据展示增强（display）

| 组件 | 说明 | 关键 props / emit | 状态 |
|------|------|------|------|
| `AppPagination` | 分页器 | `total/page/pageSize/pageSizes/showSizeChanger/showJumper`；emit `update:page/update:pageSize/change` | implemented |
| `AppSearchBox` | 搜索框（防抖+回车+清空） | `debounce/button/size`；emit `search/clear` | implemented |
| `AppQuickFilterChips` | 快捷筛选胶囊（全部/待审/已过） | `options[{label,value,count}]/multiple/allowClear` | implemented |
| `AppProgressBar` | 线性进度条 | `value/status(auto..)/showText/striped/size` | implemented |
| `AppDescriptionList` | 详情键值表 | `items[{label,value,span}]/columns/layout/bordered/size`；具名 slot 按 item.key | implemented |
| `AppOperationResult` | 结果页（导入/提交/审核完成） | `status/title/description/stats[{label,value,type}]`；slot default/`actions` | implemented |
| `AppColumnConfig` | 列显示/顺序配置（配合 DataTable） | `columns[{key,label,visible,required}]`；emit `update:columns` | implemented |
| `AppChartCard` | 图表卡片容器 | `title/subtitle/loading/empty/minHeight`；slot `toolbar`/default/`footer` | **partial** |

> 既有 `DataTable` / `AdvancedFilter` / `AppTimeline` 不重写，本组只补它们缺的能力。
> `AppChartCard` 不强绑图表库：只提供外壳 + 加载/空状态，图表本体由调用方在默认 slot 渲染 → partial。

```vue
<AppOperationResult status="success" title="Excel 导入完成"
  :stats="[{label:'成功',value:120,type:'success'},{label:'失败',value:3,type:'danger'}]">
  <template #actions><AppButton>下载错误行 Excel</AppButton></template>
</AppOperationResult>
```

## 5. 第五组：体验增强（experience）

| 组件 | 说明 | 关键 props / emit | 状态 |
|------|------|------|------|
| `AppWatermark` | 防截屏水印（学校名+用户+时间） | `text/fontSize/color/rotate/gapX/gapY`；slot default（被覆盖内容） | implemented |
| `AppPrintButton` | 打印（整页 / 指定元素 / 自定义 handler） | `label/printSelector/handler/title`；emit `print` | implemented |
| `AppAvatarGroup` | 头像组（叠加+溢出 +N） | `avatars[{name,src}]/max/size` | implemented |

## 7. 业务页面禁止自写清单（有公共组件就必须用）

以下能力**禁止**业务页面自己另写一套，必须调用公共组件；能力不够时**增强公共组件**，不允许在业务页面绕开：

1. 不允许自写**权限按钮** → `AppPermissionButton`
2. 不允许自写**脱敏函数/明文展示** → `AppSensitiveText`
3. 不允许自写**审计日志展示** → `AppAuditTrail`
4. 不允许自写**附件列表/上传态** → `AppFileList` / `AppFilePreview`
5. 不允许自写**导出确认** → `AppExportConfirm` + `AppExportButton`
6. 不允许自写**状态/风险颜色** → `AppStatusTag` / `AppRiskTag`
7. 不允许自写**空/加载/错误状态** → `AppGlobalState` / `EmptyState` / `AppOperationResult`
8. 不允许自写**批量操作条** → `AppBatchActionBar`
9. 不允许自写**审批区/审批时间线** → `AppApprovalPanel` / `AppWorkflowTimeline`
10. 不允许自写**学生/教师/组织/批次选择器** → 对应 Picker
11. 不允许自写**分页/搜索框/快捷筛选/详情键值表** → `AppPagination` / `AppSearchBox` / `AppQuickFilterChips` / `AppDescriptionList`
12. 不允许自写**页面壳/区块卡/工具栏/表单控件** → layout 组 / form 组
13. 不允许自写**日期选择/截止时间** → 公共日期组件族

## 8. 新页面接入公共组件检查清单

新页面标 implemented（已完成）前必须逐项检查（不满足只能标 partial 并写入历史欠账）：

1. 用了 `AppPageShell` / `AppSectionCard`？
2. 用了 `AppToolbar`？
3. 列表用了既有 `DataTable`（或统一列表）？
4. 筛选用了既有 `AdvancedFilter` / `AppQuickFilterChips`？
5. 日期用了公共日期组件？
6. 状态/风险用了 `AppStatusTag` / `AppRiskTag`？
7. 操作按钮用了 `AppPermissionButton`？
8. 二次确认用了 `AppConfirmDialog`？
9. 敏感字段用了 `AppSensitiveText`？
10. 操作留痕用了 `AppAuditTrail`？
11. 附件用了 `AppFileList` / `AppFilePreview`？
12. 导出用了 `AppExportButton` / `AppExportConfirm`？
13. 业务对象选择用了对应 Picker？
14. 表单用了 `AppForm` + 控件 + `AppSubmitBar`？
15. 有 empty / loading / error 三态？
16. `npm run build`（构建）通过、无明显 console error（控制台错误）？

## 9. 商业 UI 验收清单（每个组件自检）

1. 第一眼像成熟 SaaS（软件即服务）产品，不像临时页/学生作业；
2. 符合清透学院蓝，全部走 token（设计变量），无私自硬编码颜色；
3. 无土味大色块；圆角/阴影/边框/字号/字重/间距统一；
4. hover（悬停）舒服；disabled（禁用）清楚；loading（加载）不突兀；
5. empty（空状态）有正式文案；error（错误）有解决建议/重试；
6. 支持 compact（紧凑）密度（表单/标签/选择器/分页均有）；
7. 交互组件支持键盘/focus（聚焦）/aria（无障碍标签），状态不只靠红绿区分；
8. responsive（响应式）：窄屏、抽屉内、弹窗内、工具栏内都不塌；
9. 能在 `/dev/components` 展示、适合截图给学校看。
