## 1. 项目定位（必须牢记）

本项目是 **职校学生全生命周期 SaaS 平台**：

- ✅ 真实可落地、可维护、可接后端、可销售、可投标、可部署的多租户 SaaS
- ❌ 不是 Demo / 学生作业 / 单校定制后台 / AI 自嗨堆页面

**最高规则（与根目录 `CLAUDE.md` 一致）**：

1. 市场验证过的成熟商业系统流程，优先级高于早期浅设计、高于 AI 想象。
2. 能配置、能授权、能审计、能验收、能部署；禁止假按钮、假数据、mock 冒充成功。
3. 正式数据库标准 = **MySQL**（utf8mb4）；SQLite/PostgreSQL 配置仅作历史遗留，不作新开发验收依据。
4. 正式导入导出 = **Excel/xlsx**；CSV 不作正式交付标准。
5. 权限必须后端校验；禁止只靠前端隐藏菜单。

4. **教务中心**：按 `13B-教务中心V1范围与开发顺序.md` 逐模块，**不与学工 B 包并行大乱改**

6. **系统管理/RBAC**：细粒度 permission key 后端拦截 — 上线前必须收口

## 7. 验收与状态标记铁律

- `implemented`：前端+后端+MySQL+权限+审计+测试+build 全过；navPlan 同步
- `partial`：有真实页面/接口但不满足生产级闭环；**必须**写入 `历史欠账.md`
- `planned`：仅规划，无 path / 无路由 / 不可点击

**模块做完的定义**（摘自施工记录 README）：能部署、能访问、能存数据、能流转、能审计、能测试、能交付。
