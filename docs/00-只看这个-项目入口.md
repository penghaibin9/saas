# 职校学生全生命周期 SaaS 平台 · 项目入口

## 1. 前端开发前先看这里

以后任何 AI 开发前，都必须先读本文件。

## 2. PC 管理端设计稿在哪里

PC 管理端最终设计稿目录：

docs/ui/fable5-pc-final/

开发这些页面前必须参考它：

- PC 登录页
- PC 首页 / 工作台
- 学生中心
- 学生列表
- 学生360档案
- 数据中心
- 权限与审批中心
- 角色切换
- 主题系统

注意：
这里面的 HTML / PDF / zip 是设计参考，不是生产代码。
不得把导出的 HTML 直接复制进 frontend/src。

## 3. 小程序设计稿在哪里

学生小程序和教师移动工作台最终设计稿目录：

docs/ui/fable5-miniapp-final/

开发这些页面前必须参考它：

- 学生小程序首页
- 学生待办
- 学生进度
- 学生消息
- 学生我的
- 老师移动工作台
- 老师角色切换
- 老师待办
- 老师审批
- 老师学生简档

小程序不能照抄 PC，不能做成 PC 缩小版。

## 4. 小程序业务文档在哪里

开发小程序前，还必须读取：

08A-学生小程序中心.md
08B《教师移动工作台中心》.md

## 5. 后续 AI 开发规则

开发 PC 页面时，先看：

docs/ui/fable5-pc-final/

开发小程序页面时，先看：

docs/ui/fable5-miniapp-final/
08A-学生小程序中心.md
08B《教师移动工作台中心》.md

## 6. 禁止事项

- 不要把设计稿 HTML 当生产代码直接复制
- 不要把设计稿放进 frontend/src
- 不要放进 backend
- 不要改 API contract
- 不要改 provider
- 不要改 mock API
- 不要改 router
- 不要写后端
- 不要写数据库
- 不要硬编码学校名称
- 学校品牌必须来自 tenantBrandConfig

## 7. 当前结论

PC 管理端 UI 基本定型。
小程序端单独重新设计。
后续前端开发必须先引用对应设计稿目录。
