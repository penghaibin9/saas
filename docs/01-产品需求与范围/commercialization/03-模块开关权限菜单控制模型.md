# 03-模块开关·权限·菜单控制模型 V1.0

> 性质：蓝图冻结文档（P5.5 产物），不含代码。前端实现排期见《00-作战手册》第 14 章。
> 单一消费原则：学校端任何入口的可见/可用 = **licenseContext（租户+套餐+模块+功能+配额+到期）∩ permissionContext（角色+权限点+数据范围）**，由统一组合函数计算，页面禁止自行 if 判断。

## 1. 十层开关模型

| 控制层级 | 控制对象 | 示例 | 谁配置 | 学校端表现 | 前端如何体现 |
|---|---|---|---|---|---|
| 1 租户级 | 整所学校 | 某校 status=停用 | 平台后台 #2 | 全端不可登录 | 登录/入口拦截，展示"服务已停用" |
| 2 套餐级 | 模块集合+配额默认 | 标准版=05+06+07轻量 | 平台后台 #5 | 决定初始 licenses/quotas | licenseContext 初始化来源 |
| 3 模块级 | 单业务中心 | INTERNSHIP=ACTIVE、GD=DISABLED | 平台后台 #4 | 未开模块菜单隐藏、路由 403、指标消失 | 菜单过滤+路由守卫+指标过滤三处同源 |
| 4 功能级 feature | 模块内能力 | internship.enterprise_portal=off、export.encrypted_pdf=off | 平台后台 #12 | 对应入口/按钮不出现 | useFeature(key) 组合函数 |
| 5 菜单级 | 导航节点 | 某校隐藏"统计分析" | 平台菜单模板（P3 期）+模块开关推导 | 菜单树差异 | 菜单=配置数据，不写死在组件 |
| 6 按钮级权限 | 操作 | gd:review:approve 仅指导教师 | 学校端角色管理（11 中心）| 无权按钮不渲染或 disabled+提示 | AppButton :disabled + v-perm 指令（P8） |
| 7 数据范围 | 行级可见性 | INTERN_STUDENTS / ENTERPRISE_AUTH_STUDENTS | 11 中心角色配置 | 同页不同人不同数据 | provider 查询参数注入 scope |
| 8 到期只读 | 写操作总闸 | GD license=READONLY | 平台后台 #4/#6 | 历史可看、写全禁、页头横幅 | 全局 readonly 计算属性→写按钮统一 disabled+AppInlineAlert |
| 9 试用锁定 | 试用限制包 | TRIAL：200 人+禁导出 | 平台后台 #5/#6 | 功能可用但带试用角标+限额 | licenseContext.trial 叠加 quota/feature 覆写 |
| 10 人数限制 quota | 数量上限 | students.limit=1500 | 平台后台 #4 | 新增学生被拦+升级提示 | 新增动作前 useQuota(key) 校验 |

生效优先级（高→低）：租户停用 > 到期只读 > 模块禁用 > 试用覆写 > 功能开关 > 角色权限。上层拦住，下层不再判断。

## 2. 七个关键问题的冻结答案（与作战手册第 5 章一致）

1. 未购买模块 → **菜单隐藏**（不置灰）；销售展示走演示租户。
2. 到期 → **只读不隐藏**：数据可查、写按钮 disabled、页头 AppInlineAlert（warning，不可关）"模块已到期，历史数据可查看，续费请联系管理员"。
3. 超人数 → 新增动作拦截 + toast/对话框"已达套餐上限 1500 人，请联系升级"；存量功能不影响。
4. 未授权模块的 Dashboard → **指标卡/风险/待办整体不渲染**（聚合层按 licenses 过滤，不是前端藏卡）。
5. 学生端同受控：学生菜单 = 学校已购模块 ∩ 学生当前阶段（09B 阶段化）∩ 端开关。
6. 企业端独立开关：feature `internship.enterprise_portal`，默认标准版起开、基础版关。
7. 移动端/小程序独立端开关：`channel.miniapp`、`channel.teacher_mobile`，随套餐层级默认。

## 3. 学校端受控全景表

| 学校端位置 | 受什么开关控制 | 未授权表现 | 到期表现 | 只读表现 | 前端开发注意 |
|---|---|---|---|---|---|
| 学校 PC 管理端菜单 | 层3模块+层5菜单+层6角色 | 菜单项不渲染 | 菜单在，挂"只读"角标（BasePortalLayout 已支持） | 同到期 | 菜单必须来自配置数组，禁止组件内写死 |
| 学生 PC 门户菜单 | 层3+学生阶段+层6 | 不渲染 | 只读角标 | 同 | StudentPortalLayout menus 由过滤函数产出 |
| 学生小程序服务入口 | 层3+channel.miniapp | 入口卡不出现 | 卡在，点入只读 | 提交按钮禁 | P11 后实现，结构先冻结 |
| 教师移动工作台入口 | 层3+channel.teacher_mobile | 同上 | 同上 | 批阅按钮禁 | 同上 |
| 数据驾驶舱指标 | 层3（按模块归属过滤指标 id 前缀 gd-/int-/emp-） | 整卡不渲染 | 渲染+角标"数据截至到期日" | 同 | 过滤放聚合出口处，单点实现 |
| Dashboard 待办/风险 | 层3（risk/task 带 moduleCode） | 对应条目过滤 | 保留展示、处理按钮禁 | 同 | RiskEvent/TeacherTask 需补 moduleCode 字段（P7） |
| 导出按钮 | 层4 export.*（三档：台账/加密档案/脱敏外发）+层6 | 按钮不渲染 | 禁用+提示 | 禁用 | 统一 ExportButton 包装或 useFeature |
| 审批/批阅按钮 | 层6权限+层8只读 | 不渲染 | disabled+悬浮提示 | disabled | 全走 AppButton disabled，禁止自造按钮 |

| 到期只读提示 | 层8 | — | 页头横幅+菜单角标+按钮禁 | 本体 | AppGlobalState 已有 readonly 态，复用勿新造 |

## 4. licenseContext（前端 mock 数据结构冻结）

```
licenseContext = {
  tenant: { tenantId, name, status },            // 层1
  subscription: { packageId, packageName, start, end },  // 层2
  licenses: [ { moduleCode, status: TRIAL|ACTIVE|EXPIRED|READONLY|DISABLED,
                start, end, enabledFeatures: [featureKey] } ],   // 层3+4
  quotas: { students: {limit, used}, teachers: {...}, enterpriseMentors: {...} }, // 层10
  channels: { miniapp: bool, teacherMobile: bool }  // 端开关
}
```

组合函数冻结（P6-2 实现，命名不许改）：`useModule(moduleCode)` → {enabled, readonly, trial}；`useFeature(featureKey)`；`useQuota(quotaKey)` → {exceeded, limit, used}。菜单过滤、路由守卫、指标过滤、按钮禁用全部只准调这三个函数。
