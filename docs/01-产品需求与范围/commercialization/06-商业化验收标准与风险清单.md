# 06-商业化验收标准与风险清单 V1.0

> 用法：T16 验收包与 P10 演示冻结的对照底稿。风险全表 30 条见《00-作战手册》第 17 章，此处为验收执行版。

## 1. 阶段通用验收门（每阶段全部满足才算过）

1. lint 0 error / 0 warning；build 通过。
2. 报告含"停止声明"；改动文件清单与允许范围一致（越界=不通过）。
3. 无硬编码颜色；无页面直接 import mock；菜单不写死；口径函数唯一（dashboardRiskRules）。
4. 每个新页面三态齐（loading/empty/error）+ 该有的 readonly/noLicense 态。
5. 与冻结文档偏离点已列出并获认可。

## 2. 商业化专项验收（P6-2 起累加生效）

| 验收项 | 操作 | 期望 |
|---|---|---|
| 模块关闭 | /platform 关某校 GD | 该校毕设菜单消失、直达路由见 noLicense 页、首页 gd-* 指标消失 |
| 到期只读 | 置 INTERNSHIP=READONLY | 页头不可关横幅、全部写按钮 disabled、历史可查 |
| 试用限制 | 演示租户 C | 试用角标、导出不可用、超 200 人新增被拦 |
| 超额拦截 | quota.students used≥limit | 新增学生弹升级提示，存量正常 |
| 端隔离 | 学生账号访问 /admin、企业访问 /platform | 拦截并跳自己门户 |
| 平台红线 | 遍历 /platform 全页 | 无任何学生业务明细 |
| 单模块完整感 | 演示租户 B（只买实习） | 首页/菜单/待办/风险全部只见实习且不残缺 |
| 下钻闭环 | 点每个 drillable 指标 | 落到真实页面且带筛选 |
| 审计留痕 | 翻转任一开关 | 生成审计记录（谁/何时/前后值） |

## 3. P10 可演示商业版本冻结标准（10 分钟动线）

0-1min 平台后台：给"石化职院"开通实习模块 → 1-3min 切该校管理端：菜单出现、工作台指标就位 → 3-5min 学生端：我的实习→打卡→交周报 → 5-7min 教师端：退回（原因≥5字）→学生重交→通过 → 7-8min 首页风险联动数字变化+下钻 → 8-9min 切演示租户 C 展示到期只读与试用 → 9-10min 平台后台审计与续期。全程零穿帮、零 mock 痕迹外露。
