## 1. P5.5 阶段定位

P5.5 是**文档确认阶段**，在 P5（商业化页面清单与路由冻结）完成之后、P6（业务页面开发）开始之前执行。

本阶段只做一件事：**把 SaaS 后台、模块开关、套餐、到期、权限、菜单的默认方案写成可执行的拍板记录**，供后续阶段照做。

**本阶段明确不做：**

- 不开发页面
- 不新增真实路由
- 不写后端
- 不接真实 API
- 不修改 `frontend/src`
- 不做 UI 视觉设计终稿

**本文档用途：**

冻结 SaaS 后台路由域（`/platform`）、模块授权模型（`licenseContext` + `permissionContext`）、套餐与单卖策略、到期/未购行为、P6 分期边界，以及当前暂停项。后续 P6 及以后阶段不得违反本文档拍板结论。

## 3. 套餐默认方案确认

以下套餐体系照《01-模块商品化与套餐体系冻结》《00-总控手册》§3 采用，作为报价与签单默认方案。

| 套餐 | 是否采用 | 备注 |
| --- | --- | --- |
| 免费试用版 | ✅ 采用 | 单模块全功能 + 基础件；学生≤200、30 天；到期只读 |
| 基础版（单模块） | ✅ 采用 | 06 或 05 任一 + 基础件；3-6 万/年/模块 |
| 标准版 | ✅ 采用 | 05+06+07 轻量 + 移动端 + 轻量驾驶舱；8-15 万/年 |
| 专业版 | ✅ 采用 | 标准版 + 完整驾驶舱 + 学业预警 + 流程配置；15-25 万/年 |
| 旗舰/集团版 | ✅ 采用 | 全模块 + 迎新 + 集成 + 多校区；25-40 万/年 |
| 单模块采购版 | ✅ 采用 | 任一可单卖模块叠加；同基础版限制，叠加 9 折 |
| 私有化部署版 | ✅ 采用（后期规划） | 旗舰全量 + 本地部署；40-80 万买断 + 15% 维保；当前不开发 |

**全局默认规则（一并生效）：**

- 所有套餐到期 → **只读**（不隐藏、不删数据）
- 试用默认 **30 天**
- 允许 **单模块续费**

- **不允许超过 3 个页面**
- **不允许做 `/platform`**
- **不允许做企业端**
- **不允许接真实 API**
- **不允许改 Dashboard 契约**（P4.1 已冻结）
- **必须遵守**：页面不直连 mock、不拼 API path，只走 `modules/*/provider`

### P6-2 才允许

1. **UI 视觉方向未最终确认**（学校管理端 Dashboard 高级教育 SaaS 版待拍板）

**下一步建议：**

等 UI 视觉方向重新设计完成并通过人工确认后，再决定是否进入 **P6-1**（实习 3 页闭环）。在此之前，仅允许文档类工作（如本 P5.5 记录提交），禁止 `frontend/src` 业务页面开发。
