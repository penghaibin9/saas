# 06 · 等保三级待后端补齐清单（SECURITY-P0）

> 前端 P0 补强完成后，以下事项**必须由后端 / 网关 / 数据库 / 运维完成**，缺一不可。
> 在此清单完成并通过测评之前，任何场合不得宣称系统满足等保三级。

## 一、认证与会话（后端）
- [ ] 真实统一身份认证（口令 + 可选 MFA），密码哈希存储（bcrypt/argon2/SM3+盐）
- [ ] 登录失败锁定、防爆破限流、验证码
- [ ] 会话服务：HttpOnly Cookie 或短时 accessToken + refresh，并发控制、强制下线、首登改密
- [ ] 401/403/419 语义与前端安全错误页对齐

## 二、授权与数据范围（后端）
- [ ] 服务端 RBAC + 数据范围过滤（前端 getVisibleAdminMenu/guards 仅是展示层）
- [ ] 字段级授权：按角色返回明文或脱敏值（矩阵见《02-敏感字段脱敏规则.md》§4）
- [ ] 平台运营与学校租户强隔离：运营侧接口不返回学生敏感明文
- [ ] 系统管理员不默认拥有业务数据明文权限

## 三、数据加密与密钥（后端 / DB / KMS）
- [ ] 数据库存储加密（TDE 或字段级 SM4），备份加密
- [ ] KMS/HSM 密钥管理与轮换；国密算法选型（SM2/SM3/SM4）
- [ ] 字段加密公钥下发接口（前端 crypto-boundary 占位对接）
- [ ] 文件存储加密 + 限时签名 URL + 下载鉴权

## 四、传输与边界（网关 / Nginx）
- [ ] 全站 HTTPS（TLS1.2+）、HSTS、安全响应头（CSP、X-Frame-Options、X-Content-Type-Options）
- [ ] WAF、接口限流、IP 策略

## 五、审计与日志（后端 / 运维）
- [ ] 服务端审计日志（登录/导出/敏感查看/权限变更/审批），留存 ≥6 个月，防篡改
- [ ] 前端审计事件（audit-event.helper 构造）仅作参数来源，以服务端记录为准
- [ ] 导出服务端拦截：权限 + 行数 + 用途 + 服务端水印

## 六、制度与测评（运维 / 管理）
- [ ] 账号生命周期与最小权限制度、堡垒机、变更审批
- [ ] 渗透测试、漏洞扫描、等保差距分析与整改
- [ ] 应急预案与演练、数据分类分级制度文件
