# 02 · 敏感字段脱敏规则（SECURITY-P0）

> 唯一事实来源：`frontend/src/utils/security/sensitive-fields.js`（字段注册表）
> 算法出口：`frontend/src/utils/security/mask.js`；权限型判断：`role-mask.js`。
> 页面禁止各自手写脱敏。

## 一、脱敏样式

| 类别 kind | 样式 | 示例 |
| --- | --- | --- |
| phone（含 mobile/parentPhone/guardianPhone/emergencyPhone） | 前3 + **** + 后4 | 138****5678 |
| idCard（含 id_card/idcard） | 前3 + *…* + 后4 | 430***********1234 |
| bankCard | 分组样式 | 6222 **** **** 1234 |
| email | 首字符 + *** + @域名 | p***@example.com |
| address / homeAddress | 保留省市，后半隐藏 | 湖南省长沙市****** |
| familyContact | 姓 + * | 张* |
| fileUrl / attachmentUrl | 隐路径与签名参数，仅留文件名 | …/report.pdf |
| studentNo | 默认不脱敏；需要时前4后2 | 2023****01 |
| name | 默认不强制全脱敏，按角色/场景决定 | — |
| password / token | 恒定 ******，禁止前端明文出现 | ****** |

## 二、分级（沿用 00 总册 §3）

PUBLIC（可公开）→ INTERNAL（校内可见，如姓名/学号默认保留）→ SENSITIVE（默认脱敏展示）→ SECRET（禁止前端明文）。

## 三、记录级脱敏

列表 / 导出预处理统一走 `maskRecordByFields(record)`：按注册表处理全部登记字段，返回新对象，原对象不变。

## 四、权限型脱敏（角色矩阵，fail-closed）

| 角色 | 可看明文（限数据范围内） | 强制脱敏 |
| --- | --- | --- |
| 学生本人 | 自己的手机号、邮箱 | 证件号仍部分脱敏 |
| 辅导员 | 所带学生 phone / emergencyPhone / email | 身份证、银行卡 |
| 指导教师 | 所指导学生 phone | 身份证、家庭住址 |
| 就业老师 | phone / email | 身份证、家庭住址 |
| 学院管理员 | 数据范围内联系方式类 | 身份证、银行卡 |
| 教务/学籍老师 | phone | 其余默认脱敏 |
| 系统管理员 | 无（不默认绕过业务脱敏） | 全部 |
| 平台运营 | 无（租户隔离，不看学校学生明文） | 全部 |
| 未知角色 | 无 | 全部（fail-closed） |

补充规则：
- `idCard / bankCard / secret` 任何角色 UI 默认不展示完整值（如需完整值走"点击查看→审计留痕"流程，由后端授权返回）。
- `permissionActions.viewSensitive` 显式授权可放行联系方式类明文，但不放行上述强制脱敏类。
- 数据范围外（inScope=false）一律脱敏。
- 前端判断仅是展示层；后端必须按同一矩阵做字段级授权。
