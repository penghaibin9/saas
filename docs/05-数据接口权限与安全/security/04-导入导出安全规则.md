# 04-导入导出安全规则

- **文档性质**：批量导入校验、数据导出三档、水印、导出审计、批量二次确认、SoD
- **适用端**：PC 管理端为主（导出 / 批量），后端导出服务 + 审计
- **依据（只引用、不重写）**：`docs/05-数据接口权限与安全/security/00-等保三级安全基线总册.md` §9.3 导出、§8 审计；`docs/05-数据接口权限与安全/database/00-数据库设计冻结总册.md` §17.3 三种导出模式、`t_export_task`、`t_security_audit_log`；`docs/05-数据接口权限与安全/rbac/07-敏感操作权限清单.md` 2.2/2.3

## 一、批量导入安全

| 环节 | 规则 |
|---|---|
| 模板 | 固定模板 + 表头校验；拒绝任意结构文件 |
| 文件 | 走上传白名单（`xlsx/xls/csv`）与大小限制（见 `06`），先病毒扫描 |
| 校验 | 逐行校验必填 / 格式 / 唯一性（学号 / 身份证 hash 去重）；错误行落 `t_student_import_error` 并回报，不静默丢弃 |
| 事务 | 批次事务 + `t_student_import_batch` 台账；失败可回滚 / 可重导 |
| 数据范围 | 导入对象须落在当前角色数据范围与本租户 `tenant_id` 内 |
| 敏感字段 | 导入的身份证 / 手机等**入库即加密**（`xxx_encrypted` + `xxx_hash`），日志不留明文 |
| 审计 | 导入写审计（批次、行数、成功 / 失败数、操作人） |

## 二、红线 3：导出必须水印 + 审计（三档）

导出前先校验 **功能权限点 + 数据范围**，再按敏感度走对应档位。三档对应 `security.export.*`（引用 rbac/07 与 DB §17.3）：

| 档位 | 权限点 | 内容 | 水印 / 加密 | 审计 |
|---|---|---|---|---|
| **LIST 当前列表导出**（CSV/Excel） | `security.export.list` | 摘要级、字段少、敏感字段**脱敏** | L3/L4 加水印 | `EXPORT` + `t_export_task` + `t_security_audit_log` |
| **ENCRYPTED_ARCHIVE 加密档案导出**（PDF 档案） | `security.export.archive` | 较完整档案 | **加密 + 水印 + 防伪二维码 + 时间戳 + 导出人 / 用途**；异步任务，下载链接短期有效 | 同上 |
| **DESENSITIZED 脱敏外发导出** | `security.export.desensitized` | 对外提供 | **默认 `DISABLED`**（专业版开启）；姓名→随机编码、身份证删除 / 摘要、手机删除、地址删除；须填**外发对象 / 目的 / 保留期限**，记录脱敏规则版本 + 文件 hash | 同上 |

**水印必备要素**（L3/L4 导出强制，引用基线 §9.3）：学校、导出用户、时间、用途 / `requestId`；Excel/PDF 水印**半透明重复、不可轻易去除**。

**导出通用红线**：

- 先按数据范围过滤可导出集合，再叠加**行数上限 ≤ 5000 行**。
- **限流：5 次 / 小时 / 用户**；超限拒绝并审计。
- `SECRET` 级字段（完整身份证等）**一律不导出明文**。
- 平台运营不导出学生业务明细；企业导师**禁批量导出**（毕设 / 周报 / 定位等）。
- 每一次导出**必写审计** `EXPORT`，并落 `t_export_task`（模式 / 条件 / 字段清单 / 数量 / 文件 hash / 状态）。

## 三、红线 4：批量操作必须二次确认

（与 `02` 第四节一致，此处聚焦导出 / 批量数据操作）

| 要求 | 说明 |
|---|---|
| 前端二次确认 | 批量导出 / 批量改学籍 / 批量催办等弹确认框，展示对象数量 + 范围摘要；高危批量需勾选风险提示或再次确认 |
| 后端整批校验 | 对象集合必须**完全落在**数据范围内，混入超范围 ID **整批拒绝**，禁止部分静默执行 |
| 幂等 | 批量写带 `request_id`，重复提交返回 `IDEMPOTENCY_CONFLICT` |
| 审计 | 批量操作与批量导出全部写审计，记录数量 / 范围 / 结果 |

## 四、职责分离（SoD）

- **导出（尤其加密档案 / 外发）走 SoD：申请人 ≠ 审批人**，冲突返回 `SOD_VIOLATION`（409）。
- 大批量 / 高敏感导出建议"申请 → 审批 → 异步生成 → 短期链接下载"闭环，全链路留痕。

## 五、下载安全

- 导出文件走**短期签名 URL**（一次性或短 TTL，见 `06`），禁止公开直链。
- 下载前再校验 user + tenant + 数据范围 + 文件归属；下载写审计。
