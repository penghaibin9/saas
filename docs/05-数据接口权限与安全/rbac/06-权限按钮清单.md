# 06-权限按钮清单

- **文档性质**：全量权限点/按钮清单台账
- **适用端**：PC 管理端 + miniapp（本清单以 PC 端 `workflow.mock.js permissions[]` 与 `student.mock.js` 学生模块细粒度按钮为主，miniapp 按钮键详见 `03-miniapp权限矩阵.md` 第四节，本表不重复列出以免口径分裂）
- **依据**：
  - `frontend/src/modules/workflow/`（`workflow.mock.js` permissions[] 全量）
  - `frontend/src/mocks/student/student.mock.js`（roleProfiles 学生模块细粒度按钮全量）
  - `frontend/src/modules/workflow/context/permission.context.js`（判断入口）
- **当前阶段声明**：本清单为前端 mock 权限点全量台账，"默认启停"字段依据 mock 数据中标注的 `DISABLED`/启用状态如实记录；未标注禁用的权限点默认视为 ENABLED（启用）。"绑定角色"列出的是当前 mock 中已绑定该权限点的角色，不代表权限模型的唯一合法绑定方式，后续可由后端角色管理界面调整。
- **生成日期**：2026-07-04

## 一、权限点类型说明

| 类型 | 说明 |
|---|---|
| `MENU` | 菜单级权限，控制左侧导航/模块入口是否显示 |
| `PAGE` | 页面/路由级权限，控制某个具体页面是否可访问 |
| `BUTTON` | 按钮/操作级权限，控制页面内某个具体操作按钮是否可点击 |
| `DATA` | 数据级权限，控制某类数据（尤其敏感字段）是否可查看/导出 |
