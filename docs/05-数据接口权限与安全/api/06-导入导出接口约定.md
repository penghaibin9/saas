# 06 · 导入导出接口约定

> 文档性质：全端导入导出通用接口约定（本轮新增）
> 适用端：PC 管理端（学生主档、数字迎新、就业服务、在校服务、学业过程等多模块共用）
> 依据：共享事实底稿 §4、§6；`frontend/src/modules/student/api/student.api.js`（getImportTemplates/validateImport/confirmImport/getExportOptions/createExport/getTransferTasks）；引用历史冻结 `docs/05-数据接口权限与安全/api/00-API契约冻结总册.md` §一原则 9、`02-学生主档与学生360API.md` 13/14
> 当前阶段声明：以下"建议接口路径"为契约设计，当前 PC 端各模块 mock 实现均为**模拟回执**（不真正解析文件、不产生真实文件），后端接入时需实现真实文件解析与异步任务
> 生成日期：2026-07-04

## 一、导入（Import）

### 1.1 通用流程

```text
① 模板下载 → ② 用户按模板准备数据文件 → ③ 上传文件（见 07 文件上传接口约定，获得 file_id）
→ ④ 提交校验（服务端解析文件内容） → ⑤ 校验结果展示（含错误行清单）
→ ⑥ 用户确认导入（可选择"跳过错误行"或"全部取消"） → ⑦ 异步执行导入任务 → ⑧ 查询任务进度/结果
```

### 1.2 模板下载

| 项 | 内容 |
|---|---|
| 接口名称 | 导入模板下载 |
| 适用端 | PC |
| 请求方法 | GET |
| 建议路径 | `/api/v1/admin/{module}/import/template`（如 `/api/v1/admin/student/import/template`） |
| 请求参数 | `templateId?`（同一模块可能有多个导入模板，如学生主档 vs 学籍变更批量导入，对应 `student.mock` 的 `importTemplates` 列表） |
| 返回字段 | 直接返回文件流（Excel），或返回 `{fileId, downloadUrl}` 由前端二次请求下载（两种方式二选一，待后端确认） |
| 权限要求 | `{module}.import`（如 `student.import`） |
| 数据范围要求 | 不涉及数据范围（模板为静态文件） |
| 空状态 | 不适用 |
| 异常状态 | 模板不存在 |
| 错误码 | DATA_NOT_FOUND |

### 1.3 上传校验

| 项 | 内容 |
|---|---|
| 接口名称 | 导入文件校验 |
| 适用端 | PC |
| 请求方法 | POST |
| 建议路径 | `/api/v1/admin/{module}/import/validate` |
| 请求参数 | `{ templateId, fileId（先经 07 文件上传接口获得） }` |
| 返回字段 | `{ totalRows, validRows, errorRows, errors:[{row, field, message}] }`（错误行清单，对齐历史冻结 02 学生主档 API 13 validateStudentImport 的返回结构） |
| 权限要求 | `{module}.import` |
| 数据范围要求 | 导入数据须落在操作者数据范围内（如辅导员只能导入自己班级学生的信息更新，越权行标记为 error） |
| 空状态 | 不适用 |
| 异常状态 | 文件格式错误、模板不匹配、字段缺失 |
| 错误码 | VALIDATION_ERROR |
| 审计 | 写 `UPLOAD` 类审计（导入校验留痕） |

### 1.4 二次确认导入

| 项 | 内容 |
|---|---|
| 接口名称 | 确认导入 |
| 适用端 | PC |
| 请求方法 | POST |
| 建议路径 | `/api/v1/admin/{module}/import/confirm` |
| 请求参数 | `{ templateId, fileId, skipErrors: boolean（是否跳过错误行继续导入其余正确行）, requestId }` |
| 返回字段 | `{ taskId, type:'IMPORT', status:'PROCESSING'|'COMPLETED', totalRows, successRows, failedRows }`（大数据量场景应为异步任务，见 1.5；当前 mock 为同步模拟回执） |
| 权限要求 | `{module}.import` |
| 数据范围要求 | 同 1.3 |
| 空状态 | 不适用 |
| 异常状态 | 模板不存在；未先校验直接确认 |
| 错误码 | DATA_NOT_FOUND、VALIDATION_ERROR |
| 审计 | 写导入操作审计，含文件名、总行数、成功/失败行数 |

### 1.5 异步任务与进度查询

| 项 | 内容 |
|---|---|
| 接口名称 | 导入/导出任务列表与进度 |
| 适用端 | PC |
| 请求方法 | GET |
| 建议路径 | `/api/v1/admin/{module}/transfer-tasks`（对齐 `student.api.js` 的 `getTransferTasks()`） |
| 请求参数 | `type: IMPORT\|EXPORT?, status?, page?, pageSize?` |
| 返回字段 | `{ list:[{id,type,typeLabel,title,fileName,totalRows,successRows,failedRows,status,operator,roleName,time,masked,watermark,auditId}], total }` |
| 权限要求 | `{module}.import` 或 `security.export.*`（按任务类型） |
| 数据范围要求 | 仅本人发起的任务，或按角色可见全部任务（待后端确认可见范围规则） |
| 空状态 | `{list:[],total:0}` |
| 异常状态 | 无 |
| 错误码 | 无 |
| 备注 | 大数据量导入（如全校学生批量迁移）应走真正异步任务队列，前端轮询本接口获取 `status`（`PENDING/PROCESSING/COMPLETED/FAILED`）与进度百分比（待后端确认是否需要独立的进度字段，如 `progressPercent`） |

| 模块 | 导入能力（当前 mock 方法） | 对应权限点 |

| 学生主档 student | getImportTemplates/validateImport/confirmImport | student.import |
| 数字迎新 orientation | validateImport/confirmImport | onboarding 相关（待后端确认专属命名，共享底稿标注迎新入学材料审核流当前 DISABLED） |

| 平台运营 platform | importTenants（二段式） | platform.tenant.import（待后端确认） |

## 二、导出（Export）

### 2.1 三档导出与权限对应

| 导出档位 | 说明 | 对应权限点 |
|---|---|---|
| LIST | 列表导出（仅当前列表可见字段，已按脱敏规则处理） | security.export.list |
| ENCRYPTED_ARCHIVE | 加密档案导出（含更完整字段，导出文件加密，需密码或安全通道获取） | security.export.archive |
| DESENSITIZED | 脱敏导出（导出内容强制脱敏，用于跨部门/教学分析等场景） | security.export.desensitized（默认 DISABLED，专业版开通，见共享底稿 §3 权限点清单） |

### 2.2 通用规则

- 默认单次导出 **≤5000 行**，超出需拆分导出或申请特批（待后端确认特批流程）。
- 导出**写审计**（`EXPORT` 事件类型），审计内容含：导出范围、用途（`purpose` 必填，用于审计留痕）、字段清单、敏感字段数量、操作人、时间。
- 导出文件默认加水印（`tenantBrandConfig.watermarkText`），敏感字段强制脱敏（LIST/DESENSITIZED 档位）。
- 导出为**异步任务** + **签名 URL 下载**：提交导出请求 → 生成任务 → 任务完成后通过短期签名 URL 下载，不直接在响应体中返回文件二进制。

### 2.3 创建导出任务

| 项 | 内容 |
|---|---|
| 接口名称 | 创建导出任务 |
| 适用端 | PC |
| 请求方法 | POST |
| 建议路径 | `/api/v1/admin/{module}/export` |
| 请求参数 | `{ scope: string（导出范围，如"全部/当前筛选结果/勾选项"）, exportType: 'LIST'|'ENCRYPTED_ARCHIVE'|'DESENSITIZED', fieldKeys: string[]（导出字段清单）, purpose: string（用途，必填）, remark?: string, rowCount? }`（对齐 `student.api.js` 的 `createExport({scope,fieldKeys,purpose,remark,rowCount})`） |
| 返回字段 | `{ taskId, type:'EXPORT', fileName, totalRows, status:'PROCESSING'|'COMPLETED', masked: true, watermark: true, auditId }` |
| 权限要求 | `security.export.list` / `security.export.archive` / `security.export.desensitized`（按 `exportType` 对应） |
| 数据范围要求 | 导出范围不能超出操作者当前数据范围（如辅导员导出仅限本班级学生） |
| 空状态 | 不适用 |
| 异常状态 | 未选择导出范围/字段；用途未填写；超过 5000 行限制未拆分；无对应档位权限 |
| 错误码 | VALIDATION_ERROR、NO_PERMISSION |
| 审计 | 写 `EXPORT` 审计，`details` 含敏感字段数量与脱敏说明 |

### 2.4 导出结果下载

| 项 | 内容 |
|---|---|
| 接口名称 | 导出文件下载（签名 URL） |
| 适用端 | PC |
| 请求方法 | GET |
| 建议路径 | `/api/v1/files/{fileId}/url`（复用文件中心通用下载接口，见 `07-文件上传接口约定.md`） |
| 请求参数 | 路径参数 `fileId`（导出任务完成后关联的文件对象） |
| 返回字段 | `{ url: string（短期签名 URL，含有效期）, expiresIn }` |
| 权限要求 | 与创建导出任务时的权限一致（本人发起或有权限查看该导出任务） |
| 数据范围要求 | 仅任务发起人或授权角色可下载 |
| 空状态 | 不适用 |
| 异常状态 | 任务未完成；文件已过期 |
| 错误码 | DATA_NOT_FOUND |
| 审计 | 写 `DOWNLOAD` 审计 |

### 2.5 涉及模块清单

| 模块 | 导出能力（当前 mock 方法） |
|---|---|
| 学生主档 student | getExportOptions/createExport/getTransferTasks |
| 数字迎新 orientation | createExport |
| 在校服务 campusService | createExport |
| 学业过程 academic | createExport |
| 就业服务 employment | createExport |
| 数据驾驶舱 dataCenter | exportData({scope,purpose}) |
| 审批中心 approval | exportRecords({scope,purpose}) |
| 系统管理 system | exportUsers/exportRoleConfig/exportScopeRules/exportOrg/exportConfigs/exportLogs |
| 平台运营 platform | exportTenants/exportPackageConfig/exportOrders/exportIntegrations/exportApiLogs/exportSyncLogs/exportPlatformLogs |

> 所有模块导出接口共用 §二通用规则；各模块字段清单与权限点细分（待后端确认最终命名规范，建议统一为 `{module}.export.list` / `{module}.export.archive` / `{module}.export.desensitized` 或直接复用全局 `security.export.*` 三个权限点，二选一，待后端确认）。
