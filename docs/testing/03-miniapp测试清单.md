- **文档性质**：功能测试用例清单（miniapp 学生端 + 教师端，逐页覆盖）

- **生成日期**：2026-07-04

## 使用说明

- 启动方式：`cd miniapp && npm run dev:h5` → 访问 `http://localhost:5188/`。
- 前置条件默认包含："H5 开发环境已启动" + "已用对应账号登录"，仅在有额外要求时单独说明。
- 教师端因存在 6 类身份切换（辅导员/班主任 COUNSELOR、指导教师(毕设) MENTOR、实习指导教师 INTERN_MENTOR、就业老师 EMPLOYMENT、教务老师 ACADEMIC、学院管理员 COLLEGE_ADMIN），本清单中标注"当前身份"以说明该用例适用的身份场景；同一页面在不同身份下表现不同的，分别列出用例或在预期结果中说明差异。
