## 1. 本轮办理闭环

唯一正式页面仍是 `/admin/platform/commercial-control`。复用现有平台工作区和商业权威，不新建业务模块路由、不改四端公共壳、不改数据迁移或学校菜单。

1. 在平台职责核验后，分页检索学校；不再把“异常对账学校列表”当作唯一销售学校清单。
2. 发布不可变 SKU 版本：真实名称、版本、价格、批准功能范围、可选额度和明确政策版本；不预设销售价格、税额或隐式赠送能力。目录分页只展示已发布的核心 MODULE 商品，不擅自分摊 BUNDLE 金额。
3. 同一学校选 1–4 个核心模块，每项单独指定成交单价、数量、优惠和服务期。预检在服务端重新解析 SKU 指纹、代次和当前学校状态，金额用 Decimal，前端辅助显示用 BigInt 分。服务期输入明确为北京时间，数据库合同为 UTC 半开区间。
4. 正式提交复用原 `create_itemized_order` 写入器，只创建未支付订单。新增内部校验钩子在原 Tenant 锁和同一事务内、已有幂等回执检查之后执行。学校冻结、模块代次变化、续费起点早于已付截止、缺少续费来源时拒绝；不修改原订单、兄弟模块或授权来源。
5. 超时重试保留原请求和同一幂等键，按平台主体与学校存入当前标签页 sessionStorage。一般 409 / 403 / 503 不被视作“原订单未创建”；只有后端确认新命令在尝试 commit 前已 rollback 的回执才能释放键。已完成原请求先重放，不因后来商品下架或生命周期改变而再建单。
6. 学校分项台账显示未支付/已支付/已取消、币种、冻结价格、服务期和逐项履约状态。旧套餐订单不混成模块分项订单；已支付不能冒充每行均履约完成。
7. xlsx 按学校和支付状态导出并记录关键审计，1000 分项硬上限，超限整单拒绝而非静默截断。BIGINT 与金额保存为文本，公式前缀不执行；重复的订单头金额明确标注不可逐行累加。审计失败不返回文件。

商品发布时间不等于学校授权；预检不预留权益；未支付订单不等于收款；新客户/旧客户开通继续走原支付事实和受控迁移规则。页面只链接原订单中心核对收款，没有自动 mark-paid 按钮。

## 2. 新接口及职责

前缀 `/api/v1/platform`，由既有 canonical platform router 安装；原 16 条商业路由保留，新增 8 条，总数锁定为 24。

| 接口 | 职责 | 副作用 |
|---|---|---|
| GET `/commercial/skus` | commercial.view | 无；分页目录 |
| GET `/commercial/sales-tenants` | commercial.view | 无；分页学校 |
| GET `/commercial/sales-tenants/{tenant_id}/context` | commercial.view | 无；当前代次、已付截止建议 |
| POST `/commercial/sales-order-preview` | order.manage | 无；验证和报价核算 |
| POST `/commercial/sales-orders` | order.manage + Idempotency-Key | 未支付订单、分项、幂等、审计同事务 |
| GET `/commercial/sales-orders` | commercial.view | 无；强制 tenantId 与 SQL 分页 |
| GET `/commercial/sales-orders/{order_id}` | commercial.view | 无；强制 tenantId 与订单所属学校一致 |
| POST `/commercial/sales-orders-export` | order.manage | 关键审计后返回 xlsx；无支付/授权修改 |

SKU 发布复用原 POST `/commercial/skus` / commercial.manage。学校管理员即使有学校 `*` 权限也不得进入上述平台接口；平台其他职责不能获得商业读写权。读取与写入的权限仍由后端执行，前端按钮状态不是权限真值。

## 5. 2026-09-10｜本地 main 续工与实际缺口

### 已修复

- 销售、财务、售后操作在身份复核前冻结学校和请求内容；复核期间切校不再向新学校发送旧操作。旧学校的迟到响应不能覆盖新学校台账、清除其待核对请求或解除其提交锁。同学校分页采用递增序号，旧页不能盖掉新页。
- 财务/成本创建前必须成功保存原请求与幂等键。损坏的本地记录保留并关闭新增写入，不能静默删除后重复登记；缺失或学校/订单不匹配的创建回执不能显示成功，仍保留原键用于核对。

- 生命周期办理期间锁定学校与模块选择，退出预检不会串到另一模块；切换模块清空验收、退出及签收草稿。去掉预设的“30 天 / SCHOOL-CONTRACT”，必须填写真实已确认合同政策并勾选确认，后端仍独立校验。
