# 01 · 新手一键启动说明

## 准备（只做一次）

第一步：确认电脑装了 Node.js。按 Win 键 → 输入 `powershell` 回车 → 在窗口里输入 `node -v` 回车。
- 显示 `v18` 以上的版本号 → OK。
- 显示"不是内部或外部命令" → 去 https://nodejs.org 下载 LTS 版安装，装完重开 PowerShell 再试。

第二步：打开项目根目录的 PowerShell。
- 打开项目文件夹（有 `frontend`、`miniapp` 的那一层）→ 在文件夹空白处按住 Shift + 右键 → 选「在此处打开 PowerShell 窗口」。
- 后面所有命令都在这个窗口里执行。

## 方式一：一键全部启动（推荐）

第一步：在项目根目录执行：

```
powershell -ExecutionPolicy Bypass -File scripts\dev\start-all.ps1
```

第二步：会自动弹出 3 个窗口（PC 前端、小程序 H5、后端）。**不要关这些窗口**，关了服务就停了。后端窗口会提示"底座未创建入口，跳过"，这是正常的。

第三步：等 1~2 分钟编译完成，浏览器打开：
- PC 前端：http://localhost:5173/
- 小程序 H5：http://localhost:5188/ （进去后选「我是学生」或「我是老师」）

## 方式二：单独启动某一个

都在项目根目录执行：

```
powershell -ExecutionPolicy Bypass -File scripts\dev\start-pc.ps1        # 只启动 PC
powershell -ExecutionPolicy Bypass -File scripts\dev\start-miniapp.ps1   # 只启动小程序 H5
powershell -ExecutionPolicy Bypass -File scripts\dev\start-backend.ps1   # 只启动后端
```

第一次启动会自动安装依赖（npm install），可能要几分钟，耐心等。

## 怎么停服务

- 方法 1：直接关掉对应的黑色窗口。
- 方法 2：在项目根目录执行 `powershell -ExecutionPolicy Bypass -File scripts\dev\stop-dev.ps1`，它会列出要停的进程，回车确认即可。

## 怎么确认跑起来了

在项目根目录执行：

```
node scripts\check\smoke-check.mjs
```

看到 `[OK]` 就是通了。详见 [04-如何判断项目是否跑起来.md](04-如何判断项目是否跑起来.md)。

先看 [02-常见启动失败处理.md](02-常见启动失败处理.md)，按症状对号入座。
