# SLA 服务说明（模板 · 试点版）

> 本模板供与学校约定服务水平。**试点期 SLA 相对宽松**，正式商用另签正式 SLA。具体数值按双方协商填。

## 一、服务时间
- 支持时间：工作日 9:00–18:00（试点期）。
- 紧急故障（系统完全不可用）：尽力 7×__ 响应。

## 二、响应与解决时效（建议值，按协商填）
| 级别 | 定义 | 响应时间 | 解决/缓解目标 |
|---|---|---|---|
| P1 阻断 | 系统完全不可用 / 数据错误 | ≤ 1 小时 | ≤ __ 小时 |
| P2 影响 | 主要功能受影响，有临时办法 | ≤ 4 小时 | ≤ __ 工作日 |
| P3 一般 | 次要问题/体验问题 | ≤ 1 工作日 | 版本迭代解决 |
| P4 建议 | 需求/优化建议 | 记录 | 进产品待办 |

## 三、可用性目标
- 试点期可用性目标：__%（不含计划内维护）。
- 计划内维护提前 __ 小时通知，尽量安排低峰。

## 四、数据与备份
- 数据库每日备份，保留 14 天。
- **恢复演练每月一次**（未演练不承诺"备份绝对可靠"）。
- 数据归学校所有；试点结束按约定导出/销毁。

## 五、安全与合规（现状与承诺边界）
- 已具备：认证、权限、多租户隔离、脱敏、审计、限流锁定。
- **尚未完成**（不纳入试点承诺）：等保三级测评备案、第三方渗透测试。
- 敏感字段落库加密：__（已开/待开）。

## 六、变更与升级
- 版本升级提前通知；重大变更前先在测试环境验证。
- 升级前必做数据备份，保留回滚到上一个版本的能力。
