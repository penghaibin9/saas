# 学生端小程序操作手册

> 面向：学生本人。用微信小程序，随身处理。

## 一、登录
- 微信打开小程序 → "我是学生" → 登录。
- 登录后只能看到**你自己**的信息（看不到别的同学）。

## 二、首页
- 一屏看到：你现在处于哪个阶段、要做的待办、提醒、各模块进度。
- 点卡片进入对应模块。

## 三、查我的档案
- "我的档案"看基本信息、学籍信息、证照。
- 手机号、身份证等会**打码显示**（保护隐私）。
- 需要改手机号/联系人等，可发起"信息更正"申请，由老师审核。

## 四、提交服务申请（请假/证明等）
1. 进"在校服务" → 选服务（如请假）。
2. 填申请事由（**至少 5 个字**）、时间等，可传附件。
3. 提交后在"我的申请"看进度：审核中/已办结/被退回。
4. 被退回会显示原因，按提示补充再交。

## 五、交实习周报
1. 进"岗位实习" → "填写周报"。
2. 填本周工作、收获（**内容至少 20 字**）。
3. 提交。**同一周只能交一次**，重复交会提示"已提交"。
4. 老师批阅后能看到评阅意见。

## 六、其它模块
- 学业：看成绩、学分、预警。
- 毕业设计：看课题、各节点进度。
- 就业：填就业意向/去向，看推荐岗位。
- 消息：待办、通知、服务进度。

## 七、注意
- 网络差时页面会用"演示数据"兜底并提示，**你的申请/周报是否真提交成功，以出现明确"提交成功"提示为准**；若提示"已离线暂存（未提交服务器）"，请联网后重交。
- 遇到问题联系辅导员或学校信息中心。
