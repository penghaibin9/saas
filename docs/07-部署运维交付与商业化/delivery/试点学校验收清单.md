# 试点学校验收清单

> 学校按此清单逐项验收；每项"通过/不通过 + 备注"。用于确认试点系统"能用、安全、不越权"。

## 一、开局初始化
- [ ] 学校品牌正确（校名、校色、水印显示为本校）
- [ ] 院系/专业/班级导入完整，数量与提供名单一致
- [ ] 学生导入完整，可搜索到本校学生
- [ ] 教师账号可登录，初始密码已安全交接
- [ ] 初始化报告（成功/跳过/失败数量）已核对

## 二、学生端（小程序）
- [ ] 学生登录后只看到本人数据
- [ ] 可查档案，手机号/身份证脱敏显示
- [ ] 可提交一次服务申请，能在"我的申请"看到进度
- [ ] 可提交一次实习周报，重复提交被拦截（提示已提交）
- [ ] 页面不白屏，弱网有提示

## 三、教师端（小程序）
- [ ] 老师登录后只看到**本人负责范围**的学生
- [ ] 打开无权限学生 → 提示"无权限查看"（越权被拦）
- [ ] 可批一次审批（通过/退回，退回原因学生可见）
- [ ] 可批一次实习周报
- [ ] 风险学生列表按负责范围显示，不含全校

## 四、管理端（PC）
- [ ] 管理员可登录、查学生主档
- [ ] 数据看板数字与实际一致
- [ ] 敏感字段脱敏显示
- [ ] 关键操作有审计留痕

## 五、安全与合规
- [ ] 未登录访问接口被拦（401）
- [ ] 学生无法访问管理端接口（403）
- [ ] demo/其它学校数据互不可见（多租户隔离）
- [ ] 生产环境 /docs 已关闭、mock-login 已关闭（若已正式部署）

## 六、通知
- [ ] 站内待办/退回/预警提醒可见
- [ ] 短信通道方案已沟通（占位/需配密钥的现状已知悉）

## 七、知情确认（学校签字确认已了解）
- [ ] 已知悉：短信未配密钥前不发真实短信
- [ ] 已知悉：未过等保测评/渗透前不作"正式商用无风险"承诺
- [ ] 已知悉：未做恢复演练前不作"备份绝对可靠"承诺
- [ ] 已知悉：与校内系统深度对接不在试点范围
