# 02 · 演示前检查清单

> 演示开始前 **30 分钟**，在**实际演示环境和网络**下，逐条走一遍。目的是"上台前先自己跑通"。

---

## A. 能打开（5 分钟）

- [ ] PC 管理端地址能打开，看到登录/首页。
- [ ] 小程序 H5 能打开，进得去学生端和教师端。
- [ ] 微信小程序体验版能扫码进入（如需演示微信端）。
- [ ] 换一台设备/手机再打开一次，确认不是只有你这台能开。

---

## B. 关键流程能走通（10 分钟）

按你要演示的顺序，**亲自点一遍**：

- [ ] 登录 / 进入首页（工作台）。
- [ ] 学生主档：打开学生列表、点开一个学生 360 档案。
- [ ] 一个业务流程完整走通，例如：
  - [ ] 在校服务：发起一个服务申请（选择、填事由、提交）→ 能在"我的申请"看到。
  - [ ] 岗位实习：填写一份周报 → 提交后状态回填。
  - [ ] 审批中心：教师端看到待办 → 处理一条审批。
- [ ] 小程序：学生端首页→待办→消息→我的；教师端工作台→审批。

> 记住：这些是**演示数据**，走通即可；不用纠结数据是否长期保存。

---

## C. 展示效果（5 分钟）

- [ ] 投屏正常、字号够大（Ctrl+「+」放大到后排能看清）。
- [ ] 学校名称 / Logo / 平台名显示正确（品牌配置对）。
- [ ] 页面无明显白屏、无大片报错、样式正常。
- [ ] 演示中**尽量不刷新**（如需刷新，从首页正常进入而非停在子页面刷）。

---

## D. 兜底准备（5 分钟）

- [ ] 本地兜底环境已就绪（现场环境挂了能立刻切）。
- [ ] 记得上一版回滚方式（`docs/07-部署运维交付与商业化/deploy/09`）。
- [ ] 现状口径想好怎么说（README / `05-常见客户问题答复.md`）。
- [ ] `docs/07-部署运维交付与商业化/ops/08-客户现场问题处理手册.md` 在手边。

---

## E. 一句话自检

如果上面 A、B 都通过，就可以放心演示了。演示中遇到小问题，用"强刷 / 换设备 / 本地兜底"三招（见 `docs/07-部署运维交付与商业化/ops/08`）保证不中断。
