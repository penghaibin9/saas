# 管理员操作手册（PC 管理端）

> 面向：学校管理员。PC 管理端网址由我方部署时提供（形如 https://学校域名 ）。

## 一、登录
- 打开管理端网址，用管理员账号登录。
- 演示环境可用演示账号（我方提供，见《售前演示脚本》）。正式环境用你自己的账号。

## 二、导入学生（最常用）
1. 进入"学生主档"模块。
2. 下载/对照导入模板，整理好学生名单。
3. 先"校验"（看有没有错、错在第几行），再"确认导入"。
4. 导入后能在学生列表看到，可搜索、筛选、看详情。

> 大批量首次开局，建议用《新学校开局向导操作手册》一次性把院系/专业/班级/学生/教师都导好。

## 三、看数据看板
- "数据中心/工作台"能看到：学生总数、各阶段分布、风险学生、待办概况等。
- 数据来自真实业务，不是演示假数。

## 四、其它常用
- 查看/管理审批流程、系统配置、角色权限（按你被授予的权限显示）。
- 学生的手机号、身份证等敏感信息**默认脱敏显示**（打码），符合个人信息保护要求。

## 五、注意
- 你的操作会被**审计留痕**（谁、什么时间、做了什么），这是合规要求。
- 不要把账号密码告诉学生或无关人员。
- 忘记密码/账号异常，联系我方支持（见《SLA服务说明》）。

## 六、这个版本还不能做的
- 与学校已有教务/一卡通系统的实时对接（本期靠批量导入）。
- 复杂的自定义报表大屏（后续版本）。
