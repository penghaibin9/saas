# 教师端小程序操作手册

> 面向：各类老师（辅导员、实习指导、毕设指导、就业老师、教务）。用微信小程序。

## 一、登录与切换身份
- 微信打开小程序 → "我是老师" → 账号登录。
- 一个老师可能有多个身份（如既是辅导员又是毕设导师），可在"选择身份"里切换；**切换后看到的数据范围会随之变化**。

## 二、工作台
- 按你的身份显示不同重点：待批周报、待审请假、学业预警、就业待跟进等。
- 点数字进入对应处理页。

## 三、批阅实习周报（实习指导老师）
1. 进"实习周报批阅"。
2. 看到你指导的学生提交的周报（周次、内容、是否逾期）。
3. 点"通过"或"退回"，可写评阅意见。逾期未交的会标红。

## 四、毕设指导（毕设导师）
- 进"毕设指导"，看你指导学生的开题/中期/成果，逐项批阅。

## 五、就业跟进（就业老师）
1. 进"就业跟进"，按"未就业/跟进中/待核验/已落实"分类看学生。
2. 对未就业学生做电话跟进、推荐岗位、核验去向材料。
3. 只看到你负责范围内的学生。

## 六、看学生详情（360）
- 从风险学生或学生列表点进去，看该生的风险、实习、学业、就业摘要。
- **无权限的学生打不开**（提示"无权限查看"），这是防越权的正常表现。

## 七、消息
- 系统通知、学生动态、风险预警、催办提醒分类展示，未读有红点。

## 八、注意
- 敏感信息脱敏；操作留痕；只看自己负责范围。
- 网络差时页面会用"演示/缓存"兜底并提示，不会白屏；但**真正提交成功以有明确成功提示为准**。
