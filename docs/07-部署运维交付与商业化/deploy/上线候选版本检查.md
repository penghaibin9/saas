# 上线候选版本检查

这一步只回答一个问题：当前 Git commit 是否已经具备进入生产发布流程的资格。

## 使用方式

在仓库根目录执行：

```powershell
python scripts\check\check-release-readiness.py
```

返回含义：

- `READY` 且退出码为 `0`：机器状态记录允许进入生产预检，仍需现场环境检查。
- `BLOCK` 且退出码非 `0`：禁止上线，按输出逐项处理。

脚本默认只读，只检查 Git、`project-status.json` 和 release seal，不连接服务器、不读取真实密钥、不修改数据库。

## 它会阻止哪些误操作

- 工作区还有未提交修改。
- 当前功能代码晚于上一次验证基线，测试结果已经过期。
- `origin/main` 或仍在开发的功能分支尚未收敛。
- 迁移、后端矩阵、前端、浏览器链路、安全依赖、备份恢复或容量 smoke 任一门禁未通过。
- release seal 明确记录 `deliverable=false`。

## 它不会替代什么

即使本检查通过，也不能替代生产环境变量核验、真实 HTTPS、学校数据授权、生产备份、隔离恢复演练和发布后业务验收。正式执行仍以 [`生产上线runbook.md`](./生产上线runbook.md) 为准。
