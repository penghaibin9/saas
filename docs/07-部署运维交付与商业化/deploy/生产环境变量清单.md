# 生产环境变量清单

> 部署到 `backend/.env`（**该文件禁止进 git**）。真实密码/密钥仅本文件注入，不写进任何仓库或文档。
> 配套预检脚本：`scripts/check/preflight-school-trial.sh`（自动核对关键项）。

## 必配（生产不配会不安全或起不来）
| 变量 | 生产值 | 说明 |
|---|---|---|
| APP_ENV | production | 自动关 /docs、精简 /health |
| DEBUG | false | 关闭调试 |
| JWT_SECRET | `openssl rand -hex 32` 生成 | **不能用默认弱密钥**；预检会拦 change-me/dev-secret |
| DB_ENABLED | true | 走真实库 |
| DB_DRIVER | mysql | 生产用 MySQL |
| DB_HOST / DB_PORT / DB_NAME / DB_USER | 按实际 | |
| DB_PASSWORD | 强密码 | **仅此注入，禁进仓库** |
| CORS_ORIGINS | https://你的域名 | 勿留空、勿 `*`（预检会拦） |
| MOCK_LOGIN_ENABLED | false | 正式客户前必须关 |

## 通知（默认关闭；启用短信才配）
| 变量 | 值 | 说明 |
|---|---|---|
| SMS_ENABLED | false | 不发真实短信；true 才发 |
| SMS_PROVIDER | mock/aliyun/tencent | 真实发送选 aliyun/tencent |
| SMS_ACCESS_KEY_ID / SMS_ACCESS_KEY_SECRET | 服务商密钥 | **仅 .env，禁进仓库** |
| SMS_SIGN_NAME | 短信签名 | 需服务商审核 |
| SMS_TEMPLATE_TODO / _REJECTED / _WARNING | 模板ID | 服务商模板 |
| SMS_RATE_LIMIT_PER_MINUTE | 30 | 每租户每分钟上限 |

## 可选 / 预留
| 变量 | 说明 |
|---|---|
| UPLOAD_DIR | 上传目录（生产建议改对象存储） |
| FILE_STORAGE_ENDPOINT | 对象存储端点（MinIO/COS，预留） |
| REDIS_URL | 缓存（预留） |
| TENANCY_MODE | single（私有化单校）/ multi（SaaS 多校） |

## 安全红线
1. `.env`、`*.db`、证书、密钥**一律不进 git**（CI 已加禁止文件检查）。
2. 密码/密钥泄露立即轮换。
3. 每次改 .env 后跑一遍 `preflight-school-trial.sh` 再重启。
