# 02 · 服务器环境准备

> 目标：拿到一台空的 Linux 服务器（或一台能装软件的电脑），把「跑这套前端所需的基础软件」装好。
> 适合完全没配过服务器的新手，按顺序照抄命令即可。

---

## 0. 你需要准备什么

- 一台服务器：推荐 Linux（Ubuntu 22.04 或更高 / CentOS 均可），2 核 4G 起步足够跑静态站点。
- 能登录服务器的账号（一般是 `root`，或有 `sudo` 权限的账号）。
- 一个用来 SSH 登录的工具：Windows 上可用「Windows Terminal / PowerShell」或 MobaXterm、FinalShell。

> 如果暂时没有服务器，也可以先在自己电脑（Windows/Mac）上装 Node，把前端 build 出来看看效果，只是没法给别人用外网访问。

---

## 1. 需要装的软件清单

| 软件 | 作用 | 现在必须装吗 |
|---|---|---|
| Node.js（含 npm） | 构建 PC 前端和小程序 H5 | ✅ 必须 |
| Nginx | 托管静态网站、处理刷新 404、反向代理 | ✅ 必须 |
| Git | 拉取/更新项目代码（可选） | 建议装 |
| 微信开发者工具 | 上传微信小程序（装在你自己的 Windows/Mac 上，不是服务器） | 做微信小程序时才需要 |
| PostgreSQL | 数据库 | ❌ 现阶段不装（后端接入阶段再说，见 06） |
| Python + FastAPI | 后端 | ❌ 现阶段不装（预留，见 05） |

> 现在只装 **Node.js + Nginx** 就够了。数据库和后端是后续阶段的事，别提前装、别提前建库。

## 2. 装 Node.js（构建前端必需）

本项目前端用 Vite，需要 Node.js。**建议 Node 18 或 20 的 LTS 版本**。

### Ubuntu / Debian

```bash
# 安装 curl（如果没有）
sudo apt update
sudo apt install -y curl

# 安装 Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 验证
node -v     # 应显示 v20.x
npm -v      # 应显示 npm 版本号
```

### CentOS / RHEL

```bash
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo yum install -y nodejs
node -v
npm -v
```

> npm 下载慢的话，可以设国内镜像：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

---

## 3. 装 Nginx（托管网站必需）

### Ubuntu / Debian

```bash
sudo apt install -y nginx
sudo systemctl enable nginx     # 开机自启
sudo systemctl start nginx      # 启动
sudo systemctl status nginx     # 看状态，出现 active (running) 就对了
```

### CentOS / RHEL

```bash
sudo yum install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
```

装完后，浏览器访问服务器 IP（如 `http://你的服务器IP/`），能看到 Nginx 欢迎页就说明装好了。

Nginx 常用命令（先记住这几个）：

```bash
sudo nginx -t                    # 测试配置有没有写错（改配置后一定先测）
sudo systemctl reload nginx      # 平滑重载配置（不断连接）
sudo systemctl restart nginx     # 重启
sudo tail -f /var/log/nginx/error.log   # 实时看错误日志
```

## 5. 目录规划建议（新手照这个来就不会乱）

在服务器上建议这样放：

```
/opt/school-platform/            # 项目根（放源码，如果你在服务器上 build）
/var/www/pc-frontend/            # PC 前端网站根（放 frontend/dist 的内容）
/var/www/miniapp-h5/             # 小程序 H5 网站根（放 miniapp H5 产物）
/etc/nginx/conf.d/               # Nginx 站点配置放这里
```

先建好目录：

```bash
sudo mkdir -p /var/www/pc-frontend
sudo mkdir -p /var/www/miniapp-h5
```

> 也可以在自己电脑上 build 好，再把 dist 里的文件用 scp / FinalShell 上传到上面两个目录。具体怎么放见 03 和 04。

## 6. 防火墙 / 安全组（能访问的前提）

如果访问不了，多半是端口没放开。需要放开：

- 80（HTTP）
- 443（HTTPS，配了证书才用）

云服务器一般在控制台「安全组」里放开；服务器自带防火墙：

```bash
# Ubuntu ufw
sudo ufw allow 80
sudo ufw allow 443

# CentOS firewalld
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```
