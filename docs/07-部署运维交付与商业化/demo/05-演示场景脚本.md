# 05 演示场景脚本

- **文档性质**：可照着念的分步演示脚本（演示指引文档）。
- **适用端**：PC 管理端（`frontend/`）+ 小程序端（`miniapp/`）。
- **依据**：`01-演示数据总览.md`、`02-PC端演示数据口径.md`、`03-miniapp演示数据口径.md`、`04-演示角色账号.md` 中已核实的 mock 数据点；不引入未核实的数据。
- **当前阶段声明**：以下所有脚本演示的均为 mock 静态数据，`useMock=true`，无真实登录，后端未接入。演示中如被问及"这是真实数据吗"，统一回答"当前为 mock 演示数据，用于验证界面与流程设计"。
- **生成日期**：2026-07-04

## 脚本使用提示

- 以上 8 个脚本可根据听众关注点自由组合，全套演示约 27 分钟，建议一次演示选 3～4 个脚本（如"学生视角 2 个 + 教师视角 2 个 + 管理视角 1～2 个"）。
- 每个脚本开始前，建议先用 `04-演示角色账号.md` 确认目标角色的"登录/进入方式"，避免现场找不到切换入口。
- 演示前务必过一遍 `06-演示前数据检查清单.md`，尤其是"mock 数据加载正常""品牌占位正确""演示角色切换正常"三项。
