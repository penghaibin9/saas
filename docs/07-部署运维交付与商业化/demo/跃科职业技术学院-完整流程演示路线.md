## 45 分钟正式演示

### 一、管理员总览（3 分钟）

1. 打开管理端，填写学校编码 `sandbox-school`，使用 `admin2` 登录。
2. 进入“工作台”。确认 20,000 名学生、768 条学业预警、5,344 名未就业学生和跨模块待办。
3. 点击统计卡下钻，说明统计口径可回到业务明细。

### 二、学工完整流程（8 分钟）

按“学工中心 → 对应菜单”依次点击：

1. “学生主档”：检索 `2026S0001`，查看学院、专业、班级、辅导员、阶段事件和本人账号关联。
2. “请假管理”：检索 `2024S0040` 看待审核，检索 `2024S0008` 看已批准；打开详情查看申请、审批节点、意见、消息和时间线。
3. “困难认定/奖助管理”：展示申请、公示中、异议提交、学校复核、发放、申诉和已关闭异议。
4. “宿舍管理”：展示入住床位、调宿待辅导员审核、退回重交、宿舍检查和整改中记录。
5. “违纪处分”：展示处分生效、申诉复核中、解除申请退回及重交材料。
6. “谈心家校/心理关注”：查看计划、谈话记录、家校联系、心理关注、转介跟进和保密字段权限。
7. “风险台账”：页面应显示 300 条风险，其中高/严重 205 条、逾期 200 条；检索 `2024S0005` 看处理中，检索 `2024S0002` 看升级轨迹，再筛选已关闭记录看处置证据。
8. “第二课堂/学工归档”：展示活动报名、签到、学分认定、统计来源明细与归档版本。

讲解闭环：学生申请 → 辅导员初审 → 学院/学工处复核 → 公示/异议 → 消息待办 → 风险升级与关闭 → 归档和历史版本。

### 三、教务完整流程（10 分钟）

按“教务管理 → 对应菜单”依次点击：

1. “教务工作台”：查看当前学期、1 条调停课流程风险、768 条学业预警和 1,024 项成绩任务。
2. “培养方案/课程库”：从专业培养方案下钻课程、课程性质、学分学时和版本。
3. “教学计划/教学任务”：展示计划执行、任务生成、任课教师、合班与任务确认。
4. “排课课表/调停课”：展示 1,792 个教学任务和 1,792 个课表项；打开学院审核中的调课单及已批准历史单。
5. “选课控制台”：确认 1 个开放批次、2 个轮次、开放与草稿状态，以及已选、退选、待抽签三类真实明细。
6. “课堂考勤/考试管理”：查看考勤、考试计划、考场、52,000 个座位与考试成绩记录、缓考和补考。
7. “成绩管理”：查看录入、提交、发布、复查维持原判、成绩更正驳回，以及历史归档后更正形成“原记录作废 + 新有效版本”的证据链。
8. “学籍学业”：查看异动撤回、免修学院审核、重修进行中、专业分流待处理和学业预警处置。
9. “教材/资源/评价/质量”：展示教材签收与免领、收费明细、资源借用维修、评教和质量问题闭环。
10. “毕业资格/教务归档”：展示毕业条件逐项核验、延毕结论、证书作废历史、归档批次与申诉驳回。

讲解闭环：学期 → 培养方案 → 课程 → 教学计划/任务 → 排课选课 → 考勤考试 → 成绩发布与更正 → 预警 → 毕业资格 → 归档。

### 四、岗位实习完整流程（8 分钟）

1. 在“实习工作台”选择当前批次 `INT-2024-2026FALL`，确认 6,400 名学生、5,600 名在岗、300 名准备中、500 名待上岗、56 条打卡异常、1,117 份周报待批和 56 条未关闭风险。
2. 打开“批次/资格”：查看资格合格、待补材料和复核通过后进入补录的学生。
3. 打开“企业岗位/招聘补录”：查看企业资质、岗位容量、邀请接受/拒绝、志愿草稿、待企业处理、企业拒绝后修改重交和拟录用待学校确认。
4. 打开“协议保险/上岗”：展示协议版本、学生确认、企业确认、保险凭证和正式上岗记录。
5. 打开“打卡请假”：展示正常打卡、围栏异常、待核实、补卡、请假和返岗销假。
6. 打开“过程指导/周报”：检索 `2024S0007` 看待批，`2024S0009` 看退回，`2024S0001` 看通过；详情展示提交版本、教师意见和操作时间线。
7. 打开“风险处置”：检索 `2024S0100` 看待处置，`2024S0200` 看处理中，再查看升级和关闭证据。
8. 切换历史批次 `INT-2025-SUMMER-HIST`：查看 3 名学生的企业/岗位、指导记录、评价、最终成绩、审计留痕和 `INT-ARCH-2025-01` 归档。

讲解闭环：批次 → 资格 → 企业岗位 → 申请匹配 → 协议保险 → 上岗 → 打卡请假 → 周报指导 → 风险 → 评价成绩 → 归档。

### 五、毕业设计完整流程（8 分钟）

1. 在“毕业设计工作台”保留当前批次 `GD-2027`，确认 6,400 名学生；展示选题、导师、任务书、开题待审/驳回/通过和早期指导。当前日期下不提前伪造 2027 届未来答辩事实。
2. 在批次选择框切换到 `GD-2026-HIST`。
3. 确认历史批次显示 3 名学生、3 份已确认任务书、3 份中期终态、3 份已批准定稿、4 次查重（含复检）、3 份评阅、6 条答辩评分、3 份已发布成绩、3 份归档和 3 个归档版本。
4. 打开开题和指导记录，查看退回意见、修改后重交、连续指导与时间线。
5. 打开中期检查，查看正常通过与整改后通过。
6. 打开成果/查重，查看初检超阈值、整改、复检合格和冻结文件版本。
7. 打开评阅/答辩，查看回避关系、评阅完成、答辩排期、委员评分与确认。
8. 打开成绩/风险/归档，确认平均分 89.7、1 个优秀、2 个风险已关闭、归档率 100%（3/3），并查看延期答辩、成绩申诉和材料清单证据。

讲解闭环：批次 → 题目选题 → 导师 → 任务书 → 开题退回重交 → 指导 → 中期整改 → 成果查重/复检 → 评阅 → 答辩 → 成绩 → 风险关闭 → 归档版本。

### 六、教师责任视角（4 分钟）

1. 退出管理员，使用 `teacher2` 登录管理端。
2. 在教师工作台确认“王老师”、辅导员、数据范围“本人班级”、110 名学生、1 条待审请假、2 个近期待办和 1 条未读消息。
3. 点击待审请假和风险处置，确认只能看到本人授权班级；再进入实习周报查看待批任务。
4. 返回工作台，强调审批后学生端可看到状态和意见，且全程写入审计和消息记录。

### 七、学生本人视角（4 分钟）

1. 打开学生端，填写学校编码 `sandbox-school`，使用 `student2` 登录。
2. “首页工作台”：确认李体验、学号 `2026S0001`、软件技术 2601 班、1 项待办和 2 条未读消息。
3. “教务学业”：点击学期注册，查看待完成注册；再依次打开课表、成绩、选课、考试、学籍、预警和教材入口。
4. “学工事务”：打开请假申请、困难认定、奖助、宿舍、处分申诉、心理自评和第二课堂。
5. “岗位实习”和“毕业设计”：因李体验是 2026 级新生，应分别显示“尚未纳入实习安排”和“暂无毕设记录”。这是身份与时间一致的正确空状态，不用未来数据污染新生本人。
6. “消息通知”：查看学校通知与业务状态消息，说明学生只看到本人数据。

1. 管理员工作台：20,000 人及跨域风险下钻。

4. 实习：当前批次周报三状态，再切 `INT-2025-SUMMER-HIST` 看成绩归档。
5. 毕设：当前 `GD-2027` 看在办，再切 `GD-2026-HIST` 看驳回重交至 100% 归档。
6. 切换 `teacher2` 看 110 名责任学生和待办；切换 `student2` 看本人注册与新生阶段正确状态。
