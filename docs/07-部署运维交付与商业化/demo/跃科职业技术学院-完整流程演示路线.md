# 跃科职业技术学院（演示）完整流程演示路线

## 一眼看懂沙箱

这不是零散的页面填充数据。沙箱以 20,000 名学生、8 个学院、32 个专业、384 个班级为真实学校底座，同时放入可直接检索的典型流程案例。

演示时先用学校管理员看全校，再切教师看本人责任范围，最后切学生看本人办理结果，形成“学校看全局—教师办业务—学生查结果”的完整闭环。

## 45 分钟完整演示

### 1. 学校总览（3 分钟）

登录 `admin2`，进入工作台。先展示 20,000 名在册学生、学业预警、未就业学生和跨模块待办，说明所有数字都可下钻到业务记录。

### 2. 学工全过程（8 分钟）

1. 打开学生主档并检索李体验，展示一人一档、在校轨迹、风险与办事入口。
2. 打开数字迎新，展示预报到、材料、缴费、绿色通道、宿舍和现场报到漏斗。
3. 打开请假列表，分别检索 `2024S0040` 与 `2024S0008`，对比待审核和已批准。
4. 打开风险台账，检索 `2024S0005` 与 `2024S0002`，展示处理、升级、责任人与跟进记录。
5. 展示困难认定、奖助、公示、发放台账、宿舍、处分、谈话家校和学工归档。

讲解主线：学生申请 → 辅导员处理 → 学院/学工处审核 → 消息待办 → 风险联动 → 学生360 → 台账归档。

### 3. 教务全过程（10 分钟）

1. 从教务看板展示当前学期阻断项、风险项和待办。
2. 依次展示学期校历、学籍注册与异动、学院专业班级、培养方案、课程库。
3. 进入教学计划和教学任务，展示任务生成、教师分配、确认和阻断检查。
4. 展示排课规则、冲突检测、课表、调停课、课堂考勤和选课批次。
5. 展示考务、成绩录入发布、更正、学业预警、毕业资格十一项审核。
6. 以历史学期归档收尾，说明当前学期与历史已结账学期严格分离。

讲解主线：学期 → 培养方案 → 课程 → 教学任务 → 排课选课 → 考勤考试 → 成绩 → 预警 → 毕业审核 → 归档。

### 4. 岗位实习全过程（8 分钟）

1. 打开实习批次、企业岗位库和学生去向，说明 6,400 名实习学生与企业岗位容量真实关联。
2. 查看上岗准备，展示岗位、指导教师、保险、协议和资格状态。
3. 查看定位打卡与异常台账。
4. 在周报页依次检索 `2024S0007`、`2024S0009`、`2024S0001`，一眼对比待批、退回和通过。
5. 查看 `2024S0100`、`2024S0200` 的风险状态，展示责任人、期限和跟进意见。
6. 以评价、成绩和材料归档收尾。

讲解主线：批次 → 企业岗位 → 匹配落实 → 协议保险 → 上岗 → 打卡周报 → 指导巡访 → 风险处置 → 评价成绩 → 归档。

### 5. 毕业设计全过程（7 分钟）

1. 展示 2027 届批次、6,400 名学生、导师分配和题目库。
2. 查看任务书、指导记录和开题报告。
3. 在开题页依次检索 `2024S1259`、`2024S2261`、`2024S0001`，展示待审、驳回和通过。
4. 说明当前批次按真实日期只处于前期阶段；中期、成果、查重、评阅、答辩、成绩与归档在未来阶段开启，避免“8 月份已经答辩完”的穿帮数据。
5. 通过规范流程页一次展示全阶段准入条件和责任人。

讲解主线：批次 → 学生导师 → 题目选题 → 任务书 → 开题 → 过程指导 → 中期 → 成果查重 → 评阅答辩 → 成绩 → 归档。

### 6. 教师责任视角（4 分钟）

退出并登录 `teacher2`。展示其 110 名责任学生、个人待办、审批、谈话跟进和风险处置。强调教师只能看到授权范围，不是缩小版学校管理员。

### 7. 学生个人视角（5 分钟）

打开学生端并登录 `student2`。展示李体验的个人档案、迎新材料、学业、学生事务、实习、毕设、就业和消息中心，让客户看到同一业务如何回到学生本人。

## 10 分钟压缩路线

1. 管理员工作台：20,000 人和跨域风险下钻。
2. 学工风险：`2024S0005` 处理中、`2024S0002` 已升级。
3. 实习周报：`2024S0007` 待批、`2024S0009` 退回、`2024S0001` 通过。
4. 毕设开题：`2024S1259` 待审、`2024S2261` 驳回、`2024S0001` 通过。
5. 切 `teacher2` 展示责任范围，再切 `student2` 展示学生端结果。

## 演示纪律

- 当前日期为 2026-08-27。当前实习与毕设批次的数据必须符合时间真值。
- 不为了“页面有数字”提前生成未来的答辩、成绩或归档事实。
- 需要展示全年完整阶段时，使用规范流程、历史已结账学期和不同状态案例说明，不把未来事实伪装为已经发生。
- 学校名称和人物均为确定性虚构演示数据，不宣称来自真实客户学校。
