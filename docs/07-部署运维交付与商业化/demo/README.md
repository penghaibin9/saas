## 两端启动方式（供演示前准备）

### miniapp（学生端 + 教师端）

```bash
cd miniapp
npm install      # 首次运行或依赖有更新时执行
npm run dev:h5
```

- 启动后浏览器打开 **`http://localhost:5188`**（H5 开发端口）。
- 首页为登录页：点击「我是学生」→「进入学生端（模拟登录）」直接进入学生端首页（模拟登录，无需输入账号密码）。
- 点击「我是老师」→「进入教师端（模拟登录）」会先建立默认「辅导员」身份会话，再跳转到 **身份选择页**（`/pages/role-switch/index`），可在此切换到辅导员/毕设导师/实习指导教师/就业老师/教务老师/学院管理员 6 种身份中的任意一种。
- 登录页底部明确标注："当前为演示环境 · 数据均为 mock，不接后端"。

### PC 管理端

```bash
cd frontend
npm install
npm run dev
```

- 启动后浏览器打开 **`http://localhost:5173`**（Vite 默认开发端口，见 `frontend/vite.config.js` 的 `server.port: 5173`）。
- PC 端当前**无登录页拦截**（mock 阶段），各业务模块内部通过模块自带的 `roleProfiles` / `mockRuntime.activeRoleCode` 模拟"切换角色查看不同数据范围"的效果，具体操作方式见 `04-演示角色账号.md`。

## 阅读建议

- 只想知道"演示时能看到哪些数据、数据从哪来" → 看 `01`、`02`、`03`。
- 准备给客户/领导演示，想要一套可照念的脚本 → 看 `05`，配合 `04` 确认每步用哪个角色进入。
- 演示前一天/演示当天早上 → 过一遍 `06` 检查清单。
- 任何时候如果被问到"这是真数据吗" → 统一口径：**当前是 mock 演示数据，用于验证界面与流程设计，真实数据将在后端接入后由数据库提供（待后端确认接入时间）**。
