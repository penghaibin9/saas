## 1. 流程 / 待办 / 消息状态枚举（冻结册 §5.12，只引用）

```
流程实例：RUNNING / COMPLETED / RETURNED / REJECTED / CANCELLED / TERMINATED
待办任务：PENDING / CLAIMED / PROCESSING / COMPLETED / RETURNED / REJECTED / CANCELLED / EXPIRED / TRANSFERRED
消息：UNREAD / READ；回执：WAIT_RECEIPT / RECEIPTED
```

演示常用中文映射：待处理 `PENDING` / 处理中 `PROCESSING` / 已办结 `COMPLETED` / 已退回 `RETURNED` / 已驳回 `REJECTED` / 已超时 `EXPIRED` / 已转交 `TRANSFERRED`。

## 5. 审批演示话术要点

- **卡在哪一方**：实习申请五级流程页面明确显示当前卡在老师还是学院（`PENDING`/`TEACHER_AGREE`/`COLLEGE_PASS`…），解决"审批黑盒"痛点。
- **SLA 与超时**：审批模板带 SLA 时限，超时件红标；21 条里有超时/临期样例可展示。
- **转交与留痕**：可转交他人、全程审计留痕。
- **同池不同权**：切角色看待办范围差异，是权限体系的直观体现。

> 【现状差异】部分待办条数/SLA 天数为统一讲解口径，具体以 `approval.mock.js`、`todos.js` 页面实际为准；演示以"覆盖全状态、三方联动"为讲解主线即可。
