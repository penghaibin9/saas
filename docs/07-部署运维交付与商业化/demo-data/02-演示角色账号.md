## 3. 登录 / 进入方式（演示实操口径）

### PC 管理端（`frontend/`，端口 5173）

- **当前无登录页拦截**（mock 阶段）。进入模块后，通过模块自带的 `roleProfiles` / `activeRoleCode` **切换角色**查看不同数据范围与按钮可用性。
- 支持角色切换的模块：学生主档（5 档：学籍老师/辅导员/学院管理员/教务老师/系统管理员）、数字迎新、在校服务（6 档）、学业过程（5 档）、就业服务（4 档）、数据驾驶舱（5 档）、审批中心（5 档）。
- **固定单视角、不支持现场切角色**的模块：岗位实习（固定"刘强/张明远·实习指导教师"视角）、毕业设计（固定"张文澜·学院管理员"视角）、系统管理（固定"周文彬·学校管理员"视角）、平台运营（固定"陈立群·平台运营"视角）。演示这些模块时**不要临场找角色下拉**。

### 小程序（`miniapp/`，H5 端口 5188）

- 首页登录页 → 「我是学生」→「进入学生端（模拟登录）」→ 直接进入**林可欣**学生端首页（免密）。
- 首页登录页 → 「我是老师」→「进入教师端（模拟登录）」→ 先建立默认"辅导员"身份 → 跳 **身份选择页**（`/pages/role-switch/index`）→ 可切 6 种教师身份：辅导员 `COUNSELOR` / 毕设导师 `MENTOR` / 实习指导教师 `INTERN_MENTOR` / 就业老师 `EMPLOYMENT` / 教务老师 `ACADEMIC` / 学院管理员 `COLLEGE_ADMIN`。
- 教师端多身份统一挂在同一工号 **张明远（T20190087）** 上：演示"一个老师多重身份"直接用张明远切身份即可。

> 登录页底部固定标注："当前为演示环境 · 数据均为 mock，不接后端"。
