## 一、岗位实习

### 1. 实习主状态机（冻结册 §5.4，只引用）
```
INT_NOT_STARTED → PREPARING → APPLY_TEACHER_REVIEW → APPLY_COLLEGE_REVIEW → HIRED → READY → ONBOARD → ASSESSING → COMPLETED → ARCHIVED
旁路态：LEAVE_PENDING / CHANGE_PENDING / RISK_HANDLING / REPORT_RETURNED    终止：TERMINATED
实习申请五级：PENDING / TEACHER_AGREE / TEACHER_REJECT / COLLEGE_PASS / COLLEGE_REJECT / HIRED / NOT_HIRED（页面须显示"卡在哪一方"）
周报/请假：DRAFT / SUBMITTED / APPROVED / RETURNED
打卡：结果 NORMAL / ABNORMAL / MISSING；补卡 PENDING / APPROVED / REJECTED

```
GD_NOT_STARTED → TOPIC_SELECTING → TASKBOOK_PENDING → GUIDING → SUBMIT_PENDING_REVIEW →(通过)下一节点 /(驳回)RETURNED
→ MIDTERM_RECTIFY → DEFENSE_SCHEDULED → DEFENSE_SECOND(需二辩) → GRADE_PENDING_PUBLISH → COMPLETED → ARCHIVED

## 四、指标联动演示口径（可现场展示的"数据驱动"）

- **会联动**的指标：实习 / 毕设 / 就业 / 实践教学总览 4 组——由 `utils/aggregate` 以 `db.js` 学生/周报/打卡/毕设/就业/待办数据**实时算出**。现场改一条 `db.js` 记录（如把赵一凡打卡改 `NORMAL`），这 4 组指标会自动变。
- **不会联动**的指标：`dataCenter` / `academic` / `campusService` / `orientation` / `approval` / `system` / `platform` 的概览指标是**各模块预置常量**，不跟 `db.js` 变。
- **准确话术**：不要说"改一条数据全平台都变"；要说"**实习/毕设/就业/实践教学总览这组指标是实时算出来的，其余模块概览指标是预置的演示口径，都遵循数字自洽**"。

> 详细指标聚合函数与输入输出见 `docs/07-部署运维交付与商业化/demo/02-PC端演示数据口径.md` §3。
