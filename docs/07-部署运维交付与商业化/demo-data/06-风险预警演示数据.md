### 案例 A · 学业高风险：王雨桐
| 项 | 数据 |
|---|---|
| 学号 / 班级 | 2023010104 |
| 风险来源 / 等级 | 学业 / **高风险** |
| 触发条件 | **GPA 1.6、挂科 3 门**，自动触发学业预警 |

## 5. 风险演示话术要点

- **规则自动识别**：风险由规则触发（GPA 阈值、连续打卡异常天数、周报逾期），非人工打标，体现"预警"能力。
- **分级分派**：按高/中/低分级，推送对应角色（辅导员/教务/指导教师）待办。
- **闭环留痕**：发现→介入→跟进→关闭全程留痕，驾驶舱可看"本月已关闭 28 条"。
- **多处联动**：同一个赵一凡，风险、审批、待办三处一致，体现数据打通（限 `db.js` 世界观内，勿跨租户勾稽）。
- **敏感收敛**：心理关怀数据默认涉密，多数角色不可见，体现权限与隐私保护。

> 【现状差异】114 条为驾驶舱预置总量口径，与实习/学业模块的个案清单是"总量 vs 明细"两层，勿要求逐条勾稽到 114；演示按"总量三维拆分 + 旗舰个案下钻"两层讲即可。
