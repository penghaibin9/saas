# 院系导入模板说明

用途：为一所新学校批量导入院系（一级组织）。

## 字段说明
| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| name | 是 | 软件学院 | 院系全称，同校内唯一 |
| code | 否 | RJ | 院系编码，便于对接与排序 |

## 示例 CSV
```csv
name,code
软件学院,RJ
信息工程学院,XX
经济管理学院,JG
```

## 导入方式
1. 先调 `POST /api/v1/onboarding/validate`（dry-run）核对行号与错误，不落库。
2. 确认无误后调 `POST /api/v1/onboarding/confirm` 落库。
3. 请求体把本表转成 JSON：`{ "tenantId": "<学校租户ID>", "colleges": [ {"name":"软件学院","code":"RJ"}, ... ] }`

## 常见错误
- `院系名称必填`：name 为空。
- 重复导入同名院系：自动**跳过**（skipped），不会重复建。
