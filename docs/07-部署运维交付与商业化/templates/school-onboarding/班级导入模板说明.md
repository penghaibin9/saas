# 班级导入模板说明

用途：批量导入行政班级，挂靠到已存在的专业下。**导入班级前，专业必须先导入。**

## 字段说明
| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| majorName | 是 | 软件工程 | 所属专业全称，必须已存在 |
| name | 是 | 软工2401班 | 班级全称，同校内唯一 |
| grade | 否 | 2024 | 年级 |

## 示例 CSV
```csv
majorName,name,grade
软件工程,软工2401班,2024
软件工程,软工2402班,2024
数字媒体技术,数媒2401班,2024
```

## 导入方式
JSON：`{ "tenantId": "...", "classes": [ {"majorName":"软件工程","name":"软工2401班","grade":"2024"}, ... ] }`

## 常见错误
- `所属专业必填` / `专业不存在：xxx`：majorName 为空或未导入。
- 班级名会被学生表的 className 引用，请保持一致（否则学生导入时不自动挂班）。
