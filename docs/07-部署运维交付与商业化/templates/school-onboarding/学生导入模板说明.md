# 学生导入模板说明

用途：批量导入学生主档。建议先导好院系/专业/班级，学生的 className 才能自动挂班。

## 字段说明
| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| studentNo | 是 | 2024010601 | 学号，同校内唯一（重复自动跳过） |
| name | 是 | 张三 | 学生姓名 |
| gender | 否 | 男 | 男/女 |
| className | 否 | 软工2401班 | 与班级表 name 一致，用于自动挂班 |
| grade | 否 | 2024 | 年级 |
| stage | 否 | ENROLLED | 当前阶段，默认在校 ENROLLED |

> 敏感字段（手机号、身份证）不在开局批量表内，避免明文外泄；如需可后续经"信息更正/单独导入"补录，并走脱敏与加密。

## 示例 CSV
```csv
studentNo,name,gender,className,grade
2024010601,张三,男,软工2401班,2024
2024010602,李四,女,软工2401班,2024
```

## 导入方式
JSON：`{ "tenantId": "...", "students": [ {"studentNo":"2024010601","name":"张三","gender":"男","className":"软工2401班","grade":"2024"}, ... ] }`
- 建议**先 validate 看行号错误 + 将新增/跳过数量**，再 confirm。
- 学号在同一文件内重复：validate 会报 `文件内学号重复`。
- 学号在库中已存在：confirm 时自动跳过（skipped）。

## 常见错误
- `学号必填` / `姓名必填`。
- className 与班级表对不上：学生仍会创建，但不自动挂班（可后续补挂）。
