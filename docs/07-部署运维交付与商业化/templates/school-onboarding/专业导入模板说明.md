# 专业导入模板说明

用途：批量导入专业，挂靠到已存在的院系下。**导入专业前，院系必须先导入。**

## 字段说明
| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| collegeName | 是 | 软件学院 | 所属院系全称，必须已存在 |
| name | 是 | 软件工程 | 专业全称，同校内唯一 |
| code | 否 | 080902 | 专业代码 |

## 示例 CSV
```csv
collegeName,name,code
软件学院,软件工程,080902
软件学院,数字媒体技术,080906
信息工程学院,计算机网络技术,510202
```

## 导入方式
JSON：`{ "tenantId": "...", "majors": [ {"collegeName":"软件学院","name":"软件工程","code":"080902"}, ... ] }`
可与院系/班级/学生/教师放在同一次 `confirm` 请求中，系统按院系→专业→班级→学生→教师顺序处理。

## 常见错误
- `所属院系必填`：collegeName 为空。
- `院系不存在：xxx`：collegeName 对应院系未导入（confirm 阶段该行计入 failed）。
- 重复同名专业：自动跳过。
