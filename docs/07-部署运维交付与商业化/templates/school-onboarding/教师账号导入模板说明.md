# 教师账号导入模板说明

> 生产入口仅接受系统下载的标准 `.xlsx` 模板，不支持 CSV、`.xls` 或 `.xlsm`。

用途：批量创建教师登录账号、分配角色、绑定数据范围（谁能看哪些学生）。

## 字段说明
| 列名 | 必填 | 示例 | 说明 |
|---|---|---|---|
| loginName | 是 | teacher_zhou | 登录名（工号/手机号），同校内唯一 |
| name | 是 | 周老师 | 姓名 |
| roleCode / roleCodes | 是 | COUNSELOR | 只能选择 SaaS 预设角色；多角色可用逗号分隔，未知编码在预检阶段拒绝 |
| roleName | 否 | 辅导员 | 仅作导入提示，不用于隐式创建系统角色 |
| scopeType | 否 | CLASS | 数据范围类型：CLASS/COLLEGE/STUDENT/ADVISOR |
| scopeRef | 否 | 软工2401班 | 范围值：班级名/学院名/学号；ADVISOR 可空 |

### 常用 roleCode
| roleCode | 含义 | 常配 scopeType |
|---|---|---|
| COUNSELOR | 辅导员/班主任 | CLASS（本班） |
| GD_MENTOR | 毕设指导教师 | ADVISOR（按导师姓名） |
| INTERN_MENTOR | 实习指导教师 | ADVISOR |
| EMPLOYMENT_TEACHER | 就业老师 | COLLEGE 或 CLASS |
| ACADEMIC | 教务老师 | COLLEGE |
| COLLEGE_ADMIN | 学院管理员 | COLLEGE |

## 示例 CSV
```csv
loginName,name,roleCode,scopeType,scopeRef
teacher_zhou,周老师,COUNSELOR,CLASS,软工2401班
teacher_li,李老师,GD_MENTOR,ADVISOR,
teacher_wang,王老师,EMPLOYMENT_TEACHER,COLLEGE,软件学院
```

## 导入方式
JSON：`{ "tenantId": "...", "teachers": [ {"loginName":"teacher_zhou","name":"周老师","roleCode":"COUNSELOR","scopeType":"CLASS","scopeRef":"软工2401班"}, ... ] }`

## 重要：初始密码
- 每个新教师账号系统生成**一次性初始密码**，仅在 `confirm` 响应的 `teacherCredentials` 里返回一次，**不写任何日志**。
- 请立即转交本人并要求首次登录修改（账号已置 `must_change_password`）。

## 数据范围（防越权关键）
- scopeType=CLASS/COLLEGE/STUDENT/ADVISOR 会写入 `t_teacher_student_scope`，教师端只能看到范围内学生。
- 不填 scope：该教师回落"仅本租户"范围（标准版应尽量补全，避免看到全校）。

## 常见错误
- `登录名必填` / `姓名必填` / `角色编码必填`。
- 文件内 loginName 重复：validate 报错；库中已存在：confirm 跳过。
