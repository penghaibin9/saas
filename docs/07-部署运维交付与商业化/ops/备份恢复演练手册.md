# 备份恢复演练手册（P13-F）

> 核心原则：**未做过恢复演练的备份，不能宣称"生产备份可靠"。** 本手册把"有备份脚本"推进到"能演练恢复"。
> 演练默认恢复到**测试库**，绝不自动覆盖生产库。

## 一、现有能力（已具备，核查证据）
| 脚本 | 能力 | 已满足要求 |
|---|---|---|
| `deploy/backup/backup-mysql.sh` / `.ps1` | 每日备份 + gzip + 保留 14 天 + 可选附件 | 密码走环境变量（不硬编码）；`KEEP_DAYS=14` |
| `deploy/backup/restore-mysql.sh` / `.ps1` | 恢复指定备份 | **恢复前有 yes/no 确认**；**恢复前自动做安全快照**；密码走环境变量 |
| `scripts/check/check-backup-files.sh` / `.ps1` | 备份文件存在性 + 新鲜度 + gzip 完整性检查 | 本轮新增 |

## 二、每月恢复演练标准步骤（到测试库）

> 目标：证明"备份能还原成一个可登录、数据完整的库"。

1. **准备测试库**（与生产同版本 MySQL，独立实例或独立库名）：
   ```sql
   CREATE DATABASE saas_lifecycle_drill CHARACTER SET utf8mb4;
   ```
2. **取最近一份生产备份**，先校验完整性：
   ```bash
   bash scripts/check/check-backup-files.sh /var/backups/school-lifecycle
   ```
3. **恢复到测试库**（把 DB_NAME 指向演练库，**切勿指向生产**）：
   ```bash
   export DB_HOST=127.0.0.1 DB_PORT=3306 DB_USER=drill_user DB_PASSWORD=****
   export DB_NAME=saas_lifecycle_drill
   bash deploy/backup/restore-mysql.sh /var/backups/school-lifecycle/db_xxx_YYYYmmdd_HHMMSS.sql.gz
   # 脚本会要求输入 yes 确认
   ```
4. **启动一个指向演练库的后端实例**（或临时改 .env 的 DB_NAME 到演练库，端口错开）。
5. **按"恢复后验证清单"逐项核对**（见下）。
6. **填写演练报告**（用 `备份恢复演练报告模板.md`），记录耗时、结果、问题。
7. **清理**：演练完删除演练库/实例，不留脏数据。

## 三、恢复后验证清单
- [ ] `curl http://<演练地址>/health` → `{"status":"UP"}`
- [ ] `curl http://<演练地址>/health/ready` → `READY`（DB 连通）
- [ ] 关键表行数与备份时点吻合（学生数、教师数、六域主表）：
  ```sql
  SELECT (SELECT COUNT(*) FROM t_student_profile) AS students,
         (SELECT COUNT(*) FROM t_user) AS users,
         (SELECT COUNT(*) FROM t_internship_record) AS internships;
  ```
- [ ] 用一个已知账号能登录（演练库内的测试账号）。
- [ ] 抽查一名学生的六域数据完整、无乱码（utf8mb4）。
- [ ] 审计表/通知日志等 append-only 表可读。

## 四、备份文件完整性检查
- 每次备份后应能 `gzip -t` 通过（脚本 `check-backup-files` 自动做）。
- 建议每周至少一次自动完整性检查 + 告警。

## 五、备份保留策略
- 数据库全量：每日 02:00，保留 **14 天**（`KEEP_DAYS`）。
- 建议：每周一份**周备份**保留 8 周、每月一份**月备份**保留 12 个月（异地存储）。
- 附件（uploads）单独备份；生产建议对象存储自带多副本。
- 备份文件应**异地/异盘**存放，避免与生产同盘同损。

## 六、红线
1. 演练**默认到测试库**，`DB_NAME` 指向演练库；确认无误再执行。
2. `restore` 必须经 yes 确认（脚本已内置）。
3. 不写死密码/服务器路径，一律环境变量。
4. 生产恢复（真出事时）须由负责人复核后执行，并先跑安全快照（脚本已内置）。
5. **每月至少一次**演练，未演练不得对外承诺"备份可靠"。
