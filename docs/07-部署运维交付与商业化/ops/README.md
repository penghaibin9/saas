## 现阶段运维范围（重要）

当前线上真实运行的只有**前端静态站点**（PC 管理端 + 小程序 H5）和**微信小程序包**，用的是 mock 假数据。
所以现在的运维**主要是围绕 Nginx + 静态站点**：站点能不能打开、刷新会不会 404、资源加载正不正常、发版会不会出错、出错怎么回滚。

**后端、数据库相关的运维（接口 500、数据库连不上、数据库备份恢复）当前用不到**，因为还没接后端、没建库。这些内容本目录也写了，但都标注为「**后端/数据库接入后才适用，届时需补真实命令**」，现在当作提前预习即可。

## 新手运维三原则

1. **改配置先测再重载**：`sudo nginx -t` 通过后才 `sudo systemctl reload nginx`。
2. **发版留后路**：记住上一版目录名/版本号，出问题能回滚（见 `docs/07-部署运维交付与商业化/deploy/09-发布与回滚流程.md`）。
3. **不确定不硬改**：分不清是「bug」还是「mock 本来就不落库」时，先记录现象，别去改 `frontend/src/`、`miniapp/`、数据库文档。
