# 07 · 安全加固清单

> 新手能落地的基础安全项。项目另有专业文档 `docs/05-数据接口权限与安全/security/00-等保三级安全基线总册.md`，正式等保合规以那份为准；本清单是「现阶段前端上线要先做到的最基本项」。

---

## 1. 服务器登录安全

- [ ] 关闭 root 直接用密码远程登录，改用**密钥登录**（更安全）。
- [ ] 服务器登录密码/密钥**强度足够**，不与他人共享。
- [ ] 只开必要端口：80、443（和你确实用到的），其余关闭（见 `docs/07-部署运维交付与商业化/deploy/02` 防火墙一节）。
- [ ] 及时打系统安全更新：`sudo apt update && sudo apt upgrade`（择机）。

---

## 2. Nginx / 站点安全

- [ ] 配好基础安全响应头（已在 `docs/07-部署运维交付与商业化/deploy/07` 的示例里）：
  - `X-Frame-Options: SAMEORIGIN`（防点击劫持）
  - `X-Content-Type-Options: nosniff`（防 MIME 嗅探）
  - `Referrer-Policy`、`X-XSS-Protection`
- [ ] 有域名的话**上 HTTPS**（certbot 免费证书，见 `docs/07-部署运维交付与商业化/deploy/07` 第 5 节）。
- [ ] 关闭目录列表（Nginx 默认就关，别手动开 `autoindex on`）。
- [ ] 隐藏 Nginx 版本号（可选）：`server_tokens off;`。

---

## 3. 文件与权限

- [ ] 网站目录属主正确、权限不过大：`sudo chown -R www-data:www-data /var/www/`（Ubuntu）。
- [ ] 真实 `.env`（含密码/密钥）**权限收紧**（`chmod 600`），**不进 git**。
- [ ] 不把备份/日志/密钥放到网站可访问目录里（别让别人直接下载到）。

---

## 4. 密钥与敏感信息

- [ ] 任何密码、密钥、证书私钥**不提交 git**（`.gitignore` 已忽略 `.env`）。
- [ ] 微信小程序 AppSecret、后端 JWT 密钥等**严格保密**（后端接入后适用）。
- [ ] 不在前端代码里写死任何真实密钥（前端代码用户可见）。

---

## 5. 数据与隐私（现阶段 mock）

- [ ] 现在是 mock 假数据，**不涉及真实学生个人信息**——演示时也要说明这一点，别让人误以为是真实数据。
- [ ] 后端接入后，学生个人信息属于敏感数据，必须按 `docs/05-数据接口权限与安全/security/00-等保三级安全基线总册.md` 做脱敏、加密、访问控制、审计。

---

## 6. 后端/数据库接入后要补的安全项（现在不用做）

- [ ] 数据库账号最小权限、不用超级用户跑业务。
- [ ] 数据库端口不对公网开放，只对后端内网开放。
- [ ] 接口鉴权（登录令牌）、越权校验、限流。
- [ ] 敏感数据加密存储、传输全程 HTTPS。
- [ ] 完整的操作审计日志（谁在什么时候改了什么）。
- [ ] 定期安全扫描与备份恢复演练。

> 正式合规以 `docs/05-数据接口权限与安全/security/00-等保三级安全基线总册.md` 为准，本清单只保证「前端上线阶段」的基本安全底线。
