## 二、已落地内容

### 1. 数据库性能

- 新增 Alembic 性能迁移 `backend/alembic/versions/0100_tenant_hotpath_indexes.py`。
- 为统一消息、待办、学业预警、安全审计增加租户前导组合索引。
- 为迎新、学业、就业、实习学生关联增加 `tenant_id + student_id + is_deleted` 热路径索引。
- 本地开发库已经执行到 `0100_tenant_hotpaths`，新增索引已通过数据库反查确认；未操作生产数据库。
- ORM 结构审计覆盖 266 张表，没有发现业务表缺失 `tenant_id` 或缺少租户前导索引。
- `t_order.order_no` 当前为全局唯一，需要业务确认是否应改为租户内唯一。

### 2. 学生主键关联与历史数据

- 移动端迎新、学业、就业等跨模块查询优先使用 `student_id`。
- 历史兼容仅在 `student_id` 为空时使用学号、录取号或唯一姓名回退。
- 新增 `backend/scripts/backfill_student_domain_links.py`：默认 dry-run，显式确认后才写入。
- 新增 `backend/scripts/audit_tenant_schema.py`：检查租户字段、索引和唯一约束。
- 新增 `backend/scripts/audit_tenant_queries.py`：启发式扫描直接 `Session.get` 和缺少明显租户条件的查询，结果只作为人工复核清单，不直接等同于漏洞。

### 3. Redis、鉴权和自动登录

- 正式增加 Redis 客户端依赖及连接配置。
- JWT 黑名单优先写 Redis，同时保留数据库持久化与进程内降级。
- 账号状态、学校状态、当前角色和权限版本校验增加短时 Redis 缓存。
- 账号停用、密码重置、角色分配、角色权限修改、学校状态修改后主动失效缓存。
- 登录失败次数和登录锁定改为多实例共享计数。
- 增加学校级和用户级 API 限流；Redis 故障时降级到进程内保护。
- Access Token 维持 2 小时，Refresh Token 维持 7 天；小程序继续使用单飞刷新机制。

### 4. 小程序首页

- 新增 `GET /api/v1/mobile/home` 聚合接口。
- 原首页概览、迎新状态、迎新批次三个请求合并为一个请求。
- 聚合过程复用同一个数据库会话，减少重复鉴权和数据库连接。
- 首页增加 20 秒 Redis 短缓存，消息读取和迎新写操作后主动失效。
- 首页增加加载锁，阻止首次加载与下拉刷新重叠。
- 已确认首页没有额外的 `onShow` 重复加载。

### 5. 后端并发和调度

- MySQL 连接池增加获取超时、连接回收、LIFO、连接/读/写超时。
- Docker 基线改为 2 个后端副本，每个副本 4 个 Uvicorn worker。
- Web worker 中的定时任务受 `SCHEDULER_MODE` 控制。
- 新增 `backend/scripts/run_scheduled_jobs.py` 独立调度进程，防止多 worker 重复扫描。
- Nginx 增加连接数保护、登录限流、写接口限流、后端连接复用和代理超时。

### 6. SaaS 隔离与文件安全

- 增加租户结构和查询静态扫描脚本。
- 增加首页跨租户隔离测试用例。
- 关闭 Nginx 对 `/uploads/`、`/exports/` 的磁盘直读入口，避免绕过后端鉴权。
- 文件和导出结果应统一通过后端接口校验登录用户、`tenant_id`、资源归属和数据范围。

### 7. 备份、恢复和监控

- 重写 Windows/Linux MySQL 全量备份脚本。
- 备份包含事务一致性、存储过程、事件、触发器、Binlog 起点和 SHA256 校验。
- 恢复脚本增加校验、二次确认、恢复前安全快照和恢复后表数量检查。
- 增加慢 SQL 日志：只记录 SQL 动词、耗时和批量标识，不记录 SQL 参数。
- 增加接口 p50/p95/p99、状态码和慢请求进程指标。
- `/health/ready` 增加数据库连接池和 Redis 状态。
- 已编写《10校SaaS上线性能与容灾基线》文档。
