# 当前有效文档索引

> 更新：2026-07-09
> 用途：AI 与开发按场景查找**当前有效**文档；P3 文档不作为施工依据。
> 冲突时以 `文档冲突与重复清单.md` 为准。

**优先级定义**：

- **P0**：每次开工必读
- **P1**：涉及对应模块/场景时必须读
- **P2**：设计补强、验收、部署时读
- **P3**：历史参考，不作为施工依据
