> 生成日期：2026-07-04

---

## 文件清单

| 序号 | 文件 | 内容 |
|---|---|---|
| 01 | `01-项目目录结构说明.md` | 项目根目录全景：每个顶层目录是什么、能不能动 |

## 最重要的一句话

- **要动的**：PC UI 对接动 `frontend/src/`（按母版对接）；小程序后续开发动 `miniapp/`。
- **别动的**：数据库冻结文档（`docs/database/`）、API 契约（`docs/api/`）、各类"冻结"文档、`backend/`（预留）。
- **机器生成、别手改的**：`frontend/dist/`、`miniapp/dist/`、`node_modules/`。

详见 01。
