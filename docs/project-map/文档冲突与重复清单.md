## 处理原则

1. **事实状态**以代码（navPlan、pytest、MySQL）为准，不以设计总册为准。
2. **业务规则**以 modules 当前总册为准，不以 source-design 为准。
3. **技术栈**以 CLAUDE.md 最新章为准，不以 database 冻结总册头注为准。
4. 发现新冲突：追加本表 + 在 `历史欠账.md` 记一笔（若不阻断则 A 类）。
