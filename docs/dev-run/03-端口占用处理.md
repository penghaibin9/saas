# 03 · 端口占用处理

## 本项目用哪些端口

| 端口 | 谁在用 |
| --- | --- |
| 5173 | PC 前端（vite 默认） |
| 5174 | 备用（5173 被占时 vite 自动改用） |
| 5188 | 小程序 H5 |
| 3000 | 后端（Express，暂未启用） |
| 8000 | 备用后端端口（预留） |

## 第一步：先看谁占了端口

在项目根目录执行：

```
powershell -ExecutionPolicy Bypass -File scripts\dev\check-ports.ps1
```

每个端口会显示 `[空闲]` 或 `[占用]`，占用的会显示进程名和 PID。

## 第二步：判断要不要处理

- 占用的进程是 `node`，而且就是你自己刚启动的服务 → **正常，不用管**。
- 想重启服务、或者不知道是谁占的 → 往下走第三步。

## 第三步：一键停掉

在项目根目录执行:

```
powershell -ExecutionPolicy Bypass -File scripts\dev\stop-dev.ps1
```

它会先列出将要停止的进程，你按回车确认才会动手；输入 `N` 回车就取消。

## 第四步（备用）：手动停某一个

如果只想停某一个 PID（比如 check-ports 显示 PID=12345）：

```
taskkill /PID 12345 /F
```

## 小知识

端口被占时 vite 不会报死，它会自动换下一个端口（比如 5173 → 5174），启动窗口里会显示实际地址，以窗口显示为准。
