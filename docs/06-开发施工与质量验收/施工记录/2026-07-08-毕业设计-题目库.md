## 二、状态机

```
申报(DRAFT) → 提交审核(PENDING_REVIEW) → 通过(APPROVED+CONFIRMED 入池) → 分配学生
                                      ↘ 驳回(REJECTED) → 可修改再提交
入池后可停用(DISABLED) / 启用 / 归档(ARCHIVED)
```

分配选题条件：`APPROVED` + `CONFIRMED` + 未满员 + 非 `DISABLED`/`ARCHIVED`。
