# 教务中心 · 教学计划（收编）· 施工记录

- 日期：2026-07-14
- 分支：`feat/13b-parallel-mods`
- 决策：**用户 2026-07-14 拍板「收编」**（AskUserQuestion）——不建独立 `t_aa_teaching_plan*` 域。

## 一、决策背景
教务开工手册-下册 P6 已冻结"教学计划**收编、不新建表/端点/页面**"，理由是与既有 `AaProgramBinding`(年级教学计划) + `AaTeachingTaskBatch`(学期开课计划) 功能重叠。用户"把教学计划做完"的指令与该冻结决议冲突。因这是会显著改变产品的架构选择，AI 未擅自定，向用户二选一（建独立域 vs 收编），**用户选「收编（推荐）」**。

## 二、落地（零新表 / 零后端 / 零新页）
仅改 `frontend/src/config/navPlan.js` 的 `aa-teaching-plan` 节点：`path=null` + 全 `P()` 占位 → 真实路径 + `I()` 叶子指向既有已实现页：

| 教学计划三级叶子 | 收编到（既有已实现页） |
|---|---|
| 年级/专业教学计划 | 培养方案 `/admin/academic-affairs/programs`（`AaProgram`/`AaProgramBinding` 方案-年级/专业绑定） |
| 学期教学计划 / 课程开设计划 | 教学任务 `/admin/academic-affairs/teaching-tasks`（`AaTeachingTaskBatch` 学期开课计划 + `AaTeachingTask` 课程开设） |
| 计划归档 | 教务归档 `/admin/academic-affairs/archive`（本轮已建，含培养方案/教学任务数据域） |
| 实践教学计划/计划审核/发布/变更/执行进度 | 保留 `P()` 占位——审核发布走培养方案自身的审核发布链，执行进度看教学任务批次状态；实践计划在培养方案 `requirement_json` 实践环节内 |

## 三、验证
- 无新增 model/迁移/service/router/测试（收编不需要）。
- `navPlan.js` 改动为叶子指向既有路由，`vite build` 通过（见提交前 build 记录）。
- 既有 `/programs`、`/teaching-tasks`、`/archive` 页均已实现且各自 MySQL 验收通过（W3/W4 + 本轮教务归档）。

## 四、意义
**教学计划收编后，教务中心 27 个二级模块全部有可用入口 → 总体收工。** 无冗余表、无重复功能，符合手册 P6 冻结设计与"不重复造轮子"红线。

## 五、备选方案存档
《教学计划-生产级施工包.md》中"建独立域(3 表:plan 头8态/plan_course/plan_change)"的完整设计仍在，作为已论证备选存档，未执行。若学校后续确需独立教学计划工作台（如需"应开 vs 实开"偏差跟踪、计划变更单独审批链），可据该卡重启建域，届时 navPlan 叶子从收编链接改回独立域页。
