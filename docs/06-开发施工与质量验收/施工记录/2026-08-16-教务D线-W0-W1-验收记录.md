## D-W1 Archive 四态

### 冻结合同

Archive 预检、正式批次持久化回读与 Manifest 统一使用四态：

- `PASS`：已证明满足。
- `BLOCKED`：已知业务阻断，必须阻断归档。
- `NOT_APPLICABLE`：当前学期明确不适用，`blockingCount=0`，不得冒充 PASS，也不得阻断。
- `UNKNOWN`：证据不足/上下文不完整，必须 fail-closed，不得冒充 PASS。

正式阻断集合固定为：`BLOCKED + UNKNOWN`。

### 已修 false-green / false-block

- 无 `termId` / 学期日期缺失：从旧布尔假绿收紧为 `UNKNOWN`。
- 有效学期但无毕业批次：`NOT_APPLICABLE`。
- 未归档毕业批次：`BLOCKED`。
- 全部毕业批次已归档：`PASS`。
- Selection / Evaluation / Textbook 的“本学期无业务事实”不再统一冒充 PASS，按适用性返回 N/A。
- Makeup / Evaluation / Textbook 缺学期上下文按 `UNKNOWN` fail-closed。
- 学籍异动既无 `term_code`、也无可用业务/创建时间时，不再返回“待迁移补齐但 PASS”，统一 `STATUS_CHANGE_SCOPE_UNKNOWN / UNKNOWN`。
- Stage C3 `ArchiveManifest.confirm_archive` 使用同一阻断集合，避免预检 N/A 放行而正式封存再次误拦截。
- `AaArchiveItem.remark` v2 持久化 `result/ruleCode/blockingCount/summary`；`get_batch()` 回读恢复四态，N/A 即使兼容列 `present=false` 也不会刷新后退化成旧“缺失”。四态 round-trip 回归已加入 `test_aa_archive_d_w1_contract.py`。
