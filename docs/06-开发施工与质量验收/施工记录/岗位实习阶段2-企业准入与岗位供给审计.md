## 实际流转清单

| 发起与责任方 | 对象与动作 | 下一状态/结果 | 边界与四端反馈 |
|---|---|---|---|
| 学校企业经办人 | 创建企业主档 | PENDING，等待资质审核 | 不自动成为准入有效或可接收学生；学生端不展示内部待审主档 |
| 有资质审核权限的学校人员 | 待审企业通过/驳回 | ACTIVE+PASSED / REJECTED+FAILED | 驳回需原因；版本冲突不得覆盖最新事实；通过仍需检查岗位条件 |
| 考察经办人与审核人 | 登记 → 提交 → 通过/驳回考察 | DRAFT → SUBMITTED → APPROVED/REJECTED | 通过同事务更新准入有效期；考察方式、日期、人员、结论、材料应按现有字段完整录入；政策是否要求实地考察另核验 |
| 合作管理员 | 暂停/恢复/拉黑/移出/归档 | 依服务状态机流转 | 不将“移出黑名单”一律说成合作中；学生目录实时排除不满足合作条件的岗位 |
| 岗位经办人与发布人员 | 草稿编辑 → 提交 → 发布 | DRAFT → PENDING → PUBLISHED | 真实权益评估通过后发布；保存不代表发布；停用/风险/归档影响后续可用性 |
| 学校招聘组织方、受邀企业 | 开放招聘季 → 邀请 → 企业接受 → 企业报送岗位 → 学校审核发布 | 独立招聘季与参与状态，岗位保留明确来源 | 仅满足 catalog 条件的岗位进入该招聘季学生目录；历史无 campaign_id 岗位不反推招聘季 |
| 学生本人 | 进入实习选岗、筛选、查看岗位和企业 | 显示本次可见供给及选岗条件 | 未开招聘季、无权、无匹配岗位、加载失败分别表达；资格未通过不冒充可以投递；正式志愿写入留至阶段 3 |
