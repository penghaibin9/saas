## 2. 深链 / 频控 / 静默

| 能力 | 落点 | 行为 |
|---|---|---|
| 深链白名单 | `message_action_registry.py` | 未登记 key → `MESSAGE_ACTION_NOT_ALLOWED`；缺参 → 422 |
| 注册表 API | `GET /admin/message-campaigns/action-keys` | 发布页下拉、收件「去办理」取 PC 路由 |
| 发布频控 | `assert_publish_rate` @ `publish_campaign` | 同发布人 60 分钟 ≤ 20 次，超限 429 |
| 静默时段 | `apply_quiet_hours_policy` | 普通 22:00–07:00(UTC+8) 顺延；紧急可绕过并写备注 |
| 设置页展示 | `message_meta_service.channel_settings` | 展示 quietHours + rateLimit |
| 小程序详情 | `GET /mobile/me/messages/{id}` | 按 messageId 重拉，杀进程可重开 |
