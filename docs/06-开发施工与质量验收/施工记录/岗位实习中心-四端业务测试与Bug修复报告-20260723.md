## 8. 已修复 Bug

### IX-BUG-001 评价权重和不等于 1 仍可保存

- 模块：批次与规则
- 根因：`EvaluationRuleCfg` / `ScoreRuleCfg` 未校验权重和
- 修复：`model_validator` 强制和为 1.0
- 文件：`backend/app/modules/internship/schemas/internship.py`
- 回归：`tests/test_internship.py::test_batch_rejects_evaluation_weights_not_summing_to_one`；活体负向用例

### IX-BUG-002 学生主档缺 college_id 导致学院负责人误拒

- 模块：实习学生 / 权限范围
- 根因：身份导入只写 class/major；范围匹配只看 `college_id`
- 修复：
  1. `_rec_in_scope` / `can_teacher_view_student` 推导学院名
  2. `school_onboarding_service` 创建/跳过学生时回填 `college_id`
- 文件：
  - `backend/app/modules/internship/services/internship_student_service.py`
  - `backend/app/modules/internship/services/internship_service.py`
  - `backend/app/services/mobile_teacher_service.py`
  - `backend/app/services/school_onboarding_service.py`

### IX-BUG-003 批次启用后改规则与单测口径不一致

- 模块：批次状态机
- 修复：单测改为草稿改规则、启用后仅改计划人数并断言规则不可改
- 文件：`backend/tests/test_internship.py`
