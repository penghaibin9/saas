## 一次性完工标准（implemented 验收线）

1. 前端接真实接口；2. 后端 model+service+api；3. 状态机；4. 权限后端校验；5. 数据范围；6. 审计；7. 脱敏；8. **Excel/xlsx** 导入导出；9. pytest；10. lint+build；11. navPlan 同步；12. 不删旧路由/乱改生产库。

只前端 → `partial`；只有规划 → `planned`。细节见下文原「二、一次性完工标准」保留口径。

## 数据库标准（MySQL-only）

正式标准 = **MySQL**（utf8mb4）。SQLite/PostgreSQL 仅历史遗留。收口报告必须写明数据库类型。详见 `历史欠账.md` §数据库。
