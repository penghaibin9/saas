## 4–6. Bug 清单 / 根因 / 修复 / 回归

### BUG-1 资格不合格学生仍可确认选题 / 学生可填报志愿
- **复现**：创建毕设学生后设 `UNQUALIFIED`，调用 `/gd-students/{id}/assign-topic` 仍可能成功；学生端提交志愿未校验资格。
- **根因**：`assign_topic_in_session` / `submit_choices` 未校验 `eligibility_status`。
- **修复**：
  - `graduation_student_service.py`：`UNQUALIFIED` 禁止分配
  - `graduation_topic_round_service.py`：非管理员导入时要求 `QUALIFIED` 才可填报志愿
- **回归**：`test_unqualified_student_cannot_be_assigned_topic` PASS

### BUG-2 批次成绩权重≠100% / 阶段时间倒序仍可保存
- **复现**：`POST /batches/{id}/rules` 写入 advisor 0.5 + reviewer 0.3 + defense 0.3；`POST .../stages` 后一阶段早于前一阶段。
- **根因**：`set_rules`/`set_stages` 仅覆盖存储，无业务校验。
- **修复**：`graduation_batch_service.py` 增加 `_validate_and_merge_rules` / `_validate_stages`
- **回归**：`test_batch_rules_reject_non_100_percent_weights`、`test_batch_stages_reject_reversed_dates` PASS

### BUG-3 未关闭风险不阻断归档
- **复现**：材料齐全但存在 `OPEN` 风险时仍可 `submit` 归档。
- **根因**：`submit_archive`/`verify_and_file` 只检查材料清单。
- **修复**：`graduation_archive_service.py` 增加 `_assert_no_open_risks`；归档成功联动 `grad_qual_status=PASS`（不覆盖 FAIL）
- **回归**：`test_open_risk_blocks_archive_submit` PASS

### BUG-4 沙箱 `admin2` 无法登录
- **复现**：`admin2/123456` 返回账号密码不正确。
- **根因**：密码哈希与种子口令不一致（损坏/被重置）。
- **修复**：用官方 `hash_password` 恢复种子口令（仅修复初始化，未改正式管理员）。
- **回归**：`admin2` 登录成功，可创建批次与组织。

### BUG-5 学校账号列表缺少 `loginName` 字段
- **复现**：`GET /system/users` 仅返回 `userNo`，脚本/客户端按 `loginName` 匹配失败。
- **根因**：`_user_row` 未输出标准登录名字段。
- **修复**：`system.py` `_user_row` 增加 `loginName`/`realName` 别名。
- **回归**：列表可按登录名匹配。

### BUG-6（记录，未改前端 mock 创建）手工「新增账号」仍走前端 mock
- **说明**：真实创建入口为 `/system/identity-import/*`。本次按官方导入完成账号创建；前端 `createUser` mock 属系统管理欠账，未在本任务扩大范围重做整页。

### BUG-7 评阅 SoD 仅比对空白 `advisor_name` 可被绕过
- **复现**：学生 `advisor_name` 为空但题目指导教师已赋值时，仍可把题目指导教师指为评阅人。
- **根因**：`assign_review` 只比对 `stu.advisor_name`。
- **修复**：同时汇总导师档案姓名 + 题目 `advisor_name` 做回避。
- **回归**：`test_assign_review_sod_uses_topic_advisor_when_student_advisor_blank` PASS；活体 SoD 拦截 PASS

### BUG-8 中期整改中仍可提交成果
- **复现**：中期结论 `RECTIFY` / 状态 `RECTIFYING` 时学生仍可 `POST /mobile/graduation/final`。
- **根因**：`submit_final` 未校验中期门禁。
- **修复**：`graduation_service.submit_final` 拦截整改中/不通过态。
- **回归**：`test_final_blocked_while_midterm_rectifying` PASS；活体学生 B 拦截 PASS

### BUG-9 多批次毕设档案时学生端命中旧档案
- **复现**：同生多次建档后，学生端提交落在最早一条，导致新批次中期门禁失效。
- **根因**：`_resolve_gd_student` / `_resolve_domain_student` 用 `.first()` 无排序。
- **修复**：优先返回未归档且 id 最大的毕设档案。
- **回归**：`test_mobile_resolve_prefers_latest_non_archived_gd_student` PASS
