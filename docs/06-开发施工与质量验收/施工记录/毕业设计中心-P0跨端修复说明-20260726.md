# 毕业设计中心 P0 跨端修复说明（2026-07-26）

本次只处理审计确认的上线阻断项，不扩展普通产品功能。

## 修复范围

- Alembic 毕业设计、岗位实习、学工迁移分支合并为单一 head。
- 教师微信小程序毕业设计接口接入与 PC 一致的动作级权限。
- 非管理员教师必须绑定稳定导师工号身份，拒绝继续仅按姓名授权。
- 学生当前毕业设计档案按 RUNNING 批次、日期和唯一有效记录解析，不再按最大 ID 猜测。
- 学生 PC 门户和学生微信小程序任务书确认统一为版本锁定、正文 SHA-256、签署证据、状态推进同事务。
- 毕业设计中心直接修改最终毕业资格的旧入口被拦截，由教务中心统一裁决。
- 撤销指导记录增加行锁和学生数据范围校验。

## 兼容策略

为减少与现有大文件和其他并行施工的冲突，高风险旧路径采用“精确路由优先注册”方式拦截，旧路径继续保留但不会命中：

- `/api/v1/mobile/graduation/taskbook/confirm`
- `/api/v1/portal/graduation/taskbook/sign`
- `/api/v1/graduation/gd-guidances/records/{id}/void`
- `/api/v1/graduation/gd-students/{id}/grad-qual`
