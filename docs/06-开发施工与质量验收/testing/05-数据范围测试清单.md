# 05-数据范围测试清单

- **文档性质**：数据范围（Data Scope）隔离验证用例清单
- **适用端**：PC 管理端 `frontend/` + miniapp 教师端 `miniapp/`
- **依据**：`_shared_brief.md` 第 3 节（DATA_SCOPE：ALL/SCHOOL/COLLEGE/CLASS/SELF/ASSIGNED）、第 2 节（miniapp 角色数据范围：SELF/CLASS/MENTEES/INTERNS/COLLEGE）；数据范围判断入口 `frontend/src/modules/workflow/context/permission.context.js` 的 `getDataScope`；权威口径以 `docs/05-数据接口权限与安全/rbac/`（RBAC 权限与数据范围矩阵）为准
- **当前阶段声明**：当前 mock 数据分组（如"按班级/学院预先划分好的数据集合"）是**前端固定演示数据**，可验证"列表/详情/统计/导出只出现范围内数据"的**前端过滤逻辑**是否按角色正确工作。真实的多租户隔离、跨校数据隔离、服务端强制的数据范围校验（防止越权直接查询）均标注"（后端接入后验证）"，对应错误码 `NO_DATA_SCOPE`。
- **生成日期**：2026-07-04

## 一、数据范围定义与适用角色对照

| 数据范围码 | 中文含义 | PC 管理端适用角色 | miniapp 教师端适用身份 |
|---|---|---|---|
| ALL | 全平台 | 平台运营 PLATFORM_OPERATOR | — |
| SCHOOL | 本校 | 学校管理员 SCHOOL_ADMIN | — |
| COLLEGE | 本学院 | 二级学院管理员 COLLEGE_ADMIN | 就业老师 EMPLOYMENT、教务老师 ACADEMIC、学院管理员 COLLEGE_ADMIN |
| CLASS | 本班级 | 辅导员 COUNSELOR | 辅导员/班主任 COUNSELOR |
| SELF | 仅本人 | 学生 STUDENT | — |
| ASSIGNED | 被指派对象 | 指导教师 TEACHER、企业导师 ENTERPRISE_MENTOR | 指导教师(毕设) MENTOR→MENTEES 子集、实习指导教师 INTERN_MENTOR→INTERNS 子集 |

> 说明：miniapp 角色配置文件中指导教师(毕设)与实习指导教师的数据范围分别细化为 MENTEES（被指导学生子集）与 INTERNS（被指导实习学生子集），本质上是 PC 端 ASSIGNED 范围在教学实践场景下的具体化，测试时按"仅能看到本人被指派/指导的学生"这一原则验证。

## 四、越权访问统一预期（NO_DATA_SCOPE）

| 场景 | 前端 mock 阶段预期表现 | 后端接入后预期表现 |
|---|---|---|
| 列表查询超出角色数据范围（如修改筛选参数尝试查其他班级/学院） | 前端过滤逻辑仍只返回该角色范围内数据，或提示无权限，不应把越权范围的数据渲染出来 | 服务端校验 `dataScope`，越权请求返回 `{code: "NO_DATA_SCOPE", message: "数据范围越权", ...}`，HTTP 403 |
| 详情/URL 直达超出角色数据范围的具体记录 | 前端展示"无权限查看该数据"或跳转拦截页，不展示具体字段内容 | 服务端同样校验并返回 `NO_DATA_SCOPE`，同时记录审计事件（`AUDIT_EVENT_TYPE.PERMISSION_DENIED` 或等效事件） | 
| 导出超出角色数据范围的数据 | 导出功能应仅按角色范围生成文件内容 | 服务端在导出任务发起时校验数据范围，越权导出请求被拒绝并写入审计日志 |
