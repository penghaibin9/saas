# 06-导入导出测试清单

- **文档性质**：导入导出功能验证用例清单（模板下载 / 正确导入 / 错误导入 / 三档导出 / 行数上限 / 审计 / 权限拦截）
- **适用端**：PC 管理端 `frontend/`（学生主档等模块的导入导出入口）
- **依据**：`_shared_brief.md` 第 4 节（安全基线：导出策略默认 ≤5000 行，三档 LIST/ENCRYPTED_ARCHIVE/DESENSITIZED，对应权限 `security.export.list`/`archive`/`desensitized`，导出写审计）、第 3 节（权限点 `student.import`、`student.export`、`security.export.list`、`security.export.archive`、`security.export.desensitized`）、第 6 节（错误码 `VALIDATION_ERROR`）
- **当前阶段声明**：当前为 mock 版，导入导出的**前端交互与校验规则**可在 mock 阶段验证；真实文件解析、真实落库、真实文件生成与下载、审计落库查询均标注"（后端接入后验证）"。
- **生成日期**：2026-07-04
