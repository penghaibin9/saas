# 07-异常状态测试清单

- **文档性质**：异常状态验证用例清单（空态 / 加载态 / 错误态 / 无权限态 / 401-403-419-500 错误页 / 会话超时 / 网络失败重试）
- **适用端**：PC 管理端 `frontend/` + miniapp `miniapp/`
- **依据**：`_shared_brief.md` 第 4 节（会话：PC 30 分钟无操作超时，移动端 7 天，并发 3，超时前 5 分钟预警，首登强制改密；安全 HTTP：401/403/419/500；安全错误页 `/security/{401,403,419,500}`）、第 6 节（统一错误码表）
- **当前阶段声明**：错误态测试均通过 mock 层预留的 `forceError` / `MOCK_ERROR` 机制**人为触发**（当前已在 `frontend/src/modules/{dashboard,student,workflow}` 与 `miniapp/src/services/request.js` 中发现相关触发点）。真实网络故障、真实服务端 500、真实会话失效判定均标注"（后端接入后验证）"。
- **生成日期**：2026-07-04
