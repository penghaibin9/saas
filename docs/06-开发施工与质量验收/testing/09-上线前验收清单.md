# 09-上线前验收清单

- **文档性质**：上线前验收 Gate 清单（可勾选，用于阶段性验收签字）
- **适用端**：PC 管理端 `frontend/` + miniapp `miniapp/` + 后端 `backend/`（含未来数据库真实联调）
- **依据**：`_shared_brief.md` 全文（阶段声明、安全基线、API 契约、错误码）；`docs/05-数据接口权限与安全/database/00-数据库设计冻结总册.md`；`docs/05-数据接口权限与安全/api/00-API契约冻结总册.md`；`docs/05-数据接口权限与安全/security/00-等保三级安全基线总册.md`
- **当前阶段声明**：**当前阶段（2026-07-04）不具备"生产环境正式上线"的条件**。PC 管理端处于 UI 母版对接中，miniapp 为纯 mock 演示，`backend/` 真实接口尚未接入，数据库未联调真实数据。本清单列出完整的上线前 Gate 项，并逐项标注"当前阶段是否满足"，供项目组据实核对，**不得将未满足项标记为已满足**。
- **生成日期**：2026-07-04

- 本清单当前阶段的整体判定：**不通过（不具备上线条件）**，原因见"零、当前阶段总体结论"。
- 本清单用于跟踪从当前 mock 阶段到最终可上线状态之间的差距，是一份"目标清单"而非"当前已完成清单"。
