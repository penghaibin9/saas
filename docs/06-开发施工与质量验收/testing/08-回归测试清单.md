# 08-回归测试清单

- **文档性质**：回归测试基线用例清单（横向滚动条 / 白屏 / 刷新404 / mock数据加载 / build检查 / 角色切换回归 / 跨模块导航回归）
- **适用端**：PC 管理端 `frontend/` + miniapp `miniapp/`
- **依据**：`_shared_brief.md` 第 0 节（阶段声明：PC 前端 UI 母版对接中；miniapp `build:h5` 与 `build:mp-weixin` 均通过）；PC 前端路由使用 `createWebHistory()`（history 模式，存在刷新 404 风险，需 SPA fallback 支持）
- **当前阶段声明**：本清单为**每轮改动后的必测基线**，用于保证 mock 版的基础质量不被破坏。build 检查针对当前已确认的脚本：miniapp `npm run build:h5` 与 `npm run build:mp-weixin`；PC 前端 `npm run build`（`frontend/package.json` 中定义）。
- **生成日期**：2026-07-04
