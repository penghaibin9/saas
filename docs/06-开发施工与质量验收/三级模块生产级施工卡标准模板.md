# 三级模块生产级施工卡标准模板

> 用途：一个二级模块通过外部证据和总设计门禁后，为其每个三级模块分别生成一张能够直接编码、测试和验收的施工卡。

## 15. 三级施工卡设计就绪门禁

- [ ] 外部设计结论均能回链二级总包有效证据；
- [ ] 当前代码、路由、model、迁移和测试已实际核验；
- [ ] 字段、按钮、API、状态、权限、审计可直接编码；
- [ ] 正向、异常、越权、跨范围、跨租户、敏感和并发测试完整；
- [ ] MySQL升级、历史兼容、部署和回滚完整；
- [ ] 技术事实没有甩给用户确认；
- [ ] 未验证厂商能力和 `ai_proposal` 没有进入正式范围；
- [ ] 本卡与二级总包、其他三级卡的共享对象和接口无冲突。

全部通过才能标 `design_ready`。施工后回填真实修改文件、测试结果、构建、smoke、部署边界和遗留问题，全部闭环才能标 `verified`。
