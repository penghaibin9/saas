# 文档目录说明

本目录用于统一管理项目设计、商业化、前端阶段冻结与历史存档文档。

## 目录用途

- `docs/source-design/`：核心设计源文档（00-12 系列与 04A/05/06 等模块深化文档）。
- `docs/commercialization/`：商业化 SaaS 总控文档（作战手册、套餐、平台后台蓝图、开关模型、阶段分工、验收风险）。
- `docs/frontend/`：前端 P 阶段冻结草稿与执行文档（页面清单、路由冻结、菜单冻结、模块边界）。
- `docs/archive/`：历史与原始存档。
  - `docs/archive/original-docx/`：原始 docx 存档。
  - `docs/archive/old-drafts/`：旧稿与历史草案。

## 是否允许后续修改

- `source-design`：允许小范围修订（需标注版本与修订日期），不随意改动核心口径。
- `commercialization`：允许在评审结论下迭代，属于当前阶段主参考文档。
- `frontend`：允许按阶段推进补充，但需保持与 commercialization 对齐。
- `archive`：默认只读归档，不用于当前开发决策。
