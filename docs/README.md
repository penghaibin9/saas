## 统一阅读顺序（六步，任何任务不得跳步）

| 步骤 | 文档 | 作用 |

| **1** | 根目录 [CLAUDE.md](../CLAUDE.md) | 最高铁律：权限、MySQL、Git、施工红线 |
| **2** | **本页** `docs/README.md` | 九大类说明与本阅读顺序 |
| **3** | [00-项目入口与总控/00-文档总导航.md](./00-项目入口与总控/00-文档总导航.md) | 九大类/业务中心/任务类型/公共触发矩阵 |
| **4** | [03-业务模块设计/\<中心\>/README.md](./03-业务模块设计/) | 中心定位、代码目录、完成度、主总册 |
| **5** | 同目录 [文档关联索引.md](./03-业务模块设计/学工中心/文档关联索引.md) | **任务路由表**（按任务找文档，禁止猜文件名） |

**重要**：文档齐全 ≠ 代码已实现。完成度以各中心 README 所列代码目录 + `frontend/src/config/navPlan.js` 为准。

4. 仍不确定 → [project-map/模块状态总表.md](./00-项目入口与总控/project-map/模块状态总表.md)
