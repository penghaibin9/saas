## 第 1 章：产品定位与业务边界

### 1.1 模块解决的真实问题

毕业设计中心为学校提供**培养后期独立业务闭环**：从毕设批次启动、课题/选题、导师分配、任务书与过程指导、开题/中期/成果、查重/评阅/答辩/成绩，到材料归档与统计，支撑教务处、学院、导师、评阅人、答辩专家与学生协同，满足学校试点与验收。

### 1.2 主要用户与高频场景

| 角色 | 高频场景 |
|---|---|
| 毕设管理员 | 批次配置、全局进度监控、答辩编排、成绩发布、归档核验 |
| 学院毕设负责人 | 本院题目审核、导师容量、进度督办、风险处置 |
| 毕设导师 | 题目申报、志愿确认、任务书、指导记录、开题/成果批阅 |
| 评阅教师 | 独立评阅（SoD，不可评本人指导学生） |
| 答辩专家/秘书 | 答辩组评分、缺席登记、二次答辩 |
| 学生 | 选题志愿、材料提交、任务书确认、查看答辩与成绩 |

### 1.3 与其他中心边界

| 边界对象 | 本模块主责 | 只回流/不重复建设 |
|---|---|---|
| **学工中心** | 毕设业务全流程 | 学生基础画像、请假/处分等用 external-link 或学生主档只读 |
| **教务中心** | 毕设成绩、毕业资格联动标记 | 学籍、培养方案、课程成绩由教务主档回流 |
| **岗位实习中心** | — | 并行毕业前闭环，数据通过学生主档关联，不互建菜单 |
| **系统管理** | — | 用户/角色/菜单/流程模板/审计配置 |
| **学生主档** | 毕设节点、选题、材料、成绩快照 | `student_id` 为主键关联，不复制学籍核心字段 |
| **工作台** | — | 待办/消息由工作台聚合，本模块写业务待办源 |

### 1.4 数据主责裁决

- **主责**：`t_gd_*` 全表（批次、学生毕设档、题目、轮次、导师、任务书、开题/中期/成果、查重、评阅、答辩、成绩、风险、归档、模板、审计）。
- **回流只读**：学生姓名/学号/学院专业班级（学生主档）、毕业资格终审（教务）。
- **external-link**：学工心理/处分明细、教务课表/绩点（详情页 Tab 跳转，不在本模块重建）。

12. 进度/风险/统计看板

- **三级**：名单、进度、未选题、资格认定；详情 `GraduationStudentDetailView`（独立页+Tab，**partial** 部分 Tab 待深化）。

- **三级**：题目列表、待审核；详情/表单/容量/附件为路由或页内。  
- **状态**：**implemented**（含 Excel 导入导出）。

### 5.5 选题管理（gd-topics）

- **三级**：选题结果、轮次、志愿与确认、匹配、冲突、题目调整申请。  
- **状态**：**implemented**（含 mobile 学生/教师选题）。

### 5.6 导师管理与分配（gd-mentors）

- **三级**：导师名单、学生分配、冲突检测。  
- **状态**：核心 **implemented**；导师评价/批量归档 **planned**。

### 5.7 过程指导（gd-process）

- **三级**：任务书、指导记录、中期检查。  
- **交互**：列表+学生检索+Tab；**开题/成果批阅不在此模块**。  
- **状态**：**implemented**（指导/中期）；计划/签到 **planned**。

### 5.8 开题审核（gd-proposal）

- **三级**：开题报告批阅、开题模板。  
- **交互裁决**：**连续双栏**（`ProposalListView` + `ProposalReviewDetailView`）。  
- **状态**：**partial**（基础批阅闭环有；模板/答辩子流程深度待补）。

### 5.9 成果检查（gd-final-review）

- **三级**：成果批阅、查重、教师评阅、互查整改。  
- **交互**：成果 **连续双栏**；查重/评阅在 `defense-grade` Tab。  
- **状态**：成果提交 **partial**；查重/评阅 **implemented**。

### 5.10 答辩成绩（gd-defense）

- **三级**：答辩安排、答辩评分、成绩评定、专家库、申诉。  
- **交互裁决**：答辩安排 **全屏工作区**（`DefenseScheduleView`）；成绩缺项 **批量工作区**。  
- **状态**：答辩安排 **partial**；评分/成绩核心 **implemented**。

### 5.11 预警·归档·统计（gd-risk-archive）

- **三级**：问题预警、材料归档、毕设统计。  
- **交互**：风险 **独立页/双栏**；归档 **完整性工作区**。  
- **状态**：归档/统计 **implemented**；风险自动规则 **partial**（7/13 编码）。

## 第 6 章：端到端完整业务流程

### 6.1 主流程（管理员视角）

```
批次创建(DRAFT→RUNNING) → 学生建档/导入 → 题目申报审核 → 开启选题轮次
→ 学生志愿 → 匹配/教师确认 → 导师分配 → 任务书下达/学生确认
→ 开题提交/批阅 → 指导记录 → 中期检查(含整改) → 成果提交/批阅
→ 查重 → 评阅分配(SoD) → 答辩组编排/发布 → 答辩评分 → 成绩核算/发布
→ 归档核验 → 统计/驾驶舱
```

每条流程须写审计、待办（催交/驳回）、Excel 台账可选导出。

### 6.2 关键子流程摘要

| 流程 | 起点 | 核心单据 | 审批 | 终态 | 归档材料 |
|---|---|---|---|---|---|
| 选题 | 轮次 OPEN | choice + topic | 导师 confirm/reject | CONFIRMED | 选题结果台账 |
| 任务书 | GUIDING 前 | task_book | 学生 confirm | CONFIRMED | 任务书 PDF |
| 开题 | 学生提交 | proposal | 导师 review | PASSED/RETURNED | 开题报告 |
| 答辩 | 组建 defense_group | defense_score | 秘书 publish | CONFIRMED | 答辩安排表 |
| 成绩 | 三段分数齐 | grade | 管理员 publish | PUBLISHED | 成绩表 |
| 归档 | 材料齐 | archive_record | 管理员 file | FILED | 7 项清单 |

### 7.2 题目 `t_gd_topic.status`

DRAFT → PENDING_REVIEW → APPROVED / REJECTED → DISABLED / ARCHIVED；审核/驳回≥5字；停用不影响已选学生。

### 7.3 任务书 `t_gd_task_book`

PENDING_CONFIRM → CONFIRMED → CHANGE_PENDING → CONFIRMED（变更须学生重确认）。

### 7.4 成绩 `t_gd_grade`

DRAFT → CALCULATED → PUBLISHED → WITHDRAWN（撤回须原因+审计）。

### 7.5 归档 `t_gd_archive_record`

NOT_GENERATED → PENDING_SUBMIT → SUBMITTED → FILED / REJECTED（自动核验 7 项必备材料）。
