## 1. 根目录全景

```
职校学生全生命周期系统/
├── frontend/           PC 管理端前端（Vue3 + Vite）——正在做 UI 对接
├── student-portal/     学生 PC 门户（独立 Vue3 + Vite 工程）
├── miniapp/            小程序端（uni-app + Vue3，学生端+教师端混合工程）
├── backend/            统一后端（FastAPI + SQLAlchemy + Alembic + MySQL）
├── mobile/             移动端相关（共享资源，历史/预留）
├── docs/               全部项目文档（设计冻结、API、数据库、UI、部署、运维、交付…）
├── deploy/             部署示例文件（Nginx、env 模板）——本轮新增
├── AI执行状态.md        AI/新手回来先看这里，记录当前进度与红线
├── 00-UI-全端设计总册.md 顶层 UI 设计总册
├── 00-今天新设计文档/    近期设计稿工作目录
├── 99-老毕业设计系统-只参考不要照抄/  老系统，仅参考，禁止照抄
├── .git/ .gitignore    版本管理
├── .ai-backup/ .snapshots/  自动备份/快照（别手动动）
└── Future Campus SaaS 设计升级.zip 等设计压缩包（参考资料）
```

## 2. 每个目录能不能动（重要）

| 目录 | 是什么 | 能动吗 |
|---|---|---|
| `frontend/src/` | PC 前端源码 | ✅ **PC UI 对接就动这里**（按母版），但本轮文档任务不动 |
| `frontend/dist/` | PC 构建产物 | ❌ 机器生成，别手改（build 会覆盖） |
| `miniapp/` | 小程序源码 | ✅ 小程序后续开发动这里；本轮文档任务不动 |
| `student-portal/` | 学生 PC 门户源码 | ✅ 按学生门户规划开发；不得调用管理端全量接口 |
| `miniapp/dist/` | 小程序构建产物 | ❌ 机器生成，别手改 |
| `backend/` | 五端统一后端 | ✅ 按领域和身份 API 边界施工；数据结构变化必须走 Alembic |
| `docs/05-数据接口权限与安全/database/` | 数据库冻结文档 | ⛔ **只读引用，绝不修改/重设计** |
| `docs/05-数据接口权限与安全/api/` | API 契约冻结 | ⛔ 只读引用，不改 |
| `docs/04-UI与全端交互/ui/` | UI 设计稿 | ⛔ 参考用，不当生产代码、不改 |
| `docs/07-部署运维交付与商业化/deploy/` `docs/07-部署运维交付与商业化/ops/` `docs/07-部署运维交付与商业化/delivery/` `docs/00-项目入口与总控/project-map/` | 部署/运维/交付/地图文档 | ✅ 本轮新增，可维护 |
| `deploy/` | 部署示例 | ✅ 本轮新增，可维护 |
| `99-老毕业设计系统…/` | 老系统 | ⛔ 仅参考，禁止照抄进新系统 |
| `node_modules/` | 依赖 | ❌ 自动生成，别手改，别提交 |
| `.git/` `.ai-backup/` `.snapshots/` | 版本/备份 | ⛔ 别手动动 |

> ⛔ = 别碰；❌ = 别手改（机器管）；✅ = 可以按职责动。

---

## 3. 新手最容易踩的坑

1. **把设计稿 HTML 当生产代码**：`docs/04-UI与全端交互/ui/` 里的 HTML/PDF/zip 是**设计参考**，不能复制进 `frontend/src/`。
2. **手改 dist**：改了下次 build 就没了。要改改源码再 build。
3. **动数据库/API 冻结文档**：这些是全系统地基，冻结了就不能随便改。
4. **照抄老系统**：`99-老…` 只能参考思路，不能照搬代码。
