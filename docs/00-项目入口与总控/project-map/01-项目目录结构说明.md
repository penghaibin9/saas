# 项目目录结构说明

> 验证日期：2026-09-02。本文只描述当前仓库结构；完成度和交付状态以机器清单与测试门禁为准。

## 根目录

| 目录 | 用途 | 管理规则 |
|---|---|---|
| `backend/` | FastAPI 后端、MySQL 迁移、权限与审计 | 业务结构变化必须配套 Alembic 与测试 |
| `frontend/` | 学校管理 PC 端 | 修改源码，不提交 `dist/`、缓存或测试结果 |
| `student-portal/` | 学生 PC 门户 | 独立构建与权限边界 |
| `miniapp/` | 学生与教师移动端 | 同时验证 H5 与微信小程序构建 |
| `enterprise-portal/` | 企业协同门户 | 独立构建与企业身份边界 |
| `mobile/` | 移动端共享源码 | 与 `miniapp/` 的镜像文件需登记重复豁免 |
| `shared/` | 跨端契约和生成索引 | 生成内容必须可复现 |
| `e2e/` | 浏览器测试和 fixtures | 运行证据由 CI Artifact 保存 |
| `performance/` | 容量与性能脚本 | 不提交运行输出 |
| `deploy/` | 部署、回滚与运维配置 | 示例配置不得包含真实密钥 |
| `scripts/` | 开发、检查、维护与发布脚本 | 清理脚本默认只预览 |
| `docs/` | 当前文档与历史归档 | 当前文档只有一个权威路径 |
| `artifacts/release-seals/` | 小型机器裁决 JSON | 不存大型截图、日志或构建产物 |

## 本地生成目录

以下路径不属于源代码，应由 `.gitignore` 和仓库卫生门禁阻止进入 Git：

- `node_modules/`、`dist/`、`build/`、`.venv/`
- `tmp/`、`outputs/`、`uploads/`、`exports/`
- `.codex-artifacts/`、`.codex-temp/`、`.pytest_cache/`、`__pycache__/`
- `artifacts/` 中除 `artifacts/release-seals/` 外的运行证据
- `_local-backup/`、`.snapshots/`

## 权威入口

- 项目入口：根目录 `README.md`
- 文档入口：`docs/README.md`
- 当前状态：`docs/00-项目入口与总控/project-status.json`
- 文档清单：`docs/00-项目入口与总控/document-catalog.json`
- 仓库清单：`docs/00-项目入口与总控/repo-inventory.json`
- 部署入口：`docs/07-部署运维交付与商业化/deploy/README.md`

设计稿和历史材料只能作为参考，不得替代当前代码、迁移和测试事实。
