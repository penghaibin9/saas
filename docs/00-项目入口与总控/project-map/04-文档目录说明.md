# 04 · 文档目录说明（docs/）

> **已停用，不作当前施工依据。** 当前文档目录规则请读取 [`docs/README.md`](../../README.md) 和 [`00-文档总导航.md`](../00-文档总导航.md)。本文件只保留旧路径兼容说明。

> `docs/` 放全部项目文档。这份告诉你**哪份文档是什么、哪些是冻结不能改的、部署运维文档在哪**。

```
docs/
├── 00-只看这个-项目入口.md      ⭐ 开发前必读入口

```

## 2. 哪些是"冻结"文档（只读引用，绝不修改）

| 文档 | 路径 | 说明 |
|---|---|---|
| 数据库设计冻结总册 | `docs/database/00-数据库设计冻结总册.md` | 唯一权威 DB 基线，约 150 表 |

## 3. 数据库冻结文档在哪里（单独强调）

```
docs/database/00-数据库设计冻结总册.md
```

- 技术栈：PostgreSQL + FastAPI + SQLAlchemy + Alembic。
- 多租户：单库单 schema + tenant_id 行级隔离。
- 本阶段：**只有设计，未建库**。只引用、不改、不重设计。详见 `docs/deploy/06-数据库冻结文档引用说明.md`。

## 4. 部署 / 运维 / 交付文档在哪里（本轮新增）

## 5. 开发前的阅读优先级（沿用项目既有约定）

1. `docs/00-只看这个-项目入口.md`（入口）
2. `docs/commercialization/`（当前阶段主参考）
3. `docs/source-design/00-…开发冻结总册 V3.0-增强版.md` 及各中心深化文档
4. `docs/database/` `docs/api/`（冻结基线，只读）
5. `docs/ui/`（设计稿，参考不照抄）
6. `docs/frontend/`（前端阶段冻结）
7. `docs/archive/`（仅存档）

> 部署/运维/交付则看本轮新增的 `docs/deploy` `docs/ops` `docs/delivery`。
