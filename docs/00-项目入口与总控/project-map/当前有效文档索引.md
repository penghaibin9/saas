## 状态口径

- `implemented`：代码能力和真实路由存在，不代表已经通过交付门禁。
- `partial`：可使用但仍有明确能力或验收缺口。
- `planned`：没有真实业务实现。
- `unauthorized`：能力存在，但当前租户或身份未开通。
- `deliverable`：仅在迁移、测试、构建、浏览器、安全、恢复和容量门禁全部通过后为真。
