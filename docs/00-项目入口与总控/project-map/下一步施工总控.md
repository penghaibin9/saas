# 下一步施工总控

> 更新：2026-08-31
> 当前唯一目标：形成第一所学校可部署验收的统一 `main` 候选，不新增业务功能。

## 当前顺序

1. 完成仓库清单、文档清单、重复文件报告和 CI 工作流登记。
2. 固化唯一候选 commit；重新检查并只吸收其他会话已经提交且通过定向测试的增量。
3. 从空库与历史库分别验证 MySQL Alembic 迁移。
4. 运行后端矩阵、五端 lint/build/unit、跨租户/RBAC/敏感字段测试。
5. 运行第一所学校浏览器主链：登录、角色切换、学生主档、学工、教务、毕业设计、岗位实习、企业门户。
6. 执行备份恢复、安全与依赖审计、容量 smoke。
7. 生成部署包、环境变量模板、演示租户、验收清单和回滚说明。

## 冻结项

- 不重组 `apps/services/packages`，不大规模移动源码目录。
- 不改现有业务 API 路径和数据库业务模型。
- 不从其他活跃 worktree 搬运未提交文件，不清理正在被其他会话使用的 worktree。
- 不推送、不打标签、不删除远程分支。
- 门禁未全部通过前，不继续按旧 `planned` 统计重复开发已有学工模块。

## 放行规则

只有 `docs/00-项目入口与总控/project-status.json` 中全部 `releaseGates` 为 `passed` 且 `deliverable=true`，才能标记“可交付”。任何失败必须保留失败命令、commit 和复现方式。
