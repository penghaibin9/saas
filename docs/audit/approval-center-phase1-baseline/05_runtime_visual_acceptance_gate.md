# 四端逐页运行与 UI 视觉验收门禁

- 适用基线：`penghaibin9/saas@936101f00afdcf5c9803c8dd06e71b226ae5c16e` 及 25 项整改后的各 PR。
- 本文解决静态审计无法替代的部分：真实渲染、错位、遮挡、真机、弱网、键盘、并发和视觉一致性。

## 1. 每一页都必须跑的 7 态

| 状态 | 必须验证 |
|---|---|
| Normal | 真实数据、当前角色、当前范围、首屏结论和 allowedActions 正确 |
| Loading | 骨架/加载提示不抖动；禁止整页永久转圈 |
| Empty | 解释为什么为空，并给下一步；不把无权限/错误冒充无数据 |
| Error/Timeout | 明确错误、可重试；保留输入/筛选；不展示技术堆栈 |
| 403/能力未开通 | 区分无权限、未采购、租户关闭；不白屏 |
| 409/记录变化 | 告诉用户事实已变化，保留本地输入或刷新正确状态 |
| Repeat/Weak network | 按钮锁、幂等、旧请求不覆盖新请求；恢复网络可继续 |

## 5. 设计一致性门禁

| 类别 | 统一要求 |
|---|---|
| 标题/首屏 | 页面用途、范围、结论、下一步优先；禁止只有标题+大表格 |
| 卡片 | 同层级同间距/边框/圆角；不为美化堆无意义 KPI 卡 |
| 表格 | 密度稳定、列宽、长文本、操作列、sticky、分页统一 |
| 表单 | 标签宽度、必填、错误定位、保存/取消/暂存语义统一 |
| 按钮 | 主/次/危险三级清晰；危险动作二次确认；loading 禁重复 |
| 状态标签 | 同一业务状态全端同文案/颜色；颜色不是唯一识别手段 |
| 空/错态 | 无数据/无权限/未开通/错误/冲突分别设计 |
| 弹窗/抽屉 | 轻量任务使用；复杂长表单用独立页；窄屏不超屏 |
| 动效 | 禁未经豁免的 transition:all；支持 reduced-motion |
| 可访问性 | 焦点、键盘、aria、对比度、44px 移动触控目标 |
