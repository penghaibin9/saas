# 13A 学工中心 ABCD 任务包三级模块开发与关联布局总表

> 本表是 13A 后续施工的第一入口。21 个二级目录模块必须先分入 A/B/C/D，再在每个任务包内展开三级模块开发、页面布局、数据关联和验收。本文档是设计施工卡，不代表已开发。

## 1. 读法

| 层级 | 含义 | 本文要求 |
|---|---|---|
| 一级目录 | 13A 学工中心 | 一个业务中心，不再拆 A-J 小包 |
| 二级目录 | 21 个业务模块 | 必须分入 A/B/C/D 四个任务包 |
| 三级模块 | 每个二级目录下的页面/能力 | 每个任务包都必须写清“怎么开发”和“关联布局” |
| 关联布局 | 页面、数据、组件、流程之间的关系 | 至少包含左侧菜单、页面主区、右侧联动区、详情抽屉、审批/审计区、画像/风险/看板/归档/统计回链 |

## 2. A/B/C/D 开发顺序

| 顺序 | 任务包 | 覆盖二级目录 | 本包三级模块开发重点 |
|---|---|---|---|
| 1 | A 施工地图 + 底座欠账冻结 | 全部 21 个二级目录 | 先规划全量二级/三级目录、菜单位置、现有系统串联、数据来源、公共底座欠账；A 包不开发代码 |
| 2 | B 学工 PC 高频主线 | 学工看板、学生画像、班级管理、宿舍管理、请假销假、风险预警 | 先做 PC 主链路：看板入口 -> 画像中心 -> 班级/宿舍数据范围 -> 请假审批 -> 风险闭环 |
| 3 | C 审批业务闭环 | 困难认定、奖助勤贷补、违纪处分、谈心谈话、家校联系 | 在 B 的画像、待办、权限、风险基础上补审批、沟通、台账、归档 |
| 4 | D 上线补强与商业增强 | 数字迎新、心理健康、学生活动、第二课堂、社团与学生组织、党团建设、辅导员考评、学工归档、学工统计、在校服务 | 补正式上线安全、统计归档、小程序入口、商业增强和数字迎新公共底座 |

## 7. 每个三级模块开发时必须写清的内容

| 项 | 必填说明 |
|---|---|
| 页面位置 | 左侧菜单、二级目录、三级页面、详情页/抽屉/弹窗 |
| 布局 | 顶部筛选、指标卡、主表、右侧摘要、详情抽屉、审批面板、审计区 |
| API | 列表、详情、新建、编辑、状态流转、导入、导出、审计 |
| 数据表 | 主表、扩展表、审计表、关联表、唯一约束、索引 |
| 权限 | 角色、数据范围、按钮权限、详情二次鉴权、403 |
| 关联 | 画像、风险、看板、归档、统计、现有系统跳转 |
| 公共组件 | 页面壳、工具栏、选择器、日期、Excel、导出确认、审批、审计、脱敏 |
| 验收 | 401、403、跨租户、空态、错误态、加载态、审计、导入导出、非法状态 |
