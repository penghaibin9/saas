# 13B 教务中心开发阶段任务卡与验收用例

> 依据：《13B-教务中心V1范围与开发顺序.md》（阶段规格）、《13B-教务中心与现有系统融合设计.md》（契约，下称"融合设计"）、`_13-现有系统集成事实速查.md`（事实基线）。
> 结构：①13B-P1…P8 每阶段任务卡（后端 / 前端 PC / miniapp / 测试四条泳道，粒度到"一人 0.5~2 天可独立验收"）；②核心流程验收用例（11 个流程，每流程 ≥4 条，必含重复提交 409 与越权 403/404）；③回归红线。
> 用例统一格式：**前置 / 步骤 / 预期**。预期必须写全四要素：**状态变化 + 通知（待办/消息）+ 360（StageEvent/域记录）+ 统计（指标变化）**；某要素不适用时显式写"无"。

## 第二部分 核心流程验收用例

角色代号：`AC`=教务处管理员、`CO`=学院教务员（A 学院）、`CO-B`=B 学院教务员、`CN`=学生 A 的辅导员、`CN2`=其他辅导员、`TE`=任课教师、`TE2`=其他教师、`ST`=学生 A、`ST2`=学生 B（不同班/学院）。
所有断言均含统一响应体（code/bizCode）；"统计"指 stats 指标或首页卡片数值。

### 流程 1 学年学期发布

**用例 1-1 正常发布**
- 前置：AC 登录；存在 DRAFT 学期 2026-2027-1，校历教学周/考试周/节假日完整。
- 步骤：AC 进入发布确认页，点击"发布"。
- 预期：状态 DRAFT→PUBLISHED；通知：教务/学院管理员收 PUBLISHED_NOTICE，学生无通知；360：无；统计：教务首页"当前学期"卡切换，注册/课表窗口按校历生效。

**用例 1-2 校历缺失发布被拒**
- 前置：另一 DRAFT 学期教学周为空。
- 步骤：AC 点击"发布"。
- 预期：422001 VALIDATION_ERROR 携缺失项清单；状态仍 DRAFT；通知/360/统计：无。

**用例 1-3 重复发布幂等/409**
- 前置：学期已 PUBLISHED。
- 步骤：对同学期重放 publish（含前端双击场景）。
- 预期：按 P1 冻结契约二选一并锁定断言——返回 409001 或幂等成功；无论哪种：仅一条发布审计、通知不重发、数据无第二次变更。

**用例 1-4 越权发布**
- 前置：CO 登录（无 academicAffairs.term.publish）。
- 步骤：CO 直接调用 publish 端点。
- 预期：403001 NO_PERMISSION；审计记录越权尝试；状态不变；通知/360/统计：无。

**用例 1-5 demo 只读**
- 前置：demo-school 管理员登录。
- 步骤：发布任一学期。
