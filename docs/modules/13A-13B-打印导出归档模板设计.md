## 0.1 通用规范（各模板默认继承，模板节只写差异）

### 0.1.1 学校名称与 logo 取数说明（tenantBrandConfig）

1. **学校全称**：`t_tenant.school_name`（页眉主标题，如"××职业技术学院"）；简称 `t_tenant.short_name` 用于页脚。
2. **模板抬头**：`t_tenant_brand_config.platform_name`（副标题），为空则回退 school_name。
3. **logo/校徽**：`logo_light_file_id`（打印用浅底 logo）→ 文件服务换 URL；正式文书优先 `badge_file_id`（校徽）。文件缺失时打印占位框不报错。
4. **水印文案**：`watermark_text` 非空 → 作为 PDF 斜纹页面水印重复铺排；为空 → 回退 `"{school_name}内部资料"`。xlsx 首行水印串前缀替换为 `{school_name}`（替代现管线中的平台泛称，实施时 domain 配置增加 use_tenant_brand=true 项）。
5. **校训**：`motto` 仅用于归档包封面（可配置关闭）。
6. 取数一律在服务端组装时读取（导出瞬间快照），不由前端传入，防伪造抬头。

### 0.1.2 水印规则（三层）

| 层 | 内容 | 适用 |
|---|---|---|
| W1 首行水印 | 复用现有格式：`{school_name} · {模板名} · 导出人：{realName} · 时间 · 用途：{purpose} · 敏感字段已脱敏` | 全部 xlsx |
| W2 页面斜纹水印 | `{watermark_text} {realName} {yyyy-MM-dd HH:mm}` 45° 平铺，灰度 12% | 全部 PDF/打印页 |
| W3 页脚追溯条 | `导出流水：EXP-{ExportTask.id} · SHA256 前 8 位 · traceId` | 全部 PDF/打印页 |

### 0.1.3 脱敏与完整版二次授权（通用）

- 默认导出/打印一律脱敏：身份证 `_mask_id_card`、手机号 `_mask_phone`、银行卡后 4 位、家庭经济金额区间化、心理明细**一律不出现在任何模板**（含归档包）。
- **完整版**（明文身份证/联系方式/家庭经济数额）需二次授权：权限点 `studentAffairs.<biz>.exportFull` / `academicAffairs.<biz>.exportFull`（对齐既有 `student.field.view_full` 语义）+ 前端弹窗填写用途（≥5 字）+ 后端 `audit_log.record("EXPORT_FULL", resource, {reason, fields})` 落 t_security_audit_log，ExportTask.remark 追加 `FULL` 标记。
- demo-school 只读锁不拦导出读操作，但完整版导出在 demo 租户一律 403（演示环境无明文出口）。

### 0.1.4 打印记录设计（通用）

- 复用 `t_export_task` 登记打印：`export_mode="PRINT"`（现有值 LIST 之外新增枚举）、module_code=domain、row_count=打印份数语义、purpose 必填、file_hash=渲染 PDF 的 sha256。
- 每次打印同时 `audit_log.record("PRINT_<DOMAIN>", "<单据id>", {templateVersion, copies})`。
- 打印流水号 `PRN-{ExportTask.id}` 印于页脚 W3；重打不覆盖、每次新流水（可统计重打次数）。
- 不建独立打印表；查询"某单据打印过几次"= t_export_task 按 module_code+remark(单据id) 过滤。

### 0.1.5 导出权限点与审计动作命名（通用）

- 权限点：`studentAffairs.<biz>.export` / `.print` / `.exportFull`；教务同理 `academicAffairs.<biz>.*`。落 t_permission 时按证据报告 P0-3 的点分→冒号映射规则登记。
- 审计动作：`EXPORT_<DOMAIN>`（导出）、`PRINT_<DOMAIN>`（打印）、`EXPORT_FULL`（完整版附加）、`ARCHIVE_DOWNLOAD`（归档包下载）。resource 统一填业务主键或批次号。

### 0.1.6 模板可配置项（通用，接平台规则中心，不新建配置端）

规则键组 `studentAffairs.print.*` / `academicAffairs.print.*`（走 platform_service.safe_rule）：`show_logo`（默认 true）、`show_motto`（false）、`paper`（A4 竖版默认）、`sign_columns`（签字栏是否含日期列，true）、`masking_profile`（standard/strict）、`footer_text`（自定义页脚附加文案）。各模板专属项在模板节列出。

### 3.2 P2 后置项（本文只冻结契约，不实现）

1. **套打**：预印刷表格坐标定位打印（模板坐标 json 配置，规则键 academicAffairs.print.overlay_map）。
2. **红头文书**：处分决定书/毕业文件红头样式（红色标题+文号线+落款规范），依赖学校提供制式。
3. **盖章扫描件叠印**：电子章图片叠加在盖章位（需学校授权电子章使用协议+叠印动作强审计），V1 一律留白盖章位线下用印。
4. 中英文成绩单、考试安排随考务模块。

### 3.3 归档包（zip）通用设计（13A 学工归档包与 13B 教务归档共用）

1. **结构**：`{批次号}_{学生学号或班级}.zip` = manifest（清单）+ 分类目录水印 PDF + audit_sheet.pdf（审计单）+ checksum.txt。
2. **生成流程**：归档批次审批（workflow AFFAIRS_ARCHIVE / AA_ARCHIVE）终审通过 → 服务端逐单据调用对应模板 PDF 渲染（各自水印独立生成，导出人=归档确认人）→ 打包 → 总包 sha256 落 t_export_task（export_mode="ARCHIVE"，module_code=affairs_archive/aa_archive，remark=批次号）。
3. **审计单内容**：批次审批链快照、收录/缺件统计、生成时刻的规则版本（masking_profile 等）、生成人与 traceId——使归档包自证合规。
4. **红线**：心理明细永不入包；打包只收终态单据；包生成后源单据置 ARCHIVED 只读；重新打包生成新 ExportTask，旧包不可覆盖（append-only 语义）；下载每次 ARCHIVE_DOWNLOAD 审计。
5. **对账**：manifest 行数 = 包内 PDF 数 = ExportTask.row_count，三者不一致视为生成失败整体回滚（无半包）。

### 3.4 验收口径（并入 13A-P9 / 13B-P8 与试点验收脚本）

- 每个 domain：导出成功即有 t_export_task 行（purpose≥5 字、sha256 非空）；第 6 次/分 429；xlsx 首行水印含 school_name 与导出人；PDF 含 W2 斜纹与 W3 流水条。
- 脱敏抽查：默认导出无明文身份证/电话/家庭经济数额；exportFull 无权限 403+审计；有权限成功后 t_security_audit_log 有 EXPORT_FULL 行。
- demo-school：普通导出可用（只读操作）、exportFull 403；sandbox-school 全量可演示。
