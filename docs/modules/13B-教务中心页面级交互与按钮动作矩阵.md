## 一、全局约定（各页不再重复）

### 1.1 统一响应体与调用约定

- 响应体（冻结）：`{ code(数字), bizCode(字符串), message, data, traceId, timestamp }`；成功 `code=0 / bizCode=SUCCESS`。业务错误绝不 500。
- PC 全部接口 `require_staff`（学生令牌 403）；学生新建教务走 `/api/v1/mobile/academic-affairs/*`（复用既有 `/api/v1/mobile/academic/my` 学业过程聚合）。
- 新增端点前缀：`/api/v1/academic-affairs/terms|programs|courses|teaching-tasks|schedule|roll-changes|roll-registrations|graduation-audit`；成绩、预警**复用既有** `/api/v1/academic/grades`、`/api/v1/academic/warnings`（复用既有 academic 学业过程模块）；学籍档案读复用 `/api/v1/academic/students`（复用既有 academic 学业过程模块）。
- 审批一律复用 Workflow：`/api/v1/approvals/tasks/{taskId}/approve|reject|transfer`；待办写 t_unified_todo、通知写 t_unified_message（类型限 WORKFLOW_TODO / WORKFLOW_RESULT / RISK_ALERT / DEADLINE_REMINDER / STATUS_CHANGED / RETURNED_NOTICE / PUBLISHED_NOTICE / ARCHIVE_NOTICE）。
- 权限点命名 `academicAffairs.<biz>.<action>`；无 `<biz>.view` 则菜单整项隐藏。

### 1.2 错误码 → UI 提示映射（全模块统一，按钮矩阵"失败提示"列均引用此表语义）

| 错误码 | bizCode | UI 处理 |
|---|---|---|
| 401001 | UNAUTHORIZED | 静默单飞刷新 token；失败清 session 跳 /login |
| 403001 | NO_PERMISSION | toast「无操作权限」；无权限按钮应事先隐藏，此码为兜底 |
| 403002 | NO_DATA_SCOPE | 详情页整页 noPermission 态「无该学生/学院数据范围权限」；列表由后端 scope 过滤不展示越权行 |
| 404001 | DATA_NOT_FOUND | 提示「数据不存在或已被删除」，列表刷新移除该行 |
| 409001 | DATA_CONFLICT | 「已存在重复/在途数据」，引导查看已有单据 |
| 409001 | APPROVAL_VERSION_CONFLICT | 弹窗「该任务已被他人处理」，自动刷新任务最新状态与流水 |
| 409001 | IDEMPOTENCY_CONFLICT | 「请勿重复提交」，按已成功处理刷新页面 |
| 422001 | VALIDATION_ERROR | 表单逐字段红字回显后端 message；非表单场景 toast 具体原因 |
| 429001 | RATE_LIMITED | 「操作过于频繁（导出 5 次/分），请稍后再试」 |
| 400001 | BAD_REQUEST | 「请求参数错误」+ traceId，引导反馈 |

### 1.3 五态全局规范（各页【状态视图】仅写差异项）

| 态 | 规范 |
|---|---|
| loading | 列表骨架屏/详情占位；按钮 loading 并锁定 |
| empty | 空态插画 + 引导文案；有创建权限时附主操作按钮 |
| error | 错误插画 + message + traceId + 【重试】 |
| noPermission | 403 整页态（403001/403002 文案区分）；菜单级无 view 权限不渲染 |
| readonly | 页顶只读横幅并注明原因（业务状态只读 / 角色只读 / demo-school 演示只读 / 租户到期只读），全部写按钮隐藏或置灰 |

### 1.4 审批页通用交互（8/10/12/20 等审批类页共用）

1. 载入审批任务时携带 `version`（乐观锁）；【通过】【驳回】提交带回 version。
2. 已处理再审 → 409001 APPROVAL_VERSION_CONFLICT：弹窗告知已被处理，刷新显示最新节点与流水，本页转只读。
3. 驳回/退回意见必填（长度规则接平台规则中心 safe_rule 配置），422001 逐字段回显。
4. 所有提交按钮统一提交锁（同小程序 createSubmitLock 思路：点击即锁 → 返回后解锁），防连点重复请求；幂等冲突按 IDEMPOTENCY_CONFLICT 处理。
5. 每次审批动作：写 t_workflow_task（acted_at/action_reason）→ 下一节点生成 t_unified_todo + WORKFLOW_TODO 消息 → 终态给发起人/学生 WORKFLOW_RESULT/RETURNED_NOTICE → `record(action, resource)` 审计。
6. 审批中单据对发起人只读，仅当前节点未处理时发起人可【撤回】（回 DRAFT/可编辑态）。

### 1.5 演示租户与审计

- demo-school 中间件只读锁：本模块全部写操作返回 403，前端统一横幅「演示环境只读，请登录沙箱租户 sandbox-school（admin2/123456，每日 0 点重置）体验写操作」。
- 审计双层：安全审计 `app.services.audit_log.record(action, resource, detail, result)` → t_security_audit_log（含 ip/ua/traceId）；域级留痕 t_aa_audit_trail（append-only，状态流转/发布/终审必写）。导出一律登记 t_export_task（用途必填≥5 字、行数、sha256、水印）。
- 导入统一走导入管线 `/api/v1/import/domain/{domain}/validate|confirm`（dry-run 行级错误 → 批次确认，5000 行/20MB 上限）；导出统一走 `/api/v1/export/domain/{domain}`（脱敏列、首行水印、5 次/分、5000 行）。

## 二、V1 核心页面逐页规格（22 页）

### 2.1 教务首页（/admin/academic-affairs）

**【定位】** 一级模块=教务中心；二级菜单=教务首页；三级页面=无（驾驶舱本体）；路由 `/admin/academic-affairs`；谁能进=教务处（全校）/学院教务（本学院）/教师（本人课程与授课学生），角色 preset 出不同视图；从哪进=侧边栏「教务中心」；用途=按角色聚合本学期教学运行指标、待办与快捷入口。

**【展示】** 顶部：当前学期（已发布校历）+ 角色/数据范围标识。教务处视图卡片：教学任务/排课完成率/课表发布/成绩审核待办/学籍异动待审/学业预警数/毕业资格异常数；学院教务视图：本学院同类指标（未排课程/冲突/异动/毕业异常）；教师视图：今日课程/授课班级/成绩录入任务/调停课申请（P2 隐）/学生名单。筛选：学期切换。列表：待办 TOP N（t_unified_todo）、最近消息。详情字段：无（下钻至各业务页）。

**【表单】** 无表单页。

**【按钮动作矩阵】**

| 按钮 | 出现条件(角色+状态) | 动作 | API | 成功变化 | 失败提示 | 审计 |
|---|---|---|---|---|---|---|
| 刷新 | 全部可进角色 | 重拉驾驶舱数据 | GET /api/v1/academic-affairs/dashboard | 卡片/待办更新 | error 态+traceId+重试 | 只读不审计 |
| 切换学期 | 全部可进角色 | 按学期过滤指标 | 同上 ?termId= | 指标切换 | 404001 学期不存在 | 不审计 |
| 待办【去处理】 | 待办分配人（assignee 本人） | 跳对应审批/处置页 | GET /api/v1/approvals/tasks | 进入目标页 | 403002 非本人待办不可见 | 在目标页动作时审计 |
| 预警卡片下钻 | 教务处/学院教务（scope） | 跳 /warnings | 复用 GET /api/v1/academic/warnings（复用既有 academic 学业过程模块） | 列表按 scope 过滤展示 | 403002 无数据范围 | 处置时审计 |
| 【更多统计】 | 教务处/学院教务 | 跳 /stats | /api/v1/stats/* 扩展聚合 | 打开统计总览 | 403001 | 不审计 |

**【状态视图】**

| 状态 | 展示与可操作 |
|---|---|
| 五态 | 按 §1.3；empty=「本学期暂无教学数据」+（教务处）【去创建学期】；readonly 不适用（纯只读页） |
| 业务态 | 无独立业务态；卡片随各业务状态实时聚合（校历未发布时提示先发布校历） |

**【治理】** 脱敏=学生列表电话/证件不出现在首页；水印=无；审计=下钻处置时记；进360=否；进统计=本页即统计消费端（扩展 stats_service 角色 preset）；导入/导出=无；移动端=学生小程序无对应（学生视图在小程序各页）、教师端「今日课程」对应教师视图；跳转=统一待办、/warnings、/stats、各业务列表。

**【验收】** 1) 学院教务登录仅见本学院指标，请求他院数据 403002；2) 教师视图仅见本人课程/任务卡片，无管理入口。

### 2.2 学期列表（/terms）

**【定位】** 一级=教务中心；二级=学年学期与校历；三级=列表页；路由 `/terms`；谁能进=教务处（管理，全校）/学院教务（只读查看）；从哪进=菜单「学年学期与校历」；用途=学年学期全生命周期管理入口（DRAFT/PUBLISHED/FROZEN/ARCHIVED）。

**【展示】** 顶部：当前学期高亮。筛选：学年/状态/关键词。列表字段：学年、学期、起止日期、教学周数、状态、校历配置完整度（校历/节次是否配齐）、发布时间、操作。详情字段：下钻校历/节次页。

**【表单】** 新增/编辑在 `/terms/create`、`/terms/:termId/edit`（学年、学期名、起止日期必填；起止不重叠、结束>开始；详见字段文档）。

**【按钮动作矩阵】**

| 按钮 | 出现条件(角色+状态) | 动作 | API | 成功变化 | 失败提示 | 审计 |
|---|---|---|---|---|---|---|
| 新增 | 教务处 | 跳 /terms/create | POST /api/v1/academic-affairs/terms | 新增 DRAFT 行 | 409001 学年学期重叠/重复；422001 | record(create, term) |
| 编辑 | 教务处 + DRAFT | 跳 /terms/:termId/edit | PUT /api/v1/academic-affairs/terms/{termId} | 行信息更新 | 409001 version 冲突；422001 | record(update, term) |
| 校历 | 教务处（DRAFT 可编，其余只读） | 跳 /terms/:termId/calendar | — | 进校历编辑 | 404001 | 编辑页内审计 |
| 节次 | 教务处（DRAFT 可编，其余只读） | 跳 /terms/:termId/time-slots | — | 进节次配置 | 404001 | 配置页内审计 |
| 发布 | 教务处 + DRAFT 且校历/节次完整 | 跳 /terms/:termId/publish 确认 | POST /api/v1/academic-affairs/terms/{termId}/publish | DRAFT→PUBLISHED；同步排课/课表/工作台/学生端；发 PUBLISHED_NOTICE | 422001 校历或节次未配置完整 | record(publish, term)+audit_trail |
| 冻结 | 教务处 + PUBLISHED | 二次确认 | POST .../terms/{termId}/freeze | PUBLISHED→FROZEN，排课与变更入口关闭 | 409001 version 冲突 | record(freeze, term)+audit_trail |
| 归档 | 教务处 + FROZEN 且学期已结束 | 二次确认 | POST .../terms/{termId}/archive | FROZEN→ARCHIVED 只读可导出 | 422001 学期未结束 | record(archive, term)+ARCHIVE_NOTICE |
| 删除 | 教务处 + DRAFT | 二次确认（软删） | DELETE .../terms/{termId} | 行移除 | 409001 已被排课/任务引用不可删 | record(delete, term) |

**【状态视图】**

| 状态 | 展示与可操作 |
|---|---|
| 五态 | 按 §1.3；empty=「暂无学期」+【新增学期】（教务处）；学院教务 readonly 横幅「只读视图」 |
| DRAFT | 可编辑/删除/配校历节次/发布 |
| PUBLISHED | 只读+可冻结；校历变更需先冻结评估（不支持直接改已发布校历） |
| FROZEN | 只读，仅可归档 |
| ARCHIVED | 只读可导出（P2 归档查看页 /terms/:termId/archive） |

**【治理】** 脱敏=无敏感字段；水印=无；审计=全部写操作 record + audit_trail；进360=否；进统计=注册率/任务完成率均以学期为维度；导入=无；导出=P2 归档页；移动端=学生小程序「我的课表」周次读已发布校历，无独立页；跳转=校历/节次/发布页、任务批次新增（前置校验）。

**【验收】** 1) DRAFT 学期缺节次配置点【发布】→ 422001 且状态不变；发布成功后学生小程序课表周次同步；2) 学院教务调用 POST /terms → 403001，页面无【新增】按钮。

### 2.3 校历编辑（/terms/:termId/calendar）

**【定位】** 一级=教务中心；二级=学年学期与校历；三级=学期下钻编辑页；路由 `/terms/:termId/calendar`；谁能进=教务处（DRAFT 态可编，其余态只读）、学院教务只读；从哪进=学期列表【校历】；用途=维护教学周/考试周/实习周/节假日/调休。

**【展示】** 顶部：学期名+起止+状态徽标。主体：周历视图（周次×周类型着色）+ 节假日/调休清单。筛选：月份/周类型。详情字段：每周（周次、起止、类型=教学/考试/实习/假期）、节假日（日期、名称）、调休（停课日↔补课日配对）。

**【表单】** 周类型标记（周次范围+类型必填）；节假日（日期+名称必填）；调休（原日与补课日必填且配对）。校验：全部日期在学期起止内、考试周/实习周不与教学周重叠冲突、调休必须成对；详见字段文档。

**【按钮动作矩阵】**

| 按钮 | 出现条件(角色+状态) | 动作 | API | 成功变化 | 失败提示 | 审计 |
|---|---|---|---|---|---|---|
| 生成教学周 | 教务处 + DRAFT | 按起止自动切分周次 | GET/本地计算+PUT 保存 | 周历填充教学周 | 422001 学期起止缺失 | 保存时审计 |
| 标记考试/实习周 | 教务处 + DRAFT | 选周次改类型 | PUT /api/v1/academic-affairs/terms/{termId}/calendar | 周类型更新 | 422001 周次越界 | record(update, term_calendar) |
| 添加节假日/调休 | 教务处 + DRAFT | 弹窗录入 | 同上（整体保存） | 清单新增，周历标红 | 422001 调休未配对/日期越界 | 同上 |
| 保存 | 教务处 + DRAFT | 整体保存（带 version） | PUT .../calendar | 草稿更新 | 409001 version 冲突（他人已改，刷新合并） | record(update, term_calendar) |
| 去发布 | 教务处 + DRAFT 且校验通过 | 跳 /terms/:termId/publish | POST .../terms/{termId}/publish | DRAFT→PUBLISHED（学期级） | 422001 存在未闭合调休/空周类型 | record(publish, term)+audit_trail |

**【状态视图】**

| 状态 | 展示与可操作 |
|---|---|
| 五态 | 按 §1.3；empty=未生成周次时显示【生成教学周】引导 |
| DRAFT | 全量可编辑 |
| PUBLISHED/FROZEN | 整页只读横幅「校历已发布/冻结，调整需冻结评估或下学期处理」 |
| ARCHIVED | 只读可导出 |

**【治理】** 脱敏=无；水印=无；审计=保存/发布 record + audit_trail；进360=否；进统计=教学周供排课/考试/统计口径；导入/导出=无（P2 归档导出）；移动端=学生「我的课表」周次/假期标识同步；跳转=学期列表、节次配置、发布页。

**【验收】** 1) 调休只填停课日未填补课日→保存 422001 逐项红字；2) 发布后再 PUT calendar → 403/409 拒绝且页面只读。

### 2.4 节次配置（/terms/:termId/time-slots）

**【定位】** 一级=教务中心；二级=学年学期与校历；三级=学期下钻配置页；路由 `/terms/:termId/time-slots`；谁能进=教务处（DRAFT 可编）；从哪进=学期列表【节次】；用途=维护作息时间与上下课节次，供排课/课表/考试引用。

**【展示】** 顶部：学期+状态。列表字段：节次号、名称（第1节…晚自习）、开始时间、结束时间、时段（上午/下午/晚上）。筛选：无（单表全量）。

**【表单】** 节次号（唯一）、名称、起止时间必填；校验：结束>开始、节次间不重叠、节次号连续；详见字段文档。

**【按钮动作矩阵】**

| 按钮 | 出现条件(角色+状态) | 动作 | API | 成功变化 | 失败提示 | 审计 |
|---|---|---|---|---|---|---|
| 添加节次 | 教务处 + DRAFT | 行内新增 | PUT /api/v1/academic-affairs/terms/{termId}/time-slots | 节次行新增 | 422001 时间重叠/节次号重复 | 保存时审计 |
| 复制上学期 | 教务处 + DRAFT | 选来源学期整体复制 | GET 来源 + PUT 本学期 | 整表填充 | 404001 来源学期无配置 | record(copy, time_slots) |
| 恢复默认模板 | 教务处 + DRAFT | 载入平台默认作息 | PUT .../time-slots | 整表重置 | — | record(reset, time_slots) |
| 保存 | 教务处 + DRAFT | 整体保存（version） | PUT .../time-slots | 配置生效（学期发布后随之下发） | 409001 version 冲突；422001 | record(update, time_slots) |

**【状态视图】**

| 状态 | 展示与可操作 |
|---|---|
| 五态 | 按 §1.3；empty=「未配置节次」+【恢复默认模板】 |
| DRAFT | 可编辑 |
