# 2026-07-08 · 毕业设计 · 题目库 P2+ 三级模块闭环

## 目标

题目库红框 5 个三级模块生产级落地：**题目分类、题目容量、题目要求、题目附件、题目历史**，形成申报→审核→分类/要求/附件维护→容量管理→分配→审计闭环。

## 后端

| 端点 | 说明 |
|---|---|
| `GET /gd-topics/stats` | 扩展：分类统计、满员/余量、要求/附件/未分类缺口 |
| `GET /gd-topics/category-stats` | 分类维度统计 |
| `GET /gd-topics/history` | 题目操作审计链（分页+关键词/题目ID/操作类型） |
| `PUT /gd-topics/{id}/attachments` | 维护附件元数据 JSON |
| `PUT /gd-topics/{id}/capacity` | 调整容量（≥已选人数） |
| `GET /gd-topics` | 新增筛选：`hasRequirements` / `hasAttachments` / `missingCategory` |

## 前端

- `navPlan.js`：5 项 `P(...)` → `I(...)`，`?panel=category|capacity|requirements|attachments|history`
- `TopicLibListView.vue`：各 panel 专属列、筛选、概览卡片、调容量/补要求/管附件/改分类抽屉、历史审计表
- `graduation-topic.api.js`：`getCategoryStats` / `getTopicHistory` / `updateAttachments` / `updateCapacity`
