# 2026-07-07 毕业设计中心 › 毕设学生名单 — 生产级全栈闭环（MySQL 真库验收）

## 结论
**毕设学生名单前后端真闭环。** 把毕设学生 `t_gd_student` 与毕设批次(`t_gd_batch`)/选题库(`t_gd_topic`)真实打通——**学生-选题分配闭环让选题库 `selected` 变为真实值**（关闭毕设批次欠账「学生-批次绑定」），并落地节点状态机 + 风险标记 + 统计 + Excel 导入导出。前端生产级只走真实后端（不回退 mock）。

## 做了什么（真实、MySQL 设计口径）
### 后端
- **模型** `t_gd_student` additive +2 列：`batch_id`、`topic_id`（关联毕设批次与选题库）。
- **服务** `graduation_student_service.py`（新）：列表(多筛选) / 详情(批次·选题·开题/成果/查重/状态流) / 建档 / 编辑 / **分配选题** / 退选 / 分配导师 / 节点状态机(ADVANCE/ARCHIVE) / 风险 / 统计 / Excel 导入导出。
- **学生-选题分配闭环（核心）**：分配校验选题「已确认」+ 未满员；回填 `topic_id/topic_title/topic_source/advisor_name` + 推进 `TASKBOOK_CONFIRM`；**`topic.selected += 1`**；调题/退选释放旧选题名额。
- **状态机**：`选题中→任务书确认(需选题)→指导中(需导师)→中期→成果检查→答辩→归档`；非法流转全拒；审计 `t_gd_audit_trail(biz_type=STUDENT)`。
- **API** `graduation_student.py`（新，前缀 `/graduation/gd-students/*` 避开旧 `/graduation/students/*` 只读兼容）：13 端点。
- **旧 API 兼容**：`graduation_service.list_students/get_student_detail` 委托新服务，旧测试 `test_graduation.py` 保持可读。

### 前端（生产级 real-only）
- `graduation-student.api.js` + `constants/graduation-student.constants.js`。
- 重写 `GraduationStudentListView`（筛选/建档选学生+批次/分配选题抽屉/导师/导入/Excel导出）与 `GraduationStudentDetailView`（批次/选题/节点推进/归档/风险 + 材料页签 + 审计）。路由不变 `/admin/graduation/students`。
