## 一、交付内容

### 后端（公共 Excel 底座）

| 端点 | 说明 |
|---|---|
| `GET /gd-topics/import/template` | 下载 .xlsx 模板 |
| `POST /gd-topics/import/dry-run` | 粘贴行预校验 |
| `POST /gd-topics/import/xlsx` | 上传 Excel 预校验 |
| `POST /gd-topics/import/errors-xlsx` | 错误行 Excel |
| `POST /gd-topics/import/confirm` | 确认导入 + `t_excel_import_job` + 审计 |
| `POST /gd-topics/export` | 按当前筛选导出台账 Excel + 审计 |

**导入字段**：题目名称*、批次编号、题目编号、来源、指导教师、专业、分类、难度、企业名称、容量、要求/成果/技能、是否提交审核。

**校验**：文件内/库内题目编号重复；名称+导师+批次组合重复；企业题目须填企业名；批次须存在且未作废。

**落库**：默认草稿；「提交审核=是」→ `PENDING_REVIEW`。
