# 岗位实习中心页面重构记录（PC 管理端）

## 1. 本轮边界

- 目标：在不改后端业务逻辑前提下，完成岗位实习中心菜单/路由/页面归属重构。
- 允许改动：`frontend` 菜单、路由、岗位实习页面归属；岗位实习相关文档。
- 禁止改动：`backend` 业务逻辑、模型、服务、API、迁移、数据库；`miniapp`；其他中心。
