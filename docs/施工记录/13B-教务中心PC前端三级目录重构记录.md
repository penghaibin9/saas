## 一、本轮做了什么

1. navPlan.js 教务中心组重构：27 个二级节点 / 约 294 个三级叶 → **14 个二级 / 40 叶（6 partial + 34 planned 独立工作区）**；二级按真实业务对象/流程/责任角色/状态机裁决，不预设数量；对标成熟商用教务系统通用模块划分（原创实现，未复制任何第三方源代码/UI/文案/图标/版式）。
2. 状态纠偏：现有学业过程中心 6 页 implemented → **partial（待补强）**——realFirst 真接口（`/api/v1/academic/*`）+ mock 兜底，公共组件/Excel/日期底座未接完，不满足生产级 implemented 验收（CLAUDE.md §35/§39）。
3. `BasePortalLayout.vue` isPlannerView 收紧：planned 灰条仅 DEV 环境/平台侧角色（PLATFORM / PLATFORM_SUPER_ADMIN）可见，**SCHOOL_ADMIN 移出施工视角**。注意：此开关为全局壳层行为，学工/毕设/实习等中心的 planned 灰条对学校管理员同步隐藏（正式菜单只显示真实能力，符合全局口径）。
4. adminMenu.js：教务中心子项 label「学业过程」→「教务工作台」（key/moduleCode/permissionKey 不变，零权限变更）；搜索别名保留「学业过程」旧词兼容。
5. 文档：13B 页面树设计追加附录三（两套菜单口径 + 14 模块裁决表 + 下沉规则）；新建本施工记录。
