# 13A 学工中心页面级验收用例总表

> 本表用于后续开发验收，不代表当前页面已实现。所有用例默认包含租户隔离、登录态、权限、数据范围、审计、空态、错误态、加载态。

## 1. 通用验收红线

| 编号 | 用例 | 期望 |
|---|---|---|
| G-01 | 未登录访问任一管理端页面/API | 返回 401，不泄露业务数据 |
| G-02 | 学生访问 PC 管理端 | 返回 403，前端显示无权限页 |
| G-03 | 普通角色访问超范围详情 | 后端返回 403，前端不可仅靠隐藏按钮 |
| G-04 | 跨租户访问列表/详情/导出 | 无数据或 403，写安全审计 |
| G-05 | 导出任一含学生数据列表 | 必须确认、填写理由、脱敏、水印、写台账 |
| G-06 | 导入任一 xlsx | 模板下载、行级校验、错误行导出、确认后落库 |
| G-07 | 敏感信息查看 | 默认脱敏；解锁需权限、理由、审计 |
| G-08 | 状态流转 | 非法流转被拦截；重复提交幂等 |
| G-09 | 空数据 | 显示业务空态，不显示假数据 |
| G-10 | 接口错误 | 显示可重试错误态，不吞错 |

## 1.1 单页必测 17 项清单（B/C/D 核心三级页）

每个核心三级页面验收时，必须在用例记录中勾选以下 17 项（与 G 系列合并执行）：

| 序号 | 用例项 | 期望 |
|---|---|---|
| 1 | 未登录 401 | 页面/API 401 |
| 2 | 学生访问管理端 403 | 403 + 无权限页 |
| 3 | 普通角色越权 403 | 后端 403，非仅隐藏按钮 |
| 4 | 跨租户不可见 | 无数据或 403 + 安全审计 |
| 5 | 数据范围正确 | 辅导员班级/学院本院/宿管楼栋等 |
| 6 | 列表正常 | 分页、筛选、排序正确 |
| 7 | 详情正常 | 字段完整、无权字段隐藏 |
| 8 | 新增正常 | 校验通过可落库 |
| 9 | 审批正常 | 流程任务人可审，非任务人 403 |
| 10 | 状态流转正常 | 合法流转成功，非法拦截 |
| 11 | 导入模板正常 | xlsx 模板可下载 |
| 12 | 导入错误行正常 | 错误行可预览/下载 |
| 13 | 导出 xlsx 正常 | 确认、理由、脱敏、水印、台账 |
| 14 | 审计写入正常 | 关键操作可查审计 |
| 15 | 敏感字段脱敏正常 | 默认脱敏，解锁有审计 |
| 16 | 空状态正常 | 业务空态文案，无假数据 |
| 17 | 异常状态正常 | 错误提示可重试 |

不适用项标注 N/A（如纯看板无新增则 8/9 标 N/A），但须在验收记录写明原因。

## 5. 提交前检查用例

后续每个 B1/B2/B3 或 C/D 提交前必须人工确认暂存区不包含：orientation、internship、graduation、academic-affairs、miniapp、dist、node_modules、`.env`、`.claude`、query、无关删除文档。建议命令仅用于提交前人工检查：`git status --short`、`git diff --cached --name-only`、`git diff --cached --stat`。
