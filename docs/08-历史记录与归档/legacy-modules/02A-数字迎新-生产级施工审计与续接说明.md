## 四、缺什么（缺口清单）

### 缺数据库表（用户建议 13 张中约 6 张缺）
`orientation_batches`（批次）、`orientation_student_verifications`（信息核验）、`orientation_qualifications`（报到资格）、`orientation_dormitory_assignments`（宿舍预分配）、`orientation_notice_tasks`（迎新通知）、`orientation_archives`（归档）。

### 缺字段
- `batch_id`：现所有表无批次关联。
- 显式状态流转列 `previous_status / last_transition_at / last_transition_by / transition_reason`（现用 audit_trail 代偿）。
- 归档列 `archive_status / archived_at / archived_by / archive_batch_no`。

### 缺接口
批次 CRUD、信息核验、报到资格判定、未报到跟进（专口）、统计专口、归档、导入导出（orientation 专用模板/预校验/台账导出）。

### 缺状态机规范化
现有状态机可用，但枚举值与 CLAUDE.md 建议不完全一致；缺 `archived` 终态与"未核验不能直接归档""绿色通道未审不能默认可报到"等硬约束的显式落地。

### 缺关联（技术债，补页时应顺带处理）
- 学院/专业/班级：现**冗余存字符串**，未 FK 组织主数据。
- 宿舍：building/room 存字符串，未关联宿舍模块表。
- 绿色通道 未与 困难认定 / 奖助 联动。
- 通知中心、工作台待办：未推送。

### 缺权限 key 规范
现用旧 `orientation.*`；CLAUDE.md 的 `studentAffairs.orientation.*`（15 个）未落地。**旧 key 不许删，兼容映射到新 key。**
