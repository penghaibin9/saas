- **文档性质**：全生命周期主线学生数据点统一口径。
- **依据**：`docs/database/00-数据库设计冻结总册.md` §5.1（生命周期主阶段枚举，只引用）；`miniapp/src/mock/student/**`（林可欣画像）；`frontend/src/mocks/academic|campusService|employment|internship|graduation` 各模块。

## 1. 生命周期主阶段（枚举口径，来自冻结册 §5.1）

`t_student_profile.current_stage`：

```
ADMITTED → PRE_STUDENT_VERIFIED → REGISTERED_PENDING_ENROLLMENT → ENROLLED → GRADUATING → INTERN → GRADUATED → ALUMNI
异常分支：DEFERRED / NO_SHOW / SUSPENDED / DROPPED_OUT / TRANSFERRED / CANCELLED / MERGED / RECYCLED
```

| 阶段码 | 中文 | 演示黄金链路对应环节 |
|---|---|---|
| `ADMITTED` | 已录取 | 数字迎新（入学起点） |
| `PRE_STUDENT_VERIFIED` | 预报到已核验 | 数字迎新 |
| `REGISTERED_PENDING_ENROLLMENT` | 已报到待注册 | 数字迎新 → 在校 |
| `ENROLLED` | 在校 | 在校服务 + 学业过程 |
| `GRADUATING` | 毕业阶段 | 毕业设计 |
| `INTERN` | 实习 | 岗位实习 |
| `GRADUATED` | 已毕业 | 就业服务 |
| `ALUMNI` | 校友 | 就业跟踪 / 生源沉淀 |

> 说明：`INTERN` 与 `GRADUATING` 在真实学制上并行（顶岗实习期同时做毕设），演示口径按"实习→毕设"顺序讲，但注明两者是**同期并行的毕业年环节**。
