# 02 · PC 前端目录说明（frontend/）

> `frontend/` 是 PC 管理端，Vue3 + Vite。**PC UI 对接就是在这里做**（按母版对接）。本轮文档任务不改动它，这份只是讲清结构，方便后续对接的人。

---

## 1. 目录结构

```
frontend/
├── index.html            页面入口 HTML
├── package.json          依赖与脚本（dev/build/preview/lint）——⛔ 本轮不改
├── vite.config.js        Vite 配置（@ 别名指向 src，端口 5173）
├── eslint.config.js      代码规范配置
├── dist/                 构建产物（build 生成）——❌ 别手改
├── node_modules/         依赖——❌ 别手改
└── src/                  源码 ✅（PC UI 对接动这里）
    ├── main.js           应用入口
    ├── App.vue           根组件
    ├── router/           路由（createWebHistory，见下方说明）——改动需谨慎
    ├── views/            页面级视图（AdminWorkbench、admin、demo、security 等）
    ├── modules/          业务模块（按域拆分，见下）
    ├── layouts/          布局（页面骨架、母版级布局）
    ├── components/       通用组件
    ├── stores/           状态管理（Pinia）
    ├── services/         数据服务层（对接 mock / 将来对接真实接口）
    ├── mocks/            mock 假数据 ——⛔ 本轮不改
    ├── config/           配置（品牌、环境等）
    ├── security/         前端安全相关（脱敏等）
    ├── styles/           样式、设计变量
    ├── types/            类型定义
    └── utils/            工具函数
```

## 3. PC UI 对接一般动哪些目录

按母版对接 UI 时，主要涉及：

- `src/layouts/`：页面骨架 / 母版级布局（对接母版的核心）。
- `src/modules/<对应模块>/`：具体页面与组件。
- `src/views/`：页面级视图。
- `src/components/`：抽公共组件。
- `src/styles/`：设计变量、主题、样式规范。

对接前**必须先看** UI 设计稿与规范：`docs/ui/fable5-pc-final/`、`docs/ai-handoff/00-全局必读/` 下的 UI 规范/骨架蓝图。

## 4. 谨慎或不要动的

| 目录/文件 | 说明 |
|---|---|
| `src/router/` | 路由是 `createWebHistory()`；改路由会影响全站和 Nginx 兜底，非必要不动、动要谨慎 |
| `src/mocks/` | mock 数据；本轮不改。将来切真实接口时由开发统一处理 |
| `src/services/` | 数据来源切换点（mock↔真实接口）；改动需和后端联调节奏一致 |
| `package.json` / `package-lock.json` | ⛔ 本轮不改（改依赖会影响构建可复现性） |
| `vite.config.js` | 改 base/端口等要清楚影响（子路径部署才动 base） |
| `dist/` `node_modules/` | ❌ 机器生成，别手改 |

---

## 5. 关于路由模式（和部署有关）

`src/router/index.js` 使用 `createWebHistory()`（history 模式）。这决定了部署时 **Nginx 必须配 `try_files ... /index.html` 兜底**，否则刷新子页面 404。详见 `docs/deploy/03` 第 6 节、`docs/deploy/07`。**改路由模式会连带影响部署配置，别随手改。**

## 6. 怎么跑起来（回顾）

```bash
cd frontend
npm install      # 首次/换机
npm run dev      # 开发，默认 http://localhost:5173
npm run build    # 构建，产物 frontend/dist/
npm run preview  # 预览构建结果
```
