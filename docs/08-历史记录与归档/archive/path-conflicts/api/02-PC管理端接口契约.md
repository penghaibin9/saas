## 一、workflow 权限与流程（全 18 接口）

契约冻结来源：`frontend/src/modules/workflow/api/workflow.contract.js`。前端当前响应包裹为 `{ code(number,0=成功), message, data, timestamp, requestId }`；`WORKFLOW_ERROR_CODES` 见下表统一列出。moduleCode=WORKFLOW，路由 `/admin/workflow`，首页权限点 `workflow.home.view`。

### 1.1 流程中心概览

| 项 | 内容 |
|---|---|
| 接口名称 | 流程中心概览 |
| 适用端 | PC |
| 请求方法 | GET |
| 建议路径 | `/api/v1/admin/workflow/overview` |
| 请求参数 | 无 |
| 返回字段 | `{ pendingTaskCount, templateCount, enabledTemplateCount, roleCount, permissionCount, moduleUsage:[{moduleCode,enabledTemplates,pendingTasks}], recentRecords:[ApprovalRecord], abnormalHints:[{type,text,level}] }` |
| 权限要求 | workflow.home.view |
| 数据范围要求 | 按当前角色 dataScope（学校管理员 SCHOOL 可见全校汇总；其余角色按各自范围聚合） |
| 空状态 | 各计数为 0，数组为 [] |
| 异常状态 | 网络/服务端异常返回 SERVER_ERROR |
| 错误码 | SERVER_ERROR |

## 二、student 学生主档（概览引用 + PC 门面补充映射）

> **本模块接口细节以历史冻结 `docs/api/02-学生主档与学生360API.md` 为准**（15 接口：学生概览/列表/详情/基础档案/身份认证信息/核验通过/核验退回/监护人列表/保存监护人/变更学籍状态/时间线/筛选字典/导入校验/导出/审计），本文档不重复展开逐接口字段，仅补充 PC 前端门面层（`frontend/src/modules/student/api/student.api.js`）与历史冻结接口的对应关系，供后端实现时参照两侧口径差异。

| PC 门面方法（`student.api.js`） | 对应历史冻结接口（`02-学生主档与学生360API.md`） | 差异说明 |
|---|---|---|
| getContext() | 无直接对应，聚合品牌/角色/数据范围/权限动作/字典 | PC 门面扩展，建议后端合并 `/api/v1/authz/tenant/brand` + `/api/v1/authz/me/data-scope` + 本模块字典 |

契约来源：`frontend/src/modules/platform/api/platform.api.js`（50 个方法）。moduleCode=PLATFORM，路由 `/admin/platform`，首页权限点 `platform.dashboard.view`，仅 PLATFORM_OPERATOR 角色可见（数据范围 ALL）。建议后端路径前缀改用 `/api/v1/platform/*`（区别于其余模块的 `/api/v1/admin/*`，与共享底稿分端前缀表一致）。

| 项 | 内容 |
|---|---|
| 接口名称 | 平台运营看板（getDashboardSummary） |
| 适用端 | PC（PLATFORM_OPERATOR） |
| 请求方法 | GET |
| 建议路径 | `/api/v1/platform/dashboard` |
| 请求参数 | 无 |
| 返回字段 | 租户数/订单数/授权情况等汇总（待后端确认字段） |
| 权限要求 | platform.dashboard.view（对应共享底稿 workflow.audit.view 之外的平台专属权限点，（待后端确认）workflow 权限清单未见 platform 前缀权限点，建议补充） |
| 数据范围要求 | ALL |
| 空状态 | 各计数为 0 |
| 异常状态 | SERVER_ERROR |
| 错误码 | SERVER_ERROR |

| 项 | 内容 |
|---|---|
| 接口名称 | 租户列表 / 套餐列表 / 订单列表 / 集成列表 / API 接入列表 / Webhook 列表 / 同步任务列表 / 平台日志（getTenants / getPackages / getOrders / getIntegrations / getApiAccessList / getWebhooks / getSyncTasks / getPlatformLogs） |
| 适用端 | PC（PLATFORM_OPERATOR） |
| 请求方法 | GET |
| 建议路径 | `/api/v1/platform/{tenants\|packages\|orders\|integrations\|api-access\|webhooks\|sync-tasks\|logs}` |
| 请求参数 | 均调用 paginate()；getPackages/getWebhooks 默认页大小 20 |
| 返回字段 | `{list,total,page,pageSize}` |
| 权限要求 | platform.{resource}.view |
| 数据范围要求 | ALL（跨租户，唯一例外场景，须写审计） |
| 空状态 | `{list:[],total:0}` |
| 异常状态 | 无 |
| 错误码 | 无 |

| 项 | 内容 |

| 请求方法 | GET |
| 建议路径 | `/api/v1/platform/tenants/{id}` 等 |
| 请求参数 | 路径参数 id |

| 数据范围要求 | ALL |
| 空状态 | data=null |
| 异常状态 | DATA_NOT_FOUND |
| 错误码 | DATA_NOT_FOUND |

| 项 | 内容 |
|---|---|
| 接口名称 | 关键写操作（含核心模块授权：toggleTenantModule；状态机：activateOrder；及其余租户/套餐/订单/集成/API/Webhook/同步任务管理方法） |
| 适用端 | PC（PLATFORM_OPERATOR） |
| 请求方法 | POST/PATCH |
| 建议路径 | `/api/v1/platform/*` 各子资源写路径（待后端确认具体命名） |
| 请求参数（含必填校验） | createTenant（名称+编码必填，编码唯一性）、setTenantStatus（SUSPEND 时原因≥5字）、**toggleTenantModule（核心模块授权方法：底座模块禁止关闭，关闭需原因≥5字）**、importTenants（二段式）、batchRemindRenew（**当前 mock 无校验**）、savePackage（创建分支无 name 校验）、disablePackage（有在用租户恒定拒绝，原因≥5字）、createOrder（租户+类型必填，租户需存在）、**activateOrder（状态机校验：仅待开通订单可执行，联动租户+授权表三表更新，属高风险写操作）**、voidOrder（已开通禁止直接作废，原因≥5字）、saveIntegration（创建分支名称+类型必填）、setIntegrationStatus（原因≥5字）、testIntegration（只读诊断，不改字段但记审计）、saveApiAccess（创建分支 appName 必填）、resetApiSecret（不返回明文，原因≥5字）、setApiAccessStatus（原因≥5字）、saveWebhook（创建分支名称+url必填）、setWebhookStatus（原因≥5字）、redeliverWebhook、retrySyncTask（无失败行则返回失败）、setSyncTaskStatus（原因≥5字） |
| 返回字段 | 更新后实体 |
| 权限要求 | platform.{resource}.{action}（待后端确认精确命名，建议区分租户管理/套餐管理/订单管理/集成管理四类权限点） |
| 数据范围要求 | ALL，写操作须写 `t_security_audit`（对齐历史冻结总册 §六"平台运营端查看多租户是唯一例外，且必须走平台权限+写审计"） |
| 空状态 | 不适用 |
| 异常状态 | 必填校验失败、原因不足 5 字、编码重复、订单状态不允许、底座模块禁止关闭 |
| 错误码 | VALIDATION_ERROR、REJECT_REASON_REQUIRED、DATA_CONFLICT、NO_PERMISSION |

> **安全提示**：`toggleTenantModule`（模块授权开关）与 `activateOrder`（订单状态机）是平台侧最高风险的两个写操作，直接影响租户可用模块与计费，后端实现时须有独立的二次确认与审计留痕，不可照搬 mock 校验逻辑。
> 辅助方法：getContext()、getTenantOptions()、getAuthorizations()、getApiCallLogs()、getAuditLogs()。
