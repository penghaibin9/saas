# 02 · 学生主档与学生360 API

> 学生身份底座。所有业务都以 `studentId` 串联，本域是其权威来源。
> 通用规则见 [00 总册](00-API契约冻结总册.md)。前缀：PC 管理端 `/api/v1/admin/students`；学生本人 `/api/v1/student-pc/profile`。
> DB 依据：`docs/database/00-数据库设计冻结总册.md` §4.7（t_student_*）。

### 2.1 学生列表
- **方法/路径**：`GET /api/v1/admin/students`
- **用途**：按权限范围查询学生，进入 360。
- **使用页面**：PC 学生中心/学生列表；教师端"我的学生"（走 teacher-mobile 变体）。
- **请求参数**：`keyword, collegeId, majorId, classId, grade, stage, studentStatus, hasRisk, hasTodo, counselorId, page, pageSize, sort`。
- **响应字段**：`items[] { studentId, realName, studentNo, collegeName, majorName, className, currentStage, currentStageLabel, studentStatus, counselorName, keyTodoTitle, riskLevel, dataQualityStatus, updatedAt }`（手机号/证件默认脱敏，不在列表返回）。
- **权限**：`student:profile:view`。**数据范围**：按当前身份（SCHOOL/COLLEGE/CLASS/COUNSELOR_CLASSES/GD_STUDENTS/INTERN_STUDENTS…）。**审计**：否（列表）。**分页**：是。**mock**：是。**表**：t_student_profile、t_college/major/class、t_student_org_relation、t_unified_todo（聚合）、t_complaint（风险聚合）。**一期**：P1。
- **备注**：学生本人**不可**访问本接口（学生进不了后台，用 2.15）。

### 2.2 学生详情
- **方法/路径**：`GET /api/v1/admin/students/{id}`
- **用途**：学生主档静态信息（非全生命周期业务）。
- **响应字段**：分区块——基础身份（姓名/性别/出生/民族/证件号脱敏+hash/手机脱敏/照片）、招生录取、学籍组织、当前阶段、系统信息（来源/版本/合并/回收）。
- **权限**：`student:profile:view`。**数据范围**：按身份。**审计**：查看敏感字段时是。**分页**：否。**mock**：是。**表**：t_student_profile。**一期**：P1。

### 2.3 学生360（核心）
- **方法/路径**：`GET /api/v1/admin/students/{id}/profile360`
- **用途**：一个学生的全生命周期聚合工作空间（总览卡片集）。
- **使用页面**：PC 学生360、教师端学生简档(T7，摘要版)。
- **响应字段**：`{ header:{...}, cards:{ basic, currentStage, todos, risks, onboarding, campusService, academic, gd, internship, employment, recentTimeline } }`。各业务卡为摘要 + 跳转链接。
- **权限**：`student:360:view`。**数据范围**：按身份。**审计**：是（进入 360 写敏感访问）。**mock**：是。**表**：t_student_profile + 各业务摘要表 + t_student_timeline_event。**一期**：P1。
- **备注**：聚合接口降级熔断——单业务模块超 3s 返回"暂不可用"占位，不阻塞整个 360。企业导师/移动端返回**摘要版**（敏感卡剔除）。

### 2.4 学生360时间线
- `GET /api/v1/admin/students/{id}/timeline?category=&visibleToStudent=&page=`。用途：生命周期事件流。响应 `items[] { occurredAt, eventTitle, eventSummary, bizModule, bizId, category, visibleToStudent }`。权限 `student:360:view`。分页：是。表：t_student_timeline_event。一期 P1。

### 2.5 身份核验
- `POST /api/v1/admin/students/{id}/verify-identity`，体 `{ verifyType, materialFileId, result }`。用途：迎新/在校身份核验。审计：是。表：t_student_document、t_student_stage_event。一期 P2。

### 2.6 学籍状态变更（阶段事件）
- **方法/路径**：`POST /api/v1/admin/students/{id}/stage-events`
- **用途**：触发学生阶段流转（走 t_stage_transition_rule 规则校验，不硬编码）。
- **请求体**：`{ toStage, eventType, remark, requestId }`。
- **响应字段**：`{ fromStage, toStage, eventId }`。
- **权限**：`student:stage:update`。**数据范围**：按身份。**审计**：是（字段审计 + 阶段事件）。**幂等**：requestId。**mock**：是。**表**：t_student_stage_event、t_student_profile.current_stage、t_student_field_audit、t_student_timeline_event。**一期**：P3。

### 2.7 信息更正-申请
- **方法/路径**：`POST /api/v1/admin/students/{id}/corrections`
- **用途**：对权威字段流程化更正（禁止直接改表）。
- **请求体**：`{ fieldName, newValueSummary, reason, attachmentFileId, requestId }`。
- **权限**：`student:correction:create`。**审计**：是。**表**：t_student_data_correction、t_student_field_audit。**一期**：P3。
- **备注**：`reason` 必填；敏感字段（姓名/身份证/学号/学籍状态/毕业结论）走二级复核。

### 2.8 信息更正-审核
- **方法/路径**：`POST /api/v1/admin/corrections/{id}/review`
- **请求体**：`{ action:"APPROVE|RETURN|REJECT", comment, rejectReason, version, requestId }`。
- **权限**：`student:correction:review`。**审计**：是。**SoD**：applicant≠reviewer（违反 `SOD_VIOLATION`）。**乐观锁**：version。**表**：t_student_data_correction。**一期**：P3。

### 2.9 联系方式
- `GET/PUT /api/v1/admin/students/{id}/contacts`。加密存储，读默认脱敏，`field:view_full` 才返回完整。审计：查看完整/修改时是。表：t_student_contact。一期 P3。

### 2.10 家长授权
- `GET/POST /api/v1/admin/students/{id}/guardian-auths`。用途：监护人绑定与授权范围。审计：是。表：t_student_guardian_auth。一期 P3。

### 2.11 学生文件
- `GET/POST /api/v1/admin/students/{id}/documents`。上传走文件中心（先 `POST /files` 得 fileId）。响应含 review_status。审计：敏感材料下载写 t_file_access_log。表：t_student_document、t_file_object。一期 P3。

### 2.12 导入-DryRun
- **方法/路径**：`POST /api/v1/admin/students/import/dry-run`
- **用途**：上传 Excel 预检，返回逐行校验结果，不写正式库。
- **请求体**：`{ fileId, importType }`。
- **响应字段**：`{ batchId, totalRows, validRows, invalidRows, errors:[{ rowNo, fieldName, errorCode, errorMessage }] }`。
- **权限**：`student:import`。**审计**：是。**表**：t_student_import_batch、t_student_import_error。**一期**：P4。

### 2.13 导入-确认
- **方法/路径**：`POST /api/v1/admin/students/import/confirm`，体 `{ batchId, requestId }`。
- **用途**：DryRun 全通过后确认写入，**以批次为事务边界，任一行失败整批回滚**。
- **权限**：`student:import`。**审计**：是。**幂等**：requestId。**表**：t_student_import_batch、t_student_profile、t_student_stage_event…。**一期**：P4。
- **备注**：DryRun 未全通过禁止调用（返回 DATA_CONFLICT）。

### 2.14 导出
- **方法/路径**：`POST /api/v1/admin/students/export`
- **用途**：三种模式导出（当前列表/加密PDF档案/脱敏外发）。
- **请求体**：`{ mode:"LIST|PDF|DESENSITIZED", filters:{...}, fields:[...], purpose, receiver?, retentionDays? }`。
- **响应字段**：`{ exportTaskId, status }`（异步；完成后消息通知下载）。
- **权限**：`student:profile:export` / `:export-pdf` / `:export-desensitized`。**审计**：是（必填用途，写 t_security_audit_log）。**SoD**：敏感导出申请人≠审批人。**表**：t_export_task、t_desensitize_rule、t_security_audit_log。**一期**：P4。

### 2.15 学生本人主档
- **方法/路径**：`GET /api/v1/student-pc/profile`（学生 PC / 小程序"我的"）
- **用途**：学生查看**本人**主档（SELF 范围，后端按登录学生过滤）。
- **响应字段**：本人可见字段（脱敏规则同 UI）。
- **权限**：`student:profile:view-self`。**数据范围**：SELF。**审计**：否。**mock**：是。**表**：t_student_profile。**一期**：P1。
