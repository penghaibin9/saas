## 使用说明

- 每个模块一节，表格字段固定为：**需要哪些接口**（引用 `docs/api` 对应契约）/ **依赖哪些表**（引用冻结总册）/ **依赖哪些权限点** / **联调页面**（PC 路由 + miniapp 页面）/ **验收标准**。

- 表中"依赖表"若历史冻结总册/数据库冻结总册未逐字段展开，一律标注"（待与冻结总册核对）"，禁止杜撰字段。
