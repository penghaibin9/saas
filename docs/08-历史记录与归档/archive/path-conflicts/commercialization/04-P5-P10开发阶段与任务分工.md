## 派工纪律

1. 同一目录同一时间只派一个执行者（防互踩，风险 #26）。
2. 复杂工程（多文件/契约/守卫/上下文）→ Claude Code；文档/单页微调/提交 → Cursor；开工预审与收工验收 → fable5 只读；钱与边界 → 人工。
3. 每阶段开工前把《00-手册》第 13 章对应模板+本表该行一起复制给执行者。
4. 阶段之间必须经过 fable5 验收报告"通过"才放行下一阶段。
