# 04-权限测试清单

- **文档性质**：权限矩阵验证用例清单（RBAC 菜单可见性 / 按钮显隐 / 无权限拦截 / 越权 URL 直达拦截）
- **适用端**：PC 管理端 `frontend/`（7 类角色）+ miniapp 教师端 `miniapp/`（6 类教师身份）
- **依据**：`_shared_brief.md` 第 3 节（RBAC：角色码、数据范围、权限点、`workflow.mock.js` roles[]/permissions[]）、第 2 节（miniapp 角色与按钮键）；权限判断入口 `frontend/src/modules/workflow/context/permission.context.js`；权限点权威口径以 `docs/rbac/`（RBAC 权限与数据范围矩阵）为准
- **当前阶段声明**：本清单验证的是**前端 mock 层面**已实现的权限判断逻辑（`canAccessPage`/`canClickButton`/`canViewMenu`/`filterMenusByPermission`/`filterActionsByPermission` 等）。真实的服务端权限校验（防止绕过前端直接调用接口）标注"（后端接入后验证）"。
- **生成日期**：2026-07-04
