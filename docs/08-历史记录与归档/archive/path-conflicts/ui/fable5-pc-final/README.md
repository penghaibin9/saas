# PC 管理端最终设计稿归档

## 这是什么

这是 **PC 管理端最终设计稿归档** 目录。

来源：**Fable5 / Claude Design** 导出（含 `Future Campus SaaS 设计升级.zip`）。

存放内容：PC 管理端最终设计稿、zip、PDF、HTML、截图、README。

## 怎么用

**后续开发 PC 页面，必须参考本目录。**

适用页面包括但不限于：

- PC 登录页
- PC 首页 / 工作台
- 学生中心、学生列表、学生 360 档案
- 数据中心
- 权限与审批中心
- 角色切换
- 主题系统

## 重要提醒

- 本目录内的 **HTML / zip / PDF 是设计参考，不是生产代码**。
- **不得**把导出的 HTML 直接复制进 `frontend/src`。
- **不得**把设计稿放进 `backend/`。
- 小程序端单独设计，见 [`../fable5-miniapp-final/`](../fable5-miniapp-final/)。
