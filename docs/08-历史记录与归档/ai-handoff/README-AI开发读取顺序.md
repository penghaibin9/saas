## 2. 每次开发模块时的读取流程

**三步法（必须按序）：**

1. **先读 `00-全局必读/`** — 总册、UI 规范、商业化总控、P5.5 拍板、P5 路由/菜单/页面清单
2. **再读当前模块所在子目录** — 只看与本次任务相关的 1～2 份深化文档
3. **再开发** — 遵守 P5/P5.5 约束：不直连 mock、只走 provider、不超前做 P6 禁止项
