## 设计确认

V5 “深邃黑”基准不是“深色内容区 + 亮蓝主导航”的组合。深色主题侧栏应使用深色渐变：

```text
#070c13 → #111b2f → #283b66
```

选中菜单仍可使用白色卡片和深蓝文字，以保证导航识别度。

## 已知观察项

- 宿舍调宿历史可选接口可能返回 403：页面按真实权限降级，不绕权、不伪造数据。
- 自动化快速切换路由时可能出现 `net::ERR_ABORTED`：属于浏览器取消旧页面请求，需与真实服务端故障分开记录。
- 独立 `File capability inventory` 工作流因仓库基线缺少其审计脚本而失败时，不允许通过越界修改学生门户业务代码规避。
