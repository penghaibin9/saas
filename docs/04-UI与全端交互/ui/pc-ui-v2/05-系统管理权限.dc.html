高敏动作（明文查看/批量导出/删除）默认需二次确认，变更本身也走审批可配置。
布局与层级 角色列表（252px）→ 权限矩阵（主体）→ 影响与留痕（248px）。矩阵按「模块 × 能力等级（查看/操作/审批/导出/高敏）」组织，比按钮级打勾树好读一个数量级——按钮级权限收在每行展开的次级面板里。
导航 系统管理员的左栏没有业务模块，只有「平台」组 + 临时只读授权说明；顶栏范围镜片替换为「高危区」提示。这一屏本身就在演示「菜单是权限的镜子」。
核心组件 权限矩阵 PermissionMatrix（勾选/锁定/待保存三态）；影响预览面板（人数/菜单波及/回滚）；变更保存条（生效时间可选）；审计时间线；高敏动作标签（黄）。
角色差异 学校管理员可管业务角色但看不到「平台运营」；审计员进来全部只读+可导出审计日志；平台运营在另一个「平台运营」模块管租户，不进本页。
交互 勾选立即进入「待保存」态（行变米黄 + 底部保存条浮现）；保存必弹二次确认（影响人数 + 生效时间）；变更历史每条可展开 diff 并一键回滚；「从其他角色复制」是建新角色的主路径。
高级感来自哪里 ① 「影响 86 人、次日生效、可回滚」——把配置做成了发布（release）心智，这是企业级软件的成熟度信号；② 待保存态的视觉隔离让危险操作永远不含糊；③ 审计流水号（CHG-1108）贯穿，采购方的安全评审一眼看到闭环。
