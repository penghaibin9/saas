布局与层级 页头（标题+口径+动作）→ 筛选区（搜索/下拉/状态计数 chips/密度切换）→ 批量条 → 表格 → 分页。筛选与表格连为一体（共享圆角），减少一层卡片嵌套。
核心组件 DataTable（行 46px 标准/38 紧凑，首列冻结，行悬停出现快捷动作）、AdvancedFilter（已选条件变 chip 可单独关闭）、状态计数 chips（筛选即导航）、AppStatusTag/AppRiskTag、保存视图。
角色差异 辅导员进入本页自动锁定本班范围（范围镜片显示"软件2301班"且不可摘）；导出按钮对无 export 权限的角色直接隐藏；手机号明文查看需二次确认并留痕。
交互 点行任意处开 360 抽屉（列表不失焦）；勾选进入批量态（顶条变墨色）；状态 chip 即筛选；视图可保存为「风险学生盯办」等常用组合；Esc 逐层退出。
高级感来自哪里 表格不是「数据倾倒」：阶段列 = 标签+进度条+百分比三件套讲完故事；风险列有分级语言；脱敏/留痕随处可见但不喧哗（10.5px 灰字）；密度三档给教务型用户掌控感。
