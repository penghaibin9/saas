设计说明
布局 52px 顶栏（信息层）+ 224px 浅色左栏（导航层）+ 内容区。内容区纵向节奏：问候行 → 一行质量提醒 → 4 指标卡 → 双栏主体（队列 1.55 : 面 1）。全页只有一种卡片底色（白）与一种描边（#E6EAF1）。
信息层级 第一层级是「现在最该处理」队列（占视觉重心），第二层级是指标与阶段分布，第三层级才是模块入口（左栏）。旧版的大渐变横幅被降级为一行 12.5px 的提醒条——数据的庄重感来自排版而不是色块。
导航位置 顶栏不放菜单，只放身份四件套：品牌（租户）、搜索、数据范围镜片、角色切换器。左栏三段式：锚点（工作台/待办/学生360）→ 培养过程分组 → 治理/平台分组；分组按角色过滤。
核心组件 队列行 QueueItem（严重度色条 + 标题 + 归属 + SLA 标签 + 动作）；指标卡 AppMetricCard（trendQuality 决定色）；阶段分布 LifecycleStrip；风险行 RiskStudentRow。对应 components/dashboard/* 现有文件改造，不新增接口。
角色差异 工作台 = 区块注册表（queue / metrics / lifecycle / risk / approval / employment / patrol…）× 角色配置。切换角色重组区块并刷新范围，URL 不变。
交互 队列行整行可点进处理页；hover 出现快捷动作；⌘K 全局搜索学生直达 360；角色切换器下拉展示各身份的待办数与数据范围（复用小程序 T2 心智）；主题切换在左栏底部，全局变量瞬时生效。
高级感来自哪里 ① 去横幅：第一屏没有一块大渐变，庄重感来自 26px tabular 数字与 1px 线；② 克制的色彩预算：品牌蓝只出现在 6 处（logo/激活项/链接/主按钮/范围镜片/当前阶段点）；③ SLA 语言：超时/临期/积压是运营软件的词汇，不是学生作业的词汇；④ 每个数字都有出处与口径（更新时间 · 全日制在籍），这是商业软件的可信感。
