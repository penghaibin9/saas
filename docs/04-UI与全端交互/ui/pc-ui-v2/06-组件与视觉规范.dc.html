组件规范 §五 · 每项标注对应现有组件文件与示例页
顶部信息区 BasePortalLayout header · 见 01
52px 白底下描边。左：租户 logo 块（tenantBrandColor）+ 校名 + 端名；中：⌘K；右：环境标 → 数据范围镜片 → 通知 → 角色切换器。永远不放导航菜单。
导航区（左栏） BasePortalLayout aside × getVisibleAdminMenu(ctx) · 见 01–05
三段：固定锚点（工作台/待办/学生360）→ 角色过滤的模块分组 → 底部主题。模块二级手风琴原位展开，一次只开一个；徽标传压力（红=超时 黄=积压）。
角色切换器 ctx.availableRoles / switchRole · 见 01
顶栏常驻：头像+姓名+当前角色+身份数。下拉为身份卡片（角色名/数据范围/待办数），切换后待办、菜单、范围、工作台四联动，toast 确认。
数据范围显示 ctx.dataScope · 见 01/02
蓝底胶囊「◎ 数据范围 · 信息工程学院 · 全院」，不可关闭。范围锁定的页面（辅导员看本班）镜片变实心以示不可摘。越界访问 → 无权限状态页。
工作台 Hero（问候行） 替代 AppLifecycleBanner · 见 01
降级为纯排版：问候 20/700 + 口径行 12/灰。禁止渐变横幅。全局告警是 1 行黄条 notice，不是 banner。
指标卡 AppMetricCard · 见 01/03
标题 11.5 灰 + 归属角标 → 数字 24–26/700 tabular → 口径行。可选目标线进度条（targetLine）。异常指标数字直接用状态色。点击 = 带筛选下钻。
筛选区 AdvancedFilter + ModuleToolbar · 见 02
搜索 + ≤3 个常用下拉 + 高级筛选抽屉；已选条件变蓝 chip 可单删；状态计数 chips 是第一筛选公民；支持保存视图。与表格连体（共享圆角）。
表格 DataTable · 见 02
行 46/38 两档 + 密度切换；斑马纹禁用，用 1px #F1F4F8 行线；行 hover 灰底 + 左侧 2px 蓝条 + 快捷动作浮现；首列人员单元 = 头像+姓名+编号两行；点行开 360 抽屉。
状态标签 / 风险标签 AppStatusTag / AppRiskTag · 见 02
状态：浅底+深字+5px 角（在校绿/实习蓝/毕设紫/就业玫/迎新黄）。风险：等级前缀「高·原因」，高=红实底白字，中=黄浅底，低=灰浅底。语义映射全局唯一，禁止页面自定义。
抽屉 AppDrawer / AppHandleDrawer · 见 02
宽 400–480，右滑入，无整屏遮罩（列表半透明变暗 20%）；头部 = 对象卡，中部 tabs，底部动作条 + 留痕编号。处理类动作优先用抽屉，不跳页。
弹窗 AppConfirmDialog · 见 05 保存条
只用于二次确认与轻表单（≤4 字段）。确认弹窗必须陈述后果（影响人数/是否可回滚/通知谁）。宽 420，危险确认按钮右置红色。
导入导出 StudentImportExportView + export.guard · 见 02
导入 = 三步抽屉（模板下载→上传校验→差异预览后入库）；导出永远带「留痕」角标，高敏导出加水印并走 export.guard。按钮无权限即隐藏。
批量操作 见 02 批量条
勾选 ≥1 行浮出墨色批量条（已选 N + ≤4 个动作 + Esc 取消）。批量动作有进度反馈与结果摘要（成功 84 / 失败 2 · 查看失败原因）。
审计留痕 OperationLogList + audit-event.helper · 见 04/05
三种形态：时间线面板（审批/权限页右栏）、行内留痕编号（AUD-/CHG- 前缀 10px 灰字）、敏感动作「留痕」黄标。留痕是可见的产品能力，不是埋点。
空 / 加载 / 异常 / 无权限 EmptyState / LoadingState / ErrorState / AppGlobalState · 见 02
四态同构：图标块 38px + 一句话原因 + 一个动作。加载用保持版式的骨架屏（不转圈遮罩）；异常必带错误码；无权限展示当前范围并提供「申请权限」。任何列表页四态缺一不可验收。
高级感来源（总结） 排版承重（大数字+层级字阶）而非色块承重 · 1px 线代替阴影 · 品牌色预算制（6 处）· SLA/口径/留痕的运营语言 · 密度可控 · 状态语义全局唯一 · 每个数字有出处。做到这七条，不换皮肤也高级。
