主题机制 · 三条规则
① 只动三族变量 主色族（--primary-50/100/500/600/700/tint）+ 页面底（--bg-page）+ 侧栏底（--bg-sidebar）。文字墨色、状态色（成功/警示/危险）、密度、圆角全局锁定——换肤永不破坏状态语义。
② root 挂 class 默认学院蓝 = 无 class；其余挂 .th-b / .th-d / .th-c / .th-e / .th-f（见 tokens-v2.css 末尾）。偏好写入 themePreference，登录页与左栏底部均可切换。
③ 租户品牌优先 学校若配置 tenantBrandColor，则覆盖默认主题的主色族并自动生成 tint；六主题仍可叠加选择页面底色倾向。墨白主题下链接保持蓝色以保证可点击辨识。
