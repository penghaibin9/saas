- BasePortalLayout 根据学工菜单归属及历史路由目录启用 TeacherWorkspaceFrame。覆盖 student-affairs、student、orientation、campus-service 及学工工作台附属路由。
- 二级菜单切换同步进入该模块的首个可用页面；三级菜单继续打开原有业务路由。
- 页签、快捷栏、配色和菜单宽度按租户、用户、角色、当前身份上下文保存，避免模块 ctxKey 不同造成偏好分裂。首次进入时兼容读取当前模块旧配置。
