# 学生小程序 / 教师移动工作台最终设计稿归档

## 这是什么

本目录是 **学生小程序** 与 **教师移动工作台** 最终设计稿归档。

来源：**Fable5 / Claude Design** 导出。设计稿已完成主体设计并通过总验收。

## 当前包含

| 文件 | 说明 |
| --- | --- |
| `小程序设计.pdf` | PDF 设计稿总览 |
| `职校学生全生命周期小程序.zip` | Fable5 原始导出压缩包 |
| `职校学生全生命周期-小程序设计稿.html` | HTML 交互原型（浏览器预览） |

## 规模

| 端 | 屏数 |
| --- | --- |
| **学生端** | 约 **60 屏** |
| **教师端** | **T1–T30**，共 **30 屏** |

## 怎么用

1. **后续前端开发必须参考本目录。**
2. 开发前必须先读取 [`docs/00-项目入口与总控/00-只看这个-项目入口.md`](../../../00-项目入口与总控/00-只看这个-项目入口.md)。
3. 开发前还必须同时读取业务文档：
   - `08A-学生小程序中心.md`
   - `08B《教师移动工作台中心》.md`
4. **小程序开发第一步**应进入 **MINI-FOUNDATION-P0：小程序底座与通用组件**。

适用页面包括但不限于：

- 学生小程序首页、待办、进度、消息、我的
- 老师移动工作台、角色切换、待办、审批、学生简档

## 重要提醒

- **zip / html / pdf 只是设计参考，不是生产代码。**
- **严禁**把导出的 HTML 直接复制进 `frontend/src` 或小程序工程。
- **小程序不能做成 PC 缩小版** — 不能照抄 PC 管理端设计稿。
- PC 设计稿见 [`../fable5-pc-final/`](../fable5-pc-final/)，两者 **不能混用**。
- 学校品牌必须来自 `tenantBrandConfig`，禁止硬编码学校名称。
