# 后端当前接口清单（BACKEND-OVERNIGHT 快照）

> 基址 http://localhost:8000，前缀 /api/v1。响应双码：code(数字，0=成功) + bizCode(契约字符串)。
> 完整参数/schema 见 /docs 与 /openapi.json。标注：M=纯mock，D=已留 DB_ENABLED=true 结构。

| Tag | 方法与路径 | 说明 |
| --- | --- | --- |
| system | GET /health、GET /api/v1/system/info | 健康/系统信息 M |
| auth | POST /auth/mock-login、GET /auth/me、POST /auth/switch-role、POST /auth/logout | 8 演示账号 M（TODO P1/P2 真实认证）|
| authz | /authz/*（冻结契约端） | 登录底座 M |
| tenant | GET /tenant/brand | platformDisplayName=高校学生全生命周期管理平台 M |
| rbac | GET /rbac/menus、/permissions、/data-scope、/roles、/current-context | 11 角色×12 范围 M |
| students | GET /students、GET/POST/PUT /students/{id}、POST /students/{id}/void、GET .../timeline、GET .../risk-summary | D（tenant_id+is_deleted 口径已定）|
| approvals | GET /approvals/tasks、GET /tasks/{id}、POST approve/reject/transfer、GET /processed、GET /cc | D；reject 必填 reason≥5 字 |
| dashboard | GET /dashboard/summary、/dashboard/lifecycle-overview | 角色化 M |
| todos | GET /todos、GET /todos/summary、POST /todos/{id}/done（另有分端 /{admin\|student-mini\|teacher-mobile}/todos） | M |
| messages | GET /messages、POST /messages/{id}/read | M |
