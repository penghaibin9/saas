# 第一篇：第一阶段交付级组件（12+8）

> 原路径：`docs/02-总体架构与公共底座/公共组件/02-第一阶段交付级公共组件使用指南.md`

## 0. 一句话原则

学工 / 教务 / 毕设 / 实习各模块，凡是「权限按钮、导出、二次确认、状态/风险标签、附件、批量操作、审批、审计留痕、待办、消息、指标卡、脱敏、复制、帮助、字段提示」，**先来这里找，不要自己写**。

安全红线（所有组件通用）：

1. `AppPermissionButton` 只做前端体验，**越权拦截必须后端做**。
2. `AppExportButton` / `AppExportConfirm` **不伪造导出成功**，真实导出走后端并写审计。
3. `AppAuditTrail` **只展示后端真实审计**，不产生、不补全审计。
4. `AppApprovalPanel` / `AppWorkflowTimeline` **只做交互与展示**，状态流转由后端审批引擎完成。
5. 敏感字段（手机号 / 身份证 / 家庭经济 / 心理 / 处分）**必须用 `AppSensitiveText`**，默认脱敏；查看明文由调用方写审计。
6. 附件类：业务表只存 `file_id`；上传 / 签名 URL / 对象存储由文件中心对接。**未接入真实文件中心前，上传能力只能标 partial。**

## 1. 第一阶段：交付级公共组件（12 个）

### 1.1 AppPermissionButton — 权限体验按钮

```vue
<AppPermissionButton
  :allowed="can('academicAffairs.grade.publish')"
  code="academicAffairs.grade.publish"
  variant="primary"
  :loading="publishing"
  reason="无“成绩发布”权限，请联系教务处"
  @click="publish"
>发布成绩</AppPermissionButton>
```

| Prop | 说明 |
|------|------|
| `allowed` | 调用方按权限 store 计算的“是否有此操作权限”（默认 true） |
| `code` | 权限 code，仅用于展示 / 审计标注 |
| `mode` | 无权限时：`disable`(禁用+🔒+提示) / `hide`(不渲染) |
| `variant` / `size` / `loading` / `disabled` / `danger` | 透传 AppButton |
| `reason` | 无权限时的 title 提示 |

- **Emits**：`click`（仅有权限且非禁用/加载时触发）
- ⚠️ 只做体验，后端接口仍须校验模块授权+角色+数据范围+业务关系+按钮权限。

### 1.2 AppExportButton — 导出 Excel 台账

```vue
<AppExportButton :export-fn="exportStudents" :has-permission="can('...export')" @exported="onExported">
  导出学生台账
</AppExportButton>
```

- `export-fn: () => Promise<{ code, data:{ filename, contentBase64, mediaType } }>`；`code===0` 才触发下载。
- 真实导出走后端 `pack_xlsx_result` 结构并写审计。高危导出请配合 `AppExportConfirm`。

### 1.3 AppExportConfirm — 导出安全确认

```vue
<AppExportConfirm
  v-model:visible="showExport"
  :module-name="'学生主档'" :row-count="selected.length"
  :scope-label="ctx.dataScope.scopeName" :submitting="busy"
  @confirm="doExport"
/>
```

- 固定四点安全提醒 + 必填「导出用途」（写入审计日志）。`scopeLabel` 来自模块 `ctx.dataScope`，禁止硬编码。

### 1.4 AppConfirmDialog — 统一二次确认

```vue
<AppConfirmDialog
  v-model:visible="show" title="确认退回" content="退回后将生成学生待办和消息。"
  danger confirm-text="确认退回" require-reason reason-label="退回原因" show-notify
  :loading="busy" @confirm="onConfirm"
/>
```

- 兼容别名：`content`(=message)、`danger`(=type='danger')、`loading`(=submitting)。
- `require-reason` 时原因必填，少于 `reason-min-length`（默认 5）字不允许提交。
- **Emits**：`confirm({ reason, notify })`、`cancel`。

### 1.5 AppStatusTag — 状态标签

```vue
<AppStatusTag status="PENDING_REVIEW" />
<AppStatusTag type="success" label="已发布" dot size="sm" />
```

- 内置 40+ 业务状态码映射（审批/学工/教务/毕设/实习），传 `status` 自动出中文+语义色。
- `size="sm"` 表格内紧凑档。

### 1.6 AppRiskTag — 风险标签

```vue
<AppRiskTag level="HIGH" />        <!-- 也接受 high / 高 / 高风险 / SEVERE 等别名 -->
<AppRiskTag level="CRITICAL" size="sm" />
```

- 四档：LOW/MEDIUM/HIGH/CRITICAL，HIGH/CRITICAL 自动加重。

### 1.7 AppSensitiveText — 敏感字段脱敏

```vue
<AppSensitiveText type="phone" :value="stu.phone" revealable @reveal="auditReveal" />
```

- `type`：phone/idcard/name/address/generic，默认脱敏。
- `revealable` 允许查看明文；**`@reveal` 里调用方必须写敏感查看审计**。

### 1.8 AppFilePreview — 附件预览列表（既有）

```vue
<AppFilePreview :files="files" @preview="onPreview" @download="onDownload" />
```

- `files: [{ id(file_id), name, type?, size?, uploadedAt?, sensitive? }]`；只展示与派发事件。

### 1.9 AppFileList — 附件清单（含上传状态）

```vue
<AppFileList :files="files" removable
  @preview="p" @download="d" @remove="r" />
```

- `files[].status`：`uploading`(带进度条) / `done` / `error`；`sensitive` 显示「敏感」标 + 「下载将写入审计」。
- **Emits**：`preview` / `download` / `remove`。⚠️ 上传/存储由文件中心对接，未接入前标 partial。

### 1.10 AppBatchActionBar — 批量操作条

```vue
<AppBatchActionBar
  :count="selected.length" :total="list.length"
  :actions="[{key:'export',label:'批量导出',icon:'⬇'},{key:'delete',label:'批量删除',danger:true}]"
  :loading-key="runningKey"
  @action="onBatch" @clear="clearSel" @select-all="selectAll"
/>
```

- `count>0` 才浮出；`loading-key` 指定按钮转圈、其余禁用。高危动作仍需确认框+后端权限+审计。

### 1.11 AppApprovalPanel — 审批面板

```vue
<AppApprovalPanel
  title="请假审批" status="PENDING_APPROVE"
  current-node="辅导员审批" current-handler="张老师"
  :history="history"
  :can-approve="canApprove" :can-return="canReturn" :can-reject="canReject"
  :submitting="submitting"
  @approve="onApprove" @return="onReturn" @reject="onReject"
/>
```

- 当前节点 + 审批记录时间线 + 通过/退回/驳回。**驳回/退回强制填写意见**（组件已做非空+长度校验）。
- **Emits**：`approve({reason})` / `reject({reason})` / `return({reason})`。`can-*` 由调用方按审批节点权限+业务关系计算。

### 1.12 AppAuditTrail — 操作留痕展示

```vue
<AppAuditTrail :records="auditRecords" :loading="loading" @retry="reload" />
```

- `records: [{ id, action, actor, actorRole, target, reason, ip, at, result }]`。
- `result` 含「成功/通过」→绿、「驳回/越权/失败」→红、「退回/异常」→橙。⚠️ 只展示后端真实审计。

## 2. 第二阶段：可用版公共组件（8 个）

### 2.1 AppMetricCard — 指标卡（既有，新增 loading 骨架）

```vue
<AppMetricCard title="高风险预警" :value="18" unit="人" accent="risk"
  trend-type="up" trend-quality="bad" trend-label="需处理" drillable @drill="goRisk" />
<AppMetricCard title="加载中" value="—" :loading="true" />
```

- `accent`：primary/risk/warning/success（顶部色条）；`drillable` 可下钻；`loading` 显示骨架屏。

### 2.2 AppWorkflowTimeline — 工作流时间线

```vue
<AppWorkflowTimeline :nodes="nodes" :current-index="2" />
```

- `nodes[]`：`{ key, name, state?, result?, handler?, at?, comment? }`。
- `state`：done/current/pending/rejected/returned；未显式给 state 时用 `current-index` 推断。`horizontal` 可横向。

### 2.3 AppTodoPanel — 待办面板

```vue
<AppTodoPanel :items="todos" show-more @open="open" @action="handle" @more="goAll" />
```

- `items[]`：`{ id, title, meta?, at?, tag?, priority?(high|normal|low), overdue?, actionText? }`。数据来自后端统一待办。

### 2.4 AppNotificationPanel — 消息面板

```vue
<AppNotificationPanel :items="notifs" @open="open" @read-all="markAllRead" />
```

- `items[]`：`{ id, title, desc?, at?, read?, type?(info|success|warning|danger|approval) }`。未读数自动统计。

### 2.5 AppCopyableText — 可复制文本

```vue
<AppCopyableText value="S2026-000188" @copied="toast.success('已复制')" />
```

- 学号 / 订单号 / 邮箱等。**敏感字段请用 AppSensitiveText，不要用它暴露明文。**

### 2.6 AppHelpTooltip — 帮助气泡

```vue
综合测评 <AppHelpTooltip content="综合测评 = 学业70% + 素质30%，学期末结算。" />
```

- 悬停/聚焦显示；口径解释、填写说明统一用它。

### 2.7 AppFieldHint — 字段提示

```vue
<AppFieldHint type="hint" text="请输入 11 位手机号" />
<AppFieldHint type="error" text="手机号格式不正确" />
```

- `type`：hint(灰) / error(红) / success(绿) / warning(橙)。放输入框下方。

### 2.8 AppBadge — 徽标（既有，新增计数/红点）

```vue
<AppBadge type="success">已通过</AppBadge>   <!-- 文字胶囊（原用法） -->
<AppBadge :count="8" type="danger" />          <!-- 计数，超 max 显示 99+ -->
<AppBadge dot type="danger" />                 <!-- 红点 -->
```

# 第二篇：第三阶段扩展组件（骨架/表单/选择器/展示/体验）

> 原路径：`docs/02-总体架构与公共底座/公共组件/03-第二阶段公共组件使用指南.md`

## 0. 一句话原则

学工 / 教务 / 毕设 / 实习各模块开发新页面时，**页面壳、表单、师生/组织/批次选择器、分页、结果页、水印、打印**这些，一律从公共入口取，不要每个页面自己写一套。

安全红线（本批同样适用）：

1. **业务选择器（AppStudentPicker 等）只做 UI**。可见的学生/教师/班级必须由后端按**数据范围**返回，前端不得自行放大范围。
2. **AppPrintButton** 只触发打印，不生成正式套打模板；正式成绩单/证书套打由后端出 PDF。
3. **AppRichTextEditor / AppQRCode / AppChartCard** 为 partial（部分完成），未接库/后端前不得当成熟能力对外宣称。
4. **AppWatermark** 是展示层防护，不替代后端导出审计与权限。

## 2. 第二组：通用表单（form）

**校验用法**：`<AppForm ref="f" :model="model" :rules="rules">` → `await this.$refs.f.validate()` 返回 `{ valid, errors, firstInvalid }`。
`rules` 结构：`{ 字段: [{ required?, message?, min?, max?, pattern?, validator? }] }`，`validator(value, model)` 返回 `true` / 错误串 / Promise。

| 组件 | 说明 | 关键 props | v-model | 状态 |
|------|------|------|------|------|
| `AppForm` | 表单容器 + 上下文 + 校验 | `model/rules/layout/labelWidth/labelAlign/size/disabled/readonly`；emit `submit` | — | implemented |
| `AppFormItem` | 字段行（label+必填+帮助+错误） | `label/prop/required/help/hint/error`；作用域 slot `{id,disabled,readonly,status}` | — | implemented |
| `AppFormSection` | 表单分组（fieldset，可整段禁用） | `title/description/compact/disabled` | — | implemented |
| `AppTextInput` | 文本输入 | `type/placeholder/clearable/size/status/maxlength`；slot `prefix/suffix` | 值 | implemented |
| `AppNumberInput` | 数字输入（步进/夹取/精度） | `min/max/step/precision/controls/size/status` | Number | implemented |
| `AppTextarea` | 多行文本 | `rows/maxlength/showCount/status` | 字符串 | implemented |
| `AppSelect` | 单选下拉（原生，无障碍好） | `options/labelKey/valueKey/placeholder/size/status` | 值 | implemented |
| `AppMultiSelect` | 多选下拉（标签+勾选+搜索） | `options/searchable/max/status` | 数组 | implemented |
| `AppRadioGroup` | 单选组（dot/button） | `options/variant/size/block` | 值 | implemented |
| `AppCheckboxGroup` | 多选组 | `options/max/size/block` | 数组 | implemented |
| `AppSubmitBar` | 提交条（提交/取消/重置） | `submitText/showCancel/showReset/loading/disabled/danger/sticky/align`；emit `submit/cancel/reset` | — | implemented |
| `AppRichTextEditor` | 轻量富文本 | `placeholder/disabled/readonly` | HTML | **partial** |

> `AppFormValidator`（原规划）已合并进 `AppForm`（rules + validate()），不再单独出组件。
> `AppRichTextEditor` 基于 contenteditable，**HTML 未消毒**，落库/展示前必须后端 XSS 清洗；图片/粘贴清洗未做 → partial。

```vue
<AppForm ref="form" :model="m" :rules="{ title:[{required:true,min:4,message:'题目≥4字'}] }" label-width="90px">
  <AppFormItem label="题目" prop="title">
    <template #default="{ status }"><AppTextInput v-model="m.title" :status="status" clearable /></template>
  </AppFormItem>
</AppForm>
```

## 3. 第三组：高校业务选择器（picker）—— 全部 partial

**统一能力**：`options`（本地选项）/ `remoteSearch(keyword)=>Promise<options>`（远程搜索预留）/ `multiple`（多选）/ `clearable` / `disabled` + `disabledReason` / `dataScopeHint`（数据范围提示）/ empty / loading / error。

| 组件 | 用途 | 备注 |
|------|------|------|
| `AppRemoteSelect` | **基座**：单/多选 + 本地/远程 + 数据范围提示 | 其余 Picker 都基于它 |
| `AppStudentPicker` | 选学生（学号/姓名） | dataScopeHint「仅你范围内学生」 |
| `AppTeacherPicker` / `AppMentorPicker` | 选教师 / 选导师 | 按管理范围 |
| `AppClassPicker` / `AppMajorPicker` / `AppCollegePicker` | 班级 / 专业 / 学院 | |
| `AppCoursePicker` | 课程 | |
| `AppRolePicker` | 角色（不超过自身权限） | |
| `AppTenantPicker` | 学校/租户（仅运营方） | |
| `AppCompanyPicker` / `AppPositionPicker` | 企业 / 岗位 | 实习 |
| `AppBatchPicker` | 批次（毕设/实习） | |
| `AppOrgCascader` | 学院→专业→班级级联 | 本地 data 树；远程懒加载未接 |
| `AppAcademicYearPicker` / `AppTermPicker` | 学年 / 学期 | 基于 AppSelect |

> **为什么全是 partial**：这批只统一了 UI 与调用规范，**未接真实后端**。业务方注入 `remoteSearch` 接真实接口后，仍受后端**数据范围**约束；接入并验收前一律标 partial，不得宣称「已接真实师生/组织数据」。

```vue
<!-- 单选，远程搜索交给业务方注入 -->
<AppStudentPicker v-model="stuId" :remote-search="api.searchStudents" data-scope-hint="仅本班学生" />
<!-- 多选，本地选项 -->
<AppTeacherPicker v-model="ids" multiple :options="teacherOptions" />
<!-- 组织级联 -->
<AppOrgCascader v-model="org" :data="orgTree" :levels="['学院','专业','班级']" />
```

## 9. 商业 UI 验收清单（每个组件自检）

1. 第一眼像成熟 SaaS（软件即服务）产品，不像临时页/学生作业；
2. 符合清透学院蓝，全部走 token（设计变量），无私自硬编码颜色；
3. 无土味大色块；圆角/阴影/边框/字号/字重/间距统一；
4. hover（悬停）舒服；disabled（禁用）清楚；loading（加载）不突兀；
5. empty（空状态）有正式文案；error（错误）有解决建议/重试；
6. 支持 compact（紧凑）密度（表单/标签/选择器/分页均有）；
7. 交互组件支持键盘/focus（聚焦）/aria（无障碍标签），状态不只靠红绿区分；
8. responsive（响应式）：窄屏、抽屉内、弹窗内、工具栏内都不塌；
9. 能在 `/dev/components` 展示、适合截图给学校看。

# 第三篇：统计图表组件（AntV G2）

> 原路径：`docs/02-总体架构与公共底座/公共组件/04-统计图表组件使用指南.md`

## 统一出口

```js
import {
  AppStatsToolbar,
  AppMetricCard,
  AppRankingChart,
  AppStackedBarChart,
  AppFunnelChart,
  AppDrilldownChartCard,
  AppChartCard,
  AppG2Chart
} from '@/components/common'
```

## 产品级标准

统计组件按腾讯/TDesign 类中后台标准交付：清爽、克制、信息密度足、数值可解释、状态一眼能扫出来。

禁止只放一张裸图就算完成。排行、漏斗、下钻、状态分布必须优先使用带摘要信息的包装组件。

## 选型规则

| 场景 | 首选组件 |
| --- | --- |
| 统计页顶部筛选：学院、专业、班级、批次、时间范围、查询、导出 | `AppStatsToolbar` |
| 单项 KPI：人数、比例、预警数、完成率 | `AppMetricCard` |
| 专业/班级/教师排行，且需要 Top 清单辅助扫读 | `AppRankingChart` |
| 已完成/待处理/异常等状态分布 | `AppStackedBarChart` |
| 迎新、岗位匹配、就业转化、毕业流程 | `AppFunnelChart` |
| 学院 -> 专业 -> 班级层级查看 | `AppDrilldownChartCard` |
| 简单趋势、简单环图、非标准图表 | `AppChartCard + AppG2Chart + 公共 preset` |

## 禁止事项

1. 业务页面禁止直接 `new Chart()`。
2. 业务页面禁止直接管理 G2 创建、渲染、销毁生命周期。
3. 新统计页禁止手写 SVG/CSS/canvas 图表作为 implemented 交付。
4. 禁止裸图交付：没有标题层级、摘要、图例、口径说明或辅助扫读信息的统计卡，只能标 partial。
5. 图表组件不替代后端统计口径、数据范围、审计、脱敏和导出。

## implemented 验收

统计页必须做到：

1. 指标卡、筛选条、图表卡、导出确认均优先引用公共组件。
2. 指标口径、分子、分母、阈值、数据来源可解释。
3. 权限、租户、数据范围由后端真实控制。
4. 浏览器验收无“图表渲染失败”、无文字重叠、无横向溢出。
5. `npm run lint` 和 `npm run build` 通过。
