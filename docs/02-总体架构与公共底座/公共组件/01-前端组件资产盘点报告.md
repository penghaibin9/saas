## 0. 给新手的一句话

**你不需要靠记忆找组件。** 本项目已经有一批能用的公共零件，集中在三个文件夹：

| 文件夹 | 干什么 | 新手怎么引用 |
|--------|--------|--------------|
| `components/common/` | 全局通用（状态标签、确认框、日期、Excel、脱敏） | `import { AppStatusTag } from '@/components/common'` |
| `components/business/` | 列表页骨架（页面壳、表格、筛选、空错载） | `import { ModulePageShell, DataTable } from '@/components/business'` |
| `components/ui/` | 基础 UI（按钮、抽屉、卡片、徽章） | `import { AppButton, AppDrawer } from '@/components/ui'` |

另外还有 `components/dashboard/`（看板专用）和各 `modules/*/components/`（模块私有，**正在重复**，后续要抽公共）。

## 1. 盘点统计（82 项总控口径）

| 成熟度 | 数量 | 含义（给新手） |
|--------|------|----------------|
| **implemented** | **20** | 已经有统一文件，多个模块在用，可以直接复用 |
