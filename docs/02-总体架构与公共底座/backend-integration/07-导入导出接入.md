> 文档性质：导入导出接入任务清单（导入模板/校验/异步任务/二次确认；导出三档/权限/行数限制/审计/异步下载）

## 一、导入（Import）

### 1.1 通用流程

```text
① 模板下载 → ② 用户按模板准备数据文件 → ③ 上传文件（见 06-文件上传接入.md，获得 file_id）
→ ④ 提交校验（服务端解析文件内容） → ⑤ 校验结果展示（含错误行清单）
→ ⑥ 用户确认导入（可选择"跳过错误行"或"全部取消"） → ⑦ 异步执行导入任务 → ⑧ 查询任务进度/结果
```

### 1.2 导入模板

| 项 | 内容 |
|---|---|
| 建议路径 | `GET /api/v1/admin/{module}/import/template`（如 `/api/v1/admin/student/import/template`） |
| 请求参数 | `templateId?`（同一模块可能有多个导入模板） |
| 返回字段 | 直接返回文件流（Excel），或返回 `{fileId, downloadUrl}` 由前端二次请求下载（二选一，待后端确认） |
| 权限要求 | `{module}.import`（如 `student.import`） |
| 错误码 | `DATA_NOT_FOUND` |

### 1.3 上传校验

| 项 | 内容 |
|---|---|
| 建议路径 | `POST /api/v1/admin/{module}/import/validate` |
| 请求参数 | `{ templateId, fileId（先经文件上传接口获得） }` |
| 返回字段 | `{ totalRows, validRows, errorRows, errors:[{row, field, message}] }`（错误行清单） |
| 权限要求 | `{module}.import` |
| 数据范围要求 | 导入数据须落在操作者数据范围内（如辅导员只能导入自己班级学生的信息更新，越权行标记为 error） |
| 错误码 | `VALIDATION_ERROR` |
| 审计 | 写 `UPLOAD` 类审计（导入校验留痕） |

### 1.4 二次确认导入

| 项 | 内容 |
|---|---|
| 建议路径 | `POST /api/v1/admin/{module}/import/confirm` |
| 请求参数 | `{ templateId, fileId, skipErrors: boolean（是否跳过错误行继续导入其余正确行）, requestId }` |
| 返回字段 | `{ taskId, type:'IMPORT', status:'PROCESSING'|'COMPLETED', totalRows, successRows, failedRows }`（大数据量场景应为异步任务） |
| 权限要求 | `{module}.import` |
| 错误码 | `DATA_NOT_FOUND`、`VALIDATION_ERROR` |
| 审计 | 写导入操作审计，含文件名、总行数、成功/失败行数 |

### 1.5 异步任务与进度查询

| 项 | 内容 |
|---|---|
| 建议路径 | `GET /api/v1/admin/{module}/transfer-tasks` |
| 请求参数 | `type: IMPORT\|EXPORT?, status?, page?, pageSize?` |
| 返回字段 | `{ list:[{id,type,typeLabel,title,fileName,totalRows,successRows,failedRows,status,operator,roleName,time,masked,watermark,auditId}], total }` |
| 权限要求 | `{module}.import` 或 `security.export.*`（按任务类型） |
| 数据范围要求 | 仅本人发起的任务，或按角色可见全部任务（待后端确认可见范围规则） |
| 备注 | 大数据量导入（如全校学生批量迁移）应走真正异步任务队列，前端轮询本接口获取 `status`（`PENDING/PROCESSING/COMPLETED/FAILED`）与进度百分比（待后端确认是否需要独立的 `progressPercent` 字段） |

## 二、导出（Export）

### 2.1 三档导出与权限对应

| 导出档位 | 说明 | 对应权限点 |
|---|---|---|
| LIST | 列表导出（仅当前列表可见字段，已按脱敏规则处理） | security.export.list |
| ENCRYPTED_ARCHIVE | 加密档案导出（含更完整字段，导出文件加密，需密码或安全通道获取） | security.export.archive |
| DESENSITIZED | 脱敏导出（导出内容强制脱敏，用于跨部门/教学分析等场景） | security.export.desensitized（**默认 DISABLED，专业版开通**） |

> 数据库冻结总册 §17.3 对导出模式有更细的定义：1）当前列表导出（CSV/Excel，按数据范围脱敏，须填用途）；2）加密 PDF 档案导出（加水印+防伪二维码+时间戳+导出人/用途，异步任务，下载链接短期有效）；3）脱敏外发导出（姓名→随机编码、身份证删除/摘要、手机删除、地址删除，须填外发对象/目的/保留期限，记录脱敏规则版本+文件 hash）。**后端实现时应以冻结总册 §17.3 三种模式的具体规则为准**，本文档的 LIST/ENCRYPTED_ARCHIVE/DESENSITIZED 三档命名与冻结总册三种模式的对应关系（待与冻结总册核对，推断上表 LIST↔当前列表导出、ENCRYPTED_ARCHIVE↔加密PDF档案导出、DESENSITIZED↔脱敏外发导出，但字段细节需后端逐一核对）。

### 2.2 通用规则

- 默认单次导出 **≤5000 行**，超出需拆分导出或申请特批（待后端确认特批流程）。
- 导出**写审计**（`EXPORT` 事件类型），审计内容含：导出范围、用途（`purpose` 必填）、字段清单、敏感字段数量、操作人、时间。
- 导出文件默认加水印（`tenantBrandConfig.watermarkText`），敏感字段强制脱敏（LIST/DESENSITIZED 档位）。
- 导出为**异步任务** + **签名 URL 下载**：提交导出请求 → 生成任务 → 任务完成后通过短期签名 URL 下载，不直接在响应体中返回文件二进制。
- 导出与导出审批走 SoD（申请人≠审批人，对齐冻结总册 §17.4）。

### 2.3 创建导出任务

| 项 | 内容 |
|---|---|
| 建议路径 | `POST /api/v1/admin/{module}/export` |
| 请求参数 | `{ scope, exportType: 'LIST'|'ENCRYPTED_ARCHIVE'|'DESENSITIZED', fieldKeys: string[], purpose: string（必填）, remark?, rowCount? }` |
| 返回字段 | `{ taskId, type:'EXPORT', fileName, totalRows, status:'PROCESSING'|'COMPLETED', masked: true, watermark: true, auditId }` |
| 权限要求 | `security.export.list` / `security.export.archive` / `security.export.desensitized`（按 `exportType` 对应） |
| 数据范围要求 | 导出范围不能超出操作者当前数据范围（如辅导员导出仅限本班级学生） |
| 错误码 | `VALIDATION_ERROR`、`NO_PERMISSION` |
| 审计 | 写 `EXPORT` 审计，`details` 含敏感字段数量与脱敏说明 |

### 2.4 导出结果下载

| 项 | 内容 |
|---|---|
| 建议路径 | `GET /api/v1/files/{fileId}/url`（复用文件中心通用下载接口） |
| 请求参数 | 路径参数 `fileId`（导出任务完成后关联的文件对象） |
| 返回字段 | `{ url, expiresIn }` |
| 权限要求 | 与创建导出任务时的权限一致（本人发起或有权限查看该导出任务） |
| 错误码 | `DATA_NOT_FOUND` |
| 审计 | 写 `DOWNLOAD` 审计 |

### 2.5 涉及模块与联调页面

| 模块 | 导出能力（当前 mock 方法） | 联调页面（PC） |

## 四、验收标准

- [ ] 各模块导入模板下载接口已实现，返回真实可用的模板文件（非空文件）。
- [ ] 导入校验接口已实现**真实文件解析**（非当前 mock 的模拟回执），返回错误行清单，字段与 `{totalRows,validRows,errorRows,errors:[{row,field,message}]}` 一致。
- [ ] 导入确认接口支持"跳过错误行"选项，大数据量场景已实现异步任务队列（非同步阻塞）。
- [ ] 导出三档（LIST/ENCRYPTED_ARCHIVE/DESENSITIZED）权限点（`security.export.list`/`archive`/`desensitized`）已在服务端校验，非法档位请求返回 `NO_PERMISSION`。
- [ ] 导出默认 ≤5000 行限制已在服务端强制（非仅前端提示）。
- [ ] 导出任务为异步 + 签名 URL 下载（非同步返回文件二进制）。
- [ ] 导出已写 `EXPORT` 审计，含用途、范围、字段清单、敏感字段数量；导入已写对应审计。
- [ ] 冒烟用例：学生主档批量导出（LIST 档）→ 确认行数 ≤5000、水印、脱敏、写 `EXPORT` 审计（对齐 `docs/05-数据接口权限与安全/api/08-后端联调检查清单.md` 冒烟 8）。
