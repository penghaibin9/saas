# 学生小程序 / 教师移动工作台最终设计稿归档

## 这是什么

这是 **学生小程序** 和 **教师移动工作台** 最终设计稿归档目录。

存放内容：最终设计稿、zip、PDF、HTML、截图、README。

## 怎么用

**后续开发小程序，必须参考本目录。**

开发前还必须同时读取业务文档：

- `08A-学生小程序中心.md`
- `08B《教师移动工作台中心》.md`

适用页面包括但不限于：

- 学生小程序首页、待办、进度、消息、我的
- 老师移动工作台、角色切换、待办、审批、学生简档

## 重要提醒

- **小程序不能做成 PC 缩小版** — 不能照抄 PC 管理端设计稿。
- PC 设计稿见 [`../fable5-pc-final/`](../fable5-pc-final/)，两者 **不能混用**。
- 本目录内的 **HTML / zip / PDF 是设计参考，不是生产代码**。
- **不得**把导出的 HTML 直接复制进 `frontend/src` 或小程序工程。
- 学校品牌必须来自 `tenantBrandConfig`，禁止硬编码学校名称。
