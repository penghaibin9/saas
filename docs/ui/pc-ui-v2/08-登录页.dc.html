布局 560px 品牌屏 + 弹性登录屏（表单恒 400px 居中）。品牌屏是全系统唯一的深色大面：校徽、平台名、一句价值主张、生命周期节点线、三个安全承诺、校训——全部来自 tenantBrandConfig，换校即换脸。
对比旧版的改动 ① 砍掉标签云（原 9 个能力标签堆在表单下）——安全能力收成一行 10.5px 陈述；② 主题选择从方块按钮组降为色点行，选择结果全端记忆（themePreference）；③ 登录按钮是页面唯一实心主色。
交互 主题点即点即换（左屏深色底也随主题变族）；密码框聚焦态示意 1.5px 主色描边 + 3px 光环；失败 5 次锁定提示预先陈述；扫码 tab 内嵌小程序码并轮询状态。
高级感来自哪里 品牌屏用「一句话 + 一条节点线」讲产品，而不是插画堆砌；表单动线一条直线零分叉；合规声明放在脚注该在的位置——克制本身就是质感。
