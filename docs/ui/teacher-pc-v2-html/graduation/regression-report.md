## 冻结前浏览器矩阵

每页验证 `1280×900`、`1440×1000`、`1920×1080`，并检查：

1. 直接打开无控制台错误和非预期横向溢出。
2. 8 个工作区名称、顺序、当前高亮和面包屑正确。
3. 左侧菜单搜索、滚动和收起正常。
4. 8 个工作区页签互相跳转正确。
5. 默认、加载、空、错误、403 / 只读和长数据状态不叠层。
6. 切换批次后摘要、列表、待办和操作使用同一批次上下文。
7. 课题审核、发布、学生选题、导师确认和最终分配不跳状态。
8. 课题容量、导师上限、专业范围和重复分配冲突阻断最终分配。
9. 开题退回重交保留旧版本和导师意见。
10. 过程任务、指导、里程碑、中期检查、问题和延期均追加留痕。
11. 延期不直接修改原截止时间。
12. 初稿、定稿、查重报告与成果附件分别展示。
13. 查重结果不自动显示为学术结论。
14. 答辩组容量、评委回避、时间、场地和学生冲突发布前重检。
15. 应急调整保留原计划和通知历史。
16. 缺导师、评阅或答辩评分时阻断成绩计算 / 发布。
17. 审核、发布、异议和更正按钮按权限和状态显示。
18. 发布后更正生成新成绩版本，不覆盖原成绩。
19. 归档缺材料时显示缺失清单，不输出假完整包。
20. 档案下载用途、水印、范围和审计提示完整。
21. 大批次学生、课题、材料、答辩与成绩服务端分页。
22. 弹层 Escape、焦点进入、陷阱和归还完成验证。
