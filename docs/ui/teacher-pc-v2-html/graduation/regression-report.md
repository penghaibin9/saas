## 静态契约覆盖

### 我的工作台

覆盖总览、待评阅开题、待评阅成果、我的答辩评分、统计报表和操作日志。只做角色与批次范围内聚合，不复制业务台账。

### 批次与实施

覆盖批次列表、阶段时间轴、规则、学生名单 / 进度 / 未选题 / 资格、导师名单 / 分配 / 冲突。批次规则与时间轴保留版本。

### 题目与选题

覆盖题目列表、待审核题目、学生选题结果、选题轮次、志愿确认、匹配、容量冲突和题目调整。各状态互不替代。

### 过程指导

覆盖规范流程、任务书、指导记录、指导计划、导师评价和中期检查。历史、证据、整改和延期追加留痕。

### 开题与成果

覆盖开题批阅、成果提交与批阅、查重记录、教师评阅和互查整改。材料及评阅保留版本，查重不自动形成学术结论。

### 答辩与成绩

覆盖答辩安排、延期答辩、评分、秘书确认、成绩台账、优秀成果、专家库和更正申诉。发布、评分、确认、成绩与申诉分离。

### 风险与归档

覆盖问题预警、材料归档和毕设统计。风险保留来源与处置闭环，缺材料阻断完整归档包。

### 模板与设置

覆盖材料、任务书、开题和全部模板。新版本不得追溯改写已发布批次或历史材料。
