## 核心事实边界

1. 毕业设计批次贯穿资格、导师、选题、开题、过程、成果、答辩、成绩和归档。
2. 学生与教师身份来自统一身份和学生 / 教师主档，不在毕设中心复制。
3. 课题申报、审核、发布、学生选择、导师确认和最终分配是独立状态。
4. 最终分配重新校验课题容量、导师上限、专业范围和重复分配。
5. 开题、过程任务、成果材料和评分均保留版本；退回重交不覆盖原文件。
6. 开题通过只代表可进入过程阶段，不等于成果、答辩或成绩通过。
7. 指导记录、里程碑证据、中期检查、问题整改和延期审批追加留痕。
8. 延期不能直接修改原截止时间，需保存申请、原因、证据、审批和新截止。
9. 初稿、定稿和查重报告是不同事实；查重结果不自动生成学术结论。
10. 答辩发布前重新读取后端状态，校验组、时间、场地、学生、评委、回避与冲突。
11. 应急调整生成新计划版本，原计划、通知与操作审计保留。
12. 导师、评阅和答辩评分按冻结规则计算；缺失必需评分时阻断计算或发布。
13. 成绩审核、正式发布和异议 / 更正是不同权限和状态。
14. 发布后不得直接覆盖原成绩，复核形成新版本与审计。
15. 档案包只收录最终版本和完整审计；缺材料不得生成伪完整包。
16. 下载受权限、数据范围、用途、水印和审计约束。

## 开发 AI 读取顺序

1. 阅读 8 个 HTML 的 workspace、routes、states 和 boundary。
2. 阅读 `manifest-parts/320-graduation.json`。
3. 阅读 `shared/v2-graduation-key.css/js`。
4. 回到生产 `graduationWorkspaces.js`、路由、真实 Vue 页面、API 和服务。
5. 先核对批次、权限、状态和版本链，再还原视觉与交互。
6. 不复制 placeholder 数据或前端候选状态。
