## 5. 每次浏览器渲染检查

- 页面脚本完成并生成标题、主标题和业务工作区；
- 控制台 warning / error、`pageerror`、未处理 Promise；
- CSS、JavaScript、SVG 和其他实际引用是否可材料化；
- 重复 ID、根页面横向溢出；
- 页面实际提供的默认、加载、空、错误、403 / 无范围、只读和长数据状态；
- 弹层或抽屉打开、Escape 关闭和引用目标；
- 当前二级模块、三级页签和面包屑基本一致性。

## 6. 已验证业务红线

- 专业分流试分不落库，只有最终确认才写学籍专业；
- 排课规则不覆盖人工排课结果，发布或归档批次只读；
- 课堂考勤 PC 只统计移动端已提交场次；
- 迎新阶段事实不复制学生主档；
- 辅导员未配置责任范围时 fail-closed；
- 谈话与家庭联系人明文受独立权限、用途和审计保护；
- 报名不等于参加，签到不等于积分或成绩确认；
- 课程修改、停用和材料作废保留版本及审计边界；
- 成绩发布、更正、认定和复查保留分级权限、不可撤销提示和原值留痕；
- 当前学期切换不改变学期状态，教学周结构只允许草稿修改，校历发布后事件锁定；
- 学院、专业和行政班删除均为软删并要求清空下级或在册学生；
- 批量班级调整不替代个体学生转班，不静默改写学生所属班级；
- 毕业资格中的未知外部事实保持 `UNKNOWN`，不由前端伪造 `FAIL`；
- 强制归档继续暴露缺失域，归档后默认只读；
- 教务统计百分比保留分子分母，资源统计保持学校级口径，工作量不冒充薪酬核算。
