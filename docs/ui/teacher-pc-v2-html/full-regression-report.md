## 3. 已发现并修复的问题

### FR-001：课程共享渲染包无法解压

- 影响范围：`academic-affairs/courses/` 下 13 个独立 HTML。
- 失败表现：页面公共脚本执行后进入“原型加载失败”，课程工作区无法生成。
- 根因：`shared/v2-course-base-packed.js` 的压缩载荷存在两处字符损坏：一处 Base64 字符错误，另有一处字符缺失；不是颜色或布局问题，而是共享业务渲染包不可执行。
- 风险：所有课程原型共享同一载荷，因此单点损坏会造成 13 页同时不可用。
- 修复：仅修复压缩载荷，不改变课程业务、页面字段、路由、权限、API 或状态机。
- 修复提交：`b5baa6f74bfd7c2094d40a37a6439488b790b620`
- 复测：13 页 × 3 档 = 39 次，控制台错误、根溢出、导航、面包屑、页签、搜索和折叠检查全部通过。
