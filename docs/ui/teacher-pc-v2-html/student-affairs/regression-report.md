## 已完成静态核对

- 11 个关键入口均有独立 HTML。
- 页面统一引用 Teacher PC V2 Token、壳、组件、流程、统计和学工共享资源。

- 心理、家庭联系、认定材料等受保护数据不在普通列表展开。
- 请假、风险、处分、发放和档案均保留状态链与审计边界。

## 冻结前浏览器矩阵

每页至少验证：

- `1280 × 900`
- `1440 × 1000`
- `1920 × 1080`

每页至少检查：

1. 直接打开无控制台错误。
2. 页面无非预期横向溢出，宽表和标签栏只在容器内滚动。
3. 学工二级模块名称、当前高亮与面包屑正确。
4. 左侧菜单搜索、独立滚动、展开和收起正常。
5. 11 个关键页签互相跳转且当前项高亮。
6. 默认、加载、空、错误、403 / 无范围和长数据状态不叠层。
7. 无数据范围时不出现全校数据或管理按钮。
8. 学工总览所有数字有真实下钻路径；宿舍假指标不存在。
9. 学生360显示真实班级名称，不把 classId 当班级名。
10. 没有宿舍入住时显示空态，不拼接假楼栋房间。
11. 敏感详情按钮在无权限时禁用或拒绝，并说明需要用途审计。
12. 请假只显示当前节点允许的操作，续假与销假不覆盖主申请。
13. 逾期扫描与风险超时扫描有管理角色限制、二次确认和幂等说明。
14. 宿舍夜不归宿先核验请假，不直接显示为违纪。
15. 风险心理来源只见摘要，转派、升级、接管、关闭和重开顺序正确。
16. 困难认定公示、异议和最终认定版本可追溯。
17. 奖助评审通过与实际发放状态明确分开。
18. 发放失败保留原因、重试和凭证状态。
19. 处分送达、申诉、生效和解除不能跳节点。
20. 心理危机最小通知、点名授权和查看原因提示完整。
21. 统计小样本保护、分子分母和同筛选下钻正确。
22. 档案包只收录允许版本，失败原因不被隐藏。
23. 下载用途不足 5 字不能提交，文件提示脱敏、水印和有效期。
24. 所有抽屉和弹层支持 Escape；焦点陷阱与焦点归还重点验证。
