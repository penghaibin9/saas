## 已确认差异 / 疑问

1. `PRESERVED` 与 `RETAINED` 差异只记录，不修改生产代码。
2. 课程和培养方案历史视图只按真实状态/版本关系派生。
3. 教师确认不可由管理端代确认；教学班名单版本不可覆盖。
4. 课表冲突与调停课冲突均由后端正式检测器裁决。
5. 选课不建轮次时按全程先到先得；建立轮次后由轮次的 `allowEnroll / allowDrop` 控制。
6. LOTTERY 轮次关闭后才能摇号，结果一次性，不在原型中提供“重摇”。
7. 低人数课程在批次截止后取消开课；原已选学生进入 `COURSE_CANCELLED`，通过补选指引重新选择。
8. 正式选课事实以 `LOCKED` 名单为准；归档仅查询 `ARCHIVED` 批次。
9. 归档导出用途必填且不少于 5 字，导出格式为 XLSX。
10. `/my-selection` 虽位于教务管理路由树，但只有 `academicAffairs.selection.enroll` 权限用户可达。
