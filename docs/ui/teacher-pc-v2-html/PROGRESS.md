### 教务归档真实边界

1. 一学期一个归档批次。
2. 批次状态：`DRAFT / CHECKING / READY / MISSING_ITEMS / ARCHIVED / CANCELLED`。
3. 语义预检不能用“有记录”替代“业务已完成”。
4. 核心归档物料按 9 数据域追踪；扩展语义门禁可能包含更多启用域。
5. “批量归档”是单学期批次内多域集中处理，不是跨学期一键封存。
6. 普通确认归档只允许 `READY`。
7. `MISSING_ITEMS` 只能修复后重检，或明确强制归档并保留风险和原因。
8. 确认归档后批次和学期进入 `ARCHIVED`，已接入的教务写入口返回 `409 TERM_ARCHIVED`。
9. 学籍异动等缺强学期关联的入口存在当前学期降级判据，页面必须如实说明精度局限。
10. 特批解冻仅学校管理员，原因和原归档历史保留审计。
11. 正式导出仅对已归档批次开放，单域 XLSX 与全量 ZIP 要求用途、水印、权限和下载审计。
