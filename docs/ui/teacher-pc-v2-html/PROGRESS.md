## 已确认差异 / 疑问

1. `PRESERVED` 与 `RETAINED` 差异只记录，不修改生产代码。
2. `PRESERVE` 与 `RETAIN` 业务含义不同，不能合并。
3. 课程和培养方案归档均为真实状态/版本只读派生，不新增 `ARCHIVED`。
4. 教师确认必须由绑定稳定工号的教师本人完成。
5. 教学班名单版本是下游考勤、考务和成绩的正式成员事实。
6. 课表冲突由后端统一检测，前端不做假校验。
7. 课表发布后条目不可直改；计划性调停课进入独立调停课流程。
8. 教室课表依赖教室文本快照，历史手工文本不一致可能影响完整匹配。
9. 学生课表=行政班课表+本人已锁定选课，越数据范围拒绝。
10. 课表打印当前仅支持班级和教师；导出支持班级、教师和教室。
