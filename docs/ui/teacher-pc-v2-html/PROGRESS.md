### 2. 公共组件复用矩阵

新增 `component-reuse-matrix.md`，逐类记录：

- 原型视觉区域与真实 Vue 公共组件映射；
- 直接复用、组合复用、样式增强或 GAP；
- 是否建议新增公共组件及最小扩展理由；
- 影响页面范围。

已确认四类主要 GAP：

1. `AppDrawer` 焦点陷阱、Escape 和焦点归还；
2. 超大数据表的可选列冻结、服务端排序和虚拟滚动；
3. 排课、排考、座位等二维资源编排专用组件；
4. 统一 Excel 导入预检、错误行、部分成功和审计流程。

本 PR 只记录建议，没有修改生产组件。

## 已确认事实与边界

1. `PRESERVED` 与 `RETAINED` 差异只记录，不修改生产代码。
2. 课程和培养方案历史视图只按真实状态/版本关系派生。
3. 教师确认不可由管理端代确认；教学班名单版本不可覆盖。
4. 课表冲突与调停课冲突均由后端正式检测器裁决。
5. 选课不建轮次时按全程先到先得；建立轮次后由 `allowEnroll / allowDrop` 控制。
6. LOTTERY 轮次关闭后才能摇号，结果一次性，不提供“重摇”。
7. 正式选课事实以 `LOCKED` 名单为准；归档仅查询 `ARCHIVED` 批次。
8. 考务真实生命周期按生产代码为 `DRAFT → COURSE_CONFIRMED → ARRANGED / PUBLISHED → FINISHED → ARCHIVED`。
9. 自动排考必须区分预检和正式执行，保护人工编排并说明漏排原因。
10. 考场异常只记录事实，不越权替代处分、申诉或成绩处理。
11. 发布前必须重新读取后端状态，不能依赖页面旧缓存。
12. 归档后只读；导出和打印仍受权限、用途和有效数据约束。
