## 已确认差异 / 疑问

1. `PRESERVED` 与 `RETAINED` 差异只记录，不修改生产代码。
2. 课程和培养方案历史视图只按真实状态/版本关系派生。
3. 教师确认不可由管理端代确认；教学班名单版本不可覆盖。
4. 课表冲突与调停课冲突均由后端正式检测器裁决。
5. 调停课冲突预检字段变化后立即失效，提交时仍会再次校验。
6. 停课不需要目标课位，但必须填写后续补课安排；调课和补课需要目标星期、节次及可选周次/单双周/教室。
7. 终审通过直接改写课表并进入 `APPLIED`；仅 `APPLIED` 可打印通知单。
8. 调停课归档端点服务层强制只返回 `APPLIED / REJECTED / CANCELLED`。
