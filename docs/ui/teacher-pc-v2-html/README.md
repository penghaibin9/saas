## 统一红线

- 学工未配置范围时 fail-closed，不回退全校。
- 学生360不复制学生主档，只聚合授权业务事实。
- 敏感明细需要独立权限、用途和审计。
- 实习批次和毕设批次贯穿全流程。
- 推荐、匹配、申请、三方确认和协议归档不可跳状态。
- 请假不能伪造正常打卡。
- 材料退回重交、成绩发布更正、应急调整和归档均保留版本。
- 风险、宿舍异常、心理关注和查重证据不直接替代处分、诊断或学术结论。
- 缺材料、缺评分或冲突状态不能输出假完整结果。
- 导出与档案下载受权限、数据范围、用途、水印和审计约束。
