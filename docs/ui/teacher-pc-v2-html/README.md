### 教务归档

新增 4 个独立入口 HTML、共享 CSS/JS、开发还原契约、回归清单和 `manifest-parts/200-archive.json`：

- 归档批次 + 9 数据域完整性检查 + 学期封存
- 归档缺失提醒
- 批量归档工作台
- 归档导出

关键事实已进入原型：

- 一学期一个归档批次。
- 批次状态为 `DRAFT / CHECKING / READY / MISSING_ITEMS / ARCHIVED / CANCELLED`。
- 语义预检区分“有记录”和“业务已完成”。
- “批量归档”表示一个学期批次内集中处理多个数据域，不是跨学期一键封存。
- 强制归档不得隐藏缺失与风险。
- 归档后学期进入 `ARCHIVED`，已接入的核心写操作返回 `409 TERM_ARCHIVED`。
- 特批解冻仅学校管理员，原因与历史留审计。
- 正式导出仅限已归档批次，单域 XLSX 与全量 ZIP 均要求用途、水印、权限和下载审计。

教学质量与教务归档本批尚未执行真实浏览器渲染，不能宣称控制台、溢出、焦点或三档分辨率回归通过。
