### 教务统计

生产菜单共有 16 个统计入口：

- 14 个 Tab 由真实 `AaStatsOverviewView.vue` 承载；
- 调停课统计使用既有独立页面；
- 工作量申报审核使用 `AaWorkloadReviewView.vue`。

本轮新增 15 个独立 HTML、共享统计 CSS/JS、开发还原契约、回归清单和 `manifest-parts/210-stats.json`。调停课统计不重复造页，继续复用已有 `schedule-change-stats.html`。

关键统计纪律：

- 百分比同时显示分子和分母。
- 指标登记口径、范围、更新时间和下钻来源。
- 摘要和明细继承同一筛选与后端范围。
- 未配置学院范围时 fail-closed，不回退全校。
- 真实零值、空数据、未启用、无范围和接口失败分别显示。
- 教学资源为学校级共享资产，不制造学期 / 学院筛选。
- 教师工作量只供教务参考，不等于薪酬核算。
- 工作量申报状态为 `SUBMITTED / APPROVED / REJECTED`，驳回原因至少 5 字。
- 导出为同步 XLSX，用途至少 5 字，后端负责范围、水印和审计；当前没有异步历史队列。

教学质量、教务归档和教务统计本批尚未执行真实浏览器渲染，不能宣称控制台、溢出、焦点或三档分辨率回归通过。
