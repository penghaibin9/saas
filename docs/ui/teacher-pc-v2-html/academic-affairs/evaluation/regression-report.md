## 重点验证

1. 批次冻结评价对象、问卷、角色权重、匿名阈值和发布策略。
2. 学生小程序是填写入口，教师 PC 不伪造学生填写页面。
3. 任课教师不能查看学生个人答卷或未评名单。
4. 匿名样本不足显示“暂不聚合”，不显示为零分。
5. 教师自评仅本人教学任务。
6. 同行评价包含专业匹配和利益冲突回避。
7. 督导评价区分观察事实与专业判断，严重问题转整改。
8. 申诉不修改原始答卷，结果更正形成新版本。
9. 统计默认聚合、小样本隐藏，不做简单公开排名。
10. 归档保存批次规则、问卷、答卷隔离、聚合、申诉、改进和下载审计。
