# 教材管理：开发还原契约

> 本目录是教师 PC V2 高保真 HTML 原型。生产权限、采购规则、库存事务、费用接口与状态枚举以后端为准。

## 7 个真实入口

| 入口 | HTML | 核心任务 |
|---|---|---|
| 教材目录 | `textbook-catalog.html` | ISBN、版次、出版社、作者、课程适用与启停 |
| 教材选用 | `textbook-selection.html` | 按教学任务发起选用并说明数量与换版依据 |
| 审核备案 | `textbook-review.html` | 课程负责人、学院、教务分级审核与备案 |
| 征订到货 | `textbook-order.html` | 采购单、供应商、到货、验收和异常闭环 |
| 费用台账 | `textbook-fee.html` | 教材应收、减免、实收、退款与差异 |
| 教材库存 | `textbook-stock.html` | 入库、预留、发放、退回、损坏、盘点与调整 |
| 教材统计 | `textbook-stats.html` | 选用覆盖、审核效率、到货率、发放率和周转 |

## 业务链

```text
教材目录建档
  ↓
课程负责人按教学任务选用
  ↓
学院审核与教务备案
  ↓
按供应商生成征订采购单
  ↓
到货、版次和质量验收
  ↓
入库、预留、发放与退回
  ↓
教材费用对账与退款
  ↓
统计、归档和审计
```

## 关键边界

1. 教材目录记录不是本学期选用结论。
2. 教材选用提交不等于审核通过，也不等于已经采购。
3. “沿用上学期”仍需核对教学任务、版次、学生人数和教师用书。
4. 换版必须说明原因，并保留旧版选用历史和库存去向。
5. 到货数量、ISBN、版次、印刷质量、破损和短缺必须逐项验收。
6. 只有验收通过的数量才能进入可用库存。
7. 库存调整必须有来源单、原因、操作人、时间和前后数量。
8. 教材费用台账只表示教材业务费用，不是学校财务总账，也不能判断毕业费用是否结清。

## 教材目录最小字段

- ISBN
- 书名、副标题
- 作者、译者
- 出版社
- 版次、出版年份、印次
- 定价与币种
- 适用课程、专业和年级
- 教材类型
- 封面与样章
- 启用、停用与替代版本
- 重复或冲突检查结果

同一 ISBN 出现互相冲突的书名、版次或出版社时，应进入冲突处理，不直接重复建档。

## 教材选用最小字段

- 学年学期
- 教学任务和课程
- 课程负责人
- 选用教材版本
- 预计学生人数
- 教师用书数量
- 安全库存数量及依据
- 是否沿用上期
- 是否换版及换版原因
- 课程负责人意见
- 学院审核和教务备案状态

建议数量必须能解释为：

```text
预计学生人数
+ 教师用书
+ 经学校规则允许的安全库存
- 可复用且版次一致的有效库存
```

## 征订与到货

采购单至少记录：

- 供应商
- 教材、ISBN 和版次
- 征订数量、单价和金额
- 承诺交期
- 分批到货记录
- 实到数量
- 验收合格数量
- 短缺、错版、破损、印刷问题
- 退换货和补交记录
- 验收人、时间和附件

部分到货不能直接标记整个采购单完成；每个教材明细都要有独立状态。

## 库存事务

库存最小识别维度：

```text
ISBN + 版次 + 仓库 + 入库批次
```

库存数量至少拆分为：

- 现存
- 已预留
- 可用
- 已发放
- 已退回
- 损坏或冻结
- 盘盈盘亏

发放应关联课程、教学班、学生或教师领取记录；退回、错发和损坏需要独立事务，不允许直接修改总数量。

## 教材费用口径

教材费用台账可以记录：

- 按发放或学校规则形成的教材应收
- 学校批准的减免
- 财务回传或导入的实收
- 退书退款
- 调价和对账差异

禁止把教材费台账解释成：

- 学校全部费用
- 学费或住宿费结清
- 毕业费用结清
- 财务总账

## 开发 AI 读取顺序

1. 阅读每个 HTML `<head>` 的 route、permission、roles、states 和 boundary 注释。
2. 阅读 `manifest-parts/160-textbook.json` 获取机器可读字段和业务边界。
3. 阅读 `shared/v2-textbook-workbench.js` 获取页面结构、交互和中性占位数据。
4. 阅读 `shared/v2-textbook-workbench.css` 获取响应式与模块专用视觉规则。
5. 回到生产 `navPlan.js` 和真实后端 service、schema、permission、库存事务与费用接口核对。

当前只确认了导航中的 7 个入口和只读权限。新增、审核、采购、库存调整等写权限以及真实接口、状态枚举，在生产施工前必须再次核对，不能直接采用原型语义名。
