学籍状态迁移说明

学籍状态不可在页面直改，只能由注册确认、学籍异动生效和毕业审核发布等受控入口驱动，并统一写入状态变更入口与学生时间线。

办理入口

需要变更状态时前往“学籍异动”发起对应申请。

数据口径

总数、在籍、非在籍、近30天异动和 byStatus 全部来自状态汇总接口。
