初始状态受限

用于历史学籍初始化或批量新增学生主档。学号、姓名、班级必填；班级按名称精确匹配已有行政班；初始状态只允许待注册、正常、在籍注册。

导入结果

真实结果按新建、复用已有主档、已存在跳过、身份冲突、组织冲突、作废冲突和失败分类展示。

办理边界

导入不可用于休学、退学等状态变更；此类业务必须走学籍异动。

导出安全

文件首行带水印，敏感字段保持脱敏，用途写入审计。
