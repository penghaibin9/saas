## 本轮业务优化

1. 将补考、重修、缓考、免修从一个模糊列表拆成八个任务入口。
2. 补考按“资格快照 → 课程确认 → 名单锁定 → 发布 → 成绩回写 → 归档”设计。
3. 重修审批与教学班安排明确分离。
4. 免修、免考、成绩认定明确分离。
5. 毕业清考与毕业资格审核明确分离。
6. 缓考页只接收已审批记录，不越权完成缓考审批。
7. 学生端提供退回补材料和下一步动作，不只显示状态。
8. 统计默认聚合并考虑小样本脱敏。
9. 归档原件不可覆盖，下载必须留审计。
