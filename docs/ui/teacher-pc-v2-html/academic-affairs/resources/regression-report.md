## 测试脚本修正记录

首轮复用同一浏览器页面时，测试脚本使用了旧 DOM 的全局 ID 引用，导致首个页面之后的搜索、折叠和状态按钮被误报失败。

处理：

- 改为显式 `getElementById` 获取当前 DOM。
- 每次渲染新建独立浏览器页面。
- 重新执行全部 15 次渲染。

复测结果为 0 失败。该问题属于测试脚本隔离问题，不是原型页面失败，没有据此修改仓库业务设计。

- 生产施工前必须核对占用并发、冲突事务、维修停用联动和设备状态来源。

当前执行环境不能直接克隆最新 GitHub 分支。回归使用等价材料化页面；最终 GitHub 文件完成路径、引用和结构核对。

该限制已记录，不阻断继续 HTML 设计。
