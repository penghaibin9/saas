## 重点验证

1. 预审不产生终审结论。
2. 批次冻结范围、规则版本和数据截止时间。
3. 名单锁定不等于审核通过，锁定后变化形成差异版本。
4. 学分审核按培养方案模块展开，总学分不能掩盖模块缺口。
5. 课程审核区分待发布成绩、替代、免修和成绩认定。
6. 实践、毕设和实习保持来源模块责任边界。
7. 费用页明确未接入、UNKNOWN、软提醒和不阻断学业结论。
8. 历史处分不能自动导致毕业不通过，需核对有效状态和学校规则。
9. 终审支持通过、不通过、暂缓 / 待补核，并限制批量通过条件。
10. 不通过原因有代码、分项、学生说明、下一动作和证据。
11. 结果发布后复核与更正保留版本。
12. 证书号、印制、入库、签领、遗失和作废完整留痕。
13. 归档只读并关联规则、快照、分项、终审、结果和证书。

## 阻断记录

### 生产组件、API 和状态枚举未定位

代码搜索未定位到稳定的毕业资格审核生产组件、API 和后端状态枚举。当前确认事实为 `navPlan.js` 的 15 个入口、明确声明的权限，以及费用数据未接入的导航注释。

处理：

- HTML 使用 `routeName: to verify`。
- `/graduation` 预审入口的权限标记为待核对。
- 其余入口使用导航中明确出现的权限。
- 业务状态只用于原型表达，不宣称是现有后端枚举。

该问题已记录，不阻断继续设计；生产施工前必须重新核对。

### 最终 GitHub 文件无法在容器中整分支重新材料化

当前执行环境不能直接克隆或导航 GitHub 最新分支。浏览器回归使用本地等价材料化页面；最终 GitHub 文件完成文件级、引用级和语法级核对。

该限制不阻断后续 HTML 设计。
