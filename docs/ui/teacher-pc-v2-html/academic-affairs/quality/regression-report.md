每页至少验证：

- `1280 × 900`
- `1440 × 1000`
- `1920 × 1080`

每页至少检查：

1. 首次直接打开无控制台错误。
2. 根页面无非预期横向溢出；宽表只在表格容器内横向滚动。
3. 29 个教务二级模块名称、顺序、当前“教学质量”高亮正确。
4. 左侧菜单搜索、独立滚动、展开和收起正常。
5. 面包屑严格为“教务中心 / 教学质量 / 当前三级功能”。
6. 8 个三级页签可互相跳转，当前项高亮正确。
7. 正常、加载、空、错误、403 / 只读、长数据状态可切换且不叠层。
8. 抽屉和弹层可打开、关闭；Escape 行为、焦点进入与归还需要重点检查。
9. 风险等级、问题来源、责任、期限和状态在长数据下仍可辨识。
10. 质量监控不能把线索显示成已定责结论。
11. 事故页必须保留证据保护、陈述机会、回避和申诉提示。
12. 整改与复查页必须区分“材料已交”“措施完成”“整改有效”。
13. 归档页只读，下载操作显示用途与审计提示。
