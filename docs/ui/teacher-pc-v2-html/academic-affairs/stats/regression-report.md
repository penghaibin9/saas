## 指标专项核对

- 总览：15 项指标数量、卡片顺序、下钻可用性。
- 学籍：只统计 `EFFECTIVE`。
- 注册：`registered / expected` 与未注册名单一致。
- 教学任务：教师确认和管理确认不混淆。
- 课表：发布覆盖率只认正式发布批次。
- 选课：填充率容量分母、低人数阈值与批次状态一致。
- 考务：课程确认率与缺考 / 违纪事实分开。
- 成绩：有效成绩去重，发布率区分流程阶段。
- 预警：未关闭口径、等级与来源分布一致。
- 毕业：`UNKNOWN` 不变成 `FAIL`。
- 工作量：任务学时与 APPROVED 申报分开，非薪酬。
- 资源：学校级口径，无伪学院筛选。
- 导出：同步 XLSX、用途、水印、权限和审计。
