# 岗位实习中心关键原型：开发还原契约

> 本目录用 10 个高保真工作台覆盖生产 12 个二级模块和主要三级主链，不机械复制 99 个菜单入口。真实路由、权限、状态、接口和数据范围仍以生产代码为准。

## 核心事实边界

1. 实习批次是所有过程数据的上下文；页面必须显式保留 batchId。
2. 已生效的规则版本不能静默覆盖进行中学生，修改应生成新草稿并明确适用范围。
3. 学生身份来自统一学生主档；实习资格、保险、岗位和在岗状态是业务事实。
4. 企业审核、岗位发布和专业匹配是三个独立裁决；黑名单企业不得进入匹配。
5. 推荐和批量匹配只是候选结果，容量、专业、重复匹配和资质冲突必须先处理。
6. 自主实习申请、学校确认、学生确认、企业确认和协议归档不可一键跳过。
7. 调岗、退岗与终止必须保留原匹配和原协议历史。
8. 已批准实习请假写入 `LEAVE` 打卡留痕，不伪造正常打卡；补卡、位置异常和连续未打卡分别处理。
9. 日报、周报、月报和退回重交保留版本；周报问题可转指导或风险。
10. 指导计划、指导记录、企业沟通、巡访问题、整改和复查形成闭环。
11. 风险来源、客观证据、责任人、时限、处置、跟进、关闭和重开全部可追溯。
12. 企业评价、自评、学生反馈和指导老师评价按冻结规则合成；企业评价不直接等于最终成绩。
13. 成绩审核、正式发布和复核更正是不同权限与状态。
14. 就业跟进是跨就业模块入口，实习中心不复制第二套就业事实。
15. 归档只收录最终版本和完整审计；合规证据缺失时不得伪装完整。

## 公共组件映射

生产还原优先复用 `BasePortalLayout`、`ModulePageShell`、批次选择器、学生 / 企业 / 岗位选择器、`DataTable`、`AdvancedFilter`、状态组件、权限按钮、文件中心、地图 / 打卡展示、Excel 导入导出、抽屉与确认弹层。

共享原型 JS 只用于离线展示，不进入生产 Vue 运行时。

## 开发 AI 读取顺序

1. 阅读 10 个 HTML 的 route、permission、states 和 boundary。
2. 阅读 `manifest-parts/310-internship-key.json`。
3. 阅读 `shared/v2-internship-key.css/js`。
4. 回到生产 `navPlan.js`、实习路由、Vue 页面、API、状态机和后端服务。
5. 先核对批次、权限和数据范围，再还原视觉。
6. 不复制 placeholder 数据或前端候选状态。
