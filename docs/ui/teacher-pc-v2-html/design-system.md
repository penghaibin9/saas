# Teacher PC V2 设计系统

## 版本

`1.0.0`

## 页面母版

个人工作台、中心驾驶舱、业务台账、流程队列、主体详情、配置控制台、统计归档、复杂办理表单、日历与时间基座、课程主数据与版本治理、培养方案编制与校验、教学任务与名单版本、图形化课表、调停课审批、选课批次与容量治理、打印与导出预览、消息与帮助。

## 选课管理设计规则

- 批次生命周期必须在首屏清晰呈现：`DRAFT / PUBLISHED / OPEN / CLOSED / LOCKED / ARCHIVED`。
- 左侧批次、右侧详情适合教务控制台；1280 宽度下不得压坏课程表格。
- 开放态优先展示课程数、总容量、已选人数、填充率和低人数课程。
- 轮次必须区分 `FCFS / LOTTERY`，并展示选退控制与 `DRAFT / OPEN / CLOSED / DRAWN` 状态。
- 摇号属于一次性高风险动作，确认态必须写明不可重摇。
- 截止后先处理低人数课程，再锁定正式名单。
- 学生自助切面只展示真实可选课程、实时余量、选课/退课、已选状态和补选指引。
- 满额课程明确禁用选课按钮，不用假候补入口。
- 归档页只读；XLSX 导出必须填写不少于 5 字的用途。

## 统一与响应式

- 顶部一级中心、左侧二级工作区、页内三级 Tab。
- 1280/1440/1920 三档验证。
- 根页面禁止横向溢出；表格和周历在内部滚动。
- 所有原型至少有正常、加载、空、错误、无权限和长数据态，流程页补真实审批与高风险状态。
