## 统一壳

- 深蓝品牌顶栏承载六个一级中心、搜索、数据范围、主题、消息、帮助和用户。
- 左侧只承载当前中心二级工作区。
- 三级能力放页内 Tab；密集 Tab 横向滚动，禁止撑宽根页面。
- 右侧情境栏用于工作台、驾驶舱、复杂详情和校验办理页；1280 档自动收敛。
- 长表格与周历只在自身容器横向滚动。

## 课表设计规则

- 批次状态明确呈现 `DRAFT → PRE_PUBLISHED → PUBLISHED`，作废重发和归档为高风险动作。
- 课表维护使用周一至周日 × 作息节次的真实网格；课程块显示课程、教师、教室、周次、单双周、班级。
- 手工排课、拖拽改排和导入统一调用后端冲突检测，不在原型中模拟本地裁决。
- 冲突态必须同时显示错误结论与具体冲突格，便于教务人员就地修正。
- 发布后课表只读；正式调整进入作废重发或调停课流程。
- 班级、教师、教室、学生和教学班使用同一周历组件，但查询对象、权限和数据口径不同。
- 教师本人只看自己；学生越数据范围拒绝；教室查询依赖字典快照；教学班派生自教学任务。
- 周课表自动识别当前教学周；学期课表不传周次。
- 课表发布展示通知教师数和历史发布/作废记录。
- 调整记录只读展示条目级与批次级审计动作，不替代调停课审批。
- XLSX 导出必须选择对象并填写不少于 5 字用途，文件带水印并写审计。
- 打印页采用 A4 横向，当前仅支持班级和教师两种类型。

## 响应式基线

- 1440×1000：主设计基准
- 1280×900：紧凑桌面
- 1920×1080：宽屏
- 根页面禁止横向溢出；周历最小宽度由内部滚动容器承载。
