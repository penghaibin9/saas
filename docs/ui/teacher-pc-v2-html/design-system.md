## 统一壳

- 深蓝品牌顶栏承载六个一级中心、搜索、数据范围、主题、消息、帮助和用户。
- 左侧只承载当前中心二级工作区。
- 三级能力放页内 Tab；密集 Tab 横向滚动，禁止撑宽根页面。
- 右侧情境栏用于工作台、驾驶舱、复杂详情和校验办理页；1280 档自动收敛。
- 表格只在自身容器横向滚动。

## 教学任务设计规则

- 首屏优先展示批次进度、阻断类型和下一步，不用单纯表格开场。
- 任务流程为：生成 → 教师分配 → 教师本人确认 → 学院核对 → 教务终审 → READY。
- 教师本人确认具有身份约束，管理端不可代办。
- 分配、改派和调整必须使用稳定教师工号；姓名只用于展示。
- 合班要求同批次、同课程，且仅限教师确认前；合班成员不可直接调整。
- 更换任课教师会重置确认状态，提示新教师重新确认。
- 已生成课表项的任务不能直接调整，必须先进入排课模块。

## 教学班与名单版本规则

- 教学班类型：行政班开课、选课教学班、合班、重修班、分层班。
- 名单 `LOCKED` 后才是下游考勤、考务、成绩使用的正式成员事实。
- 名单变化生成新版本，历史版本标记 `SUPERSEDED`，不得覆盖或删除。
- 选课管理的教学班名单必须回到选课模块补退选并重新锁定。
- 人工名单变更先预览课表、考勤、考务、成绩影响；下游已消费时阻断直接生成新版本。
- 存量回填必须先 dry-run，全部就绪且填写不少于5字原因后才可执行。

## 状态与响应式基线

每页至少覆盖正常、加载、空、错误、无权限、长数据。流程页额外覆盖分配、确认、退回、阻断、只读、批量选择和高风险确认。

- 1440×1000：主设计基准
- 1280×900：紧凑桌面
- 1920×1080：宽屏
- 根页面禁止横向溢出，内容和状态容器必须 `min-width:0`。
