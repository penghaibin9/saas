# Teacher PC V2 设计系统

## 版本

`0.4.0`

## 页面母版

1. 个人工作台
2. 中心驾驶舱
3. 业务台账
4. 流程队列
5. 主体详情
6. 配置控制台
7. 统计归档
8. 复杂办理表单
9. 打印与导出预览
10. 消息与帮助

## 统一壳

- 深蓝品牌顶栏：品牌、六个一级中心、全局搜索、数据范围、六套主题、消息、帮助、用户。
- 左侧只放当前中心二级工作区。
- 三级业务切面放页面内 Tab / 工作区标签。
- 右侧情境栏仅在工作台、驾驶舱、详情和复杂办理页出现；1280 以下自动收敛。
- 表格允许自身横向滚动，页面根节点禁止横向溢出。

## 共享文件

- `v2-tokens.css`：颜色、语义、圆角、阴影和响应式尺寸。
- `v2-shell.css`：顶栏、侧栏、内容区、情境栏。
- `v2-components.css`：标题区、卡片、指标、筛选、表格、状态。
- `v2-workflows.css`：流程时间线、详情描述、抽屉、确认弹窗、A4 打印页。
- `v2-prototype.js`：主题、状态、Tab、抽屉和弹窗预览；localStorage 被拒时安全降级。
- `v2-registration-prototypes.js`：注册管理重要 query/工作台切面的共享高保真渲染器。
- `v2-status-change-prototypes.js`：学籍异动台账、表单、审批、详情、统计与归档的共享高保真渲染器。
- `icons.svg`：统一本地 SVG symbol 图标。

## Manifest 维护规则

- `prototype-manifest.json` 保存全量 routeIndex、验证汇总和分片加载顺序。
- `manifest-parts/*.json` 保存完整的 route → component → permission/API → HTML → states 记录。
- 后加载分片可覆盖相同 route，用于增强既有原型，但不得改变生产路由事实。
- 分片只是设计交付组织方式，不是生产菜单、权限或路由数据源。

## 业务真实性

- 页面标题、字段、表格列、筛选、按钮、状态和流程节点必须来自真实 Vue/API/常量。
- query、meta、详情状态形成明显不同页面时独立登记，必要时独立 HTML。
- 不显示接口不存在的统计，不发明审批节点，不把 redirect-only 当独立页面。
- placeholder 必须明确标注，不用真实敏感数据。
- 原型不执行写操作；抽屉和确认框只做视觉/交互预览。

## 状态基线

普通页面至少提供：正常、加载、空、错误、无权限、长数据。流程和配置页再补充真实关键状态，例如草稿/开放/关闭/归档、待审/退回/驳回/生效、只读和高危确认。

## 响应式验证

- 主基准：1440 × 1000
- 紧凑桌面：1280 × 900
- 宽屏：1920 × 1080
- 不允许根页面横向溢出；长表格在表格容器内部滚动。
