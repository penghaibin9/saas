# Teacher PC V2 Design System

## 设计方向

- 深蓝品牌顶栏
- 一级中心置于顶部
- 左侧只承载当前中心的二级工作区
- 三级能力由页面 Tab、任务卡或详情操作承载
- 工作台/中心驾驶舱允许科技感 Hero
- 普通台账使用紧凑浅色标题区
- 右侧情境栏仅用于工作台、驾驶舱和适合的办理详情
- 红、橙、绿只表达语义状态
- 禁止卡片套卡片和全页渐变

## 母版

1. 个人工作台
2. 中心驾驶舱
3. 业务台账
4. 流程队列
5. 主体详情
6. 配置控制台
7. 统计归档
8. 复杂办理表单
9. 打印与导出预览
10. 消息与帮助

## 布局

- Topbar：64px
- Sidebar：208px
- Context rail：280px
- 1440 为主基准
- 1320 以下隐藏右情境栏
- 1100 以下减少顶部一级中心显示
- 页面不得横向溢出；表格自身可横向滚动

## 组件

- `.v2-hero`：沉浸式业务 Hero
- `.v2-page-head`：普通业务标题区
- `.v2-metric`：行动指标
- `.v2-kpi`：范围统计
- `.v2-tabs`：页内三级导航
- `.v2-filter`：查询区
- `.v2-table`：业务台账
- `.v2-context-card`：提醒、帮助、快捷入口
- `.v2-alert`：风险/提醒/结论

## 六主题

原型提供：

- 学院蓝
- 商务蓝
- 雅灰
- 护眼绿
- 皓白极简
- 墨白极简

主题只影响语义 token，不复制六份页面。

## 数据真实性

- 字段、筛选、状态和操作必须来自源组件或对应 API/schema
- 无 seed/fixture 时使用 `—` 和明确标注 placeholder
- 原型不执行真实写操作
- 不复制参考图中的固定业务数字、人名或课程
