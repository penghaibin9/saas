# Teacher PC V2 设计系统

## 版本

`0.9.0`

## 页面母版

个人工作台、中心驾驶舱、业务台账、流程队列、主体详情、配置控制台、统计归档、复杂办理表单、日历与时间基座、课程主数据与版本治理、培养方案编制与校验、教学任务与名单版本、图形化课表、调停课审批、打印与导出预览、消息与帮助。

## 调停课设计规则

- 调课、停课、补课使用同一正式状态机，但字段要求不同。
- 申请表先选本人已发布课位，再填写原因；非停课需要目标星期和节次，停课需要后续补课安排。
- 冲突预检明确标注“预检结果会随字段变化失效”，提交时仍由后端再次校验。
- 审批工作台同时呈现原课位、目标课位、当前节点和操作风险。
- 流程为教师提交→学院审核→教务终审→自动改写课表并通知。
- 终审通过是高风险动作，确认框必须说明正式课表会立即变化。
- 归档只显示 APPLIED / REJECTED / CANCELLED，保持只读。
- 通知单只允许 APPLIED 打印；未生效页面须明确禁打原因。
- 统计按类型、状态、学院和教师聚合，高频教师仅用于异常识别，不直接作为绩效结论。

## 统一与响应式

- 顶部一级中心、左侧二级工作区、页内三级 Tab。
- 1280/1440/1920 三档验证。
- 根页面禁止横向溢出；表格和周历在内部滚动。
- 所有原型至少有正常、加载、空、错误、无权限和长数据态，流程页补真实审批与高风险状态。
