# 跃科资讯首发包（2026-09-10）

本目录是官网内容发布系统的可复核首发新闻包源文件。文章均为跃科编辑部基于公开权威来源整理的摘要与院校工作提示，不转载来源全文；页面会明确标注“AI 辅助整理”并保留原始来源链接。

- `manifest.json`：内容发布系统清单。
- `articles/`：新闻正文 Markdown。
- `assets/`：本项目原创 AI 品牌配图，不代表具体学校实景。
- `education-insights-20260910.zip`：由本目录生成、用于后台上传审核的资源包。

资源包必须经过“平台运营 → 官网内容运营 → 新闻资源包发布”的审核确认后才会公开。官网列表、搜索、分类、详情、RSS 与资讯索引均读取同一套已发布数据。
